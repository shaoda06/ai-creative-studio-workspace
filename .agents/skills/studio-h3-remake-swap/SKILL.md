# Viggle Remake Swap 换人

调用方提供实际造型与参考分工、保留项、执行范围和授权。按同一段源片中需要替换的表演者人数分流：

- 替换一人，即使镜头内还有其他人，沿用[单人双参考图流程](references/Viggle-Remake单人换人流程.md)。
- 同段替换多人，按[多人换人流程](references/Viggle-Remake多人换人流程.md)选择能辨认各人的源片区间，制作目标帧并绑定原片时间。

两种换人方式共用[源片准备、分段续接与合片](references/Viggle-Remake换人分段与合片.md)。按对应分支完成提示词及参考绑定，再按共用流程执行和审阅。结果交调用业务或 [Remake 外层流程](../studio-h3-remake/SKILL.md#两轮之间的交接)接续。
