# 个人页视觉制作与管理规范

## 设计规范

本文件提供账号头像、主页背景图的通用设计方法。技术规格按[目标平台资料](平台个人页规格库.md)选择；人物形式、画风、配色、文字和具体构图依据本项目与本次选定方案，不预设统一视觉风格。

### 按用途讨论

先按任务读取项目定位、所需人物资料及已采用视觉的有效记录，提取当前设计依据，不默认重读全项目或查看全部图片。视频封面可以提供设计参考，头像和背景图仍按各自用途构图，不默认直接裁切封面。

头像方案按主体类型说明辨认特征、构图和背景，使方案之间可以比较；人物头像再说明取景、站位和表情，图形、标志或文字头像不套用人物字段。主体在小尺寸下应容易辨认；多人构图应保留各自辨认所需的面积。显示裁切形状和安全区域由目标平台决定；仅当该平台采用圆形裁切时，才按圆形范围安排核心内容。预留必要余量，避免重要信息被实际裁切或界面元素覆盖；平台裁切形状与画面是否设计边框分别确定。

主页背景图按目标平台实际可见区域、遮挡位置和当前账号资料布局安排主体、文字及装饰。与头像保持适当的画风、配色或图形联系，两图各有重点；不要求重复同一主体、文字或构图。平台截图用于确认当前显示关系，不把单一设备上的位置扩大为所有平台或客户端的固定布局。

### 背景图方案与显示适配

比较方案时，分别说清主视觉、文案、布局及与头像的搭配方式，让方案在画面重点上有所区别。头像可以只提供配色、画风或图形参考；提示词写明实际采用的参考用途，不因传入头像就默认复制其人物、方形构图或全部元素。是否重复人物、是否使用文字及候选数量，按本次方案和授权确定。

排版时区分完整画布、平台默认可见区域和界面／设备覆盖区域。主文案及核心图形放在实际可见且未被遮挡的位置，外围与可能被裁掉的部分承载次要装饰。安全区域依目标平台、客户端及设备显示确定，不设通用的固定坐标或留白比例；具体平台依据见[平台规格库](平台个人页规格库.md)。用户提供的实机截图或试用反馈用于修订位置，没有实际反馈时不宣称已通过实机验证。

用户要求“整体移动”时，明确一起移动的文字、主体和相关装饰，将它们作为一组描述，保留相对位置、大小、字形及换行；同时写明方向、建议幅度、露出背景的补齐方式和需要保全的内容，避免只移动标题或通过缩放、变形挤出空间。位移数值和最终采用位置记在项目工作稿，不固化为通用参数。只移动文字等局部要求则按其实际范围执行。

### 参考与提示词

有参考素材时，按本批授权确定其用途和保留范围：项目已有素材使用相应已批准版本，用户明确指定用于本任务的原始参考记录指定依据，不把输入资格当作输出已采用。选用与本次表现形式相符的素材；没有参考素材且任务允许从文字设计时，不强制补人物图或其他参考。逐项注明来源、版本与用途；多视图用于提取设计时，不复刻其网格、标注或主体副本，不叠加互相冲突的画风要求。只保留本次需要的依据，不将项目具体设计写入通用规则。

输入资格、编辑源、换源及查看范围按[运营图片规范](../../studio-social-operations/references/运营图片制作与采用规范.md)。自由组织本次完整提示词，写清主体、构图和背景；有表情、文字或参考素材时再说明相应要求，不设置固定生图提示词模板。准备好且已获授权后按[生成与记录](个人页视觉制作与管理规范.md#生成与记录)接续。

需要选择或细化取景、构图、光影及焦点时，调用[镜头语言与表达](../../studio-creative-techniques/SKILL.md#镜头表达)；按已选方案落实为静帧描述，平台可见区域及安全裁切仍按本专项执行。候选写法的首次使用提示和针对性实际反馈沿该技能处理，图形／文字排版不强套摄影术语。

人物头像或背景图有指定表情时，编写提示词调用[表情拆解](../../studio-creative-techniques/SKILL.md#表情表达)，把方案中的抽象表情落成静帧可见状态；首次使用说明与收到具体表情反馈后的验证更新沿该技能，不将单纯采用整图视为表情已验证。

### 规格依据

分别记录目标平台的官方要求、用户指定值和建议交付值，以及适用账号类型。涉及当前限制时核实最新官方依据；平台用户发布的教程不能当作官方规范。缺少依据时如实注明，用户提供的规格可作为当前制作输入，不据此声称已核实官方要求，也不套用其他平台的数据。

平台共有的读取字段、各平台具体数值及适用状态统一维护于[平台规格库](平台个人页规格库.md)。选定的项目画面方案及用户决定写入该账号工作稿，不回填本设计规范。

## 保存与采用

索引、工作稿、执行附件、资源归属与文件命名由调用业务提供，使用[个人页索引模板](../templates/个人页视觉索引模板.md)和[工作稿模板](../templates/个人页视觉制作工作稿模板.md)记录，不规定固定目录。账号真实信息只留所属资料范围，不写入通用技能。

头像和背景图分别维护身份、候选、采用及处理记录。索引的“正式文件”引用当前采用的实际资源版本，不另存正式副本。原生与尺寸处理结果分别标明实际格式和尺寸；扩展名对应真实格式，不将某个平台的输出格式设为全部账号默认。版本及来源沿[公共图片规范](../../studio-social-operations/references/运营图片制作与采用规范.md#审阅与采用)，不按文件名猜采用。

实机试用、位置修订和新版采用继续写原账号工作稿；“先试一下”不等于正式采用。替换当前采用后保留旧版本及原决定，已发布记录不随当前索引更新。已有资料不因规则维护自动迁移或改名。

浏览展示按[调用方适配](../../studio-social-operations/references/运营与制作接续规范.md#素材状态与展示)核对。固定目录解析器只用于其已支持的输入结构；未支持时交付真实文件与记录入口，不以候选存在推定采用，不复制文件来迁就页面。

## 生成与记录

### 能力与授权

按[运营图片的工具选择与授权](../../studio-social-operations/references/运营图片制作与采用规范.md#生成与记录)确认当前能力、对象、数量和有效授权。依本次任务选择工具，已有明确选择直接沿用。只写方案或提示词时交付文本。

### 社交图片交接与结果

1. 准备完整实际提示词、参考版本与顺序、保留和修改范围、目标比例及规格、授权数量和调用方指定记录入口。
2. 按[运营图片生成与记录](../../studio-social-operations/references/运营图片制作与采用规范.md#生成与记录)调用共用模型工具及调用方实际支持的登记方式。业务命名检查或专用收尾由调用方提供，不依赖另一业务的图片类别或目录来伪装可用能力。
3. 结果使用共用资源保存入口登记原生来源、候选文件、实际尺寸、格式、数量及技术核对；保留真实返回凭据和异常。保存失败恢复保存与记录，不自动重新生成。
4. 在原工作稿补齐生成、处理和待审记录，向用户交付实际候选。自动记录已完成的技术核对直接复用，不改为重复手工登记，不将技术完成视为采用。

### 尺寸处理与交付

保留原生图及实际规格。原图达标时直接送审；确需处理时按[公共尺寸处理](../../studio-social-operations/references/运营图片制作与采用规范.md#尺寸处理)及本次授权执行，不为推荐尺寸自动缩小，也不拉伸人物或擅自裁掉重要内容。处理结果关联原图，同一画面的尺寸处理不计为再次生图。

展示实际候选和文件入口，说明使用能力、真实规格、必要处理及待审事项。同一画面的原生与尺寸版选择一份主要预览，其余提供链接，不为交付额外生成预览、拼图或其他未授权方案。用户要求内容检查时按明确范围进行。
