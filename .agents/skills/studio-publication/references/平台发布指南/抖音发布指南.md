# 抖音发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，只在已获本次代发及具体排期授权后提交。下文“项目配置”指调用方提供的账号配置；“本次说明／文案”指映射中的实际发布说明和发布文案，按真实发布对象与交付版本定位。

页面字段核实日期：2026-10-30。适用范围为电脑端视频发布／定时作品继续编辑页；已发布作品的“编辑作品”“设置权限”分开提供，不把编辑页可见字段当作新建页全部字段。

## 入口与资料

- 备料时按[表单字段与选项](#表单字段与选项)核对确切输入、账号配置和[本条发布设置](../发布准备与记录规范.md#本条发布设置)。填写按下方顺序执行，截图、提交和结果回读接续[共用代发流程](../发布准备与记录规范.md#代为定时发布)。
- 结果检查：[作品管理](https://creator.douyin.com/creator-micro/content/manage?enter_from=publish)。登录跳转后先核对项目配置中的账号身份。

## 填写顺序与选项

1. **进入正确账号。** 使用项目指定的 Chrome 配置打开[抖音创作者中心](https://creator.douyin.com/)，在首页账号区对照项目配置核对昵称，可见抖音号时一并核对。登录或切换账号后重新核对。核对通过后从左侧「作品发布」进入「发布视频」。
2. **核对成片。** 对照本条发布资料中的确切成片文件及版本，选择该文件上传，确认视频处理完成。接续已有表单时，用原上传记录或交接证据确认已加载的是同一文件。来源待核实时先查清，或按本次授权选择指定成片后再填表。
3. **逐项填写。** 按**标题 → 正文 → 话题 → 竖封面 → 横封面 → 自主声明 → 可见范围 → 保存权限 → 发布时间**填写。按下表选中平台话题并保存双封面。定时发布时选择「定时发布」，填写本条已确认的日期和时间。其他选项按本条资料在对应区域办理。
4. **回发布主表单核对。** 完成封面编辑和各项弹层后，逐项对照本条发布资料。确认视频已处理完成，标题和正文正确，话题均已选中，3:4 竖版和 4:3 横版的两张正式封面都显示在主表单。回读自主声明、可见范围、保存权限及发布时间的实际选中值。定时发布时核对回显的日期、时间和时区。仅准备预览时列明待定项。核对完成后接续[提交与异常](#提交与异常)。

### 表单字段与选项

| 表单项 | 固定处理方式 |
| --- | --- |
| 视频上传 | 上传入口显示1小时以内、16G以内；支持4K，建议视频画幅16:9、9:16、3:4、4:3或9:19.5。推荐与支持要求分别记录；选择已确认文件后等待处理完成，不改变已采用成片画幅来套用建议 |
| 标题与作品描述 | 作品描述区含独立标题框“填写作品标题，为作品获得更多流量”（上限30）及正文／话题编辑区（计数上限1000）；分别填对应内容。按页面实际计数检查，不以字符串长度替代平台计数；必要压缩同步文案，实质改写先确认 |
| 话题 | 按已确认清单添加并检查实际标签，避免仅输入文字未形成标签或重复添加 |
| 竖版封面、横版封面 | 先选本条 3:4 竖图，再选 4:3 横图。横版编辑带入竖版素材时，用指定的横图替换。核对两版裁切，保存后回发布表单核对两张缩略图。比例与数量按[封面规格库](../../../studio-cover-images/references/平台封面规格库.md) |
| 自主声明／AI生成声明 | 点击基础信息区“自主声明”打开单选弹层；六项为“内容由AI生成／内容为个人观点或见解／内容为转载信息／内容含营销推广信息／虚构演绎，仅供娱乐／无需添加自主声明”。真实AI生成内容选第一项，按“确定”保存；不能同时选AI与演绎，也不将某项勾选理解为已完成其他声明。只读核查使用“取消”退出 |
| 可见范围 | “谁可以看”有“公开／好友可见／仅自己可见”。按本条发布设置选择并回读选中状态。 |
| 保存权限／允许他人保存视频 | 发布设置中“保存权限”提供“允许／不允许”。按本条发布设置选中，已发布作品从作品管理“设置权限”核对。 |
| 发布时间 | “发布时间”提供“立即发布／定时发布”；选后者并填写用户批准排期。当前提示“支持2小时后及14天内的定时发布”，按页面校验和显示时区再确认有效性；超出范围重新申请排期，不自动改立即 |
| 独立原创声明 | 本次定时编辑表单未提供独立原创开关；“虚构演绎，仅供娱乐”属于上述自主声明的单选项，不能另行叠加或把标题中“原创”当作平台声明 |
| 合集、位置、关联、同步、推广等附加项 | 实际有“添加合集”“视频章节”“添加标签－位置”“关联热点”“添加音乐”；未安排不新增，位置推荐不自动选，自动推荐封面／章节不等于正式选用。既有作品原关联保留 |

## 提交与异常

核对当前页面接受的时间范围，按[代为定时发布](../发布准备与记录规范.md#代为定时发布)留存表单截图并提交。作品管理是本平台回读原条目、预约时间和审核状态的入口。

处理失败、审核异常、编号／资质要求时进入共用[审核处理](../发布准备与记录规范.md#审核状态与异常处理)。需更改时间、取消或提前发出时，只定位原条目并按用户授权执行，保存前后状态。出现登录、验证码或协议确认按工具权限处理，不重复上传绕过。

## 检查、记录与收尾

从作品管理核对原条目的定时时间、审核／公开状态，尤其复核横竖两张封面、自主声明和保存权限。修改时间或提前公开后，记录真实结果及与原排期的差异。

按[统一记录与检查收尾](../发布准备与记录规范.md#记录与检查收尾)逐项执行：定时回执与选项核对写本次发布说明，实际公开后补项目发布记录，同步原项目／作品状态和工作台；向用户汇报后完成浏览器及一次性跟进收尾。日后检查的安排读取[发布后检查与临时跟进](../发布准备与记录规范.md#发布后检查与临时跟进)。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。

AI声明字段含义参考[抖音安全与信任中心公告](https://trust.douyin.com/article/15868)；页面具体层级仍以当前账号可见入口为准。

## 带货作品挂品

本次要求挂品时，按[商品挂载与结果核对](../发布准备与记录规范.md#商品挂载与结果核对)核实当前账号入口、权限、实际商品及保存结果。该指南不预设商品控件已开放；无法完成时交用户接管或等待调整，不擅自无商品提交。提交与公开后的商品核对沿同一规则，记录原作品结果，不重复发布。
