# 快手发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，按本次代发授权提交。定时发布须确认具体排期。下文“项目配置”指调用方提供的账号配置；“本次说明／文案”指映射中的实际发布说明和发布文案，按真实发布对象与交付版本定位。

页面字段核实日期：2026-10-30。适用范围为电脑端新建视频发布表单。

## 入口与资料

- 发布入口：[快手视频发布](https://cp.kuaishou.com/article/publish/video)，或[创作者平台](https://cp.kuaishou.com/) → 发布作品 → 视频。
- 快手视频表单使用本条资料指定的一个常规主封面。横版或竖版待定时先确认选用。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 视频上传 | 上传入口显示1小时以内、最大12GB；支持常见格式，推荐MP4；最高支持8K，推荐1080p（1920×1080）及以上。推荐横版像素不构成竖屏视频必须改横版的要求；上传后核对实际文件 |
| 描述／文案 | 新建表单只有“作品描述”，没有独立标题框。标题、正文和话题合并后按当前表单检查整体计数。标题放首行，空行后接正文，再接话题，排版同步本次文案 |
| 话题 | 作品描述下有“@用户”“#话题”。按本条资料的话题清单添加，核对实际标签。 |
| 常规主封面 | 上传本次指定的一张图，按指定版式裁切并保存；返回发布页检查实际采用图。PK或多封面实验未指定不启用。规格读[封面规格库](../../../studio-cover-images/references/平台封面规格库.md) |
| 允许下载此作品 | 按[本条发布设置](../发布准备与记录规范.md#本条发布设置)明确勾选或取消，提交前及可用的编辑页回读。 |
| AI内容声明 | 新建表单“作者声明”的单选下拉有“内容为AI生成／演绎情节，仅供娱乐／个人观点，仅供参考／素材来源于网络”。AI内容选“内容为AI生成”，不能照抄抖音“内容由AI生成”的字段值或叠选 |
| 可见范围 | “查看权限”提供“所有人可见／好友可见／仅自己可见”三个单选项；按项目／本次批准值设置，不能把页面预选“所有人可见”视为用户已确认 |
| 同框、下载与同城展示 | 新建表单“允许别人跟我拍同框／允许下载此作品／作品展示在同城页”均为独立复选框，本入口预选开启。下载、同框按本条发布设置分别落实；同城展示未安排时按共用可选功能规则关闭。独立转载许可和原创声明开关在该入口未提供。 |
| 合集、分类、位置、推广及同步等（页面提供时） | 按共用规则，仅启用明确安排的可选项，未指定的选项留空。强制分类未定先确认，不凭项目名猜选 |
| 定时发布 | “发布时间”单选“定时发布”，使用“选择日期时间”控件，选完点日期面板“确定”，它不是页面最终“发布”。回到表单逐字回读批准日期时间；无效输入可能被控件回退，不能以曾输入过为准。日期禁选边界决定当前可排范围，不能套用其他平台14天；页面没有给出固定最小提前量文字，不把初始约1小时后的候选值当作已证明的最短提前量。所选时间被回退或拒绝时按排期规则重新确认 |

定时控件下会显示当前账号粉丝活跃时段及“一键设置”；这是本项目排期建议的候选依据，记录在项目资料，不能固化为平台通用时段，也不能点击后绕过用户对具体时间的批准。时间面板提示上传高峰可能延迟1～2分钟。

“作者服务”当前可选“关联小程序／招聘人才”，未安排不选择类型或关联对象；上传完成后还提供“添加章节”，未采用不新增。新建页未提供独立合集选择，不能把管理页的“合集管理”当作本次已关联合集。

## 提交与回执

按[获授权的代发](../发布准备与记录规范.md#获授权的代发)核对主表单并留存提交前截图。按本条授权选择立即发布或平台定时发布，定时时回读批准的排期再提交。[提交回执与汇报](../发布准备与记录规范.md#提交回执与汇报)规定本次页面提示、报错及结果不明时的记录方式。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理新增、改名或强制字段。定时提前量、可选日期范围、字数及上传限制按当前账号表单核实；页面没有某项记“不提供”，不伪记“已关闭”。账号差异及本次核实结果留在项目，平台通用变化再更新本指南。

下载权限含义参考[快手帮助中心](https://www.kuaishou.com/help/feedback/2737)，它不代替本次表单的实际选择和保存结果。

## 带货作品挂品

本次要求挂品时，按[商品挂载与表单核对](../发布准备与记录规范.md#商品挂载与表单核对)核实当前账号入口、权限，并在提交前核对主表单里的实际商品。该指南不预设商品控件已开放；无法完成时交用户接管或等待调整，不擅自无商品提交。
