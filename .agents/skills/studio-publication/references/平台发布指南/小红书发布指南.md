# 小红书发布指南

适用：Chrome中对应项目profile的电脑端后台，单条视频；不适用于手机App、图文或直播。先读[共用流程](../发布准备与记录规范.md#发布资料与选项执行)，授权与排期按[共用发布方式](../发布准备与记录规范.md#发布方式)。下文“项目配置”指调用方提供的账号配置；“本次说明／文案”指映射中的实际发布说明和发布文案，按真实发布对象与交付版本定位。

页面字段核实日期：2026-10-30。适用范围为电脑端新建视频发布表单。

## 入口与资料

- 发布入口：[小红书创作服务平台](https://creator.xiaohongshu.com/) → 发布笔记 → 上传视频。使用项目指定的 Chrome 配置，先核对目标账号和视频标签，不能在图文发布表单填写本指南的视频材料。
- 小红书视频笔记使用本条资料指定的一个主封面。横版或竖版待定时先确认选用。

## 填写顺序与选项

| 顺序／表单项 | 固定处理方式 |
| --- | --- |
| 上传视频 | 上传入口显示4小时以内、最大20GB，推荐MP4、MOV；超过1080P视频可用网页端上传。等待上传和处理完成后核对文件、作品代号；“重新上传”会更换视频，核查时不使用 |
| 标题 | 独立标题框“填写标题会有更多赞哦”，聚焦后显示计数，上限20；按页面实际计数检查，不套用抖音30上限 |
| 正文 | 正文富文本框计数上限1000；填本平台正文和指定话题，不将话题串当完整正文；话题、用户和表情各有入口 |
| 话题 | 选中对应实际话题并检查标签结果，不随意增加话题、@账号或商业关联 |
| 主封面 | 编辑并上传本次指定的一张图，按选定比例检查并保存，再回到表单复核。PK封面未明确安排不启用；规格读[封面规格库](../../../studio-cover-images/references/平台封面规格库.md) |
| 原创声明 | 内容设置中的独立开关，用于原创笔记标记及平台识别／打击搬运保护。按权利事实和[本条发布设置](../发布准备与记录规范.md#本条发布设置)填写。内容类型声明单独填写。 |
| 添加内容类型声明 | 新建表单入口名为“添加内容类型声明”，选中后显示声明值；它是内容设置中单独的下拉。有“虚构演绎，仅供娱乐”“笔记含AI合成内容”“内容包含营销广告”，以及“内容来源声明”子菜单的“自主拍摄／来源转载”。真实AI合成内容选择“笔记含AI合成内容”；原创开关不是此项，不将其他来源声明自动叠加为已确认 |
| 可见范围、下载／保存权限 | 更多设置中的可见范围有“公开可见／仅自己可见／仅互关好友可见／只给谁看／不给谁看”；后两项还需指定用户。按项目值核对，不把仅互关当作抖音好友可见。新建表单没有独立下载／保存开关，记录本入口不提供，不能宣称已关闭下载 |
| 合集、位置、关联、推广及其他可选项 | 实际内容设置有“添加章节／加入合集”；组件有地点、群聊、引用笔记、投票、直播预告、标记地点或朋友、路线、活动，另有店内商品。按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)选择，自动生成的章节待明确采用后才使用 |
| 定时发布 | “更多设置”中打开“定时发布”右侧开关，在出现的日期时间框填用户批准排期。点击文字可能只显示说明，必须核对开关和日期框实际出现。提示明确采用北京时间，支持未来1小时～14天；默认填入的时间不是用户批准时间，不直接使用。无效排期重新确认，保持原发布方式 |

新建页的原创开关和PK封面初始为关闭，内容类型声明初始为空；这是表单状态，不能代替项目选择。

## 共用代发与回执

提交前截图、提交动作与回执分别按[共用代发流程](../发布准备与记录规范.md#获授权的代发)和[共用回执规则](../发布准备与记录规范.md#提交回执与汇报)执行。

表单提示缺少节目编号、备案或资质时，说明具体缺项，材料齐备后才提交。提交动作直接返回此类错误时，沿共用回执规则汇报。普通作品代号、原创声明与节目编号各有用途。

## 临时表单核查

按[共用临时草稿规则](../发布准备与记录规范.md#上传核查与临时草稿)处理。小红书上传页可能在未手动保存时生成本地草稿。返回上传入口的草稿箱，按时长、标题和保存时间定位本次条目；离开临时表单时可能显示“Leave site? Changes you made may not be saved.”。

## 页面变化与补充范围

按[共用选项规则](../发布准备与记录规范.md#发布资料与选项执行)处理当前表单的新增、改名和强制字段。

## 带货作品挂品

按[共用商品挂载规则](../发布准备与记录规范.md#商品挂载与表单核对)操作，以当前账号实际提供的商品入口为准。
