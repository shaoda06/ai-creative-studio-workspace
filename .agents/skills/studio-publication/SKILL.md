# Studio 发布准备与记录

首次接入或对象变化时，按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、作品、采用版本和资料位置。

按[发布准备与记录规范](references/发布准备与记录规范.md)核对成片、文案、封面和[本条发布设置](references/发布准备与记录规范.md#本条发布设置)。[平台发布指南](references/发布准备与记录规范.md#平台发布指南)提供账号入口和表单字段。调用方未指定模板时使用[发布说明](templates/发布说明模板.md)和[发布文案](templates/发布文案模板.md)。

按[发布方式](references/发布准备与记录规范.md#发布方式)交给用户手动发布，或[获授权后代发](references/发布准备与记录规范.md#获授权的代发)。代发包括进入正确账号、填写并核对主表单、截图、按授权提交立即或平台定时发布，以及汇报[本次提交回执](references/发布准备与记录规范.md#提交回执与汇报)。
