# Studio 发布准备与记录

首次接入或对象变化时，按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、实际对象、资源版本和记录入口；直接调用本阶段也沿用该映射，不决定工作区或项目结构。

读取[发布准备与记录规范](references/发布准备与记录规范.md)。输入为最终成片、账号配置、已采用封面及相关报告。输出为本次作品发布包和真实执行／发布状态。发布包准备后按[发布方式](references/发布准备与记录规范.md#发布方式)接续用户手动发布或获授权的代发。代发执行读取[代为定时发布](references/发布准备与记录规范.md#代为定时发布)。预约时间已到或用户告知已手动发布时，按[发布后检查与临时跟进](references/发布准备与记录规范.md#发布后检查与临时跟进)核验，并按[实际发布与记录](references/发布准备与记录规范.md#实际发布与记录)回写。审核异常查[审核状态与异常处理](references/发布准备与记录规范.md#审核状态与异常处理)。按本次动作使用[发布说明](templates/发布说明模板.md)、[发布文案](templates/发布文案模板.md)和[发布记录](templates/发布记录模板.md)模板。

备料时先从[平台发布指南](references/发布准备与记录规范.md#平台发布指南)确认表单字段，再填[本条发布设置](references/发布准备与记录规范.md#本条发布设置)。排期按[排期建议与授权](references/发布准备与记录规范.md#排期建议与授权)确认，代发按共用流程提交前截图、提交后回读并统一汇报。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
