# Chloe 带货复盘与调整

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

先读取用户提供的成片、视频编号及已有发布或效果资料，按[运营接入](../chloe-positioning/references/社媒运营接入规范.md)确定记录位置。不主动登录后台、获取账号状态或采集运营数据；没有效果数据时只做内容分析，不逐项追问后台指标；单条复盘的采集编号填不适用，内容判断或局限注明实际成片和分析范围，不据此判断转化或收益效果。有数据时引用实际采集编号，不混用两种依据。证据只保存一份。

根据实际可得数据记录观看与互动、商品曝光或点击、订单、退款、预估与已结算佣金等相关指标。各项保留平台原始名称、统计周期、口径和来源，未提供写未取得，不推算成事实，不把预估收入当实际结算，不混用不同分母和统计阶段。

把内容问题、商品因素、账号阶段及其他已知变化分开分析；样本不足或条件不一致时保留假设，不把单条增长写成因果结论。实际发布文件不明时说明分析范围，不用脚本冒充成片，也不为补齐字段自行采集。

单条效果与结论归视频README及其证据入口，跨视频比较和下一步建议归综合资料/运营复盘.md。建议明确适用条件、准备改哪项、如何验证，回到选品、创意或资产阶段按当前任务采用。报告不自动启动返工、生成、发布或定时检查；不改旧快照。

## 时间与建议验证

效果数据按统计起始时间≤统计结束时间≤采集时间填写；跨视频结论按观察起始时间≤观察结束时间≤记录时间填写。各时间使用带时区的实际值，比较时按同一时间轴判断，允许相等。未取得的时间如实填未取得，只比较已知时间，不把未知时间补成零点或当前时间。

建议的采用与验证分开记录。采用状态为采用时，填写采用依据、验证对象及验证方法；验证对象用Markdown链接指向实际作品或被调整的原资料，可附具体发布编号、镜头或多个对象。验证方法说明准备比较或核对什么、使用何种口径或内容判断依据。只是提出建议、尚待决定或不采用时，不强求验证对象和结果。

尚未取得验证结果时，验证结果和结果证据填未取得，不为补齐字段生成资料或采集后台。一旦填写实质验证结果，无论采用状态如何，必须填写验证对象、验证方法，并用Markdown链接引用原始证据或原核对记录；本地链接指向原文件，外部证据使用实际来源链接，不另抄数据或复制附件。证据不足时保留局限，不把采用建议写成已验证有效。后续作品复盘时把真实结果补回原建议验证行。
