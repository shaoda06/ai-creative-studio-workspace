# 发布准备与记录

读取[发布准备与记录规范](references/发布准备与记录规范.md)。输入为最终成片、账号配置、已采用封面及相关报告；输出为单集发布包和真实执行／发布状态。发布包准备后按[发布方式](references/发布准备与记录规范.md#发布方式)接续用户手动发布或获授权的代发；代发执行读取[代为定时发布](references/发布准备与记录规范.md#代为定时发布)。审核变化读取[审核状态与异常处理](references/发布准备与记录规范.md#审核状态与异常处理)；用户手动发布后按[实际发布与记录](references/发布准备与记录规范.md#实际发布与记录)补录，获授权的日后检查读取[发布后检查与临时跟进](references/发布准备与记录规范.md#发布后检查与临时跟进)。使用[发布说明](templates/发布说明模板.md)、[发布文案](templates/发布文案模板.md)、[发布记录](templates/发布记录模板.md)模板，按本次动作填写。

发布前按[平台发布指南](references/发布准备与记录规范.md#平台发布指南)进入抖音、快手或小红书的电脑端视频指南；排期按[排期建议与授权](references/发布准备与记录规范.md#排期建议与授权)先建议、获批后提交；记录和收尾按[固定要求](references/发布准备与记录规范.md#记录与检查收尾)执行。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
