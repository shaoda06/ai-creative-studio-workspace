本项目用于自营视频内容与带货业务。当前账号的发布平台、目标人群和内容风格，统一见[账号定位](综合资料/账号定位.md)。

## 目录结构与资料存放

- `projects/`：每条视频一个V编号项目，包含脚本、制作记录、专属资源、剪辑交接与人工成片。
- `综合资料/`：账号定位、选品记录、运营复盘、商品资料、共用素材说明与共用资源。
- `综合资料/商品资料/`、`综合资料/共用素材/`：商品、模特、服装、造型、场景、声音的说明及资源引用。
- `综合资料/资源/`：共用图片、视频、音频的唯一正式存储及版本记录；资产说明和视频项目只引用准确版本。

目录由[初始化规范]({{skills}}/chloe-positioning/references/工作区与初始化规范.md)与脚本维护，技能统一归总目录，不复制到本资料区。

## 项目专用约定

本项目可关联多个平台账号；各项目的定位、资产、视频和复盘分别管理，默认不跨项目共享。每条视频在本项目的projects中独立保存。共用资产只保存一份，每次视频生成绑定具体版本；素材升级不改变旧任务输入。模特及造型采用完整全身三视图原图与正、侧面遮面版，保留头身比例。候选与采用分开记录。

Agent准备剪映交接，用户完成后期并导出到该视频`成片/`；成片不单独登记，发布记录直接引用实际文件，不把成片再复制进资源库。具体保存、版本和引用按[资源规范]({{skills}}/chloe-assets/references/资源存储与引用规范.md)。通用约定见[总工作区AGENTS]({{studio}}/AGENTS.md)。

处理具体视频时主动读取本README、视频README、脚本和与当前任务有关的制作记录。账号方向只在账号定位维护。初始化阶段不预设已选商品或已采用资产，不建立账号连接与权限配置。

浏览空间使用`chloe`及七个顶部栏目；账号概况读取账号定位中的账号方向，并从各视频README汇总制作概况、待处理事项和当前进度。共用资产中AI模特按模特资料显示卡片与已采用正面图；卡片标题同行提供已关联正式声音的试听按钮，未关联或未采用时禁用，点击试听不进入详情。点击卡片进入详情页，按模特信息、模特图片、造型三个标签查看人物特征、声音信息、基础三视图、面部版本和所属造型，直接引用原文件；声音信息位于人物特征下方，显示声音名称链接、说明、正式参考版本、时长与试听，无关联显示无，关联统一读取声音说明，不在模特资料重复维护；来源说明只保存在文档中。共用资产主分类为AI模特、服装、场景、声音，造型从所属模特进入。服装分类按说明展示卡片和左右详情，左侧名称与说明、右侧只显示服装展示图标签及具体版本；封面仅取已采用服装展示图，图片引用原件。场景分类复用服装的列表、左右详情及参考链接，场景展示图固定9:16，封面仅取已采用版本；声音分类按声音说明展示列表、正式参考试听与左右详情，原始参考链接在左侧最后一项，章节间隔与标题上下边距按[声音浏览页规范]({{skills}}/chloe-assets/references/资产制作规范.md#声音浏览页)统一；左右面板随内容自动等高，正式与候选声音卡片共用紧凑单行，时长靠右，候选版本折叠展示；导入、处理及采用由Agent按[声音资产流程]({{skills}}/chloe-assets/references/声音资产制作流程.md)执行：完整原件保留，正式参考以约4秒连续片段为目标，新截取结果按共用工具保存为16位PCM WAV，采样率和声道默认沿用源文件；不超过4秒的适用原件直接引用，不额外转码。“成片与发布”读取成片目录、发布资料及README发布记录，提供成片及横竖两版封面的独立预览下载、标题正文话题和挂品信息复制；其余未接入栏目保持预览。视频制作直接接入完整公共制作工作台，按每条视频的脚本、制作记录与制作轮次读取分段、审阅及交接，准确引用共用资源；平台挂品能力不由制作页提供；实际支持范围见[运营接入]({{skills}}/chloe-positioning/references/社媒运营接入规范.md)。
