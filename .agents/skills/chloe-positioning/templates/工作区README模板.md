# Chloe｜AI视频带货工作区

## 工作区定位与业务范围

AI Creative Studio 下的第三个一级子工作区，服务当前自营带货账号。起步方向为抖音新号、精选联盟选品、达人带货赚佣金；具体品类与实际账号身份见[账号定位](综合资料/账号定位.md)及[账号运营配置](综合资料/账号运营配置.md)。

## 一级业务入口

由[Chloe AI视频带货]({{skills}}/chloe-commerce-video/SKILL.md)组织业务。账号连接、发布和通用数据采集先读取[Chloe运营接入]({{skills}}/chloe-positioning/references/社媒运营接入规范.md)，再调用公共运营。

## 目录结构与资料存放

- `projects/`：每条视频一个V编号项目，包含脚本、制作记录、专属资源、剪辑交接与人工成片。
- `综合资料/`：账号定位、账号运营配置、选品记录、运营复盘、商品资料、共用素材说明与共用资源。
- `综合资料/商品资料/`、`综合资料/共用素材/`：商品、模特、服装、造型、场景、声音的说明及资源引用。
- `综合资料/资源/`：共用图片、视频、音频的唯一正式存储及版本记录；资产说明和视频项目只引用准确版本。

目录由[初始化规范]({{skills}}/chloe-positioning/references/工作区与初始化规范.md)与脚本维护，技能统一归总目录，不复制到本资料区。

## 项目索引入口

从[视频项目入口](projects/README.md)及projects实际子目录查找；当前进度只维护在各视频README，不另做重复进度表。

## 工作区专用约定

一个工作区对应当前账号，每条视频即一个项目。共用资产只保存一份，每次视频生成绑定具体版本；素材升级不改变旧任务输入。模特及造型采用完整全身三视图原图与正、侧面遮面版，保留头身比例。候选与采用分开记录。

Agent准备剪映交接，用户完成后期并导出到该视频`成片/`；不把成片再复制进资源库。具体保存、版本和引用按[资源规范]({{skills}}/chloe-assets/references/资源存储与引用规范.md)。通用约定见[总工作区AGENTS](../../AGENTS.md)。

## 项目接续与相关资料

处理具体视频时主动读取本README、视频README、脚本和与当前任务有关的制作记录。账号事实只在共用配置维护，各视频引用同一份。初始化阶段不预设已选商品、已采用资产或已连接账号。

浏览空间使用`chloe`及七个顶部栏目；账号概况读取本工作区的实际账号文档与视频进度，其余栏目保持预览。具体视频资料沿用通用资料页，不代表专用带货生产界面、跨项目媒体预览或平台挂品能力已经接通；实际支持范围见[运营接入]({{skills}}/chloe-positioning/references/社媒运营接入规范.md)。

固定资料的章节、字段、表格和更新方式按[固定资料写法规范]({{skills}}/chloe-positioning/references/固定资料写法规范.md)，写入后运行该规范的检查命令。
