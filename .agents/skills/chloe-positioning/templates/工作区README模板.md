# Chloe｜AI视频带货工作区

## 工作区定位与业务范围

本工作区管理多个独立的自营视频项目。项目名称由用户明确提供；每个项目可以关联多个平台账号，定位及真实资料在项目内维护。

## 一级业务入口

由[Chloe AI视频带货]({{skills}}/chloe-commerce-video/SKILL.md)组织业务。

## 目录结构与资料存放

本目录下每个具名项目使用同一结构：项目README、综合资料及projects。综合资料保存该项目的账号定位、选品、复盘与共用资产；projects保存其单条视频。项目内部目录按[初始化规范]({{skills}}/chloe-positioning/references/工作区与初始化规范.md)维护。

## 项目索引入口

按本目录下已建档项目的实际子目录查找，进入对应README；不在这里重复维护各视频进度。

## 工作区专用约定

项目之间默认不共享资产、账号资料或复盘记录。技能与公共工具统一维护在总技能库；通用约定见[总工作区AGENTS]({{studio}}/AGENTS.md)。

## 项目接续与相关资料

先确定当前项目并读取其README，再进入该项目的账号资料或视频README与当前记录。新建项目须先取得用户明确提供的名称；没有名称时先讨论，不代填占位名称、不先建目录。
