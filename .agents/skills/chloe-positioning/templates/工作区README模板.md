# Chloe｜AI视频带货工作区

## 工作区定位与业务范围

本工作区管理多个独立的自营视频项目。项目名称由用户明确提供；每个项目可以关联多个平台账号，定位及真实资料在项目内维护。

## 一级业务入口

由[Chloe AI视频带货]({{skills}}/chloe-commerce-video/SKILL.md)组织业务。

## 目录结构与资料存放

本目录下每个具名项目使用同一结构：项目README、综合资料及projects。综合资料保存该项目的账号定位、选品、复盘与共用资产；projects保存其单条视频。项目内部目录按[初始化规范]({{skills}}/chloe-positioning/references/工作区与初始化规范.md)维护。

## 项目索引入口

项目总索引位于 `项目总索引.md`，首次项目建档时按[共用项目总索引]({{skills}}/studio-workspace-browser/references/项目总索引规范.md)建立；已有索引时在此提供链接，不复制项目清单。

## 工作区专用约定

项目资料的使用范围见[Chloe业务入口]({{skills}}/chloe-commerce-video/SKILL.md)，通用约定见[总工作区AGENTS]({{studio}}/AGENTS.md)。

## 项目接续与相关资料

已有项目见[项目专用约定的记录与执行]({{skills}}/chloe-commerce-video/references/会话组织与接续规范.md#项目专用约定的记录与执行)。新建项目见[命名与初始化]({{skills}}/chloe-positioning/references/工作区与初始化规范.md)。
