# Chloe 账号定位与建档

接续账号方向或安排建档职责时，按[会话组织与接续](../chloe-commerce-video/references/会话组织与接续规范.md)确定承接会话。

创建或更新固定资料前，读取[固定资料写法规范](references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

账号方向只维护发布平台、目标人群和内容风格。已知内容直接沿用，未确定的保持待确定；只询问会影响当前选品或视频任务的必要缺项，不把填满模板作为开工条件。

建档读取[工作区与初始化规范](references/工作区与初始化规范.md)，使用已有初始化脚本；只建立固定骨架及资料入口，不虚构商品、模特、视频或真实发布结果。实际账号、权限和选品来源只留本机资料，不写入技能或公共仓库。

账号定位不设置固定人物策略、声音策略或制作限制，也不建立账号连接、权限和运营配置。模特、声音等具体选择随实际视频任务和已有资产确定。用户提供发布资料或明确提出相关协助时，读取[本业务接入](references/社媒运营接入规范.md)；不默认获取后台状态或运营数据。方向调整保留实际依据，不自动返工旧视频。

下一步按实际任务进入选品；已有商品和视频主题可直接进入创意，不要求重新定位。
