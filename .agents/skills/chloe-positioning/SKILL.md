# Chloe 账号定位与建档

创建或更新固定资料前，读取[固定资料写法规范](references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

输入为自营账号目标、已有决定及现状。先读工作区README和账号定位，区分已确认方向与待验证选择。受众、购买需求、品类范围、展示形式、固定人物与声音、可用素材和制作限制写入账号定位，不把探索方向当最终定位。

建档读取[工作区与初始化规范](references/工作区与初始化规范.md)，使用已有初始化脚本；只建立固定骨架及资料入口，不虚构商品、模特、视频或真实发布结果。实际账号、权限和选品来源只留本机资料，不写入技能或公共仓库。

首次启用运营先按[本业务接入](references/社媒运营接入规范.md)提供账号归属、作品身份和资料入口，再调用公共运营。账号配置归工作区，所有视频引用同一份配置；账号接入只维护连接状态、视频发布、商品挂载和核对时间，核对依据归原变更表，发布设置归对应视频，不从公共模板重新扩充固定字段。定位调整保留适用范围和依据，不自动返工旧视频或改写已执行任务。

下一步按实际任务进入选品；已有商品和视频主题可直接进入创意，不要求重新定位。
