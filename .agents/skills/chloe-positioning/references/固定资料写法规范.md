## Markdown固定语法

1. 使用UTF-8、一个一级标题。标题格式由模板确定，编号和名称替换为真实对象。保留模板全部二级标题及顺序，不新增三级标题。每个表格的位置、表头、列序保持不变。
2. `字段／内容`表是固定字段表：保留全部行、字段名和顺序，只修改内容列。其余表是记录列表：保留表头，无记录时只有表头和分隔行；不填写“暂无”的虚构数据行。
3. 表格一行表示一条记录，每个单元格必填。长正文在单元格内用`<br>`换行，正文中的竖线写`&#124;`，不在单元格中使用原始换行、未编码竖线或代码块。提示词、参数原件较长时填Markdown文件链接，不复制另一份正文。
4. 非表格文字只作说明与导航，页面不把它解释成业务字段。可选的文案、提示词或参数原件保留其正文，只从固定表格链接，不另作第二套结构化业务来源。已有字段的值不能仅写在表格外。需扩展结构时先维护所属规范、模板、初始化与检查及实际读取方，不能只在一个项目临时增加别名列。
5. 业务编号以目录为准，资料内编号和名称须相符。资源IMG/VID/AUD编号由工具分配，不能用G/M/O/L/S/A/V业务编号代替。

## 缺项、时间、数字与链接

- 决策未定用`待确定`；事实尚待核验用`待核实`；实际证据或结果未取得用`未取得`；确实无需此项用`不适用`；已经明确不存在用`无`。禁止空白、短横线、TODO或“同上”代替值，未取得数据不写0。
- 状态字段只能取后续规定的值，未知情况使用该状态的初始值；不要把上述缺项词任意填入状态。没有实际发布安排或事件就不建发布记录，不能为统计待发布视频而预造发布行。
- 名称以`时间`结尾的列／字段使用带时区ISO时间，例如`2026-11-07T09:30:00+08:00`，尚未发生用`未取得`。不写“今天”“刚才”或没有时区的时间。
- 秒、像素、帧率、金额和比例的值使用十进制数字，单位放字段名或单位列。金额区分人民币元，百分比单位写`%`且值如`12.5`。不得把预估佣金与已结算佣金混为同一指标。
- 本地文件链接相对于当前文档，用`[说明](<相对路径>)`；路径保留真实大小写。HTTP(S)链接用于真实外部来源，检查脚本不访问外网。结构映射里的`{视频目录}`是路径模式，不是一个真实文件。
- 资源引用统一写`[共用:IMG-实际编号@V001](<相对媒体文件路径>)`或`[本视频:VID-实际编号@V001](<相对媒体文件路径>)`；标签明确归属、编号、准确版本，链接必须解析到该版本原件。一个单元格只放一个资源引用；多素材拆多行。共用说明只能使用共用归属。本视频前缀只用于当前视频资源。
- 文档、清单、人工成片等非资源文件用普通文件链接。人工成片不得为了套资源引用而重复入库。各表需要证据时引用真实来源或用户决定的可追溯说明，不自动生成批准事实。

## 固定状态词

状态列用下列原词。目录初始化只设真实初始状态，不替用户确认。

| 字段 | 允许值 |
| --- | --- |
| 选择状态 | 考察、候选、选用、暂缓、不再推广 |
| 当前阶段 | 策划、资产准备、视频制作、剪映交接、人工后期、发布阶段、复盘阶段 |
| 视频状态 | 制作中、待发布、已发布 |
| 处理状态 | 正常、待用户决定、受阻 |
| 脚本状态 | 草稿、待确认、已确认 |
| 执行类型 | 图片生成、视频生成、音频生成、图片处理、视频处理、音频处理、素材导入 |
| 执行状态 | 准备中、已提交、执行中、已完成、失败、已取消、待核实 |
| 审阅结论 | 待审阅、通过、需修改、不采用 |
| 交接状态 | 待核对、可下载、已交接 |
| 发布方式 | 立即发布、定时发布 |
| 发布进展 | 待提交、已提交、审核中、已发布、失败、已撤回、待核实 |
| 采用状态 | 待决定、采用、不采用 |
| 核对结果 | 通过、不通过、待核实 |

“发布阶段”“复盘阶段”表示当前工作所处阶段，不表示已经发布或复盘完成；具体发布结果仍由发布记录填写。

视频状态是整条视频的唯一总状态：建档起为制作中，包括策划、素材准备、生成和人工后期；用户明确制作已完成后改为待发布，不要求先登记成片。待发布包含尚未提交、已提交定时或立即发布、审核中及发布失败待处理。实际发布成功后才改为已发布，并与发布记录的已发布进展一致。每条视频只计入一个总状态，三个数量相加等于视频总数；同一视频多次发布仍计一条。所有发布均已撤回时，不再计为已发布；待重新发布用待发布，明确返工则回制作中。仍有有效已发布记录时保留已发布，不因另一次发布等待或失败重计。

处理状态独立于视频状态：正常、待用户决定、受阻。后两项分别记录当前问题和具体下一步，解决后改回正常，不改变视频所属总状态。阶段变化和视频、处理状态变化在阶段变更表保留实际依据，不从目录出现文件或计划时间已到推断完成、采用或发布。

发布方式仅区分立即发布、定时发布；发布进展只记录用户提供的实际过程。确定发布安排但尚未提交为待提交；平台接受立即或定时任务为已提交；平台明确显示审核为审核中；实际成功为已发布。失败、撤回及信息待核实据实填写，不强制按顺序经过全部进展。定时发布填写计划发布时间。单次生成任务的执行状态仍可为已完成，不与整条视频状态混用。

技术执行已完成不自动把审阅写为通过、把视频状态写为待发布，或把媒体加入当前采用。当前采用表只放有用户依据的有效版本；取消采用先留变更记录，再移除该当前行。历史执行、发布、采集与返修记录保留。

## 行身份与更新方式

固定字段表维护当前值。记录列表中编号在本文件同一表内唯一且稳定，不按排序重新编号；跨文件引用带文件链接和编号。编号形式为字母前缀加至少三位数字：事项I、变更B、事实F、条件C、卖点S、执行E、审阅R、返修X、交接J、发布P、采集D、复盘R、验证T、修订U、核对K、镜头SH。编号命名空间为文件加章节，不把不同文件的E001视为同一任务。

- 当前表：账号定位、选品列表、资产当前采用、视频当前进度和采用。按事实更新同一对象；有实际变化时追加对应变更表，填写原值、新值、范围、时间、依据。初始化模板中的已确认起步方向不是新产生的执行事件，不伪造历史时间。
- 事件表：执行、输入、输出、审阅、返修、交接、成片、发布、效果、复盘及验证。新事件追加；同一真实任务／发布的进展更新原行，纠错注明依据，不创建重复事件。新的生成、修订或发布使用新编号，保留原行。
- 重试和新任务分别按工具实际身份判断。重试原任务不重复建执行行；新增任务ID创建新执行行并填写上游执行。输入／输出以执行编号关联，可一对多，每个槽位一行；旧输入不追改。
- 发布后的数据采集为新采集快照；一次快照多项指标共用采集编号，唯一键为采集编号、指标名称、统计口径。相同指标新时间采集用新编号，不覆盖旧值。
- 采用表用途是槽位，同一用途只保留一个当前版本；需要多个参考用`用途/补充说明`区分，不把多个版本塞在一个格内。

## 各类账号文件的填写责任

账号定位只在“账号方向”表维护发布平台、目标人群、内容风格三项。发布平台可填写多个已确定的平台，用顿号分隔；不以起步平台限制后续扩充。收益方式和佣金等条件按具体商品记录，不设账号变现方式。商品品类随商品与选品资料维护，不再建立账号品类范围。目标人群与内容风格使用自由描述，不设固定选项，可随实际方向更新。已确认内容沿用，其他值可保持待确定；不设置账号接入、运营配置、待决定事项或人物、声音、制作限制等策略问卷。只在当前任务确有需要时询问缺项。实际方向变化记决定与变更表，不预造决定或要求用户填写空白历史。

模特说明的资产身份固定为资产编号、资产名称、来源说明三行；页面只在页头显示编号和名称，不展示来源说明，模特信息正文读取人物特征。删除的资产类型、资产用途和使用限制不再填写，检查按模特模板拒绝额外字段；造型身份按下述规则维护，其他资产模板不变。

选品记录与商品说明按商品阶段规范。跨视频复盘一条结论一行，视频与证据列用链接及采集编号明确样本，观察窗口、比较条件与局限必须填写。建议验证关联复盘编号，采用结果有依据才写采用；没有结果时用未取得。单条事实在视频README维护，不为复盘再抄一份数据表。

## 检查与浏览接入

保存或更新固定资料后，运行`chloe_documents.py check --workspace 'workspaces/Chloe Workspace'`，脚本位于本技能scripts，使用浏览服务已有Python环境。也可加`--file`只检查某个固定文档；需要检查跨文件关系和资源时运行整个工作区。输出真实错误位置，不自动改文、不移动媒体。

检查脚本从实际模板提取章节、表头和固定字段，核对顺序、缺项、重复字段、状态、时间、数值及准确资源引用。`read --workspace ... --file ...`返回同一规则解析出的结构化内容，供后续页面接入或只读核对；不另存一套业务JSON，文档仍是业务事实来源。脚本不判断商品事实是否真实、生成质量是否合格或用户是否批准，这些按业务证据判断。

账号概况的“账号方向”按固定格式读取账号定位；制作概况和待处理事项从各视频README的“定位与当前进度”“发布记录”汇总，进度表沿用“定位与当前进度”章节名，不另维护统计文件；其余专用栏目按实际接入范围维护。修改模板字段时同步实际文档、示例、解析与页面读取，不能仅改界面标签或保留旧字段映射。

造型说明的资产身份只保留资产编号、资产名称、来源说明；造型信息只保留模特编号、造型说明。说明可选，无额外内容时填无，页面保留字段并显示原值，未填写内容显示无；仅明确不展示的字段隐藏。关联资料核对所属模特；实际生成输入在输入记录中逐项引用，不另设服装来源、商品或SKU固定字段。

造型专用输入记录新增输入用途列（输入槽位之后），固定取值为模特参考、服装参考、其他参考。服装参考必须为准确PNG/JPEG/WebP图片资源引用；没有图片不建行。模板仍是列序真源，其他文档输入表不增加此列。
