# 工作区与初始化规范

## 目录与归属

真实资料位于`workspaces/Chloe Workspace/`。工作区README使用总层规定的六个章节；`projects/`直接保存V编号视频，`综合资料/`保存账号定位、选品记录、运营复盘、商品资料、共用素材及共用资源区。发布平台、人群和风格由实际账号决定，未确定的保持待确定，不建立运营配置。

固定分类为`商品资料/`，以及`共用素材/AI模特/`、`服装/`、`造型/`、`场景/`、`声音/`。分类与资产说明只引用媒体，实际共用媒体归`综合资料/资源/图片、视频、音频`。资源索引、版本和共用引用按[资源规范](../../chloe-assets/references/资源存储与引用规范.md)。每条视频结构归[创意建档规范](../../chloe-creative/references/视频项目与脚本规范.md)，不在此复制。

固定目录由初始化脚本建立，包括暂时为空的分类；实际资产对象与视频只按明确任务建立，模板不预填生产和采用结果。重复初始化仅补缺，不覆盖已有正文、版本和引用；编号已用于另一名称时停止，不借初始化改名。

## 初始化命令

从总工作区运行，使用已有浏览服务Python环境，无需联网或启动服务：

```sh
工作区浏览服务/.venv/bin/python .agents/skills/chloe-positioning/scripts/chloe_init.py --workspace 'workspaces/Chloe Workspace' workspace --register
工作区浏览服务/.venv/bin/python .agents/skills/chloe-positioning/scripts/chloe_init.py --workspace 'workspaces/Chloe Workspace' video --id V001 --name '视频名称'
工作区浏览服务/.venv/bin/python .agents/skills/chloe-positioning/scripts/chloe_init.py --workspace 'workspaces/Chloe Workspace' asset --kind 模特 --id M001 --name '模特名'
```

示例编号与名称只是命令用法，不自动创建这些对象。`--workspace`须明确指向名为Chloe Workspace的实际或隔离目录。先执行workspace；video编号为V001等，资产类型和前缀为商品G、模特M、服装O、造型L、场景S、声音A。编号由Agent核对已有目录后明确传入，不因新修订新增业务对象。脚本输出实际目录JSON，异常直接失败；不生成媒体、不提交任务、不登记采用、不安装依赖，只有workspace命令显式传入`--register`时才登记浏览空间，不启动或重启服务。

## 登记、分发与验收

实际一级工作区按[运行资料规范](../../studio-workspace-browser/references/任务运行资料维护规范.md)登记空间id `chloe`、真实路径和`view: chloe-commerce`；由统一服务建立独立任务账本，不另启后台、不复制其他账号凭据。视频制作登记 `production_adapter: chloe-production`，接口直接使用公共制作工作台。登记加载前核对当前任务，服务只按现有启动器管理。

技能、脚本和模板归总仓库；真实商品、媒体和视频项目按Git忽略规则保留本机。公共仓库仅跟踪技能中的模板、脚本和流程；实际workspaces资料区及其README全部留本地。

验证用独立临时目录，运行：

```sh
工作区浏览服务/.venv/bin/python -m unittest discover -s .agents/skills/chloe-assets/scripts -p 'test_*.py'
```

核对固定目录、重复初始化保留内容、同一共用资源多视频引用、旧引用不随新版变化、越界和重复导入拒绝，以及并发引用保存；不能用测试资产填入真实projects。


## 固定文件的填写与检查

初始化固定文档后，按[固定资料写法](固定资料写法规范.md)及其模板填写。不同资产类型使用独立模板；重复初始化仅补缺，不用于把已有资料强制覆盖为新格式。格式更新应读取旧内容、保留实际决定及记录，再按授权范围调整结构。

从总目录执行以下只读检查和读取命令：

```sh
工作区浏览服务/.venv/bin/python .agents/skills/chloe-positioning/scripts/chloe_documents.py check --workspace 'workspaces/Chloe Workspace'
工作区浏览服务/.venv/bin/python .agents/skills/chloe-positioning/scripts/chloe_documents.py read --workspace 'workspaces/Chloe Workspace' --file '综合资料/账号定位.md'
工作区浏览服务/.venv/bin/python -m unittest discover -s .agents/skills/chloe-positioning/scripts -p 'test_*.py'
```

check检查14种固定资料、账号共用资源、每条视频资源与引用、实际剪映清单；read使用同一模板规则解析指定资料，不保存第二份数据。检查失败按原规范修正，不通过改解析器猜测字段来掩盖单篇文档偏移。资源去重与具体版本的原有隔离测试继续运行。
