# 发布资料与运营协助

接收发布、封面或复盘任务时，按[会话组织与接续](../../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)确定运营会话及与视频制作的交接，资料按下表写回原有位置。

Chloe日常选品和视频制作不预建账号连接、权限或运营配置，不要求Agent获取账号后台状态或运营数据；进入获授权的代发时按本次操作补齐必要信息。账号方向归`综合资料/账号定位.md`，只维护模板规定的三项；已知内容直接沿用，未确定内容不阻塞无关制作。

## 自动接续触发条件

用户已将成片放入对应视频的`成片/`目录，并明确确认该条视频“制作完成”时，Agent在收到确认的当次处理主动检查实际文件，接续下方发布准备，不再等待用户另说“做封面”或“准备发布资料”，也不追加一次是否开始准备的询问。用户同时明确暂缓或只做某项时，按其指定范围执行。

该接续包括查看实际成片与制作资料、准备横竖两版封面，以及标题、正文、话题和挂品信息，写回原发布资料并核对页面预览、下载和复制。封面选图、必要生成、尺寸处理与审阅采用沿本规范及公共封面技能；已有可用封面和发布资料直接沿用，只补缺项，不因再次接续重复生成。封面采用及必要内容决定仍按原规则取得，不把制作完成确认当作对新封面的批准。

确认完成后发现目录缺少成片或文件不可读取时，报告实际缺项并准备当前可完成部分，不宣称资料齐备；多个候选无法确定时只询问本次文件选择。仅发现目录新增文件而用户尚未确认制作完成，不自行认定完成。发布资料齐备后再按原流程询问用户手动发布或Agent代发，已有明确选择与授权直接沿用；自动开始准备不授权上传、定时提交或公开发布。

## 成片与发布接续

开始或继续封面、文案、话题及发布时间准备时，先按[复盘建议接续](../../chloe-review/SKILL.md#建议接续与验证回填)读取适用建议及已有T记录；Q资料中的T关联、实际素材与发布依据的交回按[阶段记录落点的发布准备项](../../chloe-review/SKILL.md#阶段记录落点)执行。

1. 进入发布环节时，读取本视频README、脚本、制作记录、关联商品及适用复盘；主动检查本视频`成片/`中的实际视频。没有成片时说明目录和缺项，可准备草稿但不称资料齐备。已有明确文件决定直接沿用；仅有一个成片时以该文件准备资料；多个候选无法从记录确定时让用户选择，不按修改时间猜。核对实际时长、尺寸和可读取性，结果写原制作记录的核对记录。
2. 使用[视频读取](../../studio-video-study/SKILL.md)查看实际成片，结合上述资料，调用[公共发布](../../nora-publication/SKILL.md)与[封面阶段](../../nora-cover-images/SKILL.md)准备可直接使用的封面图片、标题、正文、话题、商品名称、款式或SKU及真实挂品链接。成片已删去的内容不写进文案；商品承诺以真实商品资料为依据，核对画面商品与挂载对象一致。未取得的信息如实标明，只补任务必要缺项。封面的选图、文字、横竖排版和记录按[横竖封面制作](#横竖封面制作)。
3. 首次准备时按[发布资料模板](../../chloe-handoff/templates/发布资料模板.md)在本视频根目录创建`发布资料.md`，一行对应一个平台的一套资料，使用Q编号。文件创建与填写由Agent执行，页面不自动生成文案、图片或作出采用决定。先把实际资料写全并核对页面可预览、下载和复制，再询问“用户手动发布／Agent代发”；已有明确选择直接沿用，不重复询问。发布执行字段区分由谁操作，不与README中立即／定时的发布方式混用。建议时间按公共发布规则提出，不作为批准时间。
4. 用户手动发布时，交付“成片与发布”页面入口，用户直接取得成片、封面、文案、话题和挂品信息；收到实际结果后更新原发布记录。Agent代发时沿用公共发布技能，只补本次所需账号、发布选项、具体排期与授权，执行并核实提交结果。Chloe不为准备资料预建公共账号配置问卷或另建发布台账；公共技能中的发布说明及文案映射到本视频发布资料，发布结果映射到README，执行证据沿原制作记录与执行记录目录保存。
5. 准备资料不代表发布安排或发布事实，不为页面展示预造README发布行。实际安排确定后才建立发布记录，文案列使用`[Q001](<发布资料.md>)`关联准确资料行；横版封面引用、竖版封面引用、文件、标签及挂品等沿现有表格记录实际使用值；平台未使用的版式填不适用，不把准备好的两张图都记成实际上传。发布行引用的资料保留原内容，之后改版或再次发布追加新Q行；原成片、封面不覆盖。未进入实际发布安排的准备行可按当前决定更新。页面同时显示准备资料和已记录的发布进展，不把下载或复制当成发布成功。

## 代发信息与发布核对

不为发布准备新增账号配置文件或台账。首次实际代发所需账号身份、后台入口、浏览器配置及用户确认的默认选项，写入`综合资料/账号定位.md`现有“决定与变更”表；账号方向仍只有原三项。变更范围用`发布设置/平台/账号/设置项`，同一范围最后一条有效B记录表示当前选择，原值、新值、依据及记录时间保留；账号用实际稳定标识，尚无标识时使用用户明确的账号名称，不编造ID。不同账号分别记录，换号后不自动沿用另一账号权限和默认值。这里只登记本次已取得的事实与选择，不预填完整问卷；密码、Cookie和令牌不写入。

Q资料的账号填写可辨认的真实账号，依据引用相关B记录。每次代发前仍核对页面身份；本条实际保存的AI声明、可见范围、保存权限、封面及挂品等结果，写本视频`制作记录.md`的“交接与成片核对”K行，对象引用本次Q或README的P行，证据链接本次执行记录中的真实附件。一次性选项不回写成账号默认值；用户明确调整默认值才更新对应B记录。

本次需要挂品时执行[公共商品挂载规则](../../nora-publication/references/发布准备与记录规范.md#商品挂载与结果核对)，计划商品与SKU保留在Q资料，实际平台商品标识、可核实规格、挂载结果和差异写同一K核对记录，P行结果证据引用它或原附件。原始商品链接与平台回显链接不同不代表换品，须按商品身份核实；平台仅支持商品级挂载时注明不能锁定购买SKU。缺少入口、权限或目标商品时转待用户决定／受阻，不能擅自无商品提交。手动交付一并说明这些核对要点，用户提供结果后补原P、K记录。

## 发布资料调整与结果回写

已有P记录引用的Q行保持原文。提交前改稿追加新Q行，依据链接原Q及调整决定；同一次待提交P更新为引用新Q，并同步文件、封面、话题、SKU和挂品链接。README“阶段变更”B行以`P编号/发布资料`记录旧Q、新Q、时间和依据，P编号不变，不把改稿登记成第二次发布。仅变更排期或实际选项时更新原P及对应K记录并保留变更依据，不为没有内容变化的资料新建Q。

已经提交的平台作品须按本次修改授权操作原条目，核实保存结果后才更新P引用；新Q可先作为候选准备，但平台未保存成功时P仍保留实际已提交的旧Q。重新上传形成新的发布事件才新建P；原Q、P及媒体保留，不能用本地改稿替代平台结果。原记录中已发布资料的更改同样保留前后引用及实际执行证据。

公开状态与信息完整度分别判断。取得能对应平台、账号和本视频的实际公开证据后，P与视频状态可记已发布；实际时间、作品ID或链接尚未取得时填未取得／待核实，不推算。授权依据记录实际代发决定，手动发布则记录用户实际发布反馈及来源；结果证据须链接可追溯的原附件、核对记录或来源URL，并由Agent核对内容确实证明公开。缺项和挂品问题写当前问题与下一步，需用户补充时使用独立处理状态，不抹去已公开事实；仅有上传、定时或审核回执时保留相应进展。

公开后尚缺准确时间、ID或链接不阻塞已有真实效果数据的记录，但须能通过公开证据与指标来源对应同一作品。时间未知时不推算发布后时长，时间比较只使用双方已知值；补齐信息后重跑检查。一次性发布跟进按[公共发布后检查](../../nora-publication/references/发布准备与记录规范.md#发布后检查与临时跟进)，在当前会话继续检查或交接原入口与待办，不为单条任务创建定时器。

## 横竖封面制作

每条视频的发布资料分别填写横版封面引用与竖版封面引用，一套准备两版。默认比例、尺寸、格式及平台适配沿[公共封面交付预设](../../nora-cover-images/references/封面制作与管理规范.md#工作区选用的交付预设)，平台实际只用一版不取消另一版的准备；用户明确另定范围时按其要求。缺少一版时保留该版缺项，不用另一版图片代填，也不把整套记为齐备。

先从实际成片或已采用素材中选择适合本条内容的画面，判断人物状态、商品细节、清晰度及横竖构图是否合适。截帧记录来源成片及具体时码，已有素材引用准确版本；需要裁切、加字或调整排版时按实际方案处理。现有画面不能满足需求时再按公共封面工具重新生成，明确参考图用途与需要保留的人物、服装、商品特征，不凭生图改动真实商品细节。

封面文字和排版根据本条视频内容确定，文字承诺与实际成片及商品资料一致；可采用无字封面，不强制固定文案、字数、字体、字号、位置或表情模板。横竖版共用本条设计方向，分别安排文字、主体与留白，核对人物、商品和关键信息完整，不拉伸图片。实际文案、参考、排版方案及制作记录写入原制作记录，候选审阅、采用与尺寸处理沿公共封面技能。

公共封面对象映射为`本视频编号＋封面/平台/版式`，套组为本视频；不另建COV索引或封面工作稿。平台、版式、目标规格与设计方案在原制作记录的执行行及其参数记录中明确；候选沿输出记录的准确IMG版本，修改沿执行E、上游执行及返修X记录，审阅R只表示审阅，不冒充修订轮次。正式采用仍归README对应用途槽位，原图获批后的尺寸处理沿原审阅依据登记，尺寸变化不另造设计方案。

截取人工成片时，源视频普通文件链接及具体时码写该次执行的参数记录，输出截图登记为图片资源；输入记录的资源引用列只填写实际资源，不能为了填表把成片重复入库。复用共用图片时沿已有共用绑定及准确资源引用。

新制作的两版封面按[封面原件存储](../../chloe-assets/references/资源存储与引用规范.md#发布封面)分别保存真实资源版本；复用已有图片直接引用原件。README当前采用按封面/平台/横版、封面/平台/竖版区分用途；发布资料引用当次两版，发布记录分别记录实际使用的版式与原件。已被发布引用的资料及媒体保留，不能因后续改版覆盖。

| 单条封面 | 制作来源归本视频制作记录，当前采用归README，本次使用版本由发布资料直接引用；使用现有图不再复制 |
| 封面、标题、正文、话题、挂品及执行选择 | 本视频发布资料.md，按发布资料模板填写；同一Q编号只维护一套内容 |
| 发布安排及实际结果 | 本视频README的发布记录表；文案列引用发布资料的Q编号，保留原来已有文案记录 |
| 实际成片 | 本视频成片/，人工导出；不单独登记，发布记录直接引用实际文件，不再导入资源区 |
| 用户提供的截图、导出数据等证据 | 本视频制作记录.md引用真实附件，附件保存于本视频执行记录/ |
| 单条效果与复盘 | 本视频README的效果数据与单条复盘章节 |
| 跨视频结论 | 综合资料/运营复盘.md，引用单条证据与实际采用结果 |

发布资料由Agent依据实际成片和制作资料准备，发布事实与效果只记录实际取得的依据，不为填满表格追问账号状态、登录身份、权限或每项运营指标。用户明确提出发布协助、个人页、封面或运营分析任务时，再按所需动作调用公共运营；只补本次任务必要信息，不把公共账号配置模板自动带入Chloe。发布操作仍需本次授权与实际可用工具，不能从文档就绪推断平台能力已接通。

写入固定文件按[固定资料写法](固定资料写法规范.md)及所属模板执行，不新增重复状态表。商品挂载内容对应真实商品、款式和用户提供的有效链接；没有数据时只做内容层面的复盘，不自行采集后台。

## 工具与展示范围

浏览页直接对应文档章节的模块严格沿用原章节名，不添加前缀或自行改名。“账号概况”展示账号定位中的“账号方向”三项，并从各视频README的“定位与当前进度”“发布记录”汇总制作概况、待处理事项和进度。统计及待办为原记录的只读汇总，不添加账号填写字段，不采集平台后台；没有视频时保留模块及空状态。进度表沿用源章节名。视频资料、成片和复盘分别归各自栏目。“成片与发布”按视频列出实际成片数量；详情扫描成片目录，按Q编号与平台分别展示横版封面和竖版封面、标题、正文、话题、商品、款式或SKU、挂品链接及发布执行选择，两版分别提供原件预览与下载，其他发布文本可直接复制。成片目录浏览只表示可查看文件，正式发布对象以所选Q行的明确引用为准；发布进展读取README原记录。无资料显示真实空态，不生成演示内容；文件访问限当前项目成片和本项目准备资料、发布记录直接引用的准确封面原件。

空间登记使用chloe-commerce页面类型，共用统一浏览服务。其余专用栏目按实际实现范围接入，具体视频资料仍可沿用通用资料页。`综合资料/资源`是账号共用媒体的唯一存储，`chloe_resources.py resolve`解析具体版本输入；引用JSON不扩大网页或远端任务的文件访问范围。工具只接受项目内输入时，不复制共用媒体或造假项目绕过边界。

制作概况四项为视频总数、制作中、待发布、已发布，后三项互斥；待用户决定和受阻按处理状态另列提示。账号方向、待处理事项、定位与当前进度模块继续展示，无数据时仍保留空态。视频状态、处理状态、发布方式与发布进展均使用固定资料规范的选项。

共用资产页沿用公共路径导航，AI模特按共用素材/AI模特下的模特说明读取一对象一卡；整张卡片进入详情页，按模特信息、模特图片、造型三个标签只读展示。模特信息显示人物特征，模特图片首行左列显示正面面部图、右列显示面部三视图，基础全身三视图在下方独占一行，不展示资产身份表或来源说明。共用资产不设独立造型标签，按造型信息中的模特编号关联原造型说明。封面接口只读当前采用的正面面部准确版本；详情媒体及文档接口只读本模特说明、业务表中直接链接、所属造型说明及其直接引用且位于本空间综合资料下的原文件，不接受任意路径或越界符号链接，也不扩大远端任务输入权限。服装分类按服装说明读取卡片与左右详情，封面取已采用服装展示图准确版本，详情仅保留服装展示图标签，文件访问仅允许该服装说明中直接引用且位于综合资料内的原件；场景按[场景浏览页](../../chloe-assets/references/资产制作规范.md#场景浏览页)读取同类资料；声音按[声音浏览页](../../chloe-assets/references/资产制作规范.md#声音浏览页)读取声音说明、已采用音频及原始音视频参考，文件访问仍限该说明直接引用的共用原件。
