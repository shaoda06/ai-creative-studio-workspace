# 发布资料与运营协助

Chloe日常工作围绕选品和视频制作，不建立账号连接、权限或运营配置，不要求Agent获取账号后台状态或运营数据。账号方向归`综合资料/账号定位.md`，只维护模板规定的三项；已知内容直接沿用，未确定内容不阻塞无关制作。

## 资料映射

| 内容 | Chloe入口 |
| --- | --- |
| 账号方向 | 综合资料/账号定位.md的账号方向章节 |
| 单条封面 | 本视频制作记录及README中的准确资源版本，使用现有图不再复制 |
| 用户提供的发布文案、挂品信息与发布结果 | 本视频README的发布记录表；正文较长时在本视频根目录保存发布文案.md，表格引用该文件 |
| 实际成片 | 本视频成片/，人工导出；README引用准确文件，不再导入资源区 |
| 用户提供的截图、导出数据等证据 | 本视频制作记录.md引用真实附件，附件保存于本视频执行附件/ |
| 单条效果与复盘 | 本视频README的效果数据与单条复盘章节 |
| 跨视频结论 | 综合资料/运营复盘.md，引用单条证据与实际采用结果 |

只记录实际收到的资料，不为填满表格追问账号状态、登录身份、权限或每项运营指标。用户明确提出发布协助、个人页、封面或运营分析任务时，再按所需动作调用公共运营；只补本次任务必要信息，不把公共账号配置模板自动带入Chloe。发布操作仍需本次授权与实际可用工具，不能从文档就绪推断平台能力已接通。

写入固定文件按[固定资料写法](固定资料写法规范.md)及所属模板执行，不新增重复状态表。商品挂载内容对应真实商品、款式和用户提供的有效链接；没有数据时只做内容层面的复盘，不自行采集后台。

## 工具与展示范围

浏览页直接对应文档章节的模块严格沿用原章节名，不添加前缀或自行改名。“账号概况”只展示账号定位中的“账号方向”三项，不读取账号配置、待办或视频统计；视频资料、成片和复盘分别归各自栏目。

空间登记使用chloe-commerce页面类型，共用统一浏览服务。其余专用栏目按实际实现范围接入，具体视频资料仍可沿用通用资料页。`综合资料/资源`是账号共用媒体的唯一存储，`chloe_resources.py resolve`解析具体版本输入；引用JSON不扩大网页或远端任务的文件访问范围。工具只接受项目内输入时，不复制共用媒体或造假项目绕过边界。
