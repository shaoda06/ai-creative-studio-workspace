# 社媒运营接入规范

Chloe账号配置归`综合资料/账号运营配置.md`，各视频README引用同一份配置。发布对象就是V编号视频，实际平台作品ID另记；工作区级方向归账号定位，本条状态、发布事实和效果归视频README，跨视频结论归`综合资料/运营复盘.md`。不套Nora的10号或98号目录，不新增账号项目。

## 资料映射

| 内容 | Chloe入口 |
| --- | --- |
| 账号配置、连接与默认发布选项 | 综合资料/账号运营配置.md |
| 头像、背景及账号通用封面 | 实际制作时在综合资料/共用素材/对应运营物料说明中记录，媒体归综合资料/资源；新增正式物料类型先明确说明入口 |
| 单条封面 | 本视频制作记录及README中的准确资源版本；使用现有图不再复制 |
| 发布说明、文案、挂品信息与真实发布状态 | 本视频README的发布记录章节；正文较长时在本视频根目录增设发布说明.md或发布文案.md并由README引用 |
| 实际成片 | 本视频成片/，人工导出；README引用准确文件，不再导入资源区 |
| 执行与采集证据 | 本视频制作记录.md引用真实附件；需要截图、导出等实际附件时保存于本视频执行附件/，不预造结果 |
| 单条效果与复盘 | 本视频README的效果记录章节，按实际时间、平台口径和来源记录 |
| 跨视频结论 | 综合资料/运营复盘.md，引用单条证据与实际采用结果 |

公共运营只接收以上映射和真实输入，不重复维护账号配置或另造发布项目。使用公共模板时保留必要字段，实际记录可以在上述章节展开；证据与报告只维护一份，Chloe复盘补充商品和转化分析。挂品须对应商品资料中的真实商品、款式和当前可用链接；普通发布技能不代表已验证挂品操作。

## 工具与展示范围

空间登记使用现有通用资料页。项目README、成片文件和项目内`.jianying.json`清单沿现有能力展示或下载。`综合资料/资源`是账号共用存储，`chloe_resources.py resolve`可在本地解析实际输入；引用JSON不自动扩大网页或远端任务的项目文件访问范围。

共用资产网页专栏、跨项目资源预览、视频生产适配和带货后台能力须分别实际验证。现有工具只接受项目内输入时，不能复制共用媒体、造假项目或绕过边界来提交；说明具体缺项再处理。内置图片工具可以在其实际支持范围读取解析得到的本地参考路径。模型调用不等于业务采用。

通用资料页不展示工作区共用资产时，提供本地说明与准确文件入口。不得为了Chloe项目接入擅自修改共用网页代码；初始化与登记不宣称完整生产界面已接通。
