# 发布资料与运营协助

Chloe日常工作围绕选品和视频制作，不建立账号连接、权限或运营配置，不要求Agent获取账号后台状态或运营数据。账号方向归`综合资料/账号定位.md`，只维护模板规定的三项；已知内容直接沿用，未确定内容不阻塞无关制作。

## 资料映射

| 内容 | Chloe入口 |
| --- | --- |
| 账号方向 | 综合资料/账号定位.md的账号方向章节 |
| 单条封面 | 本视频制作记录及README中的准确资源版本，使用现有图不再复制 |
| 用户提供的发布文案、挂品信息与发布结果 | 本视频README的发布记录表；正文较长时在本视频根目录保存发布文案.md，表格引用该文件 |
| 实际成片 | 本视频成片/，人工导出；不单独登记，发布记录直接引用实际文件，不再导入资源区 |
| 用户提供的截图、导出数据等证据 | 本视频制作记录.md引用真实附件，附件保存于本视频执行记录/ |
| 单条效果与复盘 | 本视频README的效果数据与单条复盘章节 |
| 跨视频结论 | 综合资料/运营复盘.md，引用单条证据与实际采用结果 |

只记录实际收到的资料，不为填满表格追问账号状态、登录身份、权限或每项运营指标。用户明确提出发布协助、个人页、封面或运营分析任务时，再按所需动作调用公共运营；只补本次任务必要信息，不把公共账号配置模板自动带入Chloe。发布操作仍需本次授权与实际可用工具，不能从文档就绪推断平台能力已接通。

写入固定文件按[固定资料写法](固定资料写法规范.md)及所属模板执行，不新增重复状态表。商品挂载内容对应真实商品、款式和用户提供的有效链接；没有数据时只做内容层面的复盘，不自行采集后台。

## 工具与展示范围

浏览页直接对应文档章节的模块严格沿用原章节名，不添加前缀或自行改名。“账号概况”展示账号定位中的“账号方向”三项，并从各视频README的“定位与当前进度”“发布记录”汇总制作概况、待处理事项和进度。统计及待办为原记录的只读汇总，不添加账号填写字段，不采集平台后台；没有视频时保留模块及空状态。进度表沿用源章节名。视频资料、成片和复盘分别归各自栏目。

空间登记使用chloe-commerce页面类型，共用统一浏览服务。其余专用栏目按实际实现范围接入，具体视频资料仍可沿用通用资料页。`综合资料/资源`是账号共用媒体的唯一存储，`chloe_resources.py resolve`解析具体版本输入；引用JSON不扩大网页或远端任务的文件访问范围。工具只接受项目内输入时，不复制共用媒体或造假项目绕过边界。

制作概况四项为视频总数、制作中、待发布、已发布，后三项互斥；待用户决定和受阻按处理状态另列提示。账号方向、待处理事项、定位与当前进度模块继续展示，无数据时仍保留空态。视频状态、处理状态、发布方式与发布进展均使用固定资料规范的选项。

共用资产页沿用公共路径导航，AI模特按共用素材/AI模特下的模特说明读取一对象一卡；整张卡片进入详情页，按模特信息、模特图片、造型三个标签只读展示。模特信息显示人物特征，模特图片首行左列显示正面面部图、右列显示面部三视图，基础全身三视图在下方独占一行，不展示资产身份表或来源说明。共用资产不设独立造型标签，按造型信息中的模特编号关联原造型说明。封面接口只读当前采用的正面面部准确版本；详情媒体及文档接口只读本模特说明、业务表中直接链接、所属造型说明及其直接引用且位于本空间综合资料下的原文件，不接受任意路径或越界符号链接，也不扩大远端任务输入权限。服装分类按服装说明读取卡片与左右详情，封面取已采用服装展示图准确版本，详情仅保留服装展示图标签，文件访问仅允许该服装说明中直接引用且位于综合资料内的原件；场景按[场景浏览页](../../chloe-assets/references/资产制作规范.md#场景浏览页)读取同类资料；声音仍为分类预览。
