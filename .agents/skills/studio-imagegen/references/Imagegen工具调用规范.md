# Imagegen工具调用规范

## 实际调用

Agent读取当前可用的imagegen技能及实际工具说明，使用内置生成或编辑工具，不改为API或CLI。调用方明确实际提示词、编辑输入及范围；Agent做语义准备，执行方原样提交已备正文。

当前固定执行代理为gpt-6-luna、medium、fork_turns=none；这是执行Agent配置，不是Imagegen内部模型。不可用时回报限制，不自行换模型、换能力或重试。每条交接执行一次生图，保留实际返回和原生结果，等待时不另建轮询或定时器。

单次内置调用最多5张参考图，编辑需实际传入文件。工具要求先查看尚未看过的编辑输入时，按[总工作区图片内容查看规则](../../../../AGENTS.md#图片内容查看)确认授权，再查看该输入并执行编辑。

执行方转发原生结果，调用方登记并交用户审阅。通用 Imagegen 的输出检查建议在本工作区仅按上述规则获得查看授权后执行。工具结果及未公开参数如实记录。

### 执行代理交接与路径核对

- **主控准备输入**：交接现有执行清单的绝对路径、按原顺序解析并核对过的参考图绝对路径，以及已备调用正文。按清单格式规定的基准目录解析相对路径，并核对[资源归属和准确版本](../../studio-workspace-browser/references/项目资源与版本管理.md#目录和身份)。格式未规定基准时，在交接中明确实际基准，不从子代理的当前目录、项目根目录或记录所在目录推断。
- **子代理提交前核对**：以 UTF-8 读取清单，沿用其中的提示词原文和参考顺序。通过命令行传递时保持读写两端为 UTF-8。Windows 下从 PowerShell 调用 Python 时，先用 `$OutputEncoding = [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)` 设置管道与控制台编码，再用 `python -X utf8`。把路径作为字面值处理，保留中文、空格和括号，例如用 `Test-Path -LiteralPath <实际路径> -PathType Leaf` 逐一检查工具将接收的参考文件。调用正文或路径出现乱码、截断或找不到文件时，先按执行清单、明确的基准目录和准确资源版本核对输入。无法确认就回报缺项，不猜路径、不换版本、不提交生图。

## 返修时的模式与输入

收到普通返修要求时，调整提示词后沿用原生成渠道和模式重新生成：文生图仍不带图片；有参考图的生成引用当前制作步骤最初使用的原参考及准确版本。默认不把上一轮生成结果作为下一轮编辑输入，不逐版反复编辑；只有用户明确要求编辑某张生成图时才使用指定生成版本。输入来源须读取真实记录，不把最近候选当作原参考。

原参考属于当前图种和制作步骤，例如新图种本来就以已批准的另一图种正式图为输入时，返修仍沿用该正式参考。后续超分和本地遮面属于明确技术处理，不受生成式返修输入规则替代。每轮如实记录输入与来源，不追改历史执行。渠道不可用时按原有失败规范报告，不自动改用其他渠道。

## 固定脚本

scripts/imagegen_tool.py提供两个供调用方复用的函数：

- generation_call(prompt, references, result_store_key)：按顺序接收参考文件的绝对路径。遇到相对路径、路径不存在或指向目录时直接报出该路径。核对通过后返回可执行的内置工具调用正文，正文中保存完整返回值并转发原生结果。正文用 JSON Unicode 转义传递非 ASCII 字符，执行时还原提示词、参考路径和结果保存键原值。调用此函数只准备正文，不执行生图。
- preserve_original(source, destination, project=实际项目根目录)：将工具实际返回的PNG原字节保存到明确位置，按[共用PNG存储](../../studio-image-processing/references/图片处理工具规范.md#png保存复用与替换)复用相同内容并保护原图，核对解码及实际宽高；已有不同内容时停止。返回width、height、bytes、format、decoded。

文件处理使用工作区已配置的Python环境；不联网、不自动提交，不裁图、缩放或移除原结果。生图本身始终由Agent调用实际工具。业务交接命令和业务记录由调用方的阶段规范提供。

从命令行接收准备清单、资源查询或结果登记的 JSON 时，先解析 JSON，再使用其中的路径和命令字段。命令行 JSON 可用 Unicode 转义传递中文，解析后保留原值。

## 原生结果与恢复

原生像素可能与请求比例或正式目标存在差异。记录真实宽高，不把目标当作保证；不因预期差异自动重生或换能力。原生阶段没有ComfyUI的prompt_id、client_id或后台取回通知。

执行代理原样回传工具结果中的本地绝对路径，并确认文件存在。结果未显示或回传缺失时，先读本次已保存的返回值。仍无路径时，仅在能核实属于本次调用的执行代理专属输出目录中查找，核对调用时间和文件，唯一匹配才接续保存或登记。结果无法唯一确认时如实回报，不取全局最新图或重新生成。有图但业务登记或网页同步失败时只恢复相应步骤。需要后处理由调用方提供允许方式和目标，进入[图片处理](../../studio-image-processing/SKILL.md)。采用和正式资产保存不由本工具决定。

调用正文由公共函数按执行清单生成并返回，不要求每任务另存相同提示词TXT或JS。提示词、参考顺序和实际调用参数只在清单保存一次；真实返回值与原生结果仍须保存，旧任务恢复继续读取已有文件。
