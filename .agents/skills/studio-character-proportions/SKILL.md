# Studio 人物比例分析

在需要测量或比较人物身形、头身比例、面肩比及腿部轮廓时使用。单图按一个人物栏分析，同人不同版本或多图按输入顺序并排对照。多视角源图先选定要比较的视角，每栏显示一名人物的一个视图。

1. 按[测量与制图规范](references/测量与制图规范.md#图片测量)查看已获授权的源图，记录准确版本、视角、可见边缘和实际取点坐标。区分可见轮廓、衣料投影与关节估读。
2. 按[固定图例](assets/比例图例.json)保留纵向八条线、横向六项及统一名称和配色。合理估读的部位追加「（估）」。缺少测量依据时保留该项并标「无法判断」。计算和排版调用[制图脚本](references/测量与制图规范.md#运行与交付)。
3. 核对两张成图的对象、顺序、基准、标线和读数，与测量记录一并交回。单独分析存入本次交付目录。项目内分析按调用方给定的记录位置保存。

数字描述的是画面比例。不同视角、站姿、鞋履和服装会改变可见轮廓，解释差异时结合实际画面。出图规格和验收标准来自调用方，本公共技能提供测量、比较和制图。
