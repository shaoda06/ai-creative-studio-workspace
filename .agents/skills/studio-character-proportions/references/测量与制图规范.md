# 人物比例测量与制图

## 图片测量

优先比较相近视角及站姿。来源不同或经过裁切时，记录实际来源或版本、视角、穿鞋情况和影响读数的遮挡。位置和宽度来自画面投影。服装代理测量、侧身或透视造成的差异在结论中一并说明。

固定名称、顺序、条目数及配色以[图例](../assets/比例图例.json)为准。同一部位用同一颜色。估读仍沿用原名称，显示「（估）」并保存原因。未能定位时保留该项，显示「无法判断」，相应参考线与区间标尺留空。落地线根据所选人物用于判断站立高度的脚底或鞋底确定。

| 条目 | 取点口径 |
| --- | --- |
| `crown`、`chin` | 头部主体顶部、下巴最低点。头顶部位按可见主体取点，散开的发丝与高起的发饰单独说明。 |
| `face` | 在眉眼高度量左右脸部皮肤边缘，排除发量及耳朵。侧转时沿可见脸部取值并注明视角。 |
| `shoulder` | 两侧肩点大致高度。肩宽沿该高度取可见外轮廓，衣袖或垫肩影响边缘时注明。 |
| `bust` | 胸部最丰满处的视觉高度与该处躯干宽度。宽度取躯干边界。 |
| `waist` | 肋骨与胯之间最窄的腰部位置。用可见衣服收腰点代替时，标为估读。 |
| `hip` | 胯部较宽处的视觉高度和外轮廓，手臂、道具和衣物垂摆分别辨认。只能沿衣料估计时，标为估读。 |
| `knee`、`floor` | 膝关节中心和落地点。站姿两侧不等高时注明采用哪侧。 |
| `calf` | 单侧小腿上段取一个可见横截面。多图用相同的相对高度取点，记录所选侧与横截面高度。 |

纵向位置为 `(参考线 y − 头顶 y) ÷ (落地线 y − 头顶 y) × 100`，显示一位小数。相邻区间按这两个显示值相减。横向宽度为 `(右边缘 x − 左边缘 x) ÷ 面宽像素 × 100`，显示整数百分比。面肩比为 `1∶(肩宽像素 ÷ 面宽像素)`，保留两位小数。

## 测量记录输入

提供 UTF-8 JSON。坐标以纠正 EXIF 朝向后的源图左上为原点，x 向右、y 向下，单位为像素。`crop` 可省略，或给出 `[左, 上, 右, 下]` 裁切框（右、下为不包含的像素边界）。测量坐标始终用原图坐标。`image` 可为绝对路径或相对 JSON 所在目录的路径。`source` 填可回查的来源、资源版本或文件说明，省略时记录真实路径。`note` 保存与读数相关的姿势、服装或单腿取点说明。

下面是精简示例。实际分析为[图例](../assets/比例图例.json)中需要的每项提供实测点、估读原因或缺项原因。`estimate` 是估读依据，`missing` 是缺项原因。省略项显示「无法判断」，记录为未提供测量点。

```json
{
  "people": [
    {
      "name": "人物 A",
      "image": "全身图.png",
      "source": "用户提供的全身图",
      "note": "正面站姿，右侧小腿在全身高度 77% 处取宽。",
      "vertical": {
        "crown": {"y": 40},
        "waist": {"y": 329, "estimate": "沿可见裙腰估读"},
        "knee": {"missing": "裙摆完全遮挡"},
        "floor": {"y": 891}
      },
      "horizontal": {
        "face": {"y": 109, "left": 171, "right": 230},
        "waist": {"y": 329, "left": 148, "right": 244, "estimate": "沿衣料收腰边缘估读"}
      }
    }
  ]
}
```

肩、胸、腰、胯同时有纵向及横向测量时，两者使用同一个 y。缺头顶或落地线时，纵向百分比和区间无法判断，该栏按裁切中的实际取景呈现。缺面宽时，相对面宽的读数及面肩比显示无法判断，仍可保留已量到的宽度标线和像素坐标。

## 运行与交付

使用带 Pillow 的 Python 3.10 或以上。Studio 的浏览服务 Python 环境已有 Pillow，本命令只做本地制图。系统有微软雅黑、苹方或 Noto CJK 字体时脚本可查用，也可用 `--font` 传入可显示中文的 TTF/TTC/OTF 文件。

```powershell
& './工作区浏览服务/.venv/Scripts/python.exe' -X utf8 '.agents/skills/studio-character-proportions/scripts/proportion_charts.py' '测量输入.json' --output-dir '本次比例分析'
```

也可用 `python3 -X utf8` 和同样的脚本参数。输入文件和输出目录参数按命令当前目录解析，输入里的相对图片路径以输入 JSON 所在目录解析。单图、两图和三图分别生成一、二、三栏，四张及以上按输入顺序每行最多三栏。全身基准齐全的栏按相同身高等比缩放，对齐头顶和落地线。

调用方规定按原取景对照时，可用 `measure()` 取得各栏测量结果，再用 `chart()` 绘制所需方向。`frame_axis="width"` 按取景同宽，`frame_axis="height"` 按取景等高。两种方式均保留原画面内部的位置关系及图例的标注与读数。

纵向图每栏固定左侧位置读数、居中的人物图及右侧七个相邻区间。横向图在人物上用两端的短竖线标出宽度，右侧显示六项比例和面肩比。命令退出码为 0 时交回输出目录中的 `纵向比例图.png`、`横向比例图.png` 和 `比例分析记录.json`。记录写入实际图片路径、来源、尺寸、裁切框、测量点、估读原因、百分比和成图路径。继续测量时使用新的输出目录保存新一轮结果。报错时根据指出的输入、字体或输出位置修正后再运行。
