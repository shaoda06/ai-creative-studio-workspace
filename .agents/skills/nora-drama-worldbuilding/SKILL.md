# Nora 主旨简介与世界观

读取当前项目规则、定位、相关原稿和实际授权，再按[主旨简介与世界观规范](references/主旨简介与世界观规范.md)填写[七章模板](templates/主旨与简介模板.md)。共用原稿、表达和接续约定见[一级业务入口](../nora-serial-drama/SKILL.md)。

新写或实质修订时，按问题读取[故事方法](../nora-drama-story/references/story-craft.md)；涉及穿越、重生或系统等前提装置时读取[前提装置](references/premise-devices.md)，把规则、限制与代价写入世界观及核心设定。采用方法遵循[开发方法使用规范](../nora-serial-drama/references/开发方法使用规范.md)，不把方法中的独立文件或配额带入Nora。

本阶段是世界观与核心规则的维护来源；下游发现规则缺项或冲突时按[世界观归属](references/主旨简介与世界观规范.md#世界观的归属与维护)返回处理。旧项目独立设定仍按真实有效入口读取，不因技能拆分自动合并。

输入为已确认定位、相关原稿及核心方向；正式产出只有`01-主旨与简介/主旨与简介.md`。Agent负责人物目标、矛盾、规则与简介创作，本阶段不需要另造创作脚本。按规范核对七章、世界规则对主线的支撑及必要确认，交付前执行[合并自检](../nora-drama-review/references/文本自检与订正规范.md)；需要网页同步时调用[浏览工具](../studio-workspace-browser/SKILL.md)，不以文件存在推定批准。

完成后交[D03故事大纲](../nora-drama-story/SKILL.md)展开全剧事件。资料卡、逐集剧本和生成继续由其阶段负责。
