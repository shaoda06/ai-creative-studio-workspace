# 商品与选品写法规范

先读[固定资料写法](../../chloe-positioning/references/固定资料写法规范.md)，使用[选品记录模板](../../chloe-positioning/templates/选品记录模板.md)和[商品说明模板](../templates/商品说明模板.md)。表头和字段不自行改名。

## 选品列表

一商品一行，商品编号与商品说明目录一致，商品资料列链接真实说明；选择状态只使用固定词，选择依据说明为何考察或推广，待核实项明确缺少什么，核实时间与来源指向本次依据。商品价格、佣金、款式不再复制进列表。状态变化先留选择变更记录。

## 商品身份与事实

商品身份表维护业务编号、显示名称、平台、平台商品ID、链接、商家和类别；名称不代表选用决定。未知事实保留待核实。

款式与事实表每行一个SKU的一项事实，字段可用材质、尺寸、颜色、图案、版型、功能、适用范围等原始商品属性；字段值保留来源含义，不从AI生成图片反推商品事实。无SKU区分且已明确时填写不适用，未知SKU填写待核实。

带货条件表每行一个当前条件，字段使用售价、佣金比例、预估单笔佣金、库存、可售状态、挂品资格等实际取得项目。数字与单位分列，佣金注明原平台口径；来源和核实时间跟随该值。每个表中款式或SKU加字段为当前事实的唯一位置，变化写事实变更，历史快照由变更的原值和来源保留。

卖点与展示表每个卖点有S编号，事实依据填写本说明F编号或真实来源链接。展示方式说明镜头应呈现什么，限制说明不能编造或需要核实的部分；不能以视觉设想代替依据。

## 原始素材与关联

原始素材表每行一个用途及准确共用资源引用，来源与使用依据明确商家资料、用户提供或其他真实来源；长视频切片是新实际产出，不能只改来源标签。商品图片与服装库不重复保存。当前选品状态只维护在选品记录；视频关联从视频README的商品资料读取，不维护另一份手工视频清单。
