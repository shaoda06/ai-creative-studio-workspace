# Nora 故事大纲

读取项目规则、已确认的主旨简介与世界观、相关原稿及当前授权，按[故事大纲规范](references/故事大纲规范.md)填写[六章模板](templates/故事大纲模板.md)。原稿、表达和接续约定见[一级业务入口](../nora-serial-drama/SKILL.md)。

## 按当前问题使用方法

| 问题 | 参考及落实位置 |
| --- | --- |
| 主线因果、持续冲突与重大转折 | [故事方法](references/story-craft.md)，落实到完整主线和故事阶段 |
| 人物驱动力、关系及跨集信息状态 | [人物与跨集记忆](references/serial-character-and-memory.md)，落实到人物作用、关系与秘密伏笔 |
| 原稿改编、压缩、调序与参考吸收 | [改编方法](references/adaptation-craft.md)、[参考摄取](references/creative-reference-intake.md)，取舍依据写入既有工作稿 |
| 中段重复、机制耗尽、揭示与回报 | [机制循环](references/mechanism-loop.md)、[揭示反转回报](references/reveal-reversal-payoff.md)，落实到具体事件和人物后果 |

方法采用遵循[开发方法使用规范](../nora-serial-drama/references/开发方法使用规范.md)；只处理当前新写或实质修订问题，不把原生assets和stage-contract变成新的正式档案、配额或审批。

输入是主旨、世界规则、原稿及已确认核心设定；正式产出只有`02-故事大纲/故事大纲.md`。Agent完成剧情展开和语义核对，不由脚本拼接故事。新增或调整世界规则回[D02](../nora-drama-worldbuilding/SKILL.md)维护；不在大纲另写一套规则。

交付按规范核对六章、补充说明三小节、因果、人物变化与结局，执行[合并自检](../nora-drama-review/references/文本自检与订正规范.md)及适用的[浏览同步](../nora-workspace-browser/SKILL.md)。完成后交[D04资料设计](../nora-drama-assets/SKILL.md)及[D05分集规划](../nora-drama-episodes/SKILL.md)，不自动展开完整资料卡或逐集正文。
