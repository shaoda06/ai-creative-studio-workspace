# Nora 分集规划

先读取项目规则、全剧大纲、相关资料卡、原稿和实际授权；按[分集大纲规范](references/分集大纲规范.md)完成[分集索引模板](templates/分集索引模板.md)和[逐集七章模板](templates/分集大纲模板.md)。共用原稿、表达和接续约定见[一级业务入口](../nora-serial-drama/SKILL.md)。

## 当前动作

| 动作 | 使用规则与落实位置 |
| --- | --- |
| 全剧分集规划或逐集大纲 | [分集设计方法](references/episode-design.md)；按问题选[回报方法](../nora-drama-story/references/reveal-reversal-payoff.md)及[题材与钩子](../nora-drama-positioning/references/genre-and-hook-playbook.md)，将进入状态、主要行动、结果和承接写入七章正文 |
| 多集整稿接续或分批回读 | [整稿接入适配规范](references/整稿接入适配规范.md)；先由Agent判断真实集界，脚本只建立定位、切片及恢复进度，不将原稿集号当现行集号 |
| 已有剧集拆分与后续顺延 | [拆集规则](references/分集大纲规范.md#已有剧集的拆分与后续集号调整)，保留实际内容授权、批准和编号对应 |
| 集名登记或修改 | [集名登记与同步](references/分集大纲规范.md#集名登记与同步)，与文档批准及整集制作状态分开 |

采用方法先遵循[开发方法使用规范](../nora-serial-drama/references/开发方法使用规范.md)。正式产出为`06-分集大纲/分集索引.md`及每集一份`EPNNN-分集大纲.md`；索引只定位正文，不复制剧情或制作进度。Agent负责剧情、边界、信息状态和承接，脚本只处理明确输入；本阶段不写完整对白、镜号或视频分段。

新增人物或世界规则返回[D04资料设计](../nora-drama-assets/SKILL.md)、[D02世界观](../nora-drama-worldbuilding/SKILL.md)，全局事件变化返回[D03大纲](../nora-drama-story/SKILL.md)。交付按规范核对实际集数覆盖、状态承接、索引与必要审阅，执行[合并自检](../nora-drama-review/references/文本自检与订正规范.md)及适用的[浏览同步](../studio-workspace-browser/SKILL.md)，完成后交[单集剧本](../nora-drama-write/SKILL.md)。
