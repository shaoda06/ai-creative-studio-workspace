# 脚本使用规范

Agent对照实际来源和业务真源判断事实、因果、人物、连续性和内容问题，脚本不能产生这些结论或用户批准。原生assets与examples中的finding/verdict格式只作方法参考；Nora问题记录继续使用既有工作稿或当前交付，不自动生成独立JSON裁决、评分表或批准状态。

仅在明确受托核对一份已有原生finding/verdict数据时使用review_check.py。Python 3.9+、仅标准库；脚本读取明确JSONL问题记录和JSON结论，不修改业务来源，不看媒体，不连接后台或模型。示意命令替换为当前实际绝对路径：

```sh
python3 .agents/skills/nora-drama-review/scripts/review_check.py --findings '/实际输入/findings.jsonl' --verdict '/实际输入/verdict.json'
```

findings与verdict均必填，路径从当前目录解析。检查的是原生字段、记录对应与汇总自洽，不证明中文问题有依据或结论正确。实际输出有错误或退出非零时核对所指字段；不能改动事实迁就格式或把待决事项记为通过。相关schema见原生assets与[问题说明方法](review-method.md)，业务问题的依据和最小修订建议仍按[文本审查与返修](文本审查与返修规范.md)维护。

运行`python3 .agents/skills/nora-drama-review/scripts/selftest.py`执行现有8项原生隔离自测，验证格式与关联约束；不替代实际文本审查、用户批准或媒体查看授权。
