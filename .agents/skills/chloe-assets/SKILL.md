# Chloe 共用资产与镜头图片

开始资产任务或接收视频缺项时，按[会话职责](../chloe-commerce-video/references/会话组织与接续规范.md#会话职责与命名)确定对象归属，并按[共用资产与单条视频的交接](../chloe-commerce-video/references/会话组织与接续规范.md#共用资产与单条视频的交接)处理发型、服装、造型及镜头图片的职责和引用。

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

开始或继续模特、造型、发型、服装、场景、声音及镜头图片的准备或修改时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取与本次对象有关的建议及已有T记录；说明或执行中的T关联、准确产出及实际审阅状态的交回按[阶段记录落点的资产项](../chloe-review/SKILL.md#阶段记录落点)执行。

先读实际资产说明或视频脚本。制作模特基础图、服装展示图或场景展示图时，先按[模特与服装图片制作流程](references/模特与服装图片制作流程.md)执行已确认顺序、图种规格、批准及2倍超分自动采用规则。按[资产规格](references/资产制作规范.md)明确图片和声音用途，按[资源存储与引用](references/资源存储与引用规范.md)处理文件与来源。实际生成前核对本次对象、范围和有效授权，不因创建资料目录自动生成。

服装参考生成前固定按[服装参考两步确认](references/模特与服装图片制作流程.md#服装参考两步确认)核对提取范围、缺失视角处理方式，未明确的用选项弹窗询问；已有明确答复直接沿用，返修不重复询问未变化的决定。服装图片用途固定为服装参考图和服装展示图，当前采用只登记正式服装展示图。

发型的固定白模、文字生成、参考提取与正式采用按[发型图片制作流程](references/发型图片制作流程.md)执行。

场景生成前固定按[场景参考两步确认](references/模特与服装图片制作流程.md#场景参考两步确认)核对保留与排除范围、缺失信息处理，已明确的决定不重复询问。场景图片用途固定为场景参考图和场景展示图，展示图为9:16单幅完整环境，当前采用只登记正式场景展示图。

项目共用模特、发型、服装、造型、场景、声音和商品媒体只保存到账号共用资源区，业务目录只保存说明和引用。单条镜头新生成的首帧等归该视频资源区，采用决定归说明或视频README。已有原件直接引用，不为任务输入、正式采用或展示另存。

图片返修默认调整提示词并沿原渠道重新生成，文生图仍用文字、参考生成仍用本制作步骤的原始参考，不把上一轮候选自动作为下一轮编辑输入；只有用户明确要求时才编辑指定生成图，详见[返修输入规则](references/资产制作规范.md#图片返修输入)。

本阶段维护图片提示词、审阅记录与采用。内容查看遵守[总工作区图片内容查看规则](../../../AGENTS.md#图片内容查看)。本阶段明确要求看图的步骤为用户指定的发型参考辨认、服装与场景参考辨认，以及在已采用的造型全身定装原图上定位遮面范围。生成候选按[生成候选核对与送审](references/资产制作规范.md#生成候选核对与送审)执行。内置Imagegen、Qwen及尺寸处理调用相应Studio共用工具。造型遮面使用本套造型的超分正式原图，经studio-image-processing本地多边形纯黑填充，保持原尺寸和遮罩外像素不变；范围、检查及批准按[遮面流程](references/模特与服装图片制作流程.md#造型全身定装三视图遮面版)执行，不用生图编辑替代。保留原图与实际处理版本，不把处理输出标为原生。执行结果由共用资源工具登记，记录尚未采用的候选；技术成功不替代用户采用。

编写或实质修订共用资产图提示词时，按[技法转写](../studio-creative-techniques/SKILL.md#提示词转写)选用适用的静帧技法，取景和状态服从当前图种及用途。收到对应候选的具体技法反馈时，结合实际输入与提示词按[反馈复核](../studio-creative-techniques/references/学习与反馈维护规范.md#实际反馈复核)更新参考。

镜头首帧和画面参考按[镜头参考图制作流程](references/镜头参考图制作流程.md)及其提示词模板执行：先判断是否需要生图，按分镜选择正式资产，用户批准后2倍超分，后台通知Agent核对尺寸并自动登记本视频正式采用，不追加内容审批；现有素材能满足时直接引用。

制作视频专用导演分镜表时，按[本视频导演表接入](../chloe-creative/references/导演分镜表业务接入.md)接收已核对内容及实际参考，原图登记到本视频资源区；不套用模特和服装图的超分规格。

声音资产按[声音资产制作流程](references/声音资产制作流程.md)管理完整原始参考、约4秒连续取样、试听与正式采用；一个可复用声音一个A对象，人物发声和旁白可复用同一对象。实际固定声线、口型或对白生成能力按本次模型核对，不因有声音文件就声称功能已接通。

生成结果登记使用[图片结果自动登记](references/结果自动登记.md)：原生候选调用固定脚本，后台技术任务预先填写业务接续参数；正常通知复用收尾报告，不重复写行、测量媒体或检查整套项目。
