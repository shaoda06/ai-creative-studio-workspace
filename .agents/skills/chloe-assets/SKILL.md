# Chloe 共用资产与镜头图片

先读实际资产说明或视频脚本。按[资产规格](references/资产制作规范.md)明确图片和声音用途，按[资源存储与引用](references/资源存储与引用规范.md)处理文件与来源。实际生成前核对本次对象、范围和有效授权，不因创建资料目录自动生成。

共用模特、服装、造型、场景、声音和商品媒体只保存到账号共用资源区，业务目录只保存说明和引用。单条镜头新生成的首帧等归该视频资源区，采用决定归说明或视频README。已有原件直接引用，不为任务输入、正式采用或展示另存。

图片提示词、内容检查与候选采用由本阶段管理；内置Imagegen、Qwen及尺寸处理调用相应Studio共用工具。遮面后处理保留原图与实际处理版本，不把处理输出标为原生。执行结果由共用资源工具登记，记录尚未采用的候选；技术成功不替代用户采用。

账号声音资产只定义参考、来源和使用要求；实际固定声线、口型或对白生成能力按本次模型核对，不因有声音文件就声称功能已接通。
