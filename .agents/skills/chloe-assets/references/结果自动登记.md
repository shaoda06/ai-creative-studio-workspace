# 图片结果自动登记

## 职责与前置资料

使用所属具名项目的现有资产说明或视频制作记录。提交前建好E执行、输入行、授权及参数引用；原生结果仍为候选，用户批准原图后才安排独立超分E。固定章节与字段继续使用原模板，不新增登记台账。

共用图片的 owner 为具名项目下的 `综合资料`；镜头图片 owner 为单条视频目录。下列路径均相对 owner，只有命令参数使用绝对路径。`document` 是原执行所在文件，`adoption_document` 默认同文件；镜头图片填写 `README.md`。

## 后台图片与超分

在任务清单原 `image_plan` 中保留 `adapter: technical`、`images`，增加：

```json
{
  "business_result": {
    "adapter": "chloe-image",
    "document": "共用素材/AI模特/M001-名称/模特说明.md",
    "execution": "E002",
    "outputs": [{
      "slot": "3/images/0",
      "purpose": "正面面部",
      "source": "资源/图片/IMG-编号/V001/原图.png",
      "previous": "无"
    }],
    "adopt": {"document": "共用素材/AI模特/M001-名称/模特说明.md", "review": "R001"}
  }
}
```

- `outputs` 按任务 `outputs` 的声明顺序填写；后台按准确输出路径匹配，不依赖返回先后。`slot` 必须沿用原执行输出槽位，`purpose` 使用原文档固定用途。
- `source` 引用准确原图版本；无来源的新生成填 null。后台已保存的输出只登记引用，禁止再 import。
- 候选生成省略 `adopt`、`previous`，绝不自动写通过或采用。
- 超分采用要求 `adopt` 指向已有通过的R行，该R对象必须等于 `source`，原输入行也必须记录此来源。`previous` 保存提交时该用途的完整当前采用引用；尚无采用填“无”。结果回来后该值已改变则停止覆盖，交回Agent核对。
- 宽高复用公共超分技术报告的节点输出与对齐核对，不重读图片、不内容复审、不裁切。完成后更新原E、输出、参考版本、当前采用与B变更；来源和历史版本保持不变。

## 原生生图候选

在已有生图参数JSON中增加同样的 `business_result`，另填实际工具执行 `task_id`；修改同一目标时填原 `resource_id`，镜头图片另填 `video_project`（单条视频目录名）。不填写 `adopt`。工具结果返回后调用一次：

```sh
python "/工作区/.agents/skills/chloe-assets/scripts/chloe_result_records.py" native \
  --project-root "/工作区/workspaces/Chloe Workspace/项目名" \
  --manifest "/项目内实际路径/E001-生图参数.json" \
  --source "/工具实际返回的图片.png"
```

运行环境为浏览服务Python环境（含Pillow）。脚本按文档、E编号和输出槽位组成稳定导入身份，只保存一份资源，复用版本信息中的尺寸，写回原参数记录的 `actual_result` 与原文档。不删除工具返回原件，不生成第二份技术报告；原生工具暂存清理由原生成工具的收尾规则负责。成功输出 `status: updated` 和 `next_action: 用户审阅图片`，非零退出须按具体错误恢复同一执行。

## 通知与恢复

后台通知包含 `business_sync`。状态为 `updated` 时直接汇报或接续，不再次登记；脚本已检查所写固定文档。首次失败后的重试仍使用同一任务、E和输出身份。若仅恢复现有报告的业务写入：

```sh
python "/工作区/.agents/skills/chloe-assets/scripts/chloe_result_records.py" finish \
  --owner "/具名项目/综合资料" --manifest "/原任务清单.json" \
  --task-index 0 --report "/原任务目录/结果收尾报告.json"
```

`task-index` 是原清单 tasks 的零基位置，`report` 支持紧凑执行档案里的原报告路径。仅用于已核对的技术结果，不改后台冻结输入、不重新取回。报告、任务身份和已有采用不一致时报错，不追加另一执行。修复后仍由公共后台原任务恢复入口完成通知状态收尾。

收尾登记了共用资产的正式图片时，来源 Agent 在处理完成通知的当轮按[共用图片资产状态](资产制作规范.md#共用图片资产状态)核对对象，并接续发起确认或落实已有授权。

隔离回归：在 `工作区浏览服务` 目录执行 `.venv/bin/python -m unittest tests.test_chloe_result_completion -v`。macOS临时目录别名影响既有测试时使用 `TMPDIR=/private/tmp`。测试只写临时夹具，覆盖候选、自动采用、重复登记、乱序与中断恢复。
