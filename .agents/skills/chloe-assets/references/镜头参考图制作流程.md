# 镜头参考图制作流程

## 范围与职责

镜头参考图根据已确认分镜，将本镜头所需人物、造型、场景及起始状态组合成供视频生成使用的完整画面，归具体V视频，不新增共用资产对象。由本视频会话调用chloe-assets执行；共用资产缺项交对应资产职责补齐。导演分镜表是另一个用途，仍按[导演表接入](../../chloe-creative/references/导演分镜表业务接入.md)制作，不套用本流程的2倍超分。

## 1. 判断需求与用途

先读本视频README、已确认脚本及分段计划，按实际视频模型判断已有正式资产能否直接满足输入。能直接引用时不额外生图，不要求每镜一张。需要确定景别、机位、人物位置、构图或起始姿态时再生成。

明确关联P分段、SH镜头、脚本版本及用途：

- 首帧：目标是让视频从该画面开始，确定动作开始前或开始时的状态，不提前画成动作结束结果；能否作为实际起始帧由视频模式和图像输入条件决定，不因图片用途写了“首帧”就保证固定开场。
- 画面参考：约束人物、场景和构图，不要求视频从这张画面开始；实际工具是否支持按其输入模式核对。

接续H3时，`r2v`的普通Picture仅提供视觉参考，不能通过“第一帧完全一致”等提示词变成硬首帧。需要固定起始画面时，先核对并选择支持相应用途的实际模式及图像输入（如i2v／fl2v），提交前确认图片确实绑定到该模式的起始图像输入。模式未确定时记录用途目标和待确认项，不承诺首帧效果；已有模式不支持该要求时说明限制，由用户确认模式或用途调整，不静默换模式或把首帧降为普通参考。技术条件按[H3视频模式](../../studio-h3/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#11-视频模式与输入条件)核对。

Chloe镜头图的生成渠道、尺寸、2倍超分、记录目录及批准流程以本规范为准。共用H3只提供模型技术条件，不将Nora的EP目录、默认尺寸、制作步骤或审阅要求套入Chloe。

同一准确图片能用于多个镜头时直接复用，在各镜头说明用途，不复制媒体。脚本的“参考需求”记是否直接引用、需生成的用途及所需资产；实际执行和输入仍归制作记录。

## 2. 选择准确参考

| 需要确定的内容 | 优先选择的正式素材 |
| --- | --- |
| 人物身份和面部 | 面部三视图 |
| 穿搭与身体比例 | 造型全身三视图遮面版 |
| 环境、布置和光线 | 场景展示图 |
| 商品外观和细节 | 已核实的商品参考图，镜头需要时加入 |

按实际画面选择，不机械加入所有素材；其他参考组合说明本镜头的理由。需要的正式资产缺失时先补齐，不将候选冒充正式输入，不因制作参考图强制绑定商品。共用输入绑定准确资源编号和版本，不能写“最新图”；遮面图只是穿搭与比例参考，最终镜头画面按分镜生成完整人物面部。

## 3. 明确生成要求

从分镜提取景别、机位、人物位置与朝向、姿态、表情、物件关系、环境和光线；首帧明确动作起始状态。比例跟随本视频已确认画幅，不默认4:3或9:16。生成目标尺寸与工具实际原生输出分开记录，不把提示词中的分辨率当作工具保证。

使用[镜头参考图提示词模板](../templates/镜头参考图提示词模板.md)，保存为本视频执行记录/E编号/图片提示词.md，由制作记录的“提示词或正文”链接。参考清单和画面要求在生成前向用户说明，已有明确决定直接沿用；缺项或授权范围不明确时先澄清，不重复索要已有授权。

## 4. 生成与审阅

使用[内置生图工具](../../studio-imagegen/SKILL.md)按实际参考和提示词生成，其他渠道仅按用户明确决定使用。一次真实生成记一个图片生成E执行，原生候选保存到本视频资源区，登记真实输入、输出及尺寸。向用户提供候选，人物、穿着、构图和动作状态由用户审阅批准；生成成功不等于采用。

本流程的制定、脚本完成或资料建档都不自动授权生图。用户要求暂不生成时，只准备相应资料。

## 5. 批准后2倍超分与自动采用

用户批准候选即授权接续该图2倍超分及尺寸符合规则后的正式登记。调用[图片处理工具](../../studio-image-processing/SKILL.md)，复用[2倍超分技术规则](模特与服装图片制作流程.md#2倍超分与正式采用)中的节点尺寸计算、8像素对齐和通知要求；不使用普通插值代替超分，不为恢复名义比例裁切、补边或拉伸。

任务归实际V项目，使用公共后台的technical图片任务，原图与输出直接引用本视频资源。完成后必须通知Agent，由Agent读取报告，只核对实际宽高是否符合2倍模式及节点对齐后的预期，不增加图片内容复审或用户二次批准。尺寸异常时记录差异，不登记正式采用。正常完成后先更新本视频记录及正式采用，再向用户汇报；后台完成本身不等于业务登记完成。

本视频使用下节的制作记录和README，不套用共用资产说明的参考版本表，也不把图片任务写入视频分段执行或一采、二采轮次。

## 6. 记录、保存与交给视频生成

按[视频资料规范](../../chloe-creative/references/视频项目与脚本规范.md)维护原有文件：

- 图片生成与超分各记独立E执行；超分类型为图片处理，上游执行指向原生成E。输入引用用户批准的原生版本，输出引用实际超分版本，结果说明写尺寸核对并链接真实报告。
- 原生候选的用户批准记R审阅；不为超分结果伪造一次用户再次批准。提示词、实际参数和处理报告只保存一份，制作记录链接原件。
- README当前采用使用SH001/首帧或SH001/画面参考，多个参考用用途后缀区分；一张图服务多个镜头时各用途引用同一准确资源。正式采用依据引用原图R批准和超分E尺寸核对，时间为实际登记时间，采用变更保留原值与新值。
- 新图保存到本视频资源/图片；同一镜头图片的返修与超分沿该资源新增版本，parent和输入记录指向实际来源。共用资产仍引用原位置；原生候选及超分结果各保留一次，不覆盖、不另存正式副本。
- 视频任务使用正式采用图的准确版本，记录作为首帧还是画面参考，按实际模型映射输入。更新当前采用不改写历史任务；本视频图片不用伪造共用引用键，共用资产使用真实共用引用键。

完成后检查固定资料及准确引用；沿已有资源和制作记录入口核对可读取的正式版本，不为本流程新建测试页面或重复台账。图片采用不自动授权视频生成，视频任务仍按该视频当前有效授权执行。

## 7. 返修

默认按[原渠道返修规则](资产制作规范.md#图片返修输入)调整提示词，继续使用该制作步骤最初确定的原始参考及准确版本重新生成，不将上一轮候选自动作为输入。用户明确要求编辑指定候选或更换参考时记录新决定。返修关联原执行、审阅及后续执行；新候选重新交用户批准，再接续本流程的2倍超分和自动登记，旧采用不因返修开始而自动被替换。
