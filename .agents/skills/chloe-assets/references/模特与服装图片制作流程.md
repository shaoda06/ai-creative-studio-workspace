# 模特与服装图片制作流程

## 范围与共用顺序

本规范由chloe-assets负责，规定模特基础图片和服装展示图的制作。造型三视图共用下述留白与间距要求，其完整制作流程及场景、声音规格另行确认。

先完成并由用户确认模特说明的人物特征，再生成正面面部图。本地生图指会话内置Imagegen能力，由studio-imagegen执行，不表示本机GPU运行；按实际工具返回保存原生尺寸，提示词中的像素目标不是尺寸保证。

顺序为：正面面部生成候选 → 用户批准 → 2倍超分正式图 → 面部三视图生成候选 → 用户批准 → 2倍超分正式图 → 基础全身三视图原图候选 → 用户批准 → 2倍超分正式原图 → 本地遮面候选 → 尺寸与像素核对 → 用户批准 → 正式遮面版。每个后续生成步骤准确引用上一步的正式版本，不能拿未批准候选替代。

## 正面面部图

- 用途固定为正面面部；输入为已确认人物特征，使用内置Imagegen生成。
- 竖版3:4、纯白背景。完整保留头顶、下巴、颈部及肩部上缘；正对镜头、平视、自然闭嘴，五官无遮挡，均匀柔光，简单圆领上衣，无文字。
- 生成候选交用户审阅。批准后2倍超分，按下述尺寸核对与自动采用规则保存正式图。

## 三视图共用布局

适用于面部三视图、基础全身三视图和造型全身定装三视图。

- 三个视角分别居中放入等宽的隐形区域，人物等比例、头顶对齐，缩小人物占比以保留留白。
- 相邻完整人物轮廓之间以约画面宽度5%的连续白色间隔为目标；左右外边缘也留约5%画宽白边，上下保留白色余量。间隔从最外侧的头发、身体、手臂、服装或鞋履轮廓计算，不只看头部距离。
- 面部图完整保留头部、颈部及肩部上缘；全身图完整保留头顶、脚底和服装轮廓。三个视角不得接触、重叠或跨入相邻区域，肩部、衣服、裙摆和鞋履不能连成一片；不显示边框或分割线。
- 提示词明确留白和人物占比，不能只写“间距均匀”。生成后核对视角是否独立分开、轮廓是否完整及留白是否足够；目标比例不代表实际输出已精确达到，最终效果交用户审阅。遮面处理沿用原图布局与留白，不重新裁切或排版。

## 面部三视图

- 新增用途面部三视图；唯一人物图像参考为已采用的正面面部正式图，使用内置Imagegen生成。
- 横版16:9、纯白背景。从左至右为正面、人物自身右侧45°、背面；右侧45°展示人物右侧脸，鼻尖朝画面左侧，不使用90°纯侧面。
- 三幅都保留完整头部、颈部与肩部上缘，头部大小一致、位置对齐；背面展示后脑、发型及后颈。无文字标签。
- 留白与间距按[三视图共用布局](#三视图共用布局)执行。
- 用户批准后2倍超分，尺寸正确则自动登记正式图。

## 基础全身三视图原图

- 用途沿用全身三视图原图；图像参考为面部三视图正式图，体型与头身比例读取已确认的模特说明，使用内置Imagegen生成。
- 横版4:3、纯白背景。从左至右为正面全身、人物自身右侧45°全身、背面全身。方向与面部三视图一致，三个人物等比例、站姿一致，头顶和脚底完整入镜，无文字标签。留白与间距按[三视图共用布局](#三视图共用布局)执行。
- 女性基础着装：白色短款吊带背心（细肩带、短款衣摆）与白色瑜伽短裤，均贴身但不紧绷。
- 男性基础着装：白色背心与白色四角短裤，均贴身但不紧绷。
- 用户批准后2倍超分，尺寸正确则自动登记正式原图。

## 基础全身三视图遮面版

- 用途沿用全身三视图遮面版；输入必须是当前采用的、已完成2倍超分的基础全身三视图正式原图，引用准确资源编号与版本。不得使用未超分候选或生成式编辑的遮面图作为底图。
- 使用[本地遮罩填充](../../studio-image-processing/references/图片处理工具规范.md#本地遮罩填充)直接处理原图。按本张图片的实际脸部轮廓确定多边形坐标，在原像素尺寸上填充不透明纯黑色RGB(0,0,0)，不羽化、不重新生图、不缩放、不裁切、不补边，也不再次超分。
- 遮蔽正面及人物自身右侧45°的面部皮肤：从额头发际线下方沿面部边缘覆盖至下巴，包含眉眼、鼻、嘴、脸颊和下巴；45°覆盖鼻尖和下颌边缘，不残留五官。保留头发、发际线形状、头部外轮廓、耳朵、颈部及身体，背面完整保持原样。黑色区域是平面涂黑，不生成口罩、面具或头套。
- 每张图单独确定遮罩边界，不复用另一张图的固定坐标。执行参数保存源图准确引用、原尺寸、原图坐标系的各视角多边形、填充值、处理工具与版本，以及核对结果；坐标记录在该次执行参数，不抄入通用模板或规范。
- 保存PNG后核对实际宽高与输入完全一致、遮罩内像素全为纯黑、遮罩外所有像素与输入完全一致。面部边界交用户审阅；技术检查不能替代遮蔽范围批准。发现范围问题时调整遮罩并始终从同一正式原图另存候选，不在已经遮过的图上继续覆盖。
- 用户批准后直接登记该本地处理版本为正式遮面版，无需再超分。执行类型为图片处理，输入及资源parent指向正式原图，原图与遮面版分别保留单份；当前采用和审阅记录指向同一准确遮面版本。造型三视图的遮面处理沿用本节方式，以其自身超分正式原图为输入。

## 服装展示图

- 用途为服装展示；输入为用户提供的一张或多张准确服装参考图，使用内置Imagegen提取并生成展示图。服装为商品时直接引用已有商品图片，不另复制媒体。
- 横版16:9、纯白背景，左正面、右背面，无文字；采用隐形人台效果呈现服装体积，不出现真人、可见人台或衣架。
- 背面资料不足时必须先用选项弹窗询问：继续补充背面信息，或由AI补全背面信息。没有用户选择不自动补全。选择AI补全后，在该次执行记录注明哪些背面信息为推测，不作为已核实商品事实。
- 用户批准生成图后2倍超分，尺寸正确则自动登记正式图。原用户参考图、生成图及超分正式图分别保留来源关系。

## 2倍超分与正式采用

- 使用studio-image-processing的既有2倍超分能力；不以普通插值缩放冒充超分。业务层提供批准原图的准确版本、来源批准依据和目标宽高。
- 用户批准生成图即授权接续该图2倍超分与尺寸正确后的正式采用，无需再询问一次。使用2倍模式，按RTX节点实际尺寸规则核对：先将原始宽、高分别乘2，再各自按 max(8, round(尺寸 / 8) × 8) 对齐；round沿用节点的半值取偶数规则。例如1086×1448对应2176×2896。保留节点实际输出，不为恢复精确3:4或16:9而裁切、补边或拉伸。
- 超分完成后Agent只核对实际宽高，不看图评审内容、不检查或判断面部与纹理变化，不增加第二轮用户批准。工具正常返回且宽高符合节点对齐后的预期时自动登记当前采用为超分结果；如实际尺寸与该预期不符，仍不得登记为正式图，记录实际差异。
- 不将原生生成成功自动写为批准。原生图的用户批准记在审阅记录；超分另建图片处理执行行，上游执行指向原生成执行，输入引用批准原图、输出引用真实超分版本。完成尺寸核对写在该执行的结果说明。
- 超分后台完成后按[超分完成接续](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#超分完成接续)通知Agent。Agent复用尺寸核对结果，补齐本说明的参考版本、输出记录、执行记录、当前采用及采用变更，核对展示已读到正式版本后再汇报；不再次请求用户批准。
- 当前采用的采用依据同时注明原图的用户批准记录和超分执行编号及尺寸核对结果；采用时间为实际自动登记时间。超分图不伪造一条用户再次批准的审阅记录。
- 用途不因“候选”“批准”“正式”另造一套名称；同一用途生成原图与超分版均保存在参考版本，当前采用只指向该用途正式图。同一对象同一图种的修订与超分沿同一资源编号新增版本，parent与输入记录关联准确源版本；独立图种使用独立资源编号。
- 共用资源中的原图、超分图、遮面图各保存一份，不覆盖旧版本。说明和后续任务只引用准确版本。已批准的原图仍保留，不因它不是最终采用图而删除。

## 当前展示边界

文档与资源解析可保存面部三视图及服装展示用途；当前浏览页已显示正面面部、面部三视图与基础全身三视图，以及服装正面／侧面／背面／细节入口。面部三视图按其用途展示当前采用及其他版本，未采用候选不会自动填入当前采用框。服装展示图的专门展示后续单独调整，不把暂未展示误认为未生成，不把合成的服装展示图标作单独正面图。
