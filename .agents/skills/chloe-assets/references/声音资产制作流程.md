# 声音资产制作流程

## 范围与资料

一个 A 对象登记一项可复用声音，所有分类共用同一编号序列。声音说明登记名称、来源、声音分类、可选标签和说明。已有缺少分类字段的声线资料按人物声音参考读取。

| 声音分类 | 收录范围 | 可补充的信息 |
| --- | --- | --- |
| 背景音乐 | 用于剪辑和配乐的曲目 | 节奏、听感、是否有人声、常用段落的源音频时码 |
| 环境声 | 持续的场景底声 | 场景、可用区间、已核对的循环段 |
| 音效 | 脚步、衣料摩擦、转场等点状声音 | 对应动作或用途、主要起音位置 |
| 人物声音参考 | 说话、画外对白或旁白所用的可复用声线 | 语言、口音、声线及关联模特。同一声线共用一个对象 |

按实际用途选一个主分类，其余检索线索用标签表达。模特关联用关系「模特」、准确的 M 编号及原说明链接。素材来源和已知使用条件记在来源说明。工具、模型、声音 ID 及处理参数保存在原执行附件。

## 上传与处理

收录先确认具名项目、素材用途、分类和来源。收到链接时，从实际来源取得可用原件后记录原链接。确认共享用途后，核对文件格式与可读性，保存原字节并在「参考版本」登记「声音原始参考」的准确共用版本。已有相同共用音频时，继续引用该版本。

对已取得的音频执行 [chloe_sound.py](../scripts/chloe_sound.py)，传入 `--project-root`、`--file`、`--id`、`--title`、`--type` 和 `--source-note`。按需填写 `--tags` 和 `--description`。现有视频单独登记的原件可从同一用户原始附件补录共用版本，按既有执行记录追溯历史用法。

背景音乐、环境声和音效的完整原件登记后即可从库中试听。需要选段或加工时，按已明确的用途与区间调用[音频查找分析与处理](../../studio-entry/references/能力目录.md#音频查找分析与处理)，以新版本记录原件与处理依据。常用区间写在声音说明中，单条作品的入点、卡点、音量和淡入淡出记在该作品的剪辑或混音记录。

### 人物声音参考

声线原件、试听候选和正式采用分别登记。根据[共用声音参考方法](../../studio-creative-techniques/references/声音参考准备方法.md)准备适用的短样本。以下步骤用于声线制作。

1. **确认来源与用途**：已有录音或视频直接接收；根据描述制作新声音时，先明确需要的效果及实际工具，并取得本次生成授权。已有明确答复不重复问。视频提取、截取区间、去噪、变声等仅在本次已授权范围执行，不因上传自动加工。
2. **保存原始参考**：核对文件实际格式和可读性，通过共用资源工具原字节入库，保留完整原件和来源说明。多份原件分别登记为声音原始参考；当前具名项目内已有文件直接引用准确版本，不重复导入。上传不等于批准，不自动成为模型输入。
3. **准备候选**：按[共用声音参考方法](../../studio-creative-techniques/references/声音参考准备方法.md)选择连续样本。Chloe 正式声音参考以约4秒为目标，适用的短样本可直接引用原件。需要截取时，按确认区间和实际用途调用[共用音频处理](../../studio-entry/references/能力目录.md#音频查找分析与处理)。提取音轨登记新的音频资源并关联原视频，选段另建音频资源并记录父版本及实际区间，同一选段后续处理增加版本。
4. **技术核对与试听**：记录格式、实测时长与完整解码结果，向用户提供真实候选试听。技术可读不代表声音合适；Agent未能听辨时如实说明，不编造内容通过。尚不符合目标模型条件的素材仍可保存，具体限制写执行记录。
5. **用户批准后正式采用**：审阅记录指向用户实际试听批准的准确版本，再更新当前采用、采用变更及页面。没有图片式的超分环节，也不把处理完成自动视为内容批准。保留未采用候选及原件。用户已明确指定该声音并授权截取作为正式参考时，按该指令登记采用，记录实际区间及核对限制，不重复索要同一授权，也不编造新片段已获试听批准。

返修默认从该步骤最初使用的源音频或视频重新处理，记录实际区间和参数；用户明确要求继续处理某个候选时才引用该版本。生成式返修沿原生成渠道调整文本或参数，不自动逐轮叠加处理。

## 后续使用

其他作品可用 [共用资源脚本](../scripts/chloe_resources.py) 的 `bind` 登记准确的 `AUD 编号 + V 版本`，再用 `resolve` 取得实际共用原件。制作记录使用 `共用` 归属，记录用的是原件、选段还是实际采用版本。具体写法沿[资源存储与引用](资源存储与引用规范.md)。同一文件通过共用引用供各作品查用。

正式参考和实际台词录音是不同用途。每条视频引用明确的声音版本，记录这次作为音色参考还是直接使用原声；更新资产当前采用不改写历史输入。固定声线、对白、口型等能力按实际工具验证，不能仅凭已有音频声称已接通。

根据脚本的发声范围确定哪些分段使用该声音，并引用已采用的准确版本。音频是否适用以及怎样绑定，按[共用生成资产与提示词](../../studio-video-production/SKILL.md#生成资产与提示词)接续所选工作流。

## 页面与完成条件

声音浏览读取[声音分类、原件及采用版本](资产制作规范.md#声音浏览页)。收录完成时核对分类搜索、试听及准确版本可引用。人物声音参考的采用依据来自用户决定。

完成一次正式采用时核对：文件真实可读、来源和处理关系可追溯、采用依据与用户实际决定一致，取样采用可追溯到已指定源版本和区间、网页已读到该正式参考。音频只存共用资源一次，不另建正式音频副本，不自动提交后续视频任务。
