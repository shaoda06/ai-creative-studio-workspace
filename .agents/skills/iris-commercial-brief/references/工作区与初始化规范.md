# Iris 工作区初始化

工作区结构遵循[总层规范](../../studio-entry/references/一级子工作区结构与README规范.md)。本阶段维护Iris自己的初始化入口、业务README模板及项目目录说明。

在新下载的Studio总目录执行：

```sh
python3 .agents/skills/iris-commercial-brief/scripts/workspace_init.py --workspace 'workspaces/Iris Workspace' --register
```

脚本使用Python标准库，按[共用初始化与分发](../../studio-entry/references/一级子工作区结构与README规范.md#初始化与分发)补齐本地README和projects入口。

`--register`按[运行资料规范](../../studio-workspace-browser/references/任务运行资料维护规范.md)登记空间。省略时只创建资料区，浏览服务按[安装与启动](../../../../工作区浏览服务/README.md)单独管理。

工作区建好后，按[项目建档与README规范](项目建档与README规范.md)确定订单和作品，再填写所属模板。工作区初始化不预建客户订单或作品。
