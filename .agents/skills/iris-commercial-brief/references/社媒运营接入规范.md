# 社媒运营接入规范

本规范维护Iris业务调用[公共社媒运营](../../studio-social-operations/SKILL.md)时的对象、目录和接续。账号连接、视觉制作、发布和复盘方法由公共运营阶段维护；项目和作品建档沿[项目建档与README规范](项目建档与README规范.md)。

## 对象与状态

账号配置及跨作品事项归实际C项目；单片以F作品编号作为发布对象。横竖、长短等独立发布版本追加已有用途名，不改为剧集编号。项目状态仍归`项目状态.md`，本片状态归`作品/F编号-名称/作品状态.md`；各作品引用同一项目账号配置。客户交付、商业完单和社媒公开分别记录。

## 目录与创建时机

| 内容 | Iris位置与创建时机 |
| --- | --- |
| 账号配置 | 首次启用时建立项目`10-社交媒体资料/项目运营配置.md`，引用本规范、项目和实际作品入口 |
| 个人页资料 | 项目`10-社交媒体资料/个人页资料/账号视觉索引.md`及`其他资料/工作稿/{平台}-{账号代号}-主页视觉-工作稿.md`，实际制作时建立 |
| 封面资料 | 项目`10-社交媒体资料/封面资料/封面索引.md`及`其他资料/工作稿/封面制作-工作稿.md`，套组明确F作品及必要的发布用途，实际制作时建立 |
| 图片执行附件 | 各视觉资料的`其他资料/执行附件/`下本次记录目录 |
| 发布材料 | `作品/F编号-名称/07-返修交接/发布资料/{发布对象代号}/`，按实际任务建立`发布说明.md`、`发布文案.md`，直接引用已确认成片和封面版本 |
| 人工成片 | 引用本作品交付记录中的准确文件或资源版本，不另建运营成片副本 |
| 发布事实 | 项目`10-社交媒体资料/发布记录.md`，实际公开后记录 |
| 发布执行附件 | 项目`10-社交媒体资料/其他资料/执行附件/`下本次任务目录 |
| 复盘及采集 | 项目`10-社交媒体资料/运营复盘/{发布对象代号}/{发布对象代号}-运营复盘报告-YYYYMMDD.md`及`采集资料/{YYYYMMDD-HHmmss}/`，实际采集与报告时建立 |

上述入口登记在项目运营配置，作品按映射读取，不重复配置账号或状态。项目已有明确专用位置时沿用原位置并记录实际映射，不为运营迁移资料或另建制作项目。

## 媒体与执行适配

运营原生图、尺寸处理图和参考音视频归C项目的`资源/`，索引与工作稿记录准确版本及采用依据。成为正式图、用于发布或替换采用时只更新引用；有明确自包含交付需求才临时装入媒体。

图片生成及处理使用共用工具，传入实际C项目、F作品或账号视觉对象、输入版本和输出位置，不调用只支持短剧身份的收尾。记录使用公共运营模板，实际命名沿本项目约定，不借用EP身份。

采用既有10号目录和公共模板字段时，可核对现有[个人页](../../studio-profile-images/scripts/profile_browser_projection.py)与[封面](../../studio-cover-images/scripts/cover_browser_projection.py)展示适配；它们固定读取本项目内索引和资源，不支持任意目录或项目外资源。其他结构只交付实际文件入口并说明未适配范围，不复制媒体来迁就页面。项目与作品展示沿[建档规范](项目建档与README规范.md#网页读取与相对路径)。
