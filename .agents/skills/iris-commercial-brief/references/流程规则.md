# 需求与参考流程与规则

阶段一至三按2026-10-30用户确认的统一口径执行。

## 流程与接续

收集原件 → 整理需求与来源 → 分析参考 → 识别冲突和未知 → 用户核对 → 整理需求确认稿 → 反馈回写。

输入：客户原件、用户说明、参考及当前规格。输出：制作简报、参考分析、需求确认稿。按本次范围判断生产资料、交付整理和客户确认，不要求整阶段全部重做。

## 执行要点

输入为客户聊天、PPT、产品资料、参考片和用户补充。保留原件，提取内容和事实写明出处。先用[制作简报](../templates/制作简报.md)整理“明确要求、用户决定、推断、待确认”。不因PPT有某项方案就称已上线或真实业绩。

参考分析至少区分：故事/角色关系、讲述方式、视觉风格、节奏与声音。明确客户主要要借鉴哪一层；若影响较大，用短情节或关键画面尽早核对，不只提炼配色与卡片动效。没有实际播放/画面分析依据时说明观察范围，不能只凭链接猜测。

片长、画幅、输出规格及当前制作终点应有工作值或明确待定。用途、受众、真实功能/界面等只有影响当前决策才询问；用户明确无需确认的项目不重复列为阻塞。

产品截图改概念图时，记录可改区域与需保留的真实产品框架、功能名、导航和品牌。视觉简化不授权改整个产品；新示例数据须区分事实与示例。

完成：资料可定位，创意方向所需的重点和参考含义清楚；关键未知及其影响可见，独立工作继续。

简报记录各阶段交付材料和已知时间安排；需求确认稿不提前决定尚未讨论的创意或作制作承诺。
