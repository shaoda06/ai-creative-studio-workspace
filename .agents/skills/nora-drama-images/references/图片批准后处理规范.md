# 图片批准后处理规范

## 图片批准后处理

生产图片的批准后处理、正式保存及历史资产边界统一读取[图片超分执行规范](图片后处理业务规范.md)；按其中类型入口取得规格。画风样例按[定位画风验证流程](../../nora-drama-positioning/references/项目定位与画风规范.md#项目画风展开示例验证与复用)处理。

已获批生成图无需尺寸处理、由Agent保存到正式位置时，先从原请求读取对应`formal`；历史请求没有该字段时，在本次只读核对请求中引用已确认正式路径与当前候选入口，原请求保留。按[只读命名核对](固定脚本接口规范.md#图片的只读命名核对)核对批准候选，再调用[共用PNG保存入口](../../studio-image-processing/references/图片处理工具规范.md#png保存复用与替换)原字节保存，不手工复制或原地覆盖。来源、目标和原批准在既有记录关联；存储复用不算生成或新批准。固定工具已经完成的同项核对直接复用，不重复运行。

需要异步尺寸处理时，负责采用的Agent在提交前按[图片状态收尾](核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)定位本批须同步的具体字段。批准及已确认设定按真实决定及时登记；依赖正式保存成功的状态、路径和适用性，通过现有[采用字段与关联更新计划](../../nora-serial-drama/references/固定脚本接口规范.md#一次装配与批量入队)交固定工具在成功收尾时回写，不提前标完成。逐图事实与整批完成分开，不能用一个子任务成功覆盖仍未完成的批次状态。超分完成后通知负责Agent，复用已完成的计划回写；计划无法覆盖或发生并发冲突的具体项，按既有业务同步／异常接续入口补齐。原批准范围内的正式登记无需用户再次批准，整批业务收尾完成后再汇报，未解决前不记完成。

正式保存或替换完成后，由本轮负责采用的Agent按实际批准清单自动执行[图片状态收尾](核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)，核对工具已覆盖的更新及尚未覆盖的旧候选、当前摘要和跨阶段引用；复用已完成核验，不重复登记。
