# 进度查询与结果处理规范

### 正常图片结果

普通图片按[批次通知规则](ComfyUI-任务监控规范.md#图片批次通知与超分静默)等整批就绪后通知；正常超分静默，历史已发出的正常超分通知只读report确认，不发送对话进度、完成回复或图片。

调用[最终报告读取](../../studio-workspace-browser/references/固定脚本接口规范.md#后台最终报告读取)，同次读取自动确认收到。直接按[图片完成通知后的精简收尾](ComfyUI-任务监控规范.md#图片完成通知后的精简收尾)使用报告的delivery展示清单中的绝对路径、实测规格、数量和审核链接；展示去重及用户审核沿其链接的图片交付规则，内容分析沿[看图边界](../../nora-serial-drama/references/业务工作约定.md#看图能力调用边界)。不进入视频分支，不再核对文件、补常规记录或刷新网页。
