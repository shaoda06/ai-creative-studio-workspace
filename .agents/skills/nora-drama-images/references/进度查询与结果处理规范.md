# 进度查询与结果处理规范

### 正常图片结果

普通图片按[批次通知规则](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#图片批次通知与超分接续)等整批就绪后通知；正常超分同样通知Agent，读取report后沿用原批准补齐正式登记与同步，全部处理完再向用户汇报，不再次请求批准。

调用[最终报告读取](../../studio-workspace-browser/references/固定脚本接口规范.md#后台最终报告读取)，同次读取自动确认收到。直接按[图片完成通知后的精简收尾](ComfyUI-任务监控规范.md#图片完成通知后的精简收尾)使用报告的delivery展示清单中的绝对路径、实测规格、数量和审核链接；展示去重及用户审核沿其链接的图片交付规则，内容分析沿[看图边界](../../nora-serial-drama/references/业务工作约定.md#看图能力调用边界)。不进入视频分支，不重复技术文件核对、常规登记或网页刷新。

### 异常与恢复

异常沿[公共恢复规则](../../studio-workspace-browser/references/进度查询与结果处理规范.md#异常与恢复)处理；ComfyUI、Imagegen及本地规格处理的已有成果登记使用[图片成果登记修复](../../studio-workspace-browser/references/固定脚本接口规范.md#已有图片成果的登记修复)，保留原批准和已完成项，不重新生成或超分。

图片登记的范围冲突先修正关联更新计划，不放宽阶段保护：项目道具正式入库只更新道具阶段，已授权的剧集进度另行维护，不夹在道具收尾计划中。恢复入口按[公共登记修复](../../studio-workspace-browser/references/进度查询与结果处理规范.md#已有授权的登记修复)保留并发变化及修复前证据。
