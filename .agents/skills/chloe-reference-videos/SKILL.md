# Chloe 参考视频收录

收录用户提供的本地视频或分享链接。先确认所属具名项目及其现有参考记录，再按以下顺序处理。

1. **取得视频。** 本地文件的来源登记为「用户提供」。分享内容按 [视频读取与分析](../studio-video-study/SKILL.md) 提取链接、跟随跳转并下载。核对可打开的实际网址对应本次视频，来源登记为 `平台名－https://实际视频网址`。同时取得可播放的视频文件。
2. **检查边界及内容。** 用同一视频读取技能抽查开头、中段和结尾。检查社交平台的非内容片头、片尾，疑似边界处补帧，必要时听相邻音轨。依据实际画面及可取得的音频、字幕拟写简短简介。沿用用户提供的标题，未提供时拟一个简短标题。内容确实不清楚时询问用户缺失的信息。
3. **一次交回确认。** 向用户展示拟登记的标题、来源及简介。发现非内容片头或片尾时，同次报告其时间范围及建议保留的区间，询问是否裁剪。请用户确认登记。按用户确认的区间进行时间裁剪，保留音画；需要生成浏览器兼容版本时，沿同一原件登记。裁剪、转封装或转码均保留原件及准确来源版本。
4. **保存并核对。** 按[固定资料写法](../chloe-positioning/references/固定资料写法规范.md)建档，使用 `chloe_init.py asset --kind 参考视频` 和 `RV001` 格式的独立编号。说明在 `综合资料/共用素材/参考视频/`，实际视频在 `综合资料/资源/视频/`。用[共用资源工具](../studio-workspace-browser/references/项目资源与版本管理.md)登记原件和最终播放版本，已登记原件直接引用。处理版沿用原资源编号，关联原件和实际处理记录；时间裁剪用资源导入的 `--parent`、`--start` 和 `--duration` 记录保留区间。填写 [参考视频说明](templates/参考视频说明模板.md) 后运行固定资料检查。网页卡片及详情读取已登记的播放版本，时长、比例及分辨率取该版本的实测值。

用户确认后填写登记依据及播放版本引用。目录及模板可以先建，待确认记录在资料内保留，浏览页展示已完成登记的视频。用户选择保留完整视频且原件可直接播放时，原件引用与播放版本引用填写同一个准确版本。

时间裁剪用 FFmpeg 处理确认的连续区间，起点为保留起始时间，长度为终点减起点。需要浏览器兼容版时可用 MP4、H.264 和 AAC（有音轨时）。检查输出能解码且起止内容符合确认范围，再登记播放版本。视频文件和原始音轨以现有资源格式支持为准。
