# Chloe 导演分镜表业务接入

按[公共制作规则](../../studio-storyboard/references/导演分镜表制作规范.md)及[公共版式模板](../../studio-storyboard/templates/导演分镜表模板.md)制作，不另定义画法或分页。本阶段提供本条V视频的脚本.md（或对应历史快照）、脚本版本、镜头范围、画幅与有效制作授权。页头制作对象填V编号和名称。商品绑定与否沿视频README，不因制作导演表强制绑商品。

## 执行与保存

公共制作计划放在本视频执行记录目录，与本次提示词和参数同属执行附件，由制作记录.md的参数记录或“提示词或正文”字段引用。图中人物、造型、服装、场景需要参考时，由[资产阶段](../../chloe-assets/SKILL.md)固定准确版本；原件通过资源/共用引用.json引用，不复制到视频。生成图保存在本视频资源/图片中且只保留一份，采用时只更新引用，不复制到正式目录，不因导演表调用模特或服装的2倍超分流程。

### 准备并生成

使用浏览服务的 Python 环境。从源稿选定实际镜头后，提供一份 UTF-8 JSON 给准备命令。Agent 写逐镜画法和画面中的动作概括：

```json
{
  "direction": "同一角色与固定机位。按参考确定造型，简化背景线条。",
  "shots": [
    {"shot": "SH001", "sketch": "同格并列起步、转身、回眸三幅姿态", "action": "向前一步，转身后回看镜头"}
  ],
  "references": [{"slot": "造型面部", "key": "实际已登记的共用引用键"}]
}
```

`shots` 按源稿顺序给出本次范围。画幅从源脚本读取，填写实际画幅后制表。可省略前导画法 `direction` 或无参考时省略 `references`。有参考时按实际传图顺序写用途和共用引用键。本视频图片用 `reference` 代替 `key`，写与制作记录一致的准确 Markdown 资源引用，链接相对视频目录。

```sh
python .agents/skills/chloe-creative/scripts/chloe_director_sheet.py --project "单条视频绝对目录" --source "相对视频目录的对应脚本.md" --brief "本轮画法.json" --basis "本轮实际制表授权"
```

默认每页最多 6 镜，可用 `--page-size` 改为 1 至 6。图表号在同一视频内自动递增，候选号在同一源脚本版本内递增。指定 `--chart-version` 时，已登记或已预留的编号在出图前报错。成功时生成一份经公共校验的制作计划，带每页执行编号，并据此装配逐页提示词、参数和原制作记录。页头及列结构来自[公共版式模板](../../studio-storyboard/templates/导演分镜表模板.md#画面版式)。命令返回每页的 `manifest` 和已装配的 Imagegen `call`，只写本地文件。按现有 [Imagegen 执行交接](../../studio-imagegen/references/Imagegen工具调用规范.md#执行代理交接与路径核对)使用本批资料。

### 登记并送审

核对生成图的页头、镜头覆盖和关键姿态后，用返回的每页 `manifest` 和实际原图走[现有原生候选登记](../../chloe-assets/references/结果自动登记.md#原生生图候选)。脚本在导入前核对槽位与原计划页和执行的对应关系及编号冲突，再保存原图及准确版本。登记或展示异常时从同一份原图和参数接续。候选、审阅和返修继续使用[登记接入模板](../templates/导演表登记接入模板.md)。制表和视频执行各沿本次实际授权。

## 来源与采用

源脚本版本、图表版本和候选编号分别记录，槽位与采用字段见[登记接入模板](../templates/导演表登记接入模板.md)。一个图表版本对应一个脚本版本和候选编号。页内逐镜顺序来自计划，资源引用固定到具体 IMG 编号与 V 版本。

涉及内容反馈先更新脚本正文，按原规则保存历史版本和修订记录；局部改页保留未变页原来源及批准事实，在原记录说明仍适用和待更新范围。原生登记复用其固定资料检查；送审时在网页“视频制作 → 本条视频 → 导演分镜表”核对源版本、候选、页序与当前采用。旧记录缺少独立来源信息时显示未记录，按现有依据追溯。
