# Chloe 视频策划、脚本与分镜

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

输入为商品事实、账号定位、当前资产和适用复盘。按[视频项目与脚本规范](references/视频项目与脚本规范.md)创建或接续一条视频，创意、文案、分镜与声音写同一脚本，不额外建七套阶段目录。

编写或修订镜头时调用[共用分镜](../studio-storyboard/SKILL.md)，逐镜正文使用其模板并填入本视频脚本；商品事实与画面证据按本阶段接续。

每条视频说明面向谁、购买需求、主讲卖点、开头、商品出现方式、逐镜动作与画面证据、声音和收尾。商品展示必须对应真实资料；不承诺未核实效果，不因模特画面好看牺牲商品细节。模型专用视频提示词归生产阶段，脚本说明内容意图和实际镜头。

同商品换主题新建V项目，同一条改稿保留原项目及版本依据。已有有效脚本直接补本次内容，不重复定位或选品。镜头指出所需模特、造型、场景与声音，由资产阶段按缺项准备；已有参考绑定具体版本，不引用“最新图”。交接不自动授权图片或视频生成。
