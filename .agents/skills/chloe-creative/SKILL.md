# Chloe 视频策划、脚本与分镜

创建或接续本条策划时，按[会话组织与接续](../chloe-commerce-video/references/会话组织与接续规范.md)确定视频会话；需要共用资产时沿其中的交接规则说明缺项。

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

输入为视频主题、账号定位、当前资产和适用复盘；绑定商品时补充商品事实。新建视频时先按[商品绑定确认](references/视频项目与脚本规范.md#商品绑定确认)确认本条是否绑定商品。按[视频项目与脚本规范](references/视频项目与脚本规范.md)创建或接续一条视频，创意、文案、分镜与声音写同一脚本，不额外建七套阶段目录。

开始或继续主题、脚本及分镜编写时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取适用建议及已有T记录；建档或修订中的T关联、脚本版本与具体镜头改动的交回按[阶段记录落点的创意项](../chloe-review/SKILL.md#阶段记录落点)执行。

本条涉及人物交流、旁白或有意留白时，按[共用对白与场次表演](../studio-creative-techniques/references/对白与场次表演方法.md)写入本视频脚本。场景文字、说明叠字和字幕的制作归属按[共用画面文字写法](../studio-storyboard/references/分镜写作规范.md#画面文字与实现归属)落实在已确认的声音与字幕方案及镜头正文。

编写或修订镜头时调用[共用分镜](../studio-storyboard/SKILL.md)，逐镜正文使用其模板并填入本视频脚本；商品事实与画面证据按本阶段接续。

导演分镜表按[业务接入](references/导演分镜表业务接入.md)提供源脚本、范围和授权，调用公共规则及模板；执行与采用写回本视频原记录。

每条视频说明面向谁、内容目标、开头、展示内容、逐镜动作与画面证据、声音和收尾；绑定商品时补充购买需求、主讲卖点和商品出现方式。商品展示必须对应真实资料；不承诺未核实效果，不因模特画面好看牺牲商品细节。模型专用视频提示词归生产阶段，脚本说明内容意图和实际镜头。

换主题新建V项目，同一条改稿保留原项目及版本依据。已有有效脚本直接补本次内容，不重复定位或选品。镜头指出所需模特、造型、场景与声音，由资产阶段按缺项准备；已有参考绑定具体版本，不引用“最新图”。镜头“参考需求”按[镜头参考图流程](../chloe-assets/references/镜头参考图制作流程.md)区分直接引用、首帧和画面参考，交接确认的画幅、起始状态及准确资产。交接不自动授权图片或视频生成。
