# Studio 共用视频提示词

新写、实质修订或提交前核对视频生成提示词时，从当前业务确定实际范围、内容版本、素材用途和生成方式，再按[共用制作规范](references/视频提示词制作规范.md)完成正文、同版中文和输入核对。复用已备正文时，核对实际输入与既有结论的适用范围。

需要表情、镜头或动作链的具体表达时，查[创作技法](../studio-creative-techniques/SKILL.md#提示词转写)。有对白表演时，把分镜给出的说话人、原台词、重音、停顿和听者反应写进实际模型正文。发现措辞或接话问题，按[对白返修接续](../studio-creative-techniques/references/审查与返修方法.md#视频候选的返修接续)回正文修订。格式、标签、参数和排除要求的写入方式查实际模型工具，使用 H3 时读[Studio H3](../studio-h3/SKILL.md)及对应模式指南。

调用业务决定已确认内容与素材、项目例外、文档模板、记录位置和审阅接续。只写或核对提示词时交付文本及核对结论，生成沿本次实际授权。
