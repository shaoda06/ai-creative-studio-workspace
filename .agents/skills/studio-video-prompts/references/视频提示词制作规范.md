# 视频提示词制作规范

适用于各业务按已确认内容编写、实质修订或核对视频生成提示词。以下规则落实在调用业务既有文档、输入映射和检查记录中。

## 内容依据与实际参考

- 从本次有效的脚本或分镜确定生成范围、段长、镜头顺序、需要保留的内容及允许的变化。时长、镜头或必要内容有冲突时回对应上游处理，沿用调用业务的分段与修订规则。
- 有参考素材时，从本段内容确定必要用途，逐项核对真实文件、准确版本、用途和模型标签或槽位。多份参考定义同一主体时，区分各自提供的特征、适用对象和镜头。需要判断素材实际内容时使用有效来源记录，或按本次授权查看。
- 提交前对照计划与实际输入，确认必要参考未漏带、标签确有所指、素材职责和状态互相兼容。只为实际绑定的素材建立对应标签。发现缺项或冲突，回素材或分段方案处理。继续已批准来源的二采、后处理或恢复原任务时，沿用原执行的实际输入和业务接续条件。

## 模型正文的内容边界

- 以模型实际接收的本段正文、绑定素材和音视频上下文为准，按可见、可听的内容写清人物与环境、构图、动作和运镜、光线、声源、对白及必要的口型和时点。保留本段开始、变化、结束状态及实际接续。独立生成段按[分镜状态规则](../../studio-storyboard/references/分镜写作规范.md#独立生成分段的状态表达)写明自己的起点，用姿态、持物、视线、构图或声音等具体状态落实接点。
- 模型正文保留实际人物、地点、道具名称和模型要求的标签。项目和资产编号、文件路径、文档链接、版本号、任务ID、审批、候选轮次及工作流信息留在制作资料。字数和时长推导、帧数换算、时码计算、采样与裁切说明、检查结论也留在制作资料。用实际时点和状态表达画面，清理依赖制作历史才能理解的指令，如“按上一轮修正”。
- 保留调用业务已确认的画面和声音限制。按实际模型的正文或输入规则表达，使用 H3 时读[排除要求的写法](../../studio-h3/references/参考与接续表达规范.md#排除要求的写法)。由调用业务提供字幕、配乐、画面文字及其他内容边界，按[画面文字与实现归属](../../studio-storyboard/references/分镜写作规范.md#画面文字与实现归属)区分本次模型需呈现的文字及后期文字。

转写台词时，依据[共用声源分类](../../studio-screenplay/SKILL.md#声源与正文写法)和已确认分镜保留实际说话者、原台词、人物可听关系及需要的口型区间，按[台词与动作的同步](../../studio-storyboard/references/分镜写作规范.md#台词与动作的同步)在同一表演过程中落实时点。模型声源表达读当前模式指南，记录术语留在制作资料。

## 主体名称与指代

- 采用已确认的人物、商品、地点、道具及虚构对象名称。中文专名和已确认的中文术语在英文正文中保留原文；需要时另用英文说明外观、功能或动作。翻译、拼音、关系称呼或临时简称不能替代原名。没有专名的对象可以用稳定的描述称呼。对白、歌词和场景文字保留原语言，原话里的称呼及代词照录。
- 已声明的主体，在定义、出场、切镜、互动、画外动作和发声处使用同一个名称；视线、肢体、持物和动作目标也要写清归属。叙述中不用“他／她”、`he`、`she`、`they` 或其他泛称代替已命名主体，即使当前只有一个人。模型模式要求主体及说话者标签时，同时遵守对应格式；H3 见[主体身份与标签](../../studio-h3/references/参考与接续表达规范.md#主体身份与标签)。

## 逐镜转写

将分镜转成模型能直接理解的画面描述，按[镜头表达](../../studio-creative-techniques/SKILL.md#镜头表达)、[可见内容与画外连续性](../../studio-storyboard/references/分镜写作规范.md#镜头可见内容与画外连续性)及[状态与参考差异](../../studio-storyboard/references/分镜写作规范.md#镜头状态的变化延续与参考差异)选取本镜需要的信息。采用现有模型字段，不能靠拼接上游布局或分镜字段代替转写。需要表情、连续动作或修正动作重复时，按[提示词转写技法](../../studio-creative-techniques/SKILL.md#提示词转写)选择可见细节和动作链。

1. 先以本镜机位建立主体与必要固定锚点的画面位置、远近、朝向、视线和画外关系，交代与本镜有关的光影和需要清晰呈现的部分。换机位后重新判断，按[统一方向参照](../../studio-creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)转换上游方位；不沿用前镜的画面左右，不把人物身体左右当作画面方向。正反打按[视线连续性](../../studio-creative-techniques/references/镜头语言参考指南.md#41-正反打与视线连续性)核对机位、眼神落点和实际对视高度。
2. 按本镜可见的顺序写出各条动作的发出者、起点、路径、目标或接触面，以及动作在本镜实际到达的阶段。并行动作分别说明，未命中写清去向，不能提前写成已命中。固定镜头或纯反应镜按需要交代姿态、视线和可见的表情变化，不额外安排运动。
3. 明确相邻镜头已成立的状态和仍在继续的动作。反应在实际触发后出现，共同事件只发生一次，重新入画延续已有状态。公共正文只写已成立且各相关分段共用的事实，变化放回实际发生的镜头。遇到位置、构图、目标或动作矛盾，按业务规则返回对应分镜订正；转写本身不改变已确认动作、布局或切点。

## 模型正文与同版中文参考

中文参考完整、逐节忠实对应最终模型正文，保留章节键及顺序、素材／主体／说话者标签、镜号、时码、数值及对白原文。正文及中文参考遵守同一内容边界，保持动作、机位、声音和限制条件一致。需要补充或修正内容时，先改模型正文，再同步同版中文。

实际送入模型的是按对应模式编写的完整正文。中文参考供审阅，文档外壳、素材映射和制作说明留在记录里。有公共区和本组区时，以实际拼合的完整正文及对应中文为核对对象。

## 完成核对

- Agent 按播放顺序连读实际拼合的完整正文、相邻镜头和交流，对照上游依据、实际输入及同版中文，检查身份与声源、画内外取舍、动作触发和收束、镜头与段间接续、参考和业务限制。按正文推演人物动线与摄影机视野，检查能否同时满足要求，例如单人入画与另一人的肩背入画、背对镜头与正面口型清晰、张嘴惊讶与全段闭口。需要保留参考中的关键外观时，核对能否追溯到实际输入；场景或组合素材已能提供时无需单独增加参考。信息不足时写明缺项，不把生成目标当成素材事实。发现差异后订正对应上游或正文，再复核受影响的镜头、接点和输入；未变化且已有有效结论的部分直接复用。
- 模型工具核对能确定的格式、长度和绑定条件。格式通过不能代替内容检查；角色代称、方位或译文等需理解上下文的疑点由 Agent 判定，不能只凭关键词或出现次数判错。内容结论写入调用业务已有记录，实际输入和执行事实以请求及回执为依据，生成效果和采用决定按调用业务审阅。
