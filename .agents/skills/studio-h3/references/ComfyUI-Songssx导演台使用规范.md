# ComfyUI-Songssx导演台使用规范

适用于 `MiniMax-H3-Songssx导演台-Selflift-标准版.json`。用实际节点类型辨认工作流。该画布中，402 是 `MiniMaxH3TimelinePlanner`，403 是 `MiniMaxH3FiniteSegmentVideoSampler`，404 是 `SaveVideo`。

## 场次与分段

一次提交一个场次。在该场时间线上按播放顺序放置各生成分段，每个分段对应一个 GEN。分段是最小生成单位，GEN 内可以有多个镜头。业务提供各分段的身份、时长、镜头正文和参考素材。

当前标准画布通过 `SaveVideo` 保存整场 MP4。接续制作记录时应能查到各分段对应的 GEN 及其在场次视频中的时码。SelfLift 的低分辨率起步和高分辨率收尾在一次任务中完成。

## 工作区接入范围

当前规范记录画布和场次组织方式。Studio 的提交、取回及制作页接入另行确认。参考图居中裁切开关和一采缩放倍率以本次所用画布及插件版本为准。

返修的提交方式、分段复用与采用规则待定，定稿后在本规范维护。
