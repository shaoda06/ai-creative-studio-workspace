# 场次正文模板

将下列可用部分写入调用业务指定的剧本正文。场头按业务模板填写，样例人名及台词仅说明写法。具体声源语义见[声源与正文写法](../SKILL.md#声源与正文写法)。

```markdown
### <场次或段落标题>

<地点、时间和必要人物。调用业务另有场头时，按其字段填写。>

<按观看顺序写可见动作、变化和必要的表演反应。>

许闻舟：门开着。

（现场画外对白。周小栗站在走廊，许闻舟能听见。）

周小栗：等一下。

（内心独白。许闻舟没有开口，周小栗听不见。）

许闻舟：他认出那把钥匙了。

（叙述旁白。声音给观众听。）

叙述者：三年后，他们又回到这条走廊。

<如有关键环境声、动作声或音乐，按实际时点写清。>
```
