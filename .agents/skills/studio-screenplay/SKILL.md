# Studio 共用剧本

从调用业务给定的内容依据、时空、人物、已确认文本及声音要求出发。按[共用正文模板](templates/场次正文模板.md)写场景、动作和实际台词，在业务指定的场次、音画段或合并脚本内填入适用内容。同一原话由所属正文维护，分镜和提示词引用或转写这份实际内容。

## 声源与正文写法

| 声源 | 如何判断及记录 |
| --- | --- |
| 现场入镜对白 | 人物在现场实际发声，镜头能看见说话者。写实际说话者、交流对象及所需的发声表演。 |
| 现场画外对白 | 人物在当前场景实际发声，当前镜头看不到说话者。写声源位置和谁能听见。英文剧本用 O.S.（off-screen）。 |
| 内心独白 | 写角色心里想到的话。默认观众可听、现场人物听不见，画面中的本人没有为这句开口。英文剧本可用 V.O.（voice-over）。 |
| 叙述旁白 | 以叙述者的视角讲述，声音与当前场景的交流分开。注明叙述者。英文剧本可用 V.O.，与内心独白仍按实际性质区分。 |

电话、广播、录音、系统播报等写清实际声源、时空以及谁能听见；按作品要求表达，不凭声音是否入镜推断它是旁白或内心独白。关键的环境声、动作声和音乐写在声音说明，不混作台词。只在声音会影响表演、接续或制作时补充时点和听者。

中文正文用独立括注写「现场画外对白」「内心独白」或「叙述旁白」等实际含义，下一段保留 `说话人：原台词`。入镜对白无额外提示时直接写台词。表演、声音说明和字幕要求与实际听见的原文分开。

## 接续与核对

需要选择人物说话方式、场景反应或压稿方案时，读取[公共创作技法](../studio-creative-techniques/SKILL.md#剧本与对白)。核对正文的动作先后、台词内容、声源、知情范围和所需听者反应。逐镜时码及可见口型由[共用分镜](../studio-storyboard/SKILL.md)落实，送模型的声音表达按[共用视频提示词](../studio-video-prompts/SKILL.md)和实际模型的官方格式处理。

场头字段、目录、版本、业务约束和审批由调用业务提供。该模板用于今后的新制作，按各业务当前任务范围交付。
