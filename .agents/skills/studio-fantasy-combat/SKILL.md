# Studio 玄幻打戏方法

## 学习与反馈维护

用户要求吸收本领域图文／视频技巧时，调用[创作技法学习与维护](../studio-creative-techniques/SKILL.md)的学习分支，查重后原位更新本专项参考，不复制另一份库。实际采用具体候选写法时按[首次使用提示](../studio-creative-techniques/references/学习与反馈维护规范.md#首次实际使用时的提示)处理；收到针对性实际反馈按[反馈复核](../studio-creative-techniques/references/学习与反馈维护规范.md#实际反馈复核)更新对应写法与条件。日常设计仍按下方方法，不因查用而自动扩库或生成测试。

## 业务接入与方法使用

当前业务的输入、格式、批准和交付由调用方负责；共用接入边界、专项选择及读取范围统一见[调用与阅读](../studio-combat-methods/references/调用与阅读规范.md)。

## 法术表现的使用路径

涉及法术、法阵、剑气流光、灵力抽丝或属性粒子的设计、细化和相关反馈时，进入[法术表现设计与落地](references/xuanhuan-elements-vfx.md#法术表现设计与落地)，再按当前效果选择同页材质及[仙侠造型候选](references/仙侠法术与特效造型参考库.md)；不以“没有缺动作”跳过视觉方法。剧本落实必要的攻防与作用过程；分镜落实可见形态、运动、接触、反馈与取景；资产选取其中一个用途明确的静态状态；视频提示词在已定动作和风格内展开材质与动态，并按同页[表现核对](references/xuanhuan-elements-vfx.md#表现核对)复查实际正文。调用结果写入这些既有产出，不只登记技能名称。

已确认动作的提示词细化可明确流光、丝束、粒子等的质感、路径、层次和消散，不因此另编剧情或重排镜头；会改变能力、攻防因果、规模或核心视觉设定的缺项，回负责的上游处理。只查询、上传、取回或提交未变内容，不重新调用创作方法。

## 完整制作与局部修改

先按[完整制作与局部修改](../studio-combat-methods/references/调用与阅读规范.md#完整制作与局部修改)确定本次范围，再执行下列本专项步骤。

1. **明确依据与战斗规模**：核对已确认剧情目的、胜负走向、角色与法器、开场状态、空间、画风及本场适用强度；R3方法只用于对应规模，不把所有仙侠场面都做成最高强度。动机、强弱、赌注或环境作用尚未落实时，直读[打斗构思](../studio-combat-methods/references/combat-construction.md)相应部分。
2. **编排双向攻防**：读[核心法则](references/core-combat-laws.md)第二、四、五节，按动作节拍拆出攻击、防守或闪避、接触及实际反馈，用八步写作法明确每拍的作用和衔接。法术被躲开也须交代去向；防守方的抵抗及状态变化有具体过程。攻守次数、默认反杀及固定整秒不替代已确认剧情和调用业务的分镜时长。涉及近身拆招时再读[近战方法](references/close-quarters-engine.md)。
3. **落实材质、尺度与摄影**：涉及法术和能量表现时读[xuanhuan-elements-vfx](references/xuanhuan-elements-vfx.md)，写清形态、来源、路径、碰撞和环境作用；剑阵、法相、巨兽或宏观战场补[尺度方法](references/grand-scale-domains.md)。分镜阶段同时落实核心法则第一节的节奏、镜头和情绪方法，结合本段实际长度与已确认剧情适配；读[camera-specs-15modes](references/camera-specs-15modes.md)的适用机位与空间要求，按实际需求补群战、武器变化或一镜到底规则。新法术造型、招式及参数按下表选取，不把候选当成项目已采用设定。
4. **收束与合并自检**：先按已确认结局选择方法：需要交代败者或残局时，读核心法则第三节的适用协议；需要双人错身远离或单人冲镜的打斗硬切时，读协议D对应解法。已有结尾与这些协议均不匹配时，直接保留已确认的收尾动作和切点，核对人物位置、法器去向、能量及残留物状态、动作时序和必要的下一镜起点，完成空间与状态接续；不为套用协议补造胜负、受击、残局或改换收尾动作。只有已确认反杀或大招才读第八节对应方法。检查动作颗粒度、双方受力、尺度参照、镜头可读性及核心法则第七节适用打磨项；分镜阶段直读通用[节奏负载](../studio-combat-methods/references/combat-rhythm-and-load-guardrails.md)与[力度与节奏参考](../studio-combat-methods/references/combat-intensity-guardrails.md)的适用条件，涉及特效笔法时补[介质分层](../studio-combat-methods/references/vfx-rendering-mandate.md)。与负责业务的自检合并订正。

局部问题按下表定位，读取边界沿[共用调用规范](../studio-combat-methods/references/调用与阅读规范.md#完整制作与局部修改)。
