# Qwen-Image-2.1-图像编辑提示词模板

使用[Qwen工具规范](../Qwen工具调用规范.md)。本模板维护模型表达和输出格式，不规定业务图种、视图或固定排版。Agent编写实际正文，脚本原样装配；像素、比例和素材顺序由调用方明确。

## 1. 需求与输入图清单

```text
任务类型：{{调用方指定的实际编辑任务}}
画风来源与版本：{{调用方给出的风格正文及版本}}
画风正文：{{调用方给出的画风与美术表达要求}}
编辑目标：{{这次需要发生的明确变化；涉及结构时说明数量、位置、连接或接触关系}}

输入图清单（逐张列出）：
  图片编号：{{1、2等，与实际输入顺序一致}}
  文件或素材版本：{{实际源素材文件、版本及用户指定或批准依据，由调用方确认本次输入资格}}
  输入检查依据：{{默认引用生成／操作／用户指定／批准记录及图片版本；如按明确授权查看，另注明依据及范围，不把生成目标当成已验证画面}}
  用途：{{身份／服装体型／场景布局／道具结构／材质}}
  采用范围：{{具体从这张图保留或借用什么}}

保留画布：{{需要沿用哪张图的构图；重新构图时写“无固定画布”}}
不可改变：{{身份、年龄感、结构、色彩、材质、画风等}}
允许改变：{{本次视角、姿态、取景、服装、光线或指定部件}}

对照条件（做对照时）：{{本次改变项与固定项；仅换种子时复用原提示词，不再优化}}
新增可见区域依据：{{来自哪份已确认资料；缺失的关键设计先明确}}

取景与边缘：{{本图重点、必须可见的部位与关系、取景边界及边缘余量；按用途写清允许裁切／遮挡／画外的范围，结构图保留规定完整展示范围}}
画面文字：{{保留／替换的准确原文；无需求则省略}}

目标比例与像素：{{本次明确的目标值；像素仅保留在需求记录}}
```

画风及输入保留范围由调用方提供，Agent据此编写实际编辑正文。

## 2. 衍生与合成正文

Agent按真实输入说明保留与变化、图号及用途；单图可自然称“图像”，多图逐张对应。

## 7. 图像编辑输出格式

```json
{"rewritten_prompt":"{{按语义分段的完整编辑指令}}","wh_ratio":"{{明确比例或空字符串}}","ratio_follow":"{{输入图标签或空字符串}}"}
```

## 8. 双图编辑格式示例

仅示意两张实际输入的字段关系，具体编辑内容由调用方决定。

```json
{"rewritten_prompt":"{{实际正文，明确<image1>与<image2>各自保留和借用的内容}}","wh_ratio":"1:1","ratio_follow":""}
```

进入执行装配前明确size和wh_ratio，ratio_follow置空；保持有效JSON换行转义。
