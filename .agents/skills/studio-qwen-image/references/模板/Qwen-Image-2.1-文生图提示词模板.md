# Qwen-Image-2.1-文生图提示词模板

使用[Qwen工具规范](../Qwen工具调用规范.md)。本模板维护模型表达和输出格式，不规定业务图种、视图或固定排版。Agent编写实际正文，脚本原样装配；像素、比例和素材顺序由调用方明确。

## 1. 中文需求填写区

```text
任务与用途：{{本次素材及使用目的}}
主体与数量：{{本图实际可见的人物／场景／道具，以及明确数量}}
画风来源与版本：{{调用方给出的风格正文及版本}}
画风正文：{{调用方给出的画风与美术表达要求}}
已确认且不可改变：{{身份特征、颜色、结构、空间关系等}}

主体可见细节：{{本视图能看见的外貌或结构}}
姿态与视线：{{人物姿态、相对当前镜头的朝向、表情；不适用则省略}}
服装／材质：{{具体材料、表面状态、颜色}}

背景与边缘：{{背景、上缘、下缘及左右边缘实际可见内容}}
构图与取景：{{本图重点、景别、主体位置和占比、必须可见的区域与关系、取景边界；按用途填写允许裁切／画外与余量，结构图保留规定完整展示范围}}
光线：{{光源及其在当前画面中的方向、软硬、明暗及阴影}}

画面原文：{{需要出现在图中的原文、位置和样式；无文字则省略}}

允许补充：{{本次可以由编写者决定的细节范围}}
排除与约束：{{不应出现的内容及必须保留的边界}}

画面比例：{{采用本次明确的目标比例}}
目标像素（仅需求记录）：{{已确认宽×高，不进入模型正文}}
```

## 2. 单主体正文骨架

下列为可选表达骨架，已有正文时按实际内容和调用方要求编写，不按骨架改变已确定构图。

```text
风格要求：
{{调用方给出的画风与美术表达要求}}

画面要求：
画面在{{背景颜色与环境特征}}中呈现{{明确的单一主体}}，采用{{调用方要求的景别与取景}}。背景呈现{{可见表面、色彩变化与空间深度}}。

画面中央，{{主体位置、朝向与姿态}}。在{{主体最上方特征}}上方，{{留白范围与连续背景}}。画面左右边缘，{{周围空间的宽度与可见状态}}。

画面下缘呈现{{准确裁切位置、支撑面或衣物边界}}。{{如适用，说明局部遮挡及仍可见的部分}}。

光线来自{{光源与方向}}，形成{{软硬、亮度、阴影位置与高光特征}}，使{{重要材质与识别特征的可见效果}}。

对象描述：
主体上部呈现{{可见形状、比例和识别细节}}。在{{明确位置}}，{{第二项重要识别特征及其颜色或结构}}。{{相关区域}}周围，{{材质边界、轮廓或过渡}}。

靠近中央，{{最重要的面部或结构特征}}。{{人物的视线与表情，或物体的功能部件与结构关系}}。

在{{已命名特征}}下方，{{依空间顺序出现的细节}}。{{指定可见表面}}呈现{{材质、纹理、磨损与适度色彩变化}}。在{{另一相关位置}}，{{其他已确认细节及其与周围形体的关系}}。

```

## 3. 多区域正文骨架

```text
风格要求：
{{调用方给出的画风与美术表达要求}}

画面要求：
{{整体主体与取景目标；整体空间、背景平面与主要色调；各区域的构图关系。}}
{{光线方向、软硬，以及作用于空间和材质的结果。}}

对象描述：
画面上部：{{天空、天花板、顶部结构或已要求的标题。}}
画面左侧：{{可见元素、位置、材料，以及与中央区域的关系。}}
画面中央：{{主要对象及其空间关系。}}
画面右侧：{{可见元素与中央区域的衔接。}}
画面下部：{{前景、地面、底部结构或已要求的文字。}}
```

## 4. 可读文字插入格式

```text
在{{位置}}，以{{字体样式、颜色与相对大小}}显示文字“{{用户指定的准确原文}}”。
```

## 5. 文生图输出格式

```json
{"rewritten_prompt":"{{完整中文画面描述}}","wh_ratio":"{{用户已确定的比例}}"}
```

进入执行装配前明确size和wh_ratio，ratio_follow置空；保持有效JSON换行转义。
