# Studio 作品复盘与管理

复盘具体作品时，首次接入或对象变化按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、实际对象、资源版本和记录入口。直接调用本阶段也沿用该映射。

采集与比较先读[数据采集与核对SOP](references/数据采集与核对SOP.md)。拿到数据后，读[运营数据解读指南](references/运营数据解读指南.md)的相关指标，结合成片和其他数据提出原因假设、可执行改法及验证方式。输出按[复盘输出映射](../studio-social-operations/references/运营与制作接续规范.md#复盘输出映射)写入调用方已有固定记录，无指定结构时按[报告规范](references/运营复盘报告规范.md)和[固定模板](templates/运营复盘报告模板.md)形成报告。完成后由[阶段06](../studio-operations-guidance/SKILL.md)在实际制作时使用，不主动发起返工。

用户发来指定链接学习运营经验时，直接走[学习与沉淀](references/运营数据解读指南.md#学习与沉淀)。已明确学习用途的后续链接沿用同一流程。独立学习可直接从材料接续。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
