# 平台数据采集规范

适用于电脑端创作者后台的单条视频数据。按目标平台读取对应章节，账号和后台入口沿[电脑端平台连接指南](../../studio-operations-setup/references/运营启用与账号连接规范.md#电脑端平台连接指南)。页面模块、字段和更新范围以当前账号和作品实际显示为准。证据保存、缺项和比较规则沿[数据采集与核对SOP](数据采集与核对SOP.md)执行。

需要解释指标口径时，读取该指标旁的说明或导出定义，记录页面明确给出的统计对象、时间范围、分子和分母。取不到定义时保留已采集的原指标名、值和模块，口径记待核实。

## 抖音

从「内容管理」→「作品」定位视频，打开该条作品的数据详情。按需要分别读取以下模块。

| 模块 | 采集内容与口径 |
| --- | --- |
| 总览 → 流量、粉丝 | 抄录播放量、点赞量、评论量、分享量、收藏量、完播率、`2s跳出率`和涨粉量等页面原值。`涨粉量`和`脱粉量`分别保留。记录选中的新增／累计、每小时／每天视图及统计期。 |
| 流量分析 | 读取平均播放时长、`5s完播率`、平均播放占比、可见的留存与流量来源。比较前记录来源范围及留存图的门槛提示。 |
| 观众分析 | 页面可读时采集该条作品的观众数据。若同时读取账号粉丝数据，另记账号级来源和周期。 |

抖音作品详情提供「数据指标说明」入口。曝光、封面点击率等项目按目标作品页面实际提供情况采集。

## 快手

从「数据中心」→「作品分析」定位视频，打开「作品数据详情」。

| 模块 | 采集内容与口径 |
| --- | --- |
| 核心数据 → 播放数据 | 读播放量、平均播放时长、封面点击率、2秒跳出率、5秒完播率和完播率。按本模块显示的更新状态记录。封面点击率显示为 0% 时保留原值。分母不可见时说明曝光范围未知。 |
| 核心数据 → 互动效果 | 读点赞量、评论量、分享量、收藏量等原值。后台计数与公开页可见评论可能覆盖不同范围，分析评论内容时单独说明实际读到的样本。 |
| 观看分析、流量来源 | 留存曲线和流量来源分别保存，记录页面给出的发布龄限制、统计周期和更新时间。流量来源中若有 `完成播放量`，留在该模块原有口径，只做同一统计条件下的比较。 |
| 数据中心 → 粉丝分析 | 需要账号级数据且页面可读时单独采集。记录粉丝数据的对象与周期。 |

`继续观看用户比例`、个别秒段的跳出提示和核心卡片 `2秒跳出率` 分别读取。是否使用同一人群或分母，以当前页面的指标说明为依据。

## 小红书

从「数据看板」定位该条视频笔记并打开「笔记数据详情」，用笔记标识与「笔记管理」的作品记录对照。笔记状态或推荐限制按该条目的实际审核显示记录。

| 模块 | 采集内容与口径 |
| --- | --- |
| 核心数据 → 基础数据 | 读曝光数、观看数、封面点击率、平均观看时长、完播率、2秒退出率和涨粉数。保留页面提供的粉丝细分及其标签，分别记录实时值和带截止时间的指标。封面点击率直接取平台值。 |
| 核心数据 → 互动数据 | 读点赞数、评论数、收藏数和分享数。按页面分别记录互动值、粉丝占比及按小时／按天趋势的更新时间。 |
| 观看趋势、观看来源、观看人群资料 | 可读时保存当前模块和统计周期。遇到样本门槛或模块未开放，记录页面提示和适用模块，已显示的核心数据照常采集。 |

`2秒退出率` 保留小红书原名。并列展示其他平台的 `2秒跳出率` 时说明各自口径，分母、观看范围或统计期未明确时只作各平台内部解读。报告使用公共汇总表时，标出小红书原指标名及口径缺项。
