# 数据采集与核对SOP

## 定位作品与读取

读取项目规则、运营配置和发布记录，先核对profile、实际账号、平台作品标识、标题与发布时间，再打开对应作品数据。数据优先直接读取后台，无法取得时使用用户导出或截图并标明来源。实际操控与结束清理统一按[阶段01](../../studio-operations-setup/SKILL.md)。不切换到其他账号推算本账号数据，不自动上传、重新发布或开启PK测试。

每次采集保存实际时间及时区、平台更新时间、统计周期、原始指标名称／值、来源入口及必要截图或导出。保存于调用方指定的采集证据位置；每次采集按真实时间区分，保留原始快照，不覆盖先前数值。证据索引写在该次采集资料内，不把后台链接、技术采集方法写入报告作品信息表。避免保存令牌、Cookie、联系方式等无关数据。

## 采集节点与对比

建议按各平台实际发布时间，在发布后24小时、72小时采集，必要时补7天；错过时按实际采集时间记录，不回填严格同龄快照。账号画像／活跃时段可单独补采，写明对象与周期，不混入原单条作品快照。定时任务须有明确调度需求并通过自动化工具创建；SOP本身不表示已经设置或保证无人值守浏览器可用。登录失效时说明阻塞，保留已取得资料。

比较优先在同平台、相近发布龄和统计条件下进行，记录作品实际时长、发布时段、主要流量来源和已知投放情况；未取得投放情况不能写“无投放”。不同平台不共用统一好坏阈值，不把自然发布对比当作严格A/B实验。

保留平台原始值和口径；缺项词及限制的写入位置按[复盘输出映射](../../studio-social-operations/references/运营与制作接续规范.md#复盘输出映射)，公共独立报告使用N/A和对应“注”。曝光、播放、封面点击可能覆盖不同入口，不自行相除替代官方点击率。跳出、分秒留存和完播分母未确认一致时不互换，不用平均观看时长判断所有人在哪秒退出。说明样本量、更新延迟和未开放指标的限制。

## 账号活跃时间与发布建议

分别记录粉丝活跃、作品受众点击、账号实际观看时段等真实对象、统计周期和时区。后台未开放按输出映射填写缺项，不用行业常见时段补齐。平台直接给出的推荐时间与报告基于数据提出的测试建议分开标明；建议需要后续曝光、观看和留存共同验证，不把曲线峰值当成因果证明。

## 成片与此前采用记录

运营复盘默认包含查看和分析本次实际发布的成片，无需每次另问查看授权；这是该任务明确要求的内容读取。先确认发布记录对应的实际文件，再按[视频读取](../../studio-video-study/SKILL.md)查看必要画面、字幕和对白，结合后台数据标记近似时间点与具体内容。仅查询数据、监控指标或用户明确限定为数据采集时，不自动扩展为成片分析。

实际发布文件缺失或版本无法确定时，补齐文件或版本信息，继续不依赖它的采集；不以剧本、提示词或其他剪辑版代替实际成片。仅核对标题、时间、时长时不声称逐帧相同；抽帧、字幕或转写分析须如实记录读取范围，未经查看的内容不补写视觉结论。成片分析尚未完成时，报告明确标为数据阶段或列明缺项，不称完整复盘已完成。

沿调用方映射读取既有采用记录及实际修改依据，区分实际改变、未采用和未验证；核对实际封面与文案快照。将数据事实、原因假设、后续建议与验证结果分开。写入后按所选结构核对数据引用、数字、表头、缺失值及结论证据；公共独立报告另按[报告规范](运营复盘报告规范.md)检查注编号与章节。不更改已发布作品。
