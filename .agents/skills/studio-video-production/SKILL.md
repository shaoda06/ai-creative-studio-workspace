# Studio 共用视频制作流程

## 共用推进顺序

**定位任务与接入点 → 准备当前环节输入 → 开展工作 → 核对结果 → 交回业务接续。**

1. 确定用户本轮所需结果、实际业务、项目、阶段和授权。按所属业务的职责及已确认的状态定位起点；已有可用脚本、素材、候选或成片时从对应环节接续。
2. 读取业务指定的依据、当前版本、规格及接收条件，确定本阶段输入、输出和检查项。阶段范围及确认由业务维护。
3. 按业务指明的问题进入[能力目录](../studio-entry/references/能力目录.md)的对应分类，查用本轮全部适用的能力，可合用多项。采用共用稿件规范，沿明确或已选工具的入口执行。纯讨论、查询、已确定的原任务恢复按实际动作处理。
4. 按业务及所选执行工具核对本轮实际产出、版本和技术结果，沿既有记录登记。
5. 按接收方需求交回结果。送审、采用、返修、剪辑及发布按业务规定和实际授权接续；返修回负责该问题的阶段。

## 制作入口

从脚本进入制作时，调用业务提供已确认的剧本或脚本版本、本次制作范围、画幅、目标时长、声音方案、可用资产、交付要求及执行授权。剧本来源、改写目标和内容确认由业务负责。单独写作或返回上游修改剧本时，按[共用剧本](../studio-screenplay/SKILL.md)及[故事剧本与对白](../studio-entry/references/能力目录.md#故事剧本与对白)完成本次工作，再用确认稿接续制作。

## 阶段接续与交接

接续时，在现有制作或交接记录中引用本轮实际采用的资料、版本和已确认决定，说明各项依据适用的内容。资料有冲突时，回到该事项的原确认记录核对最新有效决定。关键依据仍不明确时，暂缓依赖该依据的工作，其余工作可继续。

交出成果时，按接收方接下来要做的事核对入口、实际版本及所需信息。复用能证明同一入口和版本可用的检查结果。发现问题时，修正原入口或在原记录中写清受影响的范围。交接核对沿用各业务已有的记录和确认流程。

### 成片确认后的封面与结束页

用户明确确认本条视频已完成后，承接本次确认的会话要在当轮主动询问是否生成抖音横版 4:3 封面、竖版 3:4 封面和与最终视频同画幅的结束页。可以选择所需项目，用户明确同意后按选定范围生成。本次已明确是否制作及范围时，直接沿用其决定。封面按[封面制作](../studio-cover-images/SKILL.md)交接，结束页按确认的成片画幅和内容制作，交付沿所属项目的素材入口。

## 工作流选择

每个新的独立视频生成任务都须由用户确认本次工作流，包括已有项目中新开制作、独立样片和另行发起的生成方案。从[视频生成编辑与处理](../studio-entry/references/能力目录.md#视频生成编辑与处理)查适用工作流、兼容范围和差别，说明推荐依据并询问用户，等用户选定后再按该工具准备正式输入及提交。本次任务已明确指定工作流时直接沿用。项目偏好、上一任务的选择和推荐均不能代替本次确认。选型与执行授权分别核对，同一次确认已覆盖的执行批次沿用其选择。

查询、取回、恢复以及依赖原请求、画布或缓存的同一任务接续，按原执行记录使用原工作流。若接续已无法使用原任务、需要另开一项独立生成，则重新确认新任务工作流。

新图像生成任务沿用用户本次指定的工作流、适用的已确认项目选型或明确覆盖本次工作的默认规则。尚无有效选择时查[图像生成与处理](../studio-entry/references/能力目录.md#图像生成与处理)，向用户说明并请其选择。工具选定后按对应规范确定模型模式及专用参数。

## 场次分镜与生成分段

按[阶段接续与交接](#阶段接续与交接)核对本轮分镜的上游依据，再按已确认的制作范围规划。整部作品进入制作时，分镜与制作计划覆盖全片。样片、短测或局部制作按已确认的镜号或时间范围准备，并按实际授权执行。

根据本版脚本，按[共用分镜](../studio-storyboard/SKILL.md)落实逐镜画面、动作、声音和时码。进入生成分段前按[工作流选择](#工作流选择)接续，按选中工具的分段、段长、参考输入和接缝规则核对可执行性。把镜头对应、计划时长、参考用途和跨段依赖写在现有分镜或分段计划中，编号与文件组织由业务确定。

划分生成段后，对照已确认的制作范围，按播放顺序逐镜核对镜号、成片时码和制作方式。每个镜头都应对应到生成段、沿用的素材或独立排版、合成等后期安排，确认镜号和成片时间线都覆盖完整。

镜头和动作设计查[分镜动作与提示词](../studio-entry/references/能力目录.md#分镜动作与提示词)，把本轮取景、动作和衔接方法落实到实际分镜。

## 导演分镜表选择

由分镜阶段按[导演分镜表制作规范](../studio-storyboard/references/导演分镜表制作规范.md#用途与制作范围)完成询问及选做，再接续生成资产准备。制表所需参考按业务接入准备，其用途与后续模型输入分别核对。

## 生成资产与提示词

从本环节直接接续时，按[阶段接续与交接](#阶段接续与交接)核对本批实际使用的分镜及素材依据。新生成任务按[工作流选择](#工作流选择)确定工作流，再准备与其模式对应的正式输入及提示词。

接续逐镜核对、资产准备和提示词时，按[导演分镜表的用途边界](../studio-storyboard/references/导演分镜表制作规范.md#用途与制作范围)核对制作依据。

资产可以按共用关系和依赖分批准备，生成任务也可按已确认的计划分批执行。在原计划或生产记录中分别写明整体制作范围、本批已备素材覆盖的镜头、本批实际执行范围和待补项。局部素材先备齐，只说明对应镜头的准备进度，不据此缩小制作范围或另立视频试片环节。

写某段正式生成提示词前，按[镜头状态与参考差异](../studio-storyboard/references/分镜写作规范.md#镜头状态的变化延续与参考差异)及[实际参考核对](../studio-video-prompts/references/视频提示词制作规范.md#内容依据与实际参考)核对该段实际需要的参考图、首帧、参考视频、音色或音频样本。已有资产引用准确版本，缺项交相应资产阶段准备。后段需要把已生成的末帧或音视频作为独立输入时，先记明依赖，来源可用后再完成该段资产核对及正式提示词。依照业务规定的执行批次和送审条件接续已就绪的范围。

业务确定资产设计、资格和采用。排参考图制作批次和准备本段参考图时查[参考资料与风格](../studio-entry/references/能力目录.md#参考资料与风格)，落实依赖、可并行范围、参考用途和画面目标。需要制图、尺寸处理或裁切音频时查[图像生成与处理](../studio-entry/references/能力目录.md#图像生成与处理)或[音频查找分析与处理](../studio-entry/references/能力目录.md#音频查找分析与处理)，按实际授权处理并核对返回文件。

资产齐备后，按[共用视频提示词](../studio-video-prompts/SKILL.md)转写本版分镜、对照实际参考并完成同版中文参考。按需将[分镜动作与提示词](../studio-entry/references/能力目录.md#分镜动作与提示词)中的转写方法落实到本段模型正文。正文格式、标签与输入语义沿所用模型及模式的规则。

## 请求核对与生成

新生成任务按[工作流选择](#工作流选择)接续。将计划与实际请求对照，核对段序、请求时长、画幅、模式、工作流配置，以及真实文件版本、上传结果与模型标签或槽位的对应。

按[阶段接续与交接](#阶段接续与交接)在本轮原记录中引用实际制作依据。采用尚未验证的做法且可能导致大范围返工时，提交前按[文本审查与制作返修](../studio-entry/references/能力目录.md#文本审查与制作返修)核对可行性，结论记在本轮计划或制作记录中。

按本次有效授权和所用工作流提交。使用 ComfyUI 时通过[共用通信](../studio-comfyui/SKILL.md)与[任务后台](../studio-workspace-browser/SKILL.md)提交、查询和取回。仅准备的任务交付当前资料，执行接续以实际授权为准。

## 候选与技术结果交回

按所用工作流的取回规则核对候选和技术结果，复用已有凭据与报告；有局部段接回、整场登记等要求时按实际工具入口办理。需要核对媒体规格时查[视频生成编辑与处理](../studio-entry/references/能力目录.md#视频生成编辑与处理)。通过原执行及关联记录交回候选文件与版本、对应场次或分段、实际脚本／分镜版本、提示词与素材输入、原请求、任务标识及技术结果。业务按自己的审阅范围组织送审，审阅和采用决定写原业务记录。

交回本批候选时，按[阶段接续与交接](#阶段接续与交接)核对业务方实际使用的审阅入口和对应结果。候选审阅或剪辑交接需要查找补用音效、核对指定声音的落点或响度、比较混音版本时，查[音频查找分析与处理](../studio-entry/references/能力目录.md#音频查找分析与处理)，把素材来源、测量或待试听时码交回原业务记录。

任务中断、取回或登记失败时，按[后台异常与恢复](../studio-workspace-browser/references/进度查询与结果处理规范.md#异常与恢复)或实际执行工具的恢复入口接续原任务。收到内容反馈时，业务按[文本审查与制作返修](../studio-entry/references/能力目录.md#文本审查与制作返修)确定返回的阶段与范围。

## 按业务决定调用执行工具

业务明确需要继续生成时，按所选工作流接续已确认的来源与执行授权，再按[请求核对与生成](#请求核对与生成)和[候选交回](#候选与技术结果交回)处理该轮。缓存、组序、局部返修和合片由原工作流规范确定。需要新选后处理能力时，提供获批源片、处理目标及执行授权，查[视频生成编辑与处理](../studio-entry/references/能力目录.md#视频生成编辑与处理)并将实际输出及技术报告交回业务。
