# 运营项目README规范

本规范只说明运营任务从调用方README或等效入口需要读取的信息，不定义项目目录、工作区归属或README固定章节。项目建立、编号、模板和状态位置由所属业务建档规则维护；已有项目沿原入口接续，独立运营任务同样由调用方明确对象与资料范围。

入口应能定位所属业务规则、账号配置、当前发布对象、成片与采用依据、唯一状态记录，以及本次需要的运营资料位置。字段与填写方式见[运营配置模板](../templates/项目运营配置模板.md)；已有同等信息直接引用，不要求复制为第二份配置或项目README。

账号配置可以属于账号、项目或其他业务对象，多件作品引用同一份配置。README只提供导航及专用约定，不重复保存账号凭据、发布事实、指标和待办表。缺少当前任务必要信息时补齐对应入口，不猜所属工作区、不创建重复制作项目、不把建档视为发布授权。
