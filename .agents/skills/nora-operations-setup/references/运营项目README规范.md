# Nora运营项目README规范

本规范只维护运营业务的项目入口。对已有创作项目开展运营，沿用其唯一项目README，在原资料入口链接10-社交媒体资料及运营配置，不另建运营项目根目录、不复制一份项目规则。项目创作目录仍归原业务，账号、发布、数据及复盘资料结构沿[运营规范](运营启用与账号连接规范.md)。

用户明确建立独立运营项目时，项目目录仍在Nora资料区projects下，按实际项目名称保存；使用[运营项目模板](../templates/运营项目README模板.md)。一级标题为实际项目名称，六个二级标题固定为项目说明、项目专用约定、目录与资料入口、进度与版本入口、接续要求、历史与特殊事项。内容分别填写实际运营对象与业务入口、本项目独有约定、运营配置及相关资料链接、唯一状态记录入口、身份/权限及当前任务读取要求、必要历史说明。没有的专用约定或历史注明暂无，不预建发布、账号或数据记录。

项目README不另存账号凭据、发布结果、数据指标和待办表，不以配置账号或创建目录替代发布授权。没有既有状态文件时先明确一份项目状态入口，不同时建立多份进度表。已有项目保留其状态文件名和专用约定，不因模板整理改变身份、采用或发布事实。
