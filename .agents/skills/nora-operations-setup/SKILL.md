# Nora 运营启用与账号连接

读取[运营启用与账号连接规范](references/运营启用与账号连接规范.md)，首次建立配置使用[项目运营配置模板](templates/项目运营配置模板.md)。输入为项目发布意向、平台账号和可用浏览器；输出为项目配置及真实连接状态。使用任何后台前执行账号核对，结束时执行同规范的标签组、页面和窗口收尾。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
