# Studio 运营启用与账号连接

首次接入或对象变化时，按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、实际对象、资源版本和记录入口；直接调用本阶段也沿用该映射，不决定工作区或项目结构。

读取[运营启用与账号连接规范](references/运营启用与账号连接规范.md)，首次建立配置使用[项目运营配置模板](templates/项目运营配置模板.md)。输入为调用方的发布意向、平台账号和可用浏览器；输出为账号配置及真实连接状态。使用任何后台前执行账号核对，结束时执行同规范的标签组、页面和窗口收尾。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。

核对调用方入口时读取[运营项目README规范](references/运营项目README规范.md)；项目建档和README模板归所属业务，本阶段只补齐运营接入信息，不另建项目。
