# Songssx 导演台

规划 GEN、编写或修订提示词、核对已备提示词并装配新任务时，按[上游资料的读取入口](references/ComfyUI-Songssx导演台使用规范.md#上游资料的读取入口)读本地保存的适用章节。涉及已生成视频的局部返修时，读[局部返修](references/ComfyUI-Songssx导演台使用规范.md#局部返修)。

装配前按[参数选择与装配前询问](references/ComfyUI-Songssx导演台使用规范.md#参数选择与装配前询问)落实配置，再按[使用规范](references/ComfyUI-Songssx导演台使用规范.md)提供已确认的 P 段、提示词、素材和接续意图。每个 P 对应一个 GEN，每个场次保存一条 MP4。业务负责批准和采用。
