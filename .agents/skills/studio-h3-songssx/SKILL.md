# Songssx 导演台

先按[参数选择与装配前询问](references/ComfyUI-Songssx导演台使用规范.md#参数选择与装配前询问)落实本次配置，再按[使用规范](references/ComfyUI-Songssx导演台使用规范.md)提供已确认的 P 段、提示词、素材和接续意图。提示词格式和参考语义读[共用 H3](../studio-h3/SKILL.md)。每个 P 对应一个 GEN，每个场次保存一条 MP4。业务负责批准和采用。
