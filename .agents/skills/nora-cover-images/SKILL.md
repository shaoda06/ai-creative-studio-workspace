# Nora 封面制作

媒体原件、处理和返修结果按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存，原索引和工作稿引用准确资源版本；采用不复制到另一目录，审核与版本依据保持原业务分工。

设计、候选、采用与更新读取[封面制作与管理规范](references/封面制作与管理规范.md)，上传适配读取[平台封面规格库](references/平台封面规格库.md)。新建资料使用[封面索引模板](templates/封面索引模板.md)与[封面制作工作稿模板](templates/封面制作工作稿模板.md)。项目通用和单集封面均为横竖成套；输入为定位、素材、本集内容及相关复盘，输出为正式图与真实采用记录。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
