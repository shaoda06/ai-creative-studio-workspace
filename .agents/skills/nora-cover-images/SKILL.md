# Studio 封面制作

首次接入或对象变化时，按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、实际对象、资源版本和记录入口；直接调用本阶段也沿用该映射，不决定工作区或项目结构。

媒体原件、处理和返修结果按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存，原索引和工作稿引用准确资源版本；采用不复制到另一目录，审核与版本依据保持原业务分工。

设计、候选、采用与更新读取[封面制作与管理规范](references/封面制作与管理规范.md)，上传适配读取[平台封面规格库](references/平台封面规格库.md)。调用方已有固定记录时按[业务记录映射](references/封面制作与管理规范.md#业务记录映射)接入；未提供映射时新建资料使用[封面索引模板](templates/封面索引模板.md)与[封面制作工作稿模板](templates/封面制作工作稿模板.md)。项目通用和单作品封面均为横竖成套；输入为定位、素材、当前作品内容及相关复盘，输出为正式图与真实采用记录。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
