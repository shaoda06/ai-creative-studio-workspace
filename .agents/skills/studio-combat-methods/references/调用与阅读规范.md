# 打戏方法的调用与阅读

## 业务接入与边界

共用方法接收调用方已经明确的剧情目的、人物能力、空间、风格和本次任务，服务剧本动作、分镜或已确认动作的提示词转写。业务负责内容来源、格式、镜号与分段、批准和交付；方法直接调用也沿实际项目约定。已确认内容、调用业务的授权和交付要求优先，方法中的案例、数值及条件建议只用于当前适用问题，不成为强制剧情或制作配额。

只写剧本时落实人物目的、动作因果、状态和结果，摄影与模型格式留到对应阶段；分镜设计覆盖来源中的动作、对白、声音及接续。方法落入当前业务产出和既有自检，不创建另一份分镜、状态台账或审批。缺少会改变已确认内容的依据时交回业务负责人，不在转写中补编。

模型正文的语义转写由调用业务负责，实际格式与运行条件读对应模型工具；H3使用[H3工具](../../studio-h3/SKILL.md)，明确任务交[ComfyUI](../../studio-comfyui/SKILL.md)和[任务后台](../../studio-workspace-browser/SKILL.md)，本方法不生成媒体。素材查看、重试、模型切换及采用仍按实际授权。

原套装中的short-drama-director、validate_prompt.py、图N、固定整秒、默认反杀、输出封装及机检门是原套装上下文，不自动成为调用业务的格式、权限或必须剧情。实际模型限制仍执行。

## 专项选择与适用条件

按本场动作性质选择通用、写实或玄幻；跨专项只读取当前问题需要的方法，不三套全读。业务调用顺序由调用方维护，方法选择不改变其阶段。

强度、镜数、贴身比例、静止及手绘化建议连同档位、适用条件和不适用情形读取，不把个案扩大成通用硬限制。固定/重复构图、慢镜、特写、正反打及长镜按实际表达判断；修改指出具体信息、表演、空间或节奏损失，不为变化强制切镜或加运镜。镜头表达使用[共用分镜写法](../../studio-storyboard/references/分镜写作规范.md)，业务补充要求由调用方提供。

## 完整制作与局部修改

首次完整制作一场打戏或大幅重排攻防时，按所选专项的专业步骤完成本阶段适用部分；已读且未变的方法复用。选镜与安排时长前读[力度与节奏默认建议](combat-intensity-guardrails.md)和[动作负荷与可读性](combat-rhythm-and-load-guardrails.md)的适用部分用于起稿，自检再核对已写的动作、受力、构图和时长，不以拍法自由跳过检查。

局部修改保留已成立的构思和未受影响设计，只补读当前问题及必要前后状态；牵动整场因果或空间时覆盖受影响完整链。错字或格式修订不重做动作设计。仅转写已确认分镜时沿原动作和素材映射，缺动作依据才交回补齐，不重做整场。

跨专项的节奏负载/激烈度直读上述当前档位；特效笔法读[介质与分层](vfx-rendering-mandate.md)，不因引用一个章节加载另一技能的全部内容。各专项仍维护自己的招式、动力链、摄影、法术及案例，不复制另一份专业库。
