# Studio 创作与制作总入口

先识别当前任务、所属业务和项目。具体业务进入对应业务阶段，并按[共用推进顺序](../studio-video-production/SKILL.md#共用推进顺序)接续；单独的工具或维护任务按实际目标直达对应入口。已有明确阶段时直接接续，沿用适用的用户授权和项目约定。

## 共用视频制作核心

[共用视频制作流程](../studio-video-production/SKILL.md)维护定位、准备、开展、核对和交回的共用顺序，以及确认脚本后接续到视频候选和技术结果的专项流程。所属业务提供具体阶段的资料、做法、规格和完成条件。

新制作或已有任务的接续按[共用工作流选择](../studio-video-production/SKILL.md#工作流选择)确定工作流。

## 共用附加能力

按本轮任务或业务指定的类别进入[能力目录](references/能力目录.md)，查阅全部适用条目，可以组合使用。已确定的工具和原任务从实际入口接续。

单独测量人物身形，或比较多个参考、版本的人物比例时，直达[人物比例分析](../studio-character-proportions/SKILL.md)。

所有业务与公共技能统一在总目录.agents/skills中维护。Nora资料在workspaces/Nora Workspace，Iris资料在workspaces/Iris Workspace，Chloe资料在workspaces/Chloe Workspace；先明确真实项目，读取所属资料区README、项目README和唯一进度或状态文件，再按同库入口接续。用户只需从总工作区新建对话，不要求切换到子目录发现技能。

调用公共脚本时显式传入所属资料空间或实际项目，不以脚本所在总目录判断业务归属。后台查询与通知按[任务空间接续](../studio-workspace-browser/references/浏览服务使用规范.md#项目空间与统一入口)执行。

业务确定内容、交付规格、素材资格、采用及完成条件。核心维护共用顺序，能力目录维护工具和方法的适用情形，工具维护模型和接口要求。Agent负责理解、创作与语义核对，脚本负责确定性装配、文件处理和执行。

## 维护入口

技能维护、查找能力或工程辅助按[工作区与技能维护入口](references/工作区与技能维护入口规范.md)分流。跨体系结构及唯一真源要求见[结构维护](维护规范.md#规则真源与引用)。队列、项目浏览及后台开发使用[浏览服务与任务后台](../studio-workspace-browser/SKILL.md)。


## 工作区说明与项目建档

首次下载或新增一级子工作区时，按[各业务初始化入口](references/一级子工作区结构与README规范.md#初始化与分发)创建本地资料区；已有工作区直接接续。新增一级子工作区时读取[工作区结构与README规范](references/一级子工作区结构与README规范.md)及其模板。业务项目结构和README由对应业务建档入口维护，具体映射见该规范，不在统一入口复制业务细则。后两层README按实际项目主动读取，AI Creative Studio根AGENTS.md保留全局指令。
