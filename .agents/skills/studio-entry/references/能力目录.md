# Studio 能力目录

按本次任务和业务阶段查阅适用分类。每项集中登记适用情形、所需输入、结果和实际入口。技能跨分类时，其他分类直接链接该条目。按所有命中的问题选读，可以合用多项能力，复用已读且仍适用的内容。用户明确指定技能或工作流时从其实际入口接续；读取能力和取得执行授权分别判断。

**阅读方式**。先核对条目的全部适用情形及业务、平台或素材条件，再读实际技能的入口和相关章节。具体操作、协议和模板由条目所指的技能维护。已选择的工具及原任务的技术依赖随其执行规范生效。独立技能按名称发现，获取方式、版本及许可见[依赖登记](../维护规范.md#独立第三方技能登记)；缺少独立方法时说明受影响的内容，缺少指定执行依赖时从对应入口处理。用户点名或已发现的适用能力可直接读取实际入口。

**维护方式**。新增或更新条目时逐项对照技能说明和 Studio 现行调用条件，覆盖全部适用情形、限制和入口。不同范围分开写，例如第三方技能本身的用途与 Studio 业务接入条件。核心和业务阶段引用能力分类并说明结果用途；安装资料、操作细节、业务规则和结果记录由实际维护者各写一处。

### 山音编剧方法

`screenwriting-master` 的原技能适用于影视点子和故事构思、人物设计、结构大纲、节拍表、Save the Cat／Story Circle／McKee、场景拆解、完整剧本及剧本诊断。覆盖概念超短片（how-to-tell／what-if）、叙事短片、电影长片和多集剧集。按名称发现实际安装入口。

Nora 的现行适用情形见下表。命中时通过本目录自动查用，无需用户点名。复用本轮已读方法，按问题补读，与当前稿件及相关审查合并处理。

| Nora 适用情形 | 选读范围 | 落实重点 |
| --- | --- | --- |
| 编写本集剧本，或实质性修订场景、动作、对白 | `references/core-methodology.md` 的「一、戏剧动作」「二、人物设计」「三、视听化写作」；节奏问题补读「六、双轨节奏系统」，跨集承接问题补读 `references/format-series.md` 的「角色状态追踪」「已公开信息清单」 | 依据已确认大纲与人物资料，把目标、阻力、行动结果、情绪变化和可见／可听表达写入本集场景和交流。 |
| 编写或实质修订场次分镜，包括镜头设计、切镜、对白覆盖或站位接续 | 核心方法中的戏剧动作和视听化写作；需要镜头方案时补读 `references/format-ultrashort.md` 的「视听语言武器库」中相关镜头、剪辑和画面构成 | 在既有逐镜字段和分段安排中，核对动作和镜头如何承担叙事作用、展示过程和揭示信息。视线、受力、持物、镜长和分段按 Nora 规则。 |
| 剧本或分镜的文本交付前合并自检 | 核心方法「四、自检体系」中与当前文本相关的条目 | 看抽象描述、无因动作、表演与情绪脱节、无效重复及场景跳变，在既有自检中按授权订正。 |

在 Studio 业务中以既定剧情、人物关系及已知信息为依据，保留获准的对白、内心独白、旁白和必要直接表达。结构比例、反转、固定节奏及字数估时作为参考，实际片长、逐句测时、动作和生成容量按业务与工具要求。使用既有正文、场头、索引、分段状态或记录承接方法；上游八步流程、逐步暂停与审批、季度规划、追踪表、节奏图、记忆检查点、评分报告及另开会话均不随参考方法引入。纯错字、格式、记录维护、生成执行、技术排查、进度查询及模型提示词转写不触发上述 Nora 接入。安装和平台触发设置见[依赖登记](../维护规范.md#独立第三方技能登记)。

## 剪辑动效与导出
