# 工作区与技能维护入口规范

技能结构、规则、资源和分享按[维护路径](../维护规范.md#维护任务读取路径)处理，并按[自动复查](../维护规范.md#维护落地后的自动复查)完成收尾。

寻找技能、工程维护、范围取舍或表述审阅，进入[技能与工程维护](能力目录.md#技能与工程维护)查用实际能力。风格资源查[参考资料与风格](能力目录.md#参考资料与风格)。安装及升级按[依赖发现与获取](../维护规范.md#外部依赖的发现与获取)和实际授权处理。

修改共用网页代码先按总工作区授权及[浏览后台维护](../../studio-workspace-browser/references/浏览后台开发维护规范.md)确定范围。ComfyUI 节点及模型部署遵守该任务的实际授权。
