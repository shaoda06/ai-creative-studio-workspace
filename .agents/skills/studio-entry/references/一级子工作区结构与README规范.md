# 一级子工作区结构与README规范

## 归属与边界

本规范由AI Creative Studio总工作区维护，只规定Nora、Iris、Chloe等一级子工作区的命名、基础结构和说明入口。项目编号、业务阶段目录、项目README及建档方法由对应业务维护，不在本规范复制。总入口只登记和引用规范。

## 工作区结构

- 一级子工作区位于总目录的`workspaces/`，使用英文女生名开头，目录名为`名字 Workspace`。工作区专用的一级、二级业务技能使用同名英文小写前缀；公共能力的命名及提炼迁移按[技能命名规则](../维护规范.md#技能命名与旧入口退役)。
- 工作区根目录使用`README.md`作为定位、独有约定和资料导航入口，不另建工作区级AGENTS.md。AI Creative Studio根AGENTS.md及开发工具自身的局部指令不受此约定替代。
- 默认由`projects/`保存独立业务项目；Chloe按其建档规范在工作区根目录直接保存具名项目，各项目内部保留自己的`projects/`视频目录；`综合资料/`保存该工作区跨项目资料，首次需要时建立；业务已规定固定骨架时按其初始化规范建立。已有配置、历史归档及独立Git按实际用途保留，不据此自动创建空目录。
- 技能、业务规范、模板和共用工具统一在总目录`.agents/skills/`维护。资料区不复制技能库、不另启浏览后台或任务监控器。
- 新建工作区按本规范及[模板](../templates/一级子工作区README模板.md)填写真实名称、业务入口和路径；空间登记及数据库位置按共用浏览服务的[运行资料维护规范](../../studio-workspace-browser/references/任务运行资料维护规范.md)执行。后台自动在总服务内建立独立任务库，不在业务资料区创建服务目录，不把创建资料目录视为已完成登记。

## 初始化与分发

公共仓库提供各业务自己的脚本、README模板和流程；实际workspaces目录全部留本地。Nora按[定位建档初始化](../../nora-drama-positioning/references/工作区与初始化规范.md)，Iris按[需求建档初始化](../../iris-commercial-brief/references/工作区与初始化规范.md)，Chloe按[账号建档初始化](../../chloe-positioning/references/工作区与初始化规范.md)执行。业务目录、内容和建档时机归各业务，共用文件创建及空间登记由studio-workspace-browser/scripts/workspace_setup.py提供。

初始化只补缺失骨架，不覆盖现有README、项目、配置或独立Git。公共模板不预填真实账号、项目清单、历史状态或已采用版本。任务库和凭据由统一后台建立，初始化不复制它们、不启动生成。

## README固定写法

一级标题为工作区英文名与业务说明。以下六个二级标题按顺序保留；其下可用三级标题展开，已有外部引用的章节锚点继续保留。

| 二级标题 | 内容 |
| --- | --- |
| 工作区定位与业务范围 | 名字、所属总工作区、业务范围及必要边界 |
| 一级业务入口 | 本工作区实际负责的一级业务及其技能链接，不抄业务流程 |
| 目录结构与资料存放 | 实际项目、综合资料、配置和历史目录的用途；不规定业务阶段目录 |
| 项目索引入口 | 链接按[共用规范](../../studio-workspace-browser/references/项目总索引规范.md)建立的项目总索引；尚无项目时说明待首次建档建立，不复制项目清单或进度表 |
| 工作区专用约定 | 仅本工作区有效的约定；通用约定引用根AGENTS，实际任务授权和状态仍归项目 |
| 项目接续与相关资料 | 进入项目时读取其README及状态文件，提供能力状态、接续及历史说明入口 |

README是需要Agent主动读取的业务说明与规则文件，不宣称由Codex默认自动注入。新增业务时更新真实业务入口；项目状态变化不要求重写工作区README。

## 项目层的维护入口

- Nora连续短剧：项目结构沿定位建档阶段及其引用的业务结构规范，项目README使用该阶段的[规范](../../nora-drama-positioning/references/项目README规范.md)和模板。
- Studio社媒运营：项目结构和README由所属业务建档阶段维护；公共运营仅规定[接入信息要求](../../studio-operations-setup/references/运营项目README规范.md)，不选择资料区或创建另一套项目结构。
- Iris商业视频：项目结构与README由[需求建档阶段](../../iris-commercial-brief/references/项目建档与README规范.md)维护。
- Chloe视频带货：工作区与具名项目骨架由[账号定位建档](../../chloe-positioning/references/工作区与初始化规范.md)维护，单条视频结构与README由[视频创意建档](../../chloe-creative/references/视频项目与脚本规范.md)维护。

新增一级业务必须明确自身项目结构与README的维护入口，不直接套用另一个业务的阶段目录。已有项目专用约定继续在其适用范围内执行。
