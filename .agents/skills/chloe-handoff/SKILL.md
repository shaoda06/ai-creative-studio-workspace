# Chloe 剪映交接与成片接续

任务关联已有项目时，先核对[项目专用约定](../chloe-commerce-video/references/会话组织与接续规范.md#项目专用约定的记录与执行)。项目内交接和接收成片按[进度与运营接续](../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)确定承接会话和原记录位置。

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

准备或继续剪映交接、接收人工成片时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取相关建议及已有T记录；J交接或实际K核对中的T关联、清单与成片落实依据的交回按[阶段记录落点的剪映交接项](../chloe-review/SKILL.md#阶段记录落点)执行。

## 剪辑方案

用用户提供的素材或已有制作文件开始，按任务查[参考资料与风格](../studio-entry/references/能力目录.md#参考资料与风格)及[剪辑动效与导出](../studio-entry/references/能力目录.md#剪辑动效与导出)。根据要保留的动作、表情或商品展示细节，提出可定位的选段、顺序、切点与节奏建议。接续参考分析时沿用适合本条的结论；仅讨论剪法时交回方案，有明确剪辑任务时按本次授权采用合适能力。

给已有视频配 BGM 或背景音时，按[剪辑配乐与原视频音轨](../studio-video-production/SKILL.md#剪辑配乐与原视频音轨)确认声音方案。

穿搭动作要卡点、重排或修顺跳接时，先按[在动作中切镜的剪辑与返修方法](../studio-creative-techniques/references/在动作中切镜指南.md#剪辑与返修怎么用)核对实际素材和接点，将选段及复看结果写进已有剪辑资料。

已有视频需要选择或调整影调时，查[视频调色指南](../studio-creative-techniques/references/视频调色指南.md)。剪辑、调色、整片补帧或音频修改结果送审，或按用户要求直接替换成片时，按[整片后期轮次](../chloe-production/references/视频制作流程与记录.md#整片后期轮次)登记主播放、来源和对照。

## 正式剪映交接

读取视频README的采用组合和制作记录，核对实际轮次、准确文件版本与交接顺序。正式交接使用完整的已采用组合。浏览临时下载按[共用制作页](../studio-workspace-browser/references/业务接入规范.md#完整制作页共用)执行。

先查视频 README 的剪映交接行、已有清单和本轮结果。清单已生成时，核对与当前采用组合一致后复用。缺少清单时，按实际轮次和采用顺序在 `剪辑交接/` 补齐唯一的 `.jianying.json` 清单和交接行。准确引用和按需打包按[共用剪映工具](../studio-jianying/SKILL.md)及[媒体清单下载](../studio-workspace-browser/references/业务接入规范.md#项目媒体清单与剪映下载)执行。

由本阶段补齐清单时同步填写README的剪映交接行，记录实际时间和采用依据。逐段输出按原顺序引用已采用片段，整场输出在时间线上只引用一次。清单字段按[共用剪映媒体清单](../studio-workspace-browser/references/业务接入规范.md#项目媒体清单与剪映下载)填写。片段采用变更按[固定资料的采用记录](../chloe-positioning/references/固定资料写法规范.md#行身份与更新方式)填写。新组合新建清单及J记录，重复下载或普通改名复用原清单。J状态记录清单核对、可下载或实际交接的事实。

正式交接前运行固定资料及视频制作检查，按[共用阶段接续与交接](../studio-video-production/SKILL.md#阶段接续与交接)核对实际交给用户的清单入口，通过后登记实际交接状态。当前阶段按实际交接或人工后期的事实更新。

如交接需要项目外共用媒体，先说明现有网页清单的项目边界；不复制共用资产来伪装兼容。

## 成片接续

用户确认本条视频完成时，按[成片确认后的封面与结束页](../studio-video-production/SKILL.md#成片确认后的封面与结束页)询问所需物料，按既有职责交接给运营会话。

用户提供已导出的成片，或明确选用已采用的视频文件作为成片时，核对准确文件，按[视频README的成片与状态规则](../chloe-creative/references/视频项目与脚本规范.md#视频readme)保存到本视频 `成片/` 并记录已明确的进度。用户已明确该条制作完成时，按[进度与运营接续](../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)交回确认的成片与相关依据。

用户要求录入已导出的视频时，可以用作品页成片目录的「上传」，或用浏览服务的 Python 环境运行 [成片录入脚本](scripts/chloe_publication_browser.py)，传入 `--project-root <具名项目绝对目录> --video <作品目录名> <视频原件绝对路径>`。两者使用同一入口保存视频原件，同名时请选用不同文件名。列表从实际成片目录读取，采用和发布决定沿上文接续。
