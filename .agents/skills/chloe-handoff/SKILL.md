# Chloe 剪映交接与成片接续

接续本条交接、人工后期结果或转入运营时，先核对[项目专用约定](../chloe-commerce-video/references/会话组织与接续规范.md#项目专用约定的记录与执行)，再按[进度与运营接续](../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)确定承接会话和原记录位置。

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

读取视频README的采用组合和制作记录，并按[视频制作流程](../chloe-production/references/视频制作流程与记录.md#采用交接与页面)中的整片轮次确认顺序、真实文件、包内名称及本次交接范围。正式交接不自动纳入未采用候选，文件更新也不自动替换已确认组合。浏览页临时下载另按所选轮次完整分段顺序读取视频，混合阶段也一起打包，允许未采用候选进入本次下载的剪映时间线；这不构成正式采用或交接，也不新增清单及J记录。

准备或继续剪映交接、接收人工成片时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取相关建议及已有T记录；J交接或实际K核对中的T关联、清单与成片落实依据的交回按[阶段记录落点的剪映交接项](../chloe-review/SKILL.md#阶段记录落点)执行。

先查本轮后台 `business_sync.handoff`、视频 README 的剪映交接行及其已有清单。已生成时，核对该清单与当前采用组合并复用。全轮直接沿用二采或缺少清单时，由本阶段按相同轮次和采用顺序在 `剪辑交接/` 补齐唯一的 `.jianying.json` 清单和交接行。准确引用和按需打包按[共用剪映工具](../studio-jianying/SKILL.md)及[媒体清单下载](../studio-workspace-browser/references/业务接入规范.md#项目媒体清单与剪映下载)执行。

用户在剪映完成人工字幕、音轨、转场及精剪，再将成片导出到本视频`成片/`。正式交接的时间线以本轮已采用片段及顺序为准。

由本阶段补齐清单时同步填写README的剪映交接行，链接该清单，记录实际交接时间和采用依据。时间线中`timeline:true`的条目须与交接时已存在的一轮完整分段组合按准确文件及顺序一致，每段在交接时须已采用；`timeline:false`只入素材箱，不占用分段位置。片段采用变更按[固定资料的采用记录](../chloe-positioning/references/固定资料写法规范.md#行身份与更新方式)填写，以便新版采用后仍可核对旧交接。新组合新建清单及J记录，旧清单保持原组合；重复下载不新增记录。运行固定资料检查和视频制作check，检查通过后才标记可下载或已交接。

README记录片段采用和草稿交接事实，人工后期仍属制作中。用户明确制作完成后将视频状态改为待发布；成片已放入对应目录时，立即按[自动接续触发条件](../chloe-positioning/references/社媒运营接入规范.md#自动接续触发条件)主动开始横竖封面及发布资料准备，无需用户单独提醒。成片直接留在本视频成片目录，不另登记编号、版本、规格或确认状态；发布时才在发布记录直接引用用户明确使用的实际文件，不按修改时间猜测。不得再导入资源区形成副本；现有资源图片直接作封面也只引用原件。

如交接需要项目外共用媒体，先说明现有网页清单的项目边界；不复制共用资产来伪装兼容。接续人工成片结果后，按[进度与运营接续](../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)完成制作与运营会话的交接，后续发布准备由该规则指定的会话承接；交付不等于发布授权。
