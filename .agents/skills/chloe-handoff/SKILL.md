# Chloe 剪映交接与成片接续

接续本条交接、人工后期结果或转入运营时，按[进度与运营接续](../chloe-commerce-video/references/会话组织与接续规范.md#进度与运营接续)确定承接会话和原记录位置。

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

读取视频README的采用组合和制作记录，并按[视频制作流程](../chloe-production/references/视频制作流程与记录.md#采用交接与页面)中的整片轮次确认顺序、真实文件、包内名称及本次交接范围。未采用候选不能自动进入时间线，文件更新也不自动替换已确认组合。

在本视频`剪辑交接/`保存一份对应组合的`.jianying.json`清单，格式和导出按[共用剪映工具](../studio-jianying/SKILL.md)及[媒体清单下载](../studio-workspace-browser/references/业务接入规范.md#项目媒体清单与剪映下载)。清单引用项目内准确视频资源路径，不复制片段。普通浏览不生成包，用户点击下载时临时打包；用户明确要求时才主动生成交付包。已有编辑过的草稿不作为缓存清理。

当前公共剪映工具只按明确视频顺序建立原速、原声轨道，不能把额外字幕、独立音轨、转场或精剪承诺成已实现能力。默认由用户在剪映完成后期，再将成片导出到本视频`成片/`；Agent不自动渲染最终成片。

清单落盘时同步填写README的剪映交接行，链接该清单，记录实际交接时间和采用依据。时间线中`timeline:true`的条目须与交接时已存在的一轮完整分段组合按准确文件及顺序一致，每段在交接时须已采用；`timeline:false`只入素材箱，不占用分段位置。片段采用变更按[固定资料的采用记录](../chloe-positioning/references/固定资料写法规范.md#行身份与更新方式)填写，以便新版采用后仍可核对旧交接。新组合新建清单及J记录，旧清单保持原组合；重复下载不新增记录。运行固定资料检查和视频制作check，检查通过后才标记可下载或已交接。

README记录片段采用和草稿交接事实，人工后期仍属制作中。用户明确制作完成后将视频状态改为待发布。成片直接留在本视频成片目录，不另登记编号、版本、规格或确认状态；发布时才在发布记录直接引用用户明确使用的实际文件，不按修改时间猜测。不得再导入资源区形成副本；现有资源图片直接作封面也只引用原件。

如交接需要项目外共用媒体，先说明现有网页清单的项目边界；不复制共用资产来伪装兼容。进入发布环节后按[本业务运营接入](../chloe-positioning/references/社媒运营接入规范.md)完成目录检查、发布资料准备及页面核对，再选择手动发布或公共发布技能代发；交付不等于发布授权。
