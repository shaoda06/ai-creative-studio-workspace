# Chloe 剪映交接与成片接续

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

读取视频README的采用组合和制作记录，确认真实文件、顺序、包内名称及本次交接范围。未采用候选不能自动进入时间线，文件更新也不自动替换已确认组合。

在本视频`剪辑交接/`保存一份对应组合的`.jianying.json`清单，格式和导出按[共用剪映工具](../studio-jianying/SKILL.md)及[媒体清单下载](../studio-workspace-browser/references/业务接入规范.md#项目媒体清单与剪映下载)。清单引用项目内准确视频资源路径，不复制片段。普通浏览不生成包，用户点击下载时临时打包；用户明确要求时才主动生成交付包。已有编辑过的草稿不作为缓存清理。

当前公共剪映工具只按明确视频顺序建立原速、原声轨道，不能把额外字幕、独立音轨、转场或精剪承诺成已实现能力。默认由用户在剪映完成后期，再将成片导出到本视频`成片/`；Agent不自动渲染最终成片。

README分别记录片段已采用、草稿可下载、待人工后期和人工成片已确认。接收成片时明确文件和版本、真实规格及读取范围；多个版本不按修改时间猜采用。网页直接引用该文件，不再导入资源区形成副本；现有资源图片直接作封面也只引用原件。

如交接需要项目外共用媒体，先说明现有网页清单的项目边界；不复制共用资产来伪装兼容。已确认成片进入[本业务运营接入](../chloe-positioning/references/社媒运营接入规范.md)和公共发布，交付不等于发布授权。
