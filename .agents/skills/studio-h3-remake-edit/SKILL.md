# Viggle Remake Edit 换背景

按[换背景流程](references/Viggle-Remake换背景流程.md)核对源动作、场景透视及目标参考帧。先明确当前源片版本、目标场景、人物和镜头保留项、执行范围与授权。

编写正文时读取[共用提示词规范](../studio-h3-remake/references/Viggle-Remake提示词规范.md)。按换背景流程配置 Edit 权重和采样，使用[共用 ComfyUI 工具](../studio-comfyui/SKILL.md)提交和取回。检查背景构图、人物动作和地面关系，再按调用业务或 [Remake 外层流程](../studio-h3-remake/SKILL.md#两轮之间的交接)接续。
