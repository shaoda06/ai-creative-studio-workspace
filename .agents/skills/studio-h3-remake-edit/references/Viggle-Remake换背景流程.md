# Viggle-Remake 换背景流程

使用 Edit 修改源视频的场景，并按任务要求保留表演者、构图、运镜、时间线和声音。源片可以是原始视频，也可以是前一轮已选定的换人结果。

## 1. 核对源动作和目标场景

- 按镜头对照源片与目标场景的机位高度、俯仰角、地面透视、人物在画面中的大小和可活动范围。人物走动时，检查进出画方向、行走通道、远近变化和落脚位置能否落在目标空间里。存在桌椅、台阶或墙面时，核对遮挡、接触和通行关系。
- 场景素材有合适内容但拍摄角度不同，可以以源片构图为基准制作该场景的目标视角。原动作与场景动线冲突时，先按调用方要求决定使用更匹配的背景构图，或使用适合该场景的源镜头。当前素材的兼容性以有代表性的连续动作样片核实。

## 2. 准备参考帧和提示词

1. 按源片切点准备 24 fps 片段，并记录实际保留区间。单段按 Edit 节点的 `17N+5` 帧长准备，合法范围为 90–345 帧。连续镜头超过上限时，按动作阶段与机位选择分段点，并为相邻段准备空间关系一致的参考帧，检查接缝。需要补帧时记录段尾补齐量，合片裁回正文。对已确定分段点且每段在上限内的输入，可复用[现有分段工具](../../studio-h3-remake/scripts/long_swap.py)的 `prepare` 和 `join`。Edit 的请求按下一节装配。
2. 从本轮源片选构图和动作有代表性的一帧，以该帧为基准制作新背景下的目标画面。保留人物站位、姿势、大小和原镜头画幅。需要核对落脚时，选鞋底和地面都入画的帧，表达实际承重脚、抬起脚、鞋底接触阴影和投影方向。镜头变化较大时，按必要的机位或动作变化补参考，并核对各参考中的空间关系。
3. 目标帧接 `#42.ref_1`，正文使用 `<Picture 1>`。需要按原动作帧对齐时，`pins` 填该帧在**实际送入段内从 0 起算**的帧号。有多张绑定参考时，每张对应一个帧号，顺序与参考端口一致。只作场景外观参考时 `pins` 留空。按 [Viggle 共用提示词规范](../../studio-h3-remake/references/Viggle-Remake提示词规范.md)描述新场景、光线与接地关系，并写明本轮要保留的人物、动作和镜头。正文时码对应同一段输入。

## 3. 装配 Edit 请求

从[已登记的 Remake API](../../studio-h3-remake/references/workflows/Viggle-Remake-单人换人-双参考图.api.json)为本次任务准备副本。下面是 Edit INT8 的基准装配。现有[画布](../../studio-h3-remake/references/workflows/Viggle-Remake-单人换人-双参考图.workflow.json)已预留 Edit 的 `#33`。

| 位置 | Edit 配置 |
| --- | --- |
| `#1` 模型 | 用服务器实际可选的 `viggle_remake_edit_pruned_int8_convrot.safetensors` |
| `#3` 模型输入 | 直接接 `#1` 的 Edit INT8 输出，沿用 `keyframe_until=0.9`。任务副本只保留这条生效的模型链 |
| `#16.sigmas` | 接 `#33`。API 副本添加 `ManualSigmas` 节点 `#33`，值为 `1.0, 0.983607, 0.96, 0.923077, 0.857143, 0.705882, 0.0` |
| `#62`、`#9`、`#34` | 分别填该段源视频、目标参考图的实际上传名和六段英文提示词 |
| `#42` | 填实际生成帧数和 `pins`。单参考时只接 `ref_1`。源片画面和音频沿用 `#63` |
| `#54`、`#12`、`#65` | 填本次短边、种子及输出前缀。基准为短边 480、Euler 六步 |

按[官方 ComfyUI 指南](https://huggingface.co/Viggle/Viggle-Remake/blob/main/COMFYUI.md)核对 Edit 权重与 Sigma。经生成授权后，用[共用 ComfyUI 提交入口](../../studio-comfyui/references/ComfyUI工具调用规范.md)逐段提交并取回 `#65`。输出按实际生成帧数检查，裁回保留区间后按原片顺序合片并封回原声。

## 4. 样片核对与返修

- 有查看授权时，检查参考帧及其前后的连续动作。重点看落脚、承重、抬脚和站定时鞋底与地板的关系，人物尺度和遮挡是否随镜头连贯，脸、穿搭、场景和原切点是否符合任务要求。
- 出现漂浮感、透视不合或动作与场景脱节时，选同一镜头做对照。保持源视频、种子和采样设置一致。先在原参考帧下补足遗漏的提示词，再用相同的动作和场景描述换成更合适的参考帧，并同步其帧位和正文时码。若参考帧附近改善、连续动作仍脱节，重点检查机位、地面透视与行走路线，优先试匹配原动作的场景视角。
- 工作流测试按 Edit 实际输出审阅，技术合片只裁去补帧、按顺序拼接并封回原声。保存实际参考、提示词、请求、模型输出和对照结论。单镜头结果用于判断该素材条件，扩到全片时按不同构图和动作复核。
