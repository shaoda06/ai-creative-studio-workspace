# 图片参考与修订方法

## 参考输入与画面目标

从调用业务已确认的画面目标、范围及素材资格出发。说明这张图实际能看到谁、处于哪一刻、哪些部位或细节需要清楚。固定实际源文件、版本、输入顺序和每张图负责的内容，在既有生成记录中说明各自保留或改变的范围。同一人物的不同视角是同一身份。需要镜头参考或首帧时，按[共用分镜](../../studio-storyboard/references/分镜写作规范.md#镜头参考图与首帧)确定用途。

按实际传入的文件写引用，图名、文件路径及提示词描述不能代替工具要求的图片输入。裁切或处理后的文件作为输入时，在原记录保留源文件与实际输入的对应。区分识别特征、服装、姿态、构图、环境、光影等用途。两张参考有冲突时，写清哪项取自哪张图；缺少决定或必要源图时补齐对应缺项。业务图种、视图方向、背景和尺寸从调用业务的规范读取。

## 参考图用途与取景

1. 先确定这张图要说明什么，再选景别、机位、取景边界和视觉重点。必须看清的主体、结构、接触点与空间关系按图的用途决定。总览有布局要求时，保留足够视野。
2. 源图按本次用途提供身份、服装、材质、空间或状态依据。目标画面呈现实际可见的内容，按需要调整源图的机位、透视、遮挡、姿态及装饰。核对原设计中须保持的身份和结构。
3. 保持人体、物件和环境之间可信的比例、透视、距离及接触关系。内容放不下时先调整机位；需要多张图分别说明时，按业务确定数量与范围。
4. 首帧、互动和局部状态图可有意裁切、遮挡或留在画外，保留识别特征和作用关系。留白使用自然背景或环境空间。结构展示图按已确认模板保留规定的视角、完整轮廓、同尺度比较及余量。
5. 效果图写清主体与效果的尺度、方向、作用位置和可见反馈，用明暗、材质及层次突出重点。装饰效果让出需要辨认的结构和接触关系。
6. 提交前核对实际提示词是否写清用途、必要可见内容、输入职责、取景和规定视图。把有意裁切与必须看清的关系写进构图，删去与用途无关的展示要求。

## 保留项与修订

根据已确认反馈重写本次完整目标，写清保留的主体、状态和画面部分，以及改变的对象、区域和预期结果。沿当前任务已确定的源参考重做时，继续引用其准确版本。要从某个候选或新的正式文件衍生时，先确认这一版本及用途，再在原记录中标明实际换源。无参考的任务按适用的文生图分支写完整目标；需要编辑源图时按业务与工具条件选择分支。

核对实际来源、保留及变化范围和目标画幅。制作、参数、原生输出、候选审阅、处理与正式采用分别按业务和实际工具办理。同一版本可以跨产出引用，沿[项目资源与版本](../../studio-workspace-browser/references/项目资源与版本管理.md)保存来源和结果。
