# 声音参考准备方法

先明确用途，例如取某人的音色、使用原话、保留特定环境声。按任务实际提供的来源和权限确定所需声音；区分谁在发声、是否有其他声音覆盖以及目标声音能否辨认。仅取音色时，可选择能听清特征的片段，完整一句是否必要由实际用途决定。静音检测可辅助定位停顿，声源和适用性由实际听辨确认。

优先选连续的原始区间。原件本身符合已确认用途和长度时可引用整份准确版本；需要选段时，在原记录中写清源文件版本和实际起止点或起点与长度，保留原件。不可辨认的声源、重叠人声或其他限制按实际记录。补静音、拼接、变速、去噪或改变音色是另外的处理目标，按具体要求执行。

调用方确定目标时长、格式、剪裁与采用权限。明确的裁剪、格式与时长核对交[共用音频处理](../../studio-audio-processing/SKILL.md)，视频中的取声按实际工具处理。技术可读、听辨适用、用户采用与模型可用分别按所属业务确认。
