# 人物姿态参考表

按人物定住时的身体状态查找姿态。条目以能直接写进提示词的定姿文字为主，配一张带短标注的统一画风全身示意图。视频中的进入、停留和离开由当前分镜按[完整动作链](完整动作链设计与转写指南.md)设计。

## 分类与查用

- [站姿](人物姿态/站姿.md)

按人物的主要支撑方式和身体状态归类，如站姿、坐姿、蹲姿、跪姿、卧姿。每个类别各用一个文件，首个姿态正式收录时创建类别文件并在这里加入口。同一姿态只登记在一个类别，先按名称、同义词与可见轮廓查重。方向或手脚位置的小变化可写成同条变体。形成不同重心、轮廓或展示效果的姿态，可另列条目。

正式收录时分配编号。格式为「分类名-三位流水号」，各类从 `001` 开始，按该类已用编号顺延。条目标题写完整编号和名称，引用时使用完整编号。同一条目返修沿用原号。调整类别时按目标类别编号，并同步受影响的引用。原帖顺序或页码随当次审阅记录保存，候选沿用拟收录名称。

分镜或模型提示词需要具体姿态时，按表演、展示目的和取景选条目，将影响画面的定姿文字落实到分镜或模型正文。视角、人物、服装、道具与方向按当条作品调整，按实际动作接点写出过渡。示意图用于识别、选姿势和核对，实际模型的图片输入按该次任务和所选工具确定。

## 识别要收录的材料

用户分享帖子、图集、视频或截图，提出看站姿、坐姿、摆姿、体态或补充人物姿态参考时，进入本表。接续已经明确的姿态收录工作时，可用链接或图片继续提供素材，沿用当前收录范围。链接用途未交代时，结合上下文和实际内容判断。姿态教学、摆姿示范中的定姿内容归本表，涉及其他用途的内容按[参考分析](学习与反馈维护规范.md#参考分析的观察与取舍)处理。收录依本次实际授权。

查看图文原帖时按需使用[浏览器操作](../../studio-browser-operations/SKILL.md)，视频中的定姿画面按[视频读取与分析](../../studio-video-study/SKILL.md)定位。提取用户指定的姿态时，把该图或该时点作为本次材料。姿态范围未定时，先提供当前可辨认的姿态供用户选择。

## 提取与写法

1. **定位原始姿态。** 先看总体内容和说明。总览用于定位，提取时优先看对应单图、清晰画面或视频中姿势定住的时刻。一次只收录所指定或确认的范围。遇到遮挡或透视不明，写可见关系和足以表达构图的相对朝向，无法确认的关节角度或受力保持未定。
2. **按原图构建定姿正文。** 先看姿态依靠哪里支撑、从哪个视角可见，再锁定让它区别于常见摆法的身体关系。把决定轮廓的部位写成可定位的关系，例如「画面右肩高于左肩，画面左髋高于右髋」「杯身整个在同侧肩的外缘之外」「双腕明显高于头顶」。按图中的实际差异选写。遇到侧身回看，分别写躯干转向、脸朝向和头往哪边倾。手脚与身体或道具有接触时，写清接触点、位置和方向。用原图可见的相对关系表达幅度，能辨认到哪一层就写到哪一层。在同一条内，「左腿」「右手」等按人物自身左右，「画面左侧」「画面右侧」按观看者左右。
3. **在提交前拿实际提示词对照原图。** 优先核对如果画错就会变成另一个姿势的关系，检查一个只看到正文的读者能否找到同样的位置、方向和接触点。把会造成误读的笼统表述改成具体关系，再核对同一正文里的总体视角和局部朝向是否一致。比如端杯站姿先明确杯在肩外和肘在腰旁，再写手握杯侧。捧脸单腿后屈先写胸廓与腰胯的错位和抬膝相对承重腿的位置，再补脸朝向和手腕。关键关系存在疑问时回看对应单图或可用的相邻画面，依据看得清的内容修正文。

## 统一示意图与核对

用[女性关节人偶正面站姿基准图](../assets/人物姿态线稿基准-正面站姿.png)保持同一人偶比例和白底黑线画法。画面保留清楚的外轮廓、较细的结构线和简化关节。省略五官、头发、衣物和身体细节。姿势依条目正文，支撑或接触所必需的椅子、包带等可用简化轮廓。选择能看清承重、躯干朝向和四肢位置的视角，给短标注预留白边。

新制作的独立线稿成品统一为 **竖版 3:4、宽 1086 × 高 1448 像素、PNG**，与基准图同规格。生成时请求竖版 3:4。原生图尺寸有差异时，保留原生 PNG，按成品画布等比适配并用白底留边，保留完整人形。短标注按成品画布排字。

1. **生图前备好正文、输入和短标注。** 按[提取与写法](#提取与写法)核对本轮实际正文。从中选最值得在画面上指给人看的要点，通常两三处。每处用一句短话说明可见状态，如「脸朝画面左微转」「右腿后屈，脚尖朝下」。基准图负责线稿画风和人偶比例。对转身遮挡、躯干扭转、复杂手脚交叠或精确道具接触等仅靠文字容易偏移的姿态，可在首轮把本次允许使用的对应单图作为第二张实际输入。提示词明确第二张图只提供机位、姿态和接触位置，造型及线稿画法按基准图。输入角色、文件和顺序沿[共用图片参考方法](图片参考与修订方法.md)核对，短标注的文字随该条目维护。
2. **同一轮制作完成线稿和标注。** 按本次授权调用[Studio Imagegen](../../studio-imagegen/SKILL.md)，使用已核对的实际参考和定姿正文生成线稿。接着在同一轮用备好的短标注排版，输出一张独立的带标注线稿 PNG。字形、字号和加粗用本地工具排字，可用 FFmpeg 的 `drawtext`。标注放在对应部位附近的留白里，必要时用细引线，保证全身轮廓和关节清楚可见。
3. **核对本轮成品。** 对照原图、定姿正文和带标注线稿，复核关键身体关系、图上短句及排版，并检查独立成品的 PNG 格式和实际宽高。原图的关键信息漏写时更新条目正文，正文已清楚而图有偏差时按工具规则返修。返修图以对应版本重新核对标注再交审。

### 图注版式

在统一线稿成品画布上使用华文楷体（Windows 字体文件 `STKAITI.TTF`），字号 **36–37 像素**，用 **1 像素同色描边**微加粗。字色用深灰 `#303845`，需要引线时可用浅灰 `#9AA2AE`。制作左右对比图时，右栏整体随带标注线稿等比缩放。核对工具实际加载的字体、常规预览下的可读性和字形完整性，文字与引线避开人体轮廓。字体暂不可用时，说明具体排版缺项。

## 送审与采用

完成自身核对后，把带标注线稿、实际用于生成的定姿正文和所见差异一起交用户审阅。每条姿态有对应原帖单图或用户提供的原图时，都排成一组左右对照，左边放该条原图，右边复用本轮独立的带标注线稿。通过等比缩放、留白和对齐，让两侧人物大小接近，保留全身、原有比例和朝向。原图暂时无法排入时，仍交回该条带标注线稿与正文，说明缺项以及哪些姿态细节尚未核实。

同轮提取多张姿态时，默认按原帖顺序或用户指定顺序，把全部左右对照纵向拼成一张长图，各组标明对应序号和姿态名称，整轮一次送审。送审前核对长图覆盖本轮全部姿态，原图与线稿一一对应。某条原图暂时无法排入时，在该条位置说明缺项。各条定姿正文、所见差异和可放大的单组对比图随当次审阅记录查用。

用户审阅确认合格后，使用下方的[录入脚本](#从送审记录批量录入)归档已确认的带标注线稿及其对应正文。需要调整时，按反馈修订定姿正文或线稿，再提交对应版本供审阅。

### 从送审记录批量录入

向用户交付的 Markdown 送审记录直接兼作录入清单。每条用 `## 原帖 01 姿态名称` 作为小节标题，按送审顺序排列。序号在本轮唯一，保留原有前导零。截图等没有原帖图号时，按送审顺序编排本轮序号。每节保留独立带标注线稿链接、定姿正文和图上标注，其余审阅信息可照常记在同节。

```markdown
## 原帖 01 单手叉腰站

[独立带标注线稿](带标注线稿/01.png)

**定姿正文**：身体近正面，右手贴在同侧腰侧，右肘向外。左臂自然垂下，双脚着地。

**图上标注**：右手叉腰；左臂自然下垂
```

图注用一行记录，多句以中文分号分隔。线稿链接相对于送审记录所在目录，使用本轮的 1086 × 1448 带标注 PNG。带空格的链接用 Markdown 尖括号包住。用户确认采用后，从仓库根目录用 Python 3.10 或以上运行[录入脚本](../scripts/adopt_poses.py)。

```text
python -X utf8 .agents/skills/studio-creative-techniques/scripts/adopt_poses.py --review "当次送审目录/送审记录.md" --category 站姿
```

`--review` 指向本轮送审记录，相对路径以运行目录为准。`--category` 指定正式分类。只采用其中几条时，加 `--only 02 07`，填写本轮实际序号。省略 `--only` 表示用户已确认整批，同一批按送审顺序录入。获准启用新分类时，从 001 开始并同步分类入口。

脚本在本地按分类续号，保存通过解码和尺寸核对的 PNG，并按[保存与记录](#保存与记录)写入定姿正文、图链和图注。运行成功退出码为 0，输出原帖序号、正式编号、名称和录入结果，可带回当次审阅记录。同一分类里图文完全相同的条目复用原号。输入有缺项或同名条目的内容不同，检查会给出出错项并以非零码退出。已收录条目的正式返修按原编号和版本规则办理。脚本读取送审记录，写入共用姿态目录和分类入口，源图、审阅记录和 Git 提交由原流程管理。

## 保存与记录

- **基准图**使用上面的原生文件。[站姿-001 普通正面站姿](人物姿态/站姿.md#站姿-001-普通正面站姿)直接引用基准图，短说明随条目展示。
- **候选图**保留工具返回的原生 PNG。拟收录名称、实际用于生成的定姿正文、短标注、所用参考，以及原生 PNG、独立带标注 PNG 和实际交回的对比图路径，一并记在当前工作记录或对话。带标注线稿和左右对比图归当次审阅资料，跨业务姿态表审阅材料可放在总层 `综合资料/` 的当次目录。原帖页码和实际所见差异按[参考分析](学习与反馈维护规范.md#参考分析的观察与取舍)留在本次记录。
- **正式示意图**把采用的带标注线稿 PNG 保存到 `assets/人物姿态/<分类>/<条目名称>.png`。对应类别文件下用一个小节记条目编号和名称、定姿正文、示意图相对链接与图上的短标注。适用条件、同义名称和变体确有用时写在同节。版本回溯用 Git 历史。改过正文或示意图时，在同一次修改中核对图文和相对链接。
