# 人物姿态参考表

按人物定住时的身体状态查找姿态。条目以能直接写进提示词的定姿文字为主，配一张带短标注的统一画风全身示意图。视频中的进入、停留和离开由当前分镜按[完整动作链](完整动作链设计与转写指南.md)设计。

## 分类与查用

- [站姿](人物姿态/站姿.md)

按主要支撑方式归类，站姿、坐姿等类别各用一个文件。有新类别的首个收录条目时，再建该类文件并在这里加入口。同一姿态只登记在一个类别，先按名称、同义词与可见轮廓查重。方向或手脚位置的小变化可写成同条变体。形成不同重心、轮廓或展示效果的姿态，可另列条目。

分镜或模型提示词需要具体姿态时，按表演、展示目的和取景选条目，将影响画面的定姿文字落实到分镜或模型正文。视角、人物、服装、道具与方向按当条作品调整，按实际动作接点写出过渡。示意图用于识别、选姿势和核对，实际模型的图片输入按该次任务和所选工具确定。

## 识别要收录的材料

用户分享帖子、图集、视频或截图，提出看站姿、坐姿、摆姿、体态或补充人物姿态参考时，进入本表。接续已经明确的姿态收录工作时，可用链接或图片继续提供素材，沿用当前收录范围。链接用途未交代时，结合上下文和实际内容判断。姿态教学、摆姿示范中的定姿内容归本表，涉及其他用途的内容按[参考分析](学习与反馈维护规范.md#参考分析的观察与取舍)处理。收录依本次实际授权。

查看图文原帖时按需使用[浏览器操作](../../studio-browser-operations/SKILL.md)，视频中的定姿画面按[视频读取与分析](../../studio-video-study/SKILL.md)定位。提取用户指定的姿态时，把该图或该时点作为本次材料。

## 提取与写法

1. **定位原始姿态。** 先看总体内容和说明。总览用于定位，提取时优先看对应单图、清晰画面或视频中姿势定住的时刻。一次只收录所指定或确认的范围。遇到遮挡或透视不明，写可见关系和足以表达构图的相对朝向，无法确认的关节角度或受力保持未定。
2. **写成可复现的定姿正文。** 从支撑和可见轮廓入手，补足能区分该姿态的身体关系。按实际需要写清承重和接触、身体各部位相对机位的朝向、肩与胯的高低或错位、腰的弯转、四肢的弯曲和相对位置，以及头与脸的朝向。正文用具体位置和关系表达，精度取决于原图和该姿态的关键特征。在同一条内，「左腿」「右手」等按人物自身左右，「画面左侧」「画面右侧」按观看者左右。
3. **连读并对照。** 对照原图复查正文能否摆出同一轮廓，尤其留意一句简写是否把关键关系写平。例如捧脸单腿后屈时，若原图的胸廓偏画面右、腰胯偏左、画面左肩较高，正文就要交代这种错位。右膝收近承重腿前方、右小腿近水平伸向画面左、脚尖朝下，也比只写「单腿后屈」更能复现腿部姿势。

## 统一示意图与核对

用[女性关节人偶正面站姿基准图](../assets/人物姿态线稿基准-正面站姿.png)保持同一人偶比例和白底黑线画法。画面保留清楚的外轮廓、较细的结构线和简化关节。省略五官、头发、衣物和身体细节。姿势依条目正文，支撑或接触所必需的椅子、包带等可用简化轮廓。选择能看清承重、躯干朝向和四肢位置的视角，给短标注预留白边。

1. **生图前备好正文和短标注。** 从定姿正文中选最值得在画面上指给人看的要点，通常两三处。每处用一句短话说明可见状态，如「脸朝画面左微转」「右腿后屈，脚尖朝下」。短标注的文字随该条目维护。
2. **同一轮制作完成线稿和标注。** 按本次授权调用[Studio Imagegen](../../studio-imagegen/SKILL.md)，使用基准图和定姿正文生成线稿。接着在同一轮用备好的短标注排版，输出一张独立的带标注线稿 PNG。字形、字号和加粗用本地工具排字，可用 FFmpeg 的 `drawtext`。标注放在对应部位附近的留白里，必要时用细引线，保证全身轮廓和关节清楚可见。
3. **核对本轮成品。** 对照原图、定姿正文和带标注线稿，复核关键身体关系、图上短句及排版。原图的关键信息漏写时更新条目正文，正文已清楚而图有偏差时按工具规则返修。返修图以对应版本重新核对标注再交审。

### 图注版式

以单列示意图宽 1080 像素为基准，使用华文楷体（Windows 字体文件 `STKAITI.TTF`），字号 **36–37 像素**，用 **1 像素同色描边**微加粗。字色用深灰 `#303845`，需要引线时可用浅灰 `#9AA2AE`。不同尺寸按单列宽度同比例调整字号和描边。排字后核对常规预览下可读、字形完整，文字和引线的摆放避开人体轮廓。

## 送审与采用

候选通过自身核对后，把带标注的线稿和实际用于生成的定姿正文一起交用户审阅。有对应帖子单图时，优先把两张图排成一张对比图，左边放原帖单图，右边放本轮带标注线稿。通过等比缩放、留白和对齐，让两侧人物大小接近，保留全身、原有比例和朝向。对比图及实际所见差异随正文送审。原图暂时取不到时，交回带标注线稿与正文，并说明缺项。

用户审阅确认合格后，按下方的正式示意图规则归档。需要调整时，按反馈修订定姿正文或线稿，再提交对应版本供审阅。

## 保存与记录

- **基准图**使用上面的原生文件。普通正面站姿示例直接引用基准图，短说明随条目展示。
- **候选图**保留工具返回的原生 PNG。拟收录名称、实际用于生成的定姿正文、短标注、所用参考和原生 PNG 路径记在当前工作记录或对话。带标注线稿和左右对比图归当次审阅资料。原帖页码或实际差异需要追溯时沿[学习与反馈维护规范](学习与反馈维护规范.md#学习与收录)留在本次记录。
- **正式示意图**把采用的带标注线稿 PNG 保存到 `assets/人物姿态/<分类>/<条目名称>.png`。对应类别文件下用一个小节记条目名称、定姿正文、示意图相对链接与图上的短标注。适用条件、同义名称和变体确有用时写在同节。版本回溯用 Git 历史。改过正文或示意图时，在同一次修改中核对图文和相对链接。
