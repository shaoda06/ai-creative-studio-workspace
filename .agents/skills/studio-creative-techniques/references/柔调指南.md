# 柔调指南

柔调适用于希望降低画面光比、让颜色更收敛的场景。亮部过渡柔和，暗部还有黑位和质感，肤色、主体与环境靠明暗和色彩差异区分。先看画面当前哪一部分太强，再确定要收光比、收颜色，还是两者都做。

## 适用场景

| 场景 | 优先调整 | 保留重点 |
| --- | --- | --- |
| 暖光户外人像、穿搭 | 轻压皮肤与墙面的高光，按实际画面收一点黄橙 | 斜阳方向、自然肤色、深色衣服的面料和原色 |
| 有明确色彩重点的户外或生活方式画面 | 逐个减弱抢眼的环境色。草木偏艳时试收绿，墙面泛黄时试收黄，肤色过橙时小幅收橙 | 场景的主色、肤色和商品辨识色 |
| 偏淡、青灰的古风或氛围画面 | 减少部分颜色的饱和度，按光源在亮、暗部保留轻微色差 | 人物轮廓、衣料纹理和前后景层次 |
| 底片反差已很低或颜色已有明显偏差 | 先补基础曝光、偏色或局部黑位，选一帧确认层次后再叠柔调 | 已有的亮暗细节和真实光线关系 |

## 一、先建立基础影调

1. 核对源片的实际色彩空间、传递特性和是否已做过转换。已知是 Log 时，先明确匹配的输入与目标色彩空间，再选择适用的技术转换，或在当前工具中做可核对的手动基础还原。有些还原 LUT 同时带来较强的对比或饱和度，先看叠加前的亮部和肤色，给后续风格保留空间。
2. 教程的剪映手调演示在素材上放调整层，依次补自然饱和度、轻加对比、调整阴影，把平淡的 Log 底片收回到有层次的基调。画面发灰时先定位阴影和黑位，保留白衣、浅色墙和天空的内部层次。根据需要小幅调对比，看到亮区开始失去过渡就回退幅度。
3. 已渲染的 SDR 直接以现有显示画面为起点。多镜头先校正需要连续的曝光和偏色，光源本身的变化保留在画面里。已有清楚的黑位和颜色时，基础调整可以很轻。

## 二、建立柔调风格

**手调路径。** 用亮度曲线或高光、阴影控制先调整光比。亮部刺眼时，让上段曲线过渡平缓，检查高光中的皮肤和浅色衣服还有没有细节。暗部只改到能看清面料和轮廓，画面需要更实一点时调阴影或黑位。随后再用整体饱和度或 HSL 收颜色。只有个别色相抢眼时，先处理对应色相，保住嘴唇、服装和商品的必要辨识色。

**滤镜路径。** 先在已建立基础影调的代表镜头上试与画面目的相符的滤镜，降强度，再回到素材微调反差、亮部和饱和度。教程用剪映的「清透晴天」示范降低到强度 70，再微调画面。这个值对应教程镜头和剪映滤镜，复用时从本素材的人像、亮部和商品颜色决定强度。使用手调也可以做出所需的柔调，并可按镜头分别控制。

**用色差保留层次。** 颜色收敛后，如果主体和背景黏在一起，可以让亮、暗部保留少量冷暖差。教程用暗部青蓝、亮部橙红举例，也演示了按场景收绿、黄、橙的做法。有明确暖光时，可保留光源已有的暖色，只在暗部轻微调整。色轮、分区色彩平衡和 HSL 都可以用来做这一步，幅度以画面上的可见变化为准。

## 三、用对照判断该怎么修

| 看见的问题 | 下一步调整 |
| --- | --- |
| 脸和墙面仍太亮，白衣上的纹理变少 | 优先回收亮部，让上段曲线更平缓，回看落在同一亮区的皮肤和浅色衣料 |
| 整体发灰，深棕或黑色衣料缺少质感 | 给暗部找回黑位和局部层次，观察翻领、袖口和头发能否分开 |
| 肤色发青发灰，或者环境暖光淡得太多 | 减弱冷暗部或降饱和的幅度，优先收最抢眼的色相。再看肤色和金色光线的关系 |
| 单帧舒服，切到另一景别时色温和亮度跳变 | 回到相邻镜头的基础匹配，保留真实光源变化，再检查整段 |

同帧对照优先选一个能看清脸的近景、一个能看清服装原色和材质的镜头、一个能交代环境光的镜头。对齐画面、时刻和显示条件，分别看肤色、衣料和背景，再播放整段核对。送审记录写清调了什么、希望保住什么、哪些属于本次实际素材的选择。

## 制作样例｜暖光街角穿搭

**条件与目标。** 已剪好的 SDR 短片包含近距离微笑、打开深棕夹克和街角回眸。皮肤和墙面都有偏暖的亮部，目标是适度柔化，同时保留服装棕色与斜阳方向。

**实际做法。** FFmpeg 中用缓和的曲线轻压上段高光，保留深色衣料层次。对黄及邻近暖色色相轻微降饱和，暗部小幅偏冷，亮部沿用现场已经存在的暖光。原剪辑、帧率与配乐沿用该版。

**核对与采用。** 同帧对照中，近景额头和脸颊少了一点橙，墙面金黄略淡，夹克翻领和袖口的变化最小。该版已获采用。这条反馈支持在相近的暖光户外 SDR 素材上尝试轻量柔调，具体曲线和色相参数按新片重新取值。
