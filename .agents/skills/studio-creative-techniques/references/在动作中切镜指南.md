# 在动作中切镜指南

## 适用情形

**Cutting on Action（在动作中切镜）**是在可见动作正在发生时换镜头，把观众的注意力带进下一镜。换视角后接着展示同一次动作，观众仍能把它看成连续过程，这种接法常叫 **Match on Action（动作匹配剪辑）**。俯身起笑、从椅子起身、伸手接物和转肩迈步都可以提供切点。

固定机位的一条素材也能缩短动作过程。比如保留后退起步，切到人物继续后退的较远位置，略过中间不影响理解的步伐。不同动作也能重排，让手臂的运动、身体的转向或一个清楚的落点把两段连起来。它们分别解决同一次动作的连续、同一过程的省略、多个动作的编排。检验标准取决于这一刀希望观众看见什么。

### 先决定这一刀的用途

- **换景别或角度。** 前镜把视线带到动作，后镜让接触点、表情或空间关系更清楚。看清一次开门只需让观众在两镜间认出门和开门进度，手腕是否需要特写取决于门锁或手部动作是否重要。
- **省略时间。** 优先缩掉重复步伐、长时间定姿和可推知的过程。保留观众需要看见的发力、接触、转向、揭示或反应。省略后仍能说明人物怎么到达下一状态。
- **做节奏变化。** 选择动作差异能带来新信息的位置，例如从正面看剪裁切到转身看背包。需要观众读懂转身时留出转肩或一步转向。想用明显跳切表现时间跳过或造型突变时，按该意图判断两镜，不必假装时间连续。
- **给重要结果留时间。** 如果观众在等比心成形、捂嘴笑或一句话后的反应，可以把它留到读懂再切。停在动作结果、视线变化或反应上，也能是有意安排的切点。

## 怎么选切点

### 从看得见的变化下手

先说清哪一项要保住，再把相关动作粗分为**起势、进行、落定和反应**。挑一个观众容易跟住的变化，例如眼睛刚抬向镜头、肩部开始转向、手离开身体、支撑脚落地、另一只手刚握住物件。每个动作只观察与这刀有关的部位。有时笑意比脚步重要，有时观众主要在看鞋、道具或两人的距离。

同一次动作跨视角时，前镜切出与后镜切入应处于相容阶段。前镜中人刚推开门，后镜可以从门已经开了一小段、还在继续转动的位置接入。门又合回去、手换了边，或者前后各推一次，都会改变观众理解到的事件。跨视角时先核对动作和空间本身，再看画面上的运动方向和视线。方向变化有故事或空间依据时，用可见转向或清楚的环境关系带出变化。

### 对照切点两侧

已有素材时，在本次可查看范围内，先按正常速度看拟用段及前后余量。找出前镜最后一个能看见预期动作的区间，以及后镜第一个能接住它的区间。难以确认动作阶段时，逐帧看拟用切点两侧的几帧。以实际画面核对素材中出现的动作。

按这刀的重要信息选查：

| 观察点 | 两边连起来看什么 |
| --- | --- |
| 动作进度 | 谁先起势、何时接触、何时结束。下一镜有没有重复一遍同一动作，或直接跳过理解所需的阶段？ |
| 方向和重心 | 人往哪里走、头和肩往哪边转、哪只脚承重。故意改向时，观众能不能看见转向的依据？ |
| 手、物件和视线 | 同一只手是否继续握、推、放；物件是否保持可推知的位置和持有状态；重要目光是否指向同一个对象？ |
| 取景与注意力 | 下一镜最先看见什么。景别改变是否让观众更容易看清当下重点？同机位跳过一段时，位置变化是否还像同一过程？ |
| 声音 | 台词是否完整；脚步、碰撞、开关门等是否和画面对得上；环境声跨镜是否突然断掉或重复？ |

在同一个动作的可用范围内，比较稍早、稍晚的切法，按正常速度选接得最自然的一处。取舍看动作速度、景别变化和叙事需要。没有固定重叠帧数、停顿时长或每段必须切几刀的要求。找不到合适接点时，可保留一小段实际过渡、换一个出入点、用有信息的插入镜承接，或让该动作在同一镜完成。

### 和音乐一起处理

画面接点先成立。音乐卡点可以落在换镜，也可以落在动作里本身可见的事件，例如落脚、抬眼、比心合拢、手碰到嘴边。给观众看清动作的停顿有自己的时长。先定所需的画面与可用出入点，再在附近选听得见的重音、找合适的乐段起点，或保留画面更顺的位置。需要实测拍点、起音或音画偏差时，查[音频分析](../../studio-audio-analysis/SKILL.md)，把节拍估计与实际听到的重音结合起来。

对白主导的段落保留词句和反应节奏。画面要先切过去时，可让获准保留的对白或环境声继续跨镜。剪辑条件需要保留同期声、脚步或拟音时，按动作真实落点核对。片长以本次交付要求为准；给出的是大约时长时，让动作读得清和整条节奏一起决定具体长度。

### 曲线变速与段落卡点

先区分效果用于段落接续，还是用于段内突出动作或表情。曲线变速描述速度随时间变化，并不对应唯一的剪法；“闪进”“英雄时刻”等名称只能辅助沟通，还要说明实际快慢区间、要突出的时刻及与音乐的关系。段内先快后慢可以与段间直接切换组合，不必另加模糊、闪白等转场图层。

用已有素材时，先选每段最有意思、能独立读懂的动作或表情，再处理入点、出点和速度反差。快段可压缩准备过程，慢段留给需要看清的变化或结果；速度幅度、停留和保留时长随素材调整，不固定每套衣服必须占同样时长。音乐的引入段可以正常开场，在循环或重音进入时开始另一种节奏；具体落点沿上方音乐核对方法确定。

慢放前检查源帧率、动作速度和拟用倍率。24fps素材以0.45倍播放时，每秒只有约10.8个源时刻，简单重复帧输出高帧率不能补出缺失动作。确需改善慢放时，可先处理原动作素材，再以新素材的实际帧率重新计算选段与速度映射；避免沿用旧的逐帧编号后仅改变导出帧率。插帧与超分的选型、目标规格和执行按[视频处理](../../studio-video-processing/SKILL.md#后处理工作流选择)办理，不把所有素材固定为60fps或固定分辨率。

## 分镜设计怎么用

先用[怎么选切点](#怎么选切点)确定镜头交接要保留的事件与可见变化。选取景，让前镜能交代动作的开始，后镜能接住进度并交代新信息。需要两个角度都拍到同一动作时，在两边留出可剪的过程。至少明确切点附近动作开始前的状态、可接入的动作阶段和要保留的结果。动作本身、机位和具体可见范围分别写进既有字段，交接点写在「转场方式」。

> SH012 → SH013，动作匹配切。中景里她按下门把手，门刚向里开时切到门内侧近景。后镜门沿同一方向继续打开，她的右手仍握着把手，门锁轻响延续过切口。

分镜返修先找断在前镜结束、后镜开始、机位还是动作设计。改了切点就连读相邻两镜，核对该有的接触、反应或转向是否仍可见。一个镜头已经能交代必要动作时，可让它继续拍完。模型提示词只按实际工作流能执行的模式表达动作与换镜；涉及整条事件或跨模型分段时查[完整动作链指南](完整动作链设计与转写指南.md#24-确定每个切点两侧的动作进度和方向)。

## 剪辑与返修怎么用

1. **核对版本、素材与要留的动作。** 先看被反馈的版本和对应底片，标记观众觉得突兀的切口。用实际画面确认动作位置、可剪方向和前后的保留项。按[视频读取与分析](../../studio-video-study/SKILL.md#按问题查看画面)精查必要区间。
2. **分辨是接点、节奏还是素材问题。** [对照切点两侧](#对照切点两侧)，说清两个镜头前后实际在发生什么。动作在底片里完整时，可调整出入点、补回短过渡或重排可独立成立的动作。底片里缺少关键接触、反应或转身时，先看其他已获准使用的素材能否补足。仍缺时，给出可行的现有剪法，把依赖新素材的部分交回上游。
3. **试听和复看。** 有配乐时按[和音乐一起处理](#和音乐一起处理)核对实际重音。无声按正常速度连看是否顺，再开原声和配乐听节奏、对白及动作声。有疑问的接点再逐帧查。最终连看本段前后，确认关键动作可辨、视线跟得上、原本重要的结果仍保留。有明确时长或规格时一起核对。
4. **把决定写回原剪辑资料。** 在已有时间线、剪辑方案或返修记录中标明本轮用到的源版本、关键出入点和复看结论。分镜未到出片阶段时，写计划动作阶段即可；已有实片时，用实际源片区间或帧号与成片位置对应。

想缩短开场或修顺连续动作之间的跳接时，可对照下方[穿搭剪辑实例](#穿搭剪辑实例)。

## 穿搭剪辑实例

### V004 · 笑意刚起时切到全身

**要保留的观看感受**：近镜里的对视和笑是开头的钩子，全身镜接着展示衣着。完整靠近过程容易拖慢开场，把靠近、俯身和后退切得太碎又会让距离连续跳动。

**切法**：以人物已靠近镜头的画面入场，让观众看到她俯身、抬眼和笑起来。笑意刚起时踩拍换到全身，较完整的剪法用后退接续；更短的剪法把宽景入点推进到叉腰换重心、交叉腿的动作，省略可推知的路程。后面的夹克展示和回头都有自己的可读时间。

**查用方式**：当开场主要靠一个表情抓住视线时，先找到表情刚发生的时刻，再比较宽景应接同一动作还是压缩到下一可读动作。快速切换也应让观众能跟上人从近处到远处的变化。

### V005 · 缩短后退，重排抬腿、比心和回眸

**要保留的观看感受**：开头仍像在和镜头打招呼，后段看得清比心和捂嘴笑。固定机位底片有多个独立穿搭动作，可以重新排序。

**切法**：近景保留浅笑与刚起身后退，踩鼓点切到仍在后退、已开始展臂的较远画面。中段用侧抬腿收步接双手上抬成比心。比心落手时接入侧身转肩，给观众看见身体转到背面，再从背身落脚衔接回眸。末尾留住招手、手到嘴边和后面的笑。

**查用方式**：展臂后立刻跳到全背身时，转向缺了观众需要看的过程；踩拍仍会觉得突兀。补回侧身这一小段，或把回眸移到适合接转身的位置，就能保住背包的展示，也让动作顺序读得懂。少剪可以避免动作被切碎，单段留得过长又会拖慢节奏；每个动作要留多久，按它的作用和素材里实际发生的过程判断。
