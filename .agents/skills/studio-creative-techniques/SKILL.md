# Studio 创作技法学习与维护

统一处理创作技巧的学习收录、创作查用及实际反馈。剧本与对白、表情、镜头及完整动作链的方法在本目录维护；打戏动作机制、法术和模型专用规则沿下方归属引用，不复制另一份资料。只读取当前入口和相关主题，不默认加载全部参考。

## 剧本与对白

**从场景写出目标语言的对白**：先确认说话者此刻想争取什么、听者掌握哪些信息、这句话怎样改变局面。按目标语言的口语习惯、人物身份和关系重写，保留原情节事实与台词作用。交付要求逐句对照或直译时按该要求写。写完按[公共对白估时](../studio-storyboard/references/分镜写作规范.md#对白估时)核对容量，再连同接话、停顿和动作读一遍。

**压稿时保住前面铺垫的结果**：先删重复解释和没有新结果的收尾，再看高潮处的爆发、表态或后续动作是否真正改变了关系、选择或下一步行动。承担这项变化的节拍应留足时间。比如多场试探终于换来人物公开拒绝并交还钥匙，重复解释拒绝理由可以删，拒绝及交还钥匙仍要能被观众看清。未承担新作用的喊叫或余韵按实际节奏取舍。

## 表情表达

图片／视频提示词中已指定且需要呈现的抽象表情，按[表情拆解方法](references/表情拆解方法.md)和[表情参考表](references/表情参考表.md)落实具体面部变化；分镜、剧本可以保留表演意图。已有清楚且适用的描述直接复用，不为调用技能换词、加长或给中性图加情绪。首次采用候选及针对性反馈沿上表对应入口。

## 镜头表达

选择或细化景别、构图、角度、运镜、光影及焦点时，按[镜头选择与转写](references/镜头语言参考指南.md#选择与转写)落实。分镜阶段辅助选择拍法，图片／视频提示词转写已确认设计；已有适用表达直接复用。表情方法处理面部变化，镜头方法处理怎样拍清这些变化。首次采用具体候选或组合及实际反馈沿上表处理。

完整事件的连续动作与切镜组织，使用[完整动作链设计与转写指南](references/完整动作链设计与转写指南.md)中的整条方法和贯穿示例；正式分镜与模型正文的读取时机、输出和核对责任分别由对应业务技能维护。

## 提示词转写

需要落实人物表情或细化拍法时，按[表情表达](#表情表达)和[镜头表达](#镜头表达)选读。图片写清选定时刻可见的状态。视频涉及连续动作或跨镜头接续时，按[完整动作链指南](references/完整动作链设计与转写指南.md)把已确认的动作起点、变化、落点和切镜接续写进实际模型正文，已有中文参考随之同步。其他专业按[主题归属](#主题归属)选读。

首次实际采用未验证的具体写法或组合，按[首次使用提示](references/学习与反馈维护规范.md#首次实际使用时的提示)在本次交付说明里写清观察重点。

| 内容 | 唯一维护位置及取用方式 |
| --- | --- |

| 表情意图、面部变化、强度及组合 | 本技能的[拆解方法](references/表情拆解方法.md)和[参考表](references/表情参考表.md)；通用拆解方法与具体写法分开维护 |
| 景别、构图、机位、运镜、光影、焦点 | 本技能的[镜头指南](references/镜头语言参考指南.md) |
| 完整动作链的镜头组织、转写与连读检查 | 本技能的[完整动作链指南](references/完整动作链设计与转写指南.md)集中维护方法和完整示例；镜号、P段及已确认动作归分镜，模型结构与标签归视频提示词，打戏动作机制沿下方专业入口 |
| 转场与镜间衔接技巧 | 优先补入镜头指南相关章节；独立内容足够时再拆参考。区分镜内变化、切镜和后期转场，明确前镜结束、后镜开始及匹配条件；逐镜写法与核对归[共用分镜](../studio-storyboard/SKILL.md)，实际编号及业务分段归调用业务的阶段，实现格式归实际模型工具，不把术语当作模型已支持的功能 |
| 通用特效与材质 | 先检查[介质与分层](../studio-combat-methods/references/vfx-rendering-mandate.md)及相关题材资料的适用范围。已有归属原位更新，打戏专用要求沿其适用条件。确需新增类别时，按[新增参考类别](references/学习与反馈维护规范.md#新增参考类别)处理 |
| 修仙法术、阵法、剑气与灵力 | [玄幻专项](../studio-fantasy-combat/SKILL.md)的[法术表现方法](../studio-fantasy-combat/references/xuanhuan-elements-vfx.md)及[造型参考库](../studio-fantasy-combat/references/仙侠法术与特效造型参考库.md)；保留专业设计与调用流程 |
| 武侠、通用动作与写实格斗 | [通用打戏](../studio-combat-methods/SKILL.md)或[写实专项](../studio-realistic-combat/SKILL.md)按问题选择方法；攻防因果、动力链和节奏不迁入本技能 |
| 国风、古风等题材／风格分享 | 按实际知识点归入画风、造型、镜头或动作的适用参考。业务专用方法按所属业务的定位或资产规范维护，跨业务可用的镜头与动作方法归上方相应共用参考。项目已采用的风格留在项目资料 |
| 模型格式、输入标签、工作流及参数 | 沿[H3](../studio-h3/SKILL.md)、图片对应能力及[ComfyUI执行](../studio-comfyui/SKILL.md)的现行规范；外部技巧不能直接覆盖接口或执行规则 |

同一帖子可以涉及多个主题，读取结果复用，逐项归位。新增内容优先补现有条目或章节，已有完整专业流程的资料继续原位维护。现有分类无法承接的可复用内容按[新增参考类别](references/学习与反馈维护规范.md#新增参考类别)与用户讨论归属。只有职责和工作流程确实独立时才考虑另设技能，不按每个知识主题创建技能或空参考文件。

## 业务边界

通用逐镜模板与写作核对由[共用分镜](../studio-storyboard/SKILL.md)维护。正式剧情与表演意图、资产设计、编号、业务接续和模型结构由对应业务及工具负责。本技能只提供方法，落实到当前获授权的产出和既有自检，不另造一份分镜或增加审核轮次。缺项会改变已确认剧情、人物关系、站位、视线、风格、能力或镜头时，回负责业务处理，不在转写中补编。

材料获取与视频分析调用[studio-video-study](../studio-video-study/SKILL.md)，纯图文使用当前可用的页面与图片能力；读完回到学习入口完成归并。本技能不生成媒体、不自动审片、不主动监控账号或批量扩抓、不为验证额外测试。上传、查询、下载、后处理和正常结果通知不触发创作重写或参考验证。维护修改沿[结构维护规范](../studio-entry/维护规范.md#维护任务读取路径)处理。
