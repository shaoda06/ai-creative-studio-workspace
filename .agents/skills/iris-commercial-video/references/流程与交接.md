# 流程与交接

## 阶段与职责

本文件归一级业务入口，只管理阶段关系和接续；各阶段详细做法、内部生产与交付整理模板由对应二级技能维护，入口见[主控路由](../SKILL.md)。

| 阶段 | 必需输入 | 输出 | 确认与接续 |
| --- | --- | --- | --- |
| 需求与参考 | 客户原件、用户说明、参考及已知规格 | 简报、参考理解、关键未知 | 用户确认理解；产品事实缺项由用户向客户补充 |
| 创意与音画 | 简报、参考、已选方向或甲方原稿 | 制作脚本，对外方案按需 | 按既有确认范围整理来稿，实质改动按项目确认 |
| 分镜与声音 | 当前脚本与反馈 | 镜头、台词及声源、分段计划，导演表按用户选择 | 用户核对可执行性；客户看画面方向 |
| 资产 | 分镜需求及实际模式 | 参考图、业务内容、采用版本 | [资产阶段](../../iris-commercial-assets/SKILL.md)管理有条件的样例验证、实际采用及按范围交接；待绑定不等于齐备 |
| 视频生产 | 当前分镜、采用素材、模式参数和授权 | 按批生产记录、真实候选与实际决定；样片说明按需 | [视频生产阶段](../../iris-commercial-production/SKILL.md)管理路线及按批审阅，接续沿实际授权 |
| 返修与交接 | 具体反馈、原采用及实际交接要求 | 返修候选、当前采用组合、实际交接；包和说明按需 | [返修阶段](../../iris-commercial-handoff/SKILL.md)评估方案；用户明确要求时Agent才调用脚本打包，日常下载由网页后台处理 |
| 完单复盘 | 用户明确最终交付的说明、相关真实历史与产物 | 一次完单复盘、查重后的规则建议、按需结项摘要 | [复盘阶段](../../iris-commercial-retrospective/SKILL.md)按维护授权处理建议；此前只留必要问题记录，不追索人工细节 |

从确认的制作脚本到候选取回按[共用视频制作核心](../../studio-video-production/SKILL.md)接续。按[资产阶段](../../iris-commercial-assets/references/流程规则.md#分批交接与完成)说明本批覆盖范围、待绑定项及影响。候选交视频生产阶段组织批次审阅，实际返修、采用和交接沿上表分工。对关键理解先用短段文字或关键图确认，再扩大投入。

### 整合方案与阶段交接

用户要求整合参考或方案时，可以在一份方案里集中说明内容。方案确认后，按[创意阶段规则](../../iris-commercial-creative/references/流程规则.md#当前制作脚本的命名与网页核对)把已确认内容存成独立制作脚本并登记版本。正式分镜另存为分镜与声音制作稿，引用本次实际使用的脚本版本。后续制作按各阶段已有要求和实际授权接续，沿用用户已经确认的内容。

## 业务与工具分工

Agent理解、写作、选择版本和处理反馈；脚本按明确输入完成装配、文件处理及自动检查。工具实际可用范围以[能力状态](工具适配.md)为准，不以登记名称替代验收。项目共用事项记项目状态，具体作品的阶段、版本、授权和交付记作品状态，各阶段按实际进展更新；客户批准由用户提供事实，不由技能推定。实际对外整理与导出进入[跨阶段交付规则](对外交付.md)。

## 目录与当前入口

新订单按[项目建档与README规范](../../iris-commercial-brief/references/项目建档与README规范.md)创建。项目 README 承载共用说明和作品导航，项目状态保存共用事项及整单结项。每件作品在 `作品/F编号-名称/` 独立保存阶段资料，作品 README 提供本片导航，作品状态唯一保存本片阶段、有效版本、实际授权、待办和会话职责。其他文件按范围引用，不复制状态表。横竖、长短版属于同片交付版本。

一级目录、阶段主文件及过程资料的存放统一执行建档规范。作品 F001、镜头 SH001、生产段 P001 各有身份；SH/P/R 及业务资产 A 编号在作品内使用，图片/视频等资源编号按项目资源索引管理，内容段落不直接等于镜头或生产段；订单不套EP集号。

分别使用[项目状态模板](../templates/项目状态.md)和[作品状态模板](../templates/作品状态.md)。具体作品的批准在作品状态中指向对象和版本，共用批准从项目状态引用；执行记录保存任务ID、真实参数/输入/来源和结果，不回写历史请求。发生新决定时明确其影响范围、替代版本、失效下游及可复用项，按实际授权通知相关会话；无消息权限时先更新项目入口并告知用户。

## 返修与并行

每个目录/对象指定一名当前写入者，同一作品的多个会话共用一份资产清单和一份作品状态，跨作品事项共用项目状态。接续先查文件及批准记录，再补读会话；读到旧快照不覆盖新事实。分支会话可能继承同一段聊天，复盘须去重。

本次任务只改受影响项；用户指出一个系统性缺口时，检查本批同类镜头，不等用户逐段重复指出。内容、角色、界面或声音变更时，核对制作脚本、已确认的分镜脚本、已采用素材、实际绑定和交付稿是否同步。导演表按[共用用途规则](../../studio-storyboard/references/导演分镜表制作规范.md#用途与制作范围)用于审阅，PDF交付稿按实际生产资料和成果整理。

版本递增并保留不同内容的历史。候选存在、技术完成、用户采用、客户确认、剪辑包交接、最终客户交付分别记录。人工最终交付可按用户明确报告完成登记，无需否定用户已完成的事实；未取回的成片路径和参数写“未记录”，不编造。

## 阶段交付记录

交付稿由本阶段生产资料及实际成果整理，按[对外交付规则](对外交付.md)先审Markdown，批准具体版本后调用固定PDF工具。阶段生产稿记来源映射和整理范围；所属作品状态记用户决定、发送及甲方确认事实；共用事实引用项目状态，两者相互引用，不另建重复状态表。新订单可沿既有工作进入任一阶段，不因目录换代重做已确认内容。

当前后三阶段的六份模板分别由各阶段维护：内部生产/返修交接/完单复盘按实际任务使用，对外样片/交接/结项说明按需整理，不要求每次生产生成全套。阶段字段、必填时点及工具分工直接读取对应阶段规则，不在一级入口复制细则。

## 整片制作轮次

作品的审阅组合按[视频生产阶段](../../iris-commercial-production/references/整片制作轮次与网页接入.md)维护；单次生成批次保留原编号，未改段引用原版本，旧轮次保留。临时查看候选、失败重试和重新下载不新增轮次，不增加全片重做或重复审批。

## 社媒运营接续

账号运营、社媒封面、发布及传播效果复盘交独立一级入口[Studio社媒运营](../../studio-social-operations/SKILL.md)。先按[本业务运营接入](../../iris-commercial-brief/references/社媒运营接入规范.md)提供C项目、F作品、交付版本、账号及资料位置，再按公共运营方法接续；使用原项目／作品状态。

项目已有适用运营报告时，创意、分镜、封面及交付准备按[后续制作参考](../../studio-operations-guidance/SKILL.md)筛选，采纳内容写原阶段工作稿。没有报告不阻塞制作，也不自动创建采集任务。商业完单复盘继续归本业务，传播效果复盘归运营；客户验收或成片交付不等于社媒发布授权。
