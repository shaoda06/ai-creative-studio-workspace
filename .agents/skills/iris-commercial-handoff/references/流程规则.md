# 返修与交接流程与规则

媒体保存执行[项目资源与版本管理](../../studio-workspace-browser/references/项目资源与版本管理.md)：用户原件、生成结果和处理结果归项目资源区；候选、采用和客户意见仍由本阶段原Markdown维护。每次使用明确资源编号与版本，采用不移动／复制媒体，技术输入输出另列准确引用；客户批准不从资源存在或最新版推定。

更新日期：2026-11-02。按用户已确认的业务决定和模板正式维护；不因规则落地授权真实返修、生成或打包。

## 流程与接续

定位具体反馈与来源 → 评估局部修复或相关段重做 → 按授权处理 → 审阅采用 → 维护当前采用组合 → 实际交接；用户明确需要包时再调用共用工具，交接说明按需整理。

使用[返修与剪辑交接模板](../templates/返修与剪辑交接.md)记录本轮范围；无返修只做交接时跳过返修部分，不为打包另造返修记录。一个批次一份主记录，保留未受影响的已采用素材。

## 执行要点

Agent把问题定位到具体段/镜、来源版本、时间窗口与允许修改范围，先评估局部修复是否合适。工具可用、范围可控且能保留未受影响内容时才局部修；角色、动作或构图逻辑等不适合局部处理的问题回相关生产段重做，不为了局部修而局部修。

| 问题及条件 | 可评估方向 | 必须核对 |
| --- | --- | --- |
| 小范围错字、平面可跟踪 | 局部去字/贴字与跟踪 | 遮挡、透视、边缘、字形及整个窗口 |
| 画面可复用、台词或声线需换 | 独立配音与对应窗口替换 | 时长、声线、接缝、口型及音效损失 |
| 短暂误张嘴、有可用闭口样本 | 嘴部局部合成 | 贴片边缘、脸部形变、运动和遮挡 |
| 角色出场、动作或构图逻辑错误 | 相关生产段重生成 | 上下游连续性、原音轨与重做范围 |

这些是可评估方向，不代表每种工具均已接通或全部故障都能局部修。操作前核对[工具适配](../../iris-commercial-video/references/工具适配.md)及实际工具；讨论能否修不授权付费或新生成，有效已有授权按原范围执行。

新处理保存新候选，不覆盖原件；检查整个受影响窗口和上下游，记录实际副作用，用户明确采用后更新当前组合。顺序、每段版本、实际时长、音轨、速度和规格以真实素材/工具报告为据，不为凑目标时长自行裁切、变速或改声。超过60秒的对外时长同时写准确分钟换算。未采用候选留项目历史，不混入默认采用包。

## 按需打包与自动检查

需要剪映包时，默认jypack；ZIP仅在需要归档、备用入口或明确要求时生成。接收方有明确格式要求时优先遵循；两种能力都保留，不改包内部格式。默认格式只决定需要包时选哪种，不构成自动打包授权。

- 用户在网页点击下载后，由后台调用共用脚本打包、自动检查并提供下载，返回真实成功或具体错误。
- Agent需要时准备已采用文件、顺序、规格等业务输入并处理异常；只有用户明确要求时，才调用同一脚本生成并提供包。生成完成或阶段交接不自动触发打包；不手工拼包、不逐包打开剪映。
- 脚本按明确输入生成并检查包，技术校验、媒体/引用边界及异常处理归提供端studio-jianying；后台负责受权文件访问、下载响应及临时文件。通过一级[工具适配](../../iris-commercial-video/references/工具适配.md)定位，不把打包实现搬进业务技能。
- 剪映导入、播放、保存重开等客户端实测属于工具首次开发、相关逻辑修改后的隔离验收或兼容故障排查，不是每单/每包必经业务步骤。明确要求专项实测时只记录真实范围，不把脚本结构检查描述成客户端已导入。

可以仅交接已采用素材，不以生成包或逐包客户端实测为交接前置。业务采用、文件交接、用户使用和最终客户交付分别记录。人工字幕、BGM、精剪及变速继续由用户接续；用户说明最终交付后登记事实，未收到最终文件时路径/参数写未记录。

## 内部记录与填写时点

以下字段归[内部模板](../templates/返修与剪辑交接.md)，授权、采用和交接事实引用项目状态及原记录；技术事实引用脚本/后台档案，不重复抄写。

| 字段 | 填写条件 | 最少需要什么 |
| --- | --- | --- |
| 项目、本轮范围、记录版本与依据入口 | 使用本模板时必填 | 当前订单、本轮是返修/交接或两者、对应生产与项目状态入口；执行范围引用原授权，仅评估时不写成已获执行授权 |
| 原问题与修改范围 | 实际返修时必填 | 来源段/镜/版本、问题时间窗口、具体反馈、本轮允许修改什么；未受影响的采用素材保留 |
| 处理选择与原因 | 已确定返修方案时必填 | 局部修复或相关段重做的选择、当前可用工具与原因；实际执行仍按授权 |
| 新候选、结果与采用依据 | 处理/审阅实际发生后记录 | 引用真实处理报告、候选及用户决定，不预先填已采用；有副作用时说明 |
| 当前采用组合 | 实际交接或已有采用变化时必填 | 段号、采用文件/版本与来源、顺序/时长、音轨/速度/规格；共用技术值引用报告，不复制整份参数 |
| 实际交接范围与接收情况 | 交接实际发生时记录 | 给谁、交接哪些真实文件及实际结果，引用项目状态；未收到确认不补造客户确认 |
| 打包请求、包与自动检查结果 | 只有实际打包需求并已触发时填写 | 网页用户点击或Agent调用所依据的明确用户要求、脚本产物和自动检查入口；Agent不手工拼包或逐包打开剪映 |
| 专项客户端实测 | 明确要求且实际执行时才记录 | 客户端/版本、真实范围及结果；常规交接没有这一必经项，工具开发验收留工具维护记录 |
| 人工接续说明 | 接收方实际需要时填写 | 准确台词/业务文字、必要时间位置及已知限制，不增加默认字幕/BGM/精剪/变速任务 |
| 对外整理 | 确需另有对外说明时填写 | 对应模板4及有效生产来源；批准/发送引用项目状态，实际PDF及报告发生后再链接 |

## 交付整理与完成

需要向实际接收方说明内容时，使用[素材与剪辑交接说明](../templates/素材与剪辑交接说明.md)，由当前采用及真实交接整理，不另建一份采用真源，也不在每次网页下载时强制生成说明稿。

| 字段 | 填写条件 | 最少需要什么 |
| --- | --- | --- |
| 项目名称、说明版本、日期 | 使用本模板时必填 | 当前对外说明的身份 |
| 本次交接范围 | 必填 | 明确是素材、剪辑草稿或实际已有成片；仅交接草稿不称最终成片完成 |
| 实际文件及用途 | 有交接文件时必填 | 实际随附文件名、对应内容/范围、必要打开或使用说明；不放内部本机路径 |
| 本轮修改摘要 | 有相关已完成修订时填写 | 实际修改及影响范围，不重写创意方案或补造客户确认 |
| 剪辑接续资料 | 接收方实际需要时填写 | 文字、声音、素材对应及人工接续范围；只保留有用说明，不要求接收方提供手工操作日志 |
| 检查结论与使用限制 | 实际影响接收和使用时填写 | 有包时从脚本自动报告提取必要结论和具体异常；专项客户端实测只列明确要求且真实执行的范围，不因未逐包打开剪映增设待验环节 |
| 本次需要确认事项 | 确有必要时填写 | 对具体文件/范围的真实待确认点；仅交接告知时不凑确认问题、不额外承诺后续工作 |

对外稿只呈现接收方所需事实，不附内部服务、缓存、请求、失败流水或成本分析。实质修改先回写内部生产内容，再按[跨阶段交付规则](../../iris-commercial-video/references/对外交付.md)处理Markdown批准及PDF；已有有效批准直接沿用，整理说明不自动导出或发送。交接确认、甲方确认及最终交付不相互代替。

## 已确认的技术留档边界

技术凭据、原任务恢复及独占提交保护按[共用后台精简留档](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#执行附件精简留档)执行，旧历史不清理或转换；业务记录只引用技术档案。导演包仅用户明确要求时导出，不作为返修、采用或交接完成条件。
