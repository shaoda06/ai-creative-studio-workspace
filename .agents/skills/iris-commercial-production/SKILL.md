# Iris 视频生产

媒体原件、上传参考音视频及修改版本统一按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存；本技能继续维护原业务记录和采用。输入、审核、采用及导出引用准确版本，不因阶段再次复制媒体。

按[阶段规则](references/流程规则.md)处理本次范围。业务阶段负责内容、业务条件和记录，不在内部嵌套更深业务技能。

新生成批次先按[提交前确认](references/流程规则.md#提交前确认)核对工作流及配置来源，并向用户说明本次分段和时长。

- 输入：当前分镜、明确素材版本、可用执行工具及授权。
- 内部生产：[模板](templates/生产任务.md)，一批一份主记录，字段与时点见阶段规则。
- 作品制作轮次：[轮次与网页接入](references/整片制作轮次与网页接入.md)，新视频批次按[清单接口](references/任务服务接入.md#iris-制作轮次自动登记)提供已确认资料，由提交脚本登记到同一份[轮次索引](templates/制作轮次.json)。
- 交付整理：[模板](templates/制作进展与样片说明.md)，来源于当前生产资料与实际成果。

Agent与脚本按[业务与工具分工](../iris-commercial-video/references/流程与交接.md#业务与工具分工)协作；工具接续查[能力状态](../iris-commercial-video/references/工具适配.md)，实际整理对外材料时读取[跨阶段交付规则](../iris-commercial-video/references/对外交付.md)。

送审、二采和样片例外按[制作策略](references/流程规则.md#执行要点)接续，保留本批授权范围。

本工作区接入共用视频任务引擎时，读[任务服务接入](references/任务服务接入.md)。本阶段提供业务输入与成果登记，服务运行和监控归共用工具，不改变业务授权或自动采用。

处理前明确 C 项目与 F 作品；本阶段资料和本片状态归作品，客户共用原件及媒体版本归项目。目录与状态分工统一按[建档规范](../iris-commercial-brief/references/项目建档与README规范.md)执行。

收到后台通知后，按[结果接续](references/任务服务接入.md#后台结果接续)回写本批生产记录并进入原定审阅或交接。
