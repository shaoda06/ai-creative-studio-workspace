# 商业生产接入公共任务服务

商业业务使用共用[studio-workspace-browser](../../studio-workspace-browser/SKILL.md)提交、查询及恢复任务。浏览入口和任务监控由统一工作区服务维护，生产阶段不运行独立后台或任务页。服务登记和启停交共用工具，商业阶段只维护业务输入、成果归属与采用记录。

任务清单使用本项目的实际文件、输出位置和授权范围，通过studio-comfyui/scripts/comfyui_dispatch.py提交，先prepare-only，内容与授权齐全后入队。technical适配只保存真实成果及客观媒体报告；业务状态、候选与采用由本阶段按实际结果维护，不伪造短剧编号。

资料和执行附件保留在商业项目内；总技能库中的共用客户端从所属资料区的工作区浏览服务/runtime/task-service.json读取统一地址、空间前缀和本空间token。查询、报告及恢复子命令明确传入`--workspace "Iris实际资料根目录"`。读取原任务状态、报告或重试取回时沿用原ID，不重新生成，不复制其他空间任务库或采用记录。


## 视频制作页

业务展示适配由scripts/iris_browser_production.py维护，资料区在统一浏览服务登记production_adapter为iris-commercial-production。适配只读已提交装配记录、实际请求和输出；准备稿不冒充执行，任务完成不自动采用。不要求EP目录，不自行启动后台。H3技术正文及槽位解释调用共用studio-h3/scripts/h3_browser_context.py；历史Nora资料只读调用原解析，不转成新订单流程。

网页的“视频制作”按实际批次和分段显示视频、候选、参考与当次生成文字。缺少分镜快照或本地来源时明确提示；原业务文件在“制作资料”入口。用户主动填写的网页意见统一保存在当前项目生产目录的“视频修改意见.json”，跨批按分段、阶段与R版本区分；它是审阅意见，不替代正式采用或客户决定。不为展示复制技术请求、媒体或另建状态台账。
