# 商业生产接入公共任务服务

商业业务使用共用[nora-workspace-browser](../../nora-workspace-browser/SKILL.md)提交、查询及恢复任务。浏览入口和任务监控由统一工作区服务维护，生产阶段不运行独立后台或任务页。服务登记和启停交共用工具，商业阶段只维护业务输入、成果归属与采用记录。

任务清单使用本项目的实际文件、输出位置和授权范围，通过nora-comfyui/scripts/comfyui_dispatch.py提交，先prepare-only，内容与授权齐全后入队。technical适配只保存真实成果及客观媒体报告；业务状态、候选与采用由本阶段按实际结果维护，不伪造短剧编号。

资料和执行附件保留在商业项目内；总技能库中的共用客户端从所属资料区的工作区浏览服务/runtime/task-service.json读取统一地址、空间前缀和本空间token。查询、报告及恢复子命令明确传入`--workspace "Iris实际资料根目录"`。读取原任务状态、报告或重试取回时沿用原ID，不重新生成，不复制其他空间任务库或采用记录。
