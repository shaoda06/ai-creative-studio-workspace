# 分镜与声音流程与规则

阶段一至三按2026-10-30用户确认的统一口径执行。

## 流程与接续

读取音画 → 拆镜与调度 → 声音和文字对应 → 连续性核对 → 制作已获授权的导演表 → 回写讨论 → 整理交付。

输入：当前音画、声音方向、实际参考及反馈。输出：分镜与声音制作稿、导演表、分镜脚本与导演表。按本次范围判断生产资料、交付整理和客户确认，不要求整阶段全部重做。

## 执行要点

按[制作分镜模板](../templates/分镜与声音制作稿.md)拆镜。每镜写镜号、时间/时长、景别、机位构图、运镜、起始状态、动作、结束状态、台词/声源、业务文字、音效、转场、依赖资产。填写运镜字段须实际解释如何看清动作，不能只加空字段。

拆成生成段时，在本版分镜的分段表登记 P 段、按实际顺序排列的 SH 镜号和段内时码。镜号逐个列出，例如「SH001、SH002」。用 `段内Shot及时间` 记录从本段 0 秒起算的范围，例如 `Shot 1：0–3秒；Shot 2：3–7秒`，编号顺序对应同一行的镜号，范围首尾相接并覆盖该段计划时长。只有全片时码或还没有确定切点时，保留镜号，段内时码留空。

作品确有业务场次时，在同一张表为每个 P 段填写 `场次`（如 `S001`、`S002`）。按本版分镜的出场顺序给连续场次编号，同一场次的 P 段连续排列。场次用于浏览和审阅分组；无需分场次的作品留空，按整片组织。作品内的 P 段编号不随场次重新起号。

固定物件、手部接触、抽屉开合、卡片位置和摄影机方向前后衔接；切镜后从已有状态继续，不能重演上一动作或让道具复位。单独片段重新说明其入镜状态，引用同一图不保证连续性。

每句标发声者和起止窗口、是否画外音。角色口型只对应本人台词；其他声源说话时明确可见角色的嘴部与反应。不以“中性青年”等模糊声线替代本单需要的清楚区别。以选定声线、参考音频（如有）和实际结果为准，不承诺只写提示词即可锁声。

导演表用于构图和动作沟通，镜号、文字、时间来自当前分镜。按信息密度分页，不默认一页四镜；后续文字改稿影响导演表时标为旧图，不能作已更新。交付用[分镜交付模板](../templates/分镜脚本与导演表.md)，与内部逐镜稿分开；图文PDF制作见[对外交付](../../iris-commercial-video/references/对外交付.md)。

完成：镜头相加与目标时长对应、动作连续、声源及文字明确、依赖资产可定位。进入生产前只阻塞实际必需缺项，不让可后补的展示稿阻碍已授权任务。

## 交付整理与完成

本阶段交付整理、批准及导出顺序统一执行[跨阶段交付规则](../../iris-commercial-video/references/对外交付.md)，本节只补充所属阶段的交付内容与完成要求。

导演表的八列、速写、分页、来源及采用只在[导演表规则](导演表规则.md)维护；使用[导演表内容与登记](../templates/导演表内容.md)，不为商业订单移植EP目录或网页展示依赖。
