# Studio PDF导出

调用方提供已经选定并获准导出的Markdown版本、实际图片、布局、品牌配置及输出位置。业务批准与内容来源由调用方负责，工具不改写正文、不挑方案、不发送文档。隔离样稿按明确测试授权运行。

使用[scripts/export_pdf.py](scripts/export_pdf.py)，命令、依赖、布局标记与成功/失败判断见[调用规范](references/调用规范.md)。通用版式只在[布局资源](assets/layout.json)维护，水印文字由业务/订单配置传入，不在工具内写客户品牌。

Agent核对来源、批准及逐页视觉效果；脚本负责实际配图嵌入、固定排版、连续页码、水印和技术检查。自动通过不等于视觉审阅或客户确认。导出问题恢复原Markdown/配置再另存新版本，不临时重写一份导出程序。
