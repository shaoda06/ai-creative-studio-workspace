# PDF固定导出调用规范

## 环境与命令

Python需pypdf、reportlab；Node需marked、playwright及其可用Chromium。优先使用当前Codex提供的load_workspace_dependencies定位已配置运行环境；不将本机绝对路径写进脚本，不自动安装或升级。苹方样式需要本机已安装PingFang SC，字体不随本工具分发。默认布局沿已认可的C001排版方法，已去除个案路径、章节和页数。

在工作区根执行，使用已配置的Python和Node：

```sh
"$PDF_PYTHON" .agents/skills/studio-pdf-export/scripts/export_pdf.py \
  --source /实际已批准稿.md --layout mixed \
  --output /新版本交付稿.pdf \
  --node "$PDF_NODE" --node-modules "$PDF_NODE_MODULES"
```

PDF_PYTHON、PDF_NODE、PDF_NODE_MODULES是本次定位到的运行环境路径。Node包已可正常解析时可省略node-modules，Node已在PATH时可省略node。路径均为本机文件，图片相对Markdown位置解析，也支持实际本地绝对路径。运行只读取明确文件并在输出旁创建临时排版目录，完成后清理；不联网取图、修改源稿或发送客户。

成功退出0，返回exported、PDF及同名.检查.json路径和页数；自动核对通过后才写PDF。已有输出或检查报告拒绝覆盖，另存新版本。环境、缺图、缺字或字体检查失败保留具体错误，不用备用字体或跳过图片冒充完成。创建/编辑PDF还需遵循当时可用pdf技能的制品标记及渲染检查要求。

## 三种布局与图片

- text：文字稿，默认A4竖向，长正文自动分页，表头重复，保持标题层级。
- album：图册，默认A4横向；可用--orientation portrait选择竖向图册。图片保持比例、限制到页面可用高度，不裁图或重绘。
- mixed：文字与图页混合，默认首段竖向。用下面的标记明确另起一页及方向；没有固定章节名、图表页数或镜头数。

```markdown
# 当前交付标题

这里是已有正文。

<!-- pdf-page: landscape -->
### 本页图表名称

![实际图表名称](<../../studio-pdf-export/references/相对路径/已准备的图表.png>)

<!-- pdf-page: portrait -->
## 后续说明
```

每个标记开启独立分页段，段内文字仍可自然分页；文字稿和图册也可用同一标记。图册需要单图一页时，每页写自己的标记，避免将标题和大图挤入上一页。PNG、JPEG、WebP、SVG读实际文件后嵌入PDF，不依赖外链；图像解码和显示比例自动检查。正文使用普通Markdown标题、段落、列表、粗体、表格和图片；本工具不执行任意HTML，分页标记由工具解释。

## 排版配置

固定导出生成无水印 PDF。需要调整字体、字号、行距、纸张、页距、图片最大高度或页码时，用 `--profile` 传入覆盖 [layout.json](../assets/layout.json) 的 JSON。历史配置中的 `watermark` 字段会被忽略。嵌入图片前核对图片本身的品牌标记及使用范围。

正文、标题为苹方；连续页码沿原实现使用8pt Helvetica数字。页码和图片比例由固定配置及脚本统一管理。内容、批准和正式交付状态归业务阶段。

## 检查与验收

检查报告记录实际页数/方向/尺寸、图片入口、实际PDF字体、有效配置、耗时和自动结论。自动检查正文可提取文字、图片加载及比例、连续页码；字体选择为苹方时核对Chromium实际渲染字体及PDF字形形式；macOS可能输出不带BaseFont名称的Type3字形，不能据此误判未使用苹方。报告visual_review保持pending，Agent按pdf技能渲染逐页查看，另在本次验收/交付记录中写真实视觉结论。

检查大标题与正文、表格跨页、图像比例和留白、中文字形、连续页码和有无额外叠层。自动文字核对不证明每个像素都可读；长表和实际客户配图仍要逐页检查。维护后用隔离文字稿、横/竖图册及混合稿验证，覆盖缺图和已有版本等真实失败场景，不提交客户生成任务。

临时HTML、分页PDF和排版检查文件只在本次临时目录使用，操作成功或失败均由工具清理；正式PDF、必要检查报告、原Markdown与实际配图保留。逐页视觉检查所需的临时渲染图保留到检查完成，再清理本次副本。其他过程资料边界见[临时资料生命周期](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#临时资料生命周期)。
