# 导演台正文与素材业务接续规范

本文件保存从模型工具归回本业务阶段的约定；模型格式、槽位与技术操作仍由共用H3工具维护。

每个组分别列清“模型标签 → 公共或本组 → 实际文件及版本 → 用途”。沿用既有05计划映射和[逐集目录规范第4节](../../nora-drama-production/references/逐集目录与资产管理规范.md#4-视频执行输出审核与采用)中的实际输入映射，不另造素材排序台账。按第2.4节逐组核对有效槽位、混合数量及音视频时长，再核对正文中的标签；上传成功或网页能显示槽位不等于输入已经符合全部限制。

先规划公共与本组素材及定义的归属，按逐集内容规范的语言适配完成并保留各段完整模型正文及中文参考版，再拆到上述两处，核对导演台实际拼接后的完整正文。模型正文的内容边界沿用该规范。网页的 `@` 素材选择最终对应官方标签；直接填写API时使用明确的 `<Picture N>`／`<Audio N>`／`<Video N>`。

拼接后的完整正文执行[模型提示词长度规则](视频提示词制作规范.md#模型提示词长度)。填写完成及公共／本组正文变化后，逐组检查实际拼接字符串：subject_definitions标题只出现一次，后五节顺序正确，标签与实际素材对应；在既有准备／执行记录注明计数结果。正文与分镜的状态及其他内容核对按[模型正文的内容核对](视频提示词制作规范.md#模型正文的内容核对)执行，台词格式差异按[声源与台词格式转写](视频提示词制作规范.md#声源与台词格式转写)处理。

公共定义只写各段共同成立的身份、外形或空间结构，不代写随剧情变化的动作、穿戴、姿态、情绪或持有物状态。本段独有开场图可简述必要的图中起始状态及参考范围。每段实际需要的可见／可听起始状态、变化时点及结束状态主要写在本组`detailed_description`，其他章节按上述参考分工核对；画外接续记录的筛选和局部入画边界按[镜头可见内容与画外连续性](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头可见内容与画外连续性)处理，不将制作依据中的整份状态记录复制为出镜要求；参考保留范围和目标状态有差异时一并核对，不只在逐镜正文补一句而保留其他章节的冲突要求。不在前段复制后续段才发生的状态，也不以“变化后保持”概括整场后复制到每段；当前段已经成立的状态须明确，不只引用其他段。具体连续性与参考差异处理按[镜头状态规则](../../short-drama-storyboard/references/场次分镜制作规范.md#镜头状态的变化延续与参考差异)执行。
