# 固定脚本接口规范

## H3正文与内容核对检查

用于原生H3导演台一采、二采的正文准备；业务顺序与证据含义由[内容核对规范](视频提示词制作规范.md#提示词编写与检查顺序)维护。逐组优先读取`taskType`／`task_type`，未指定时沿用公共区及导演台模式；同一画布不同模式分别检查。r2v／v2v／rv2v使用Ref2VA六节及Subject对应；t2v／i2v／fl2v使用基础三节，按实际首尾图槽位检查首行对齐说明、结束时点和镜号。基础模式不强制Subject表，可填写`subjects:{}`；四类内容核对及中英文对应仍完整保留。fl2v支持首尾、仅首、仅尾及无图文本组，不将普通r2v参考误当作首尾帧。具体正文结构按[h3-prompt-writing模式指南](../../h3-prompt-writing/SKILL.md)执行。

独立离线入口只读本机文件，不联网、不上传、不入队、不调用模型。正常生成由[统一任务清单入口](../../nora-serial-drama/references/固定脚本接口规范.md#一次装配与批量入队)自动执行准备检查并按授权入队，本轮仅准备时才加`--prepare-only`；已备结论按[执行前检查与复用](../../studio-comfyui/references/ComfyUI-服务配置与任务提交规范.md#执行前检查与复用)接续。同一检查自动纳入`执行检查报告.json`的`content_checks`；不能用离线报告代替正式准备报告。模式与首尾图包含在本次内容绑定中，修改后需重新准备；不回写历史任务的原正文或批准事实。

在工作区根目录使用可用Python 3.10＋运行，Windows加`-X utf8`。路径参数相对当前目录；`--basis-file`和输入映射内证据路径相对`--project`且必须在项目内。

```powershell
python -X utf8 .agents/skills/nora-video-prompts/scripts/h3_prompt_checks.py --project "projects/项目名" --workflow "projects/项目名/执行附件/工作流.api.json" --mapping "projects/项目名/执行附件/输入映射.json" --basis-file "09-剧集制作/EP编号/02-本集剧本/本集剧本.md"
```

`--output`可指定一个尚不存在的JSON报告文件；默认只向标准输出报告，不改写任何输入或历史报告。`--basis-file`可重复，用于返回所选依据文件的指纹，不替Agent填写判断。退出码0表示确定性检查和证据绑定通过，1表示失败；查看`issues`及各`groups[].issues`。输出的`input_sha256`用于标识本次实际启用的公共区与原组输入（含正文、素材、时长和接续）；变化后须先核对再更新记录，不直接刷新指纹冒充检查。

只写或修订提示词、尚未装配工作流时，可直接检查正式提示词文档（可重复`--document`）：

```sh
python .agents/skills/nora-video-prompts/scripts/h3_prompt_checks.py --document "项目内/P001-视频提示词.md" --document "项目内/P002-视频提示词.md" --mode r2v --output "尚不存在的正文检查.json"
```

文档模式读取“提交给模型的完整提示词”和“中文提示词参考版”的text围栏，`--mode`默认r2v；不使用`--project`、`--workflow`、`--mapping`或`--basis-file`。输出`documents[].issues`及`ok`，退出码0为确定性正文检查通过，1为失败；不检查素材绑定或替Agent填写内容判断，不构成生成准备通过。正文检查会报告空间描述中的明确地理方位，忽略对白、引号内可见文字与已定义的主体专名；不据此声称所有自然语言方向问题均已识别。

`space_action.shots`的`shot`为画面正文中从1开始的镜号，须完整覆盖、不重复；`prompt_quote`必须在对应Shot内，`note`为该镜的实际判断。工具只验证覆盖与原文，不推断判断正确；旧任务恢复沿原记录，新准备缺项须补做实际核对。

既有`输入映射.json`中的`content_review`使用以下结构。每个选中原组一项，未选中组不纳入；`node`为字符串节点ID，`index`为从0开始的真实原组序。下例是字段说明，示例省略号不能提交。

```json
{
  "content_review": {
    "version": 1,
    "groups": [{
      "node": "实际导演台节点ID",
      "index": 0,
      "input_sha256": "离线检查返回的当前输入指纹",
      "subjects": {"1": "来源中的准确中文名称"},
      "chinese": {
        "file": "项目内既有提示词文档.md",
        "sha256": "当前中文正文指纹"
      },
      "checks": {
        "identity": {
          "status": "pending",
          "note": "实际检查范围、判断以及问题处理结果",
          "prompt_quote": "当前模型英文中的准确片段",
          "sources": [{"file": "上游依据的项目相对路径.md", "sha256": "依据指纹", "quote": "文件内实际原文"}]
        },
        "space_action": {"status": "pending", "note": "...", "prompt_quote": "...", "sources": [], "shots": [{"shot": 1, "prompt_quote": "该镜最终正文准确片段", "note": "本镜空间、各动作路径目标及结束接续的具体判断"}]},
        "continuity_sound": {"status": "pending", "note": "...", "prompt_quote": "...", "sources": []},
        "translation": {"status": "pending", "note": "...", "prompt_quote": "...", "chinese_quote": "对应中文准确片段", "sources": []}
      }
    }]
  }
}
```

`subjects`覆盖所有已定义Subject，包括人物、场景、道具；来源名称不能根据模型译名反造。四类检查全部完成且有具体依据后才填写`passed`；`sources`引用相应采用剧本、分镜、资产或项目定位，不能引用核对记录自身作为证明。中文使用既有文档的“中文提示词参考版”text围栏；兼容已存在的冻结TXT，不为新任务另建中文正文。指纹按UTF-8解码、去BOM、统一换行为LF后的文本计算SHA-256；中文仅计算抽取后的正文并去除首尾空白。工具返回`chinese_sha256`；使用任务清单的新`content_review`注释方式时，工具自动填写这些既有指纹字段，不先运行离线检查取值再人工抄写。下方带指纹对象供已绑定映射及独立核对复用；独立检查仍可用`--basis-file`取得依据指纹，不能以刷新指纹代替实际核对。

字幕问题的处理条件与对照范围执行[提示词对照](../../nora-serial-drama/references/画面文字与字幕规范.md#生成字幕问题的提示词对照)。用户明确授权省略模型正文中的字幕禁令时，在该组核对记录填写`subtitle_instruction_omission_authorization`非空字符串，记录本次授权。它仅消除该组的`subtitle_rule`提示，在检查报告留存；默认任务及其余正文、翻译、依据和输入绑定检查保持。此字段属于制作记录，不进入模型正文，不用于推定生成结果没有字幕。

阻断项覆盖模式与章节结构、首尾帧槽位和时点、逐镜核对证据覆盖、Subject名称及引用映射、正文长度，以及证据原文存在性和当前输入／中文／依据的绑定。方位词、角色代称、字幕表达及逐节中英文标签／数字出现次数等启发式检查写入逐组或逐文档的`warnings`，不计入`issues`、`ok`或失败退出码；工具不据此宣称内容错误，也不自动将人工核对标为通过。Agent按[内容核对规范](视频提示词制作规范.md#模型正文的内容核对)处理语义提示，仍须完成实际核对并保留已有证据。空间合理性、动作可实现性、完整翻译语义和参考图身份本身不由正则或指纹证明；`three-quarter view`等正常镜头术语不作为禁词。`passed`、非空备注或摘录存在均不能替代Agent实际连读和推演。

新任务的提交条件与历史兼容只见[内容核对提交条件](ComfyUI-服务配置与任务提交规范.md#内容核对的提交条件)。接口不提供跳过内容检查的参数，不自动修正文或制造通过结论。

回归命令（浏览服务目录）：

```powershell
.venv/Scripts/python.exe -X utf8 -B -m unittest tests.test_prompt_review tests.test_execution_checks tests.test_preparation_policy tests.test_submission_lifecycle -q
```

文档检查CLI的回归命令（工作区根目录）：

```sh
python -B -m unittest discover -s .agents/skills/nora-video-prompts/scripts -p test_h3_prompt_documents.py -q
```

测试使用临时项目与模拟网络，覆盖空间方位告警与对白／专名保留、逐镜证据缺项、英文违规、中文摘要、证据缺失、正文／依据变化、旧报告复用、新任务上传前停止及历史恢复，不生成视频。离线检查已有执行资料时使用独立新报告，不覆盖原执行检查报告。
