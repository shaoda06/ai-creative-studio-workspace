# AiMixer导演台正文与素材业务接续规范

本文件保存从模型工具归回本业务阶段的约定；模型格式、槽位与技术操作仍由共用H3工具维护。

每个组分别列清“模型标签 → 公共或本组 → 实际文件及版本 → 用途”。沿用既有05计划映射和[逐集目录规范第4节](../../nora-drama-production/references/逐集目录与资产管理规范.md#4-视频执行输出审核与采用)中的实际输入映射，不另造素材排序台账。有效槽位、混合数量及音视频时长按[AiMixer 导演台第2.4节](../../studio-h3/references/ComfyUI-AiMixer导演台节点使用规范.md#24-公共与本组的数量和时长限制)逐组核对。

按[Nora 语言适配](视频提示词制作规范.md#h3模型正文的语言与命名)完成并保留各段模型正文及中文参考版，再按[AiMixer 导演台公共／本组规则](../../studio-h3/references/ComfyUI-AiMixer导演台节点使用规范.md#4-公共提示词与本组提示词)拆分；网页及 API 的标签写法按[AiMixer 导演台素材编号规则](../../studio-h3/references/ComfyUI-AiMixer导演台节点使用规范.md#23-网页顺延与api填写的区别)处理。

填写完成及公共／本组正文变化后，执行[AiMixer 导演台合并核对](../../studio-h3/references/ComfyUI-AiMixer导演台节点使用规范.md#25-合并后的核对)，在既有准备／执行记录注明[完整正文计数](视频提示词制作规范.md#模型提示词长度)。按[Nora 内容核对](视频提示词制作规范.md#模型正文的内容核对)核对实际拼接正文与同版中文。

公共与本组的分配执行[AiMixer 导演台参考定义与状态描述](../../studio-h3/references/ComfyUI-AiMixer导演台节点使用规范.md#41-参考定义与状态描述)，正文分工执行[共用H3参考定义与保留说明](../../studio-h3/references/参考与接续表达规范.md#ref2va参考定义与保留说明)。Nora 的画外接续来源在对应 P 段依据中登记，正文按[共用逐镜转写](../../studio-video-prompts/references/视频提示词制作规范.md#逐镜转写)选择必要信息。
