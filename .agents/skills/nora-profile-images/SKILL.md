# 个人页准备

头像与背景图分别设计、制作和采用。按动作读取[制作与管理规范](references/个人页视觉制作与管理规范.md)，平台数值读取[平台个人页规格库](references/平台个人页规格库.md)。首次建档使用[索引模板](templates/个人页视觉索引模板.md)及[工作稿模板](templates/个人页视觉制作工作稿模板.md)。输入为项目定位、账号配置和所需素材，输出为正式视觉文件及真实采用记录；制作图片不代表已经修改平台主页。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
