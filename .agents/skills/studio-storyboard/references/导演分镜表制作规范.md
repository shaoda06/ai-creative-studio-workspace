# 导演分镜表制作规范

## 用途与制作范围

导演分镜表把指定版本的分镜脚本转为图文表格，仅供用户直观理解和审阅构图、空间、调度与动作等分镜安排。

后续逐镜核对、资产准备、提示词编写和生成以已确认的分镜脚本及已采用素材为依据。导演分镜表的整页和单格均不作为后续制作的核对依据，也不作为参考图、首帧或其他生成输入。

文字分镜和生成分段形成可展示稿后，调用业务须在原分镜讨论或送审中询问用户是否需要制作及范围。用户已明确本次范围的选择时直接沿用。用户选择制作时按所选范围执行，选择无需制作时以文字分镜继续。图表制作须有实际授权。分镜内容确认仍按业务流程判断，已具备条件且与待审内容无关的任务可独立接续。

调用方提供制作对象、源文件与版本、镜头范围、画幅、适用人物及资产引用、生成授权和保存入口。已批准正文可补做图表，不重新审阅未改变内容。实际执行调用 [Imagegen](../../studio-imagegen/SKILL.md)或用户指定的图片工具；能力选择与本次授权由调用方明确，不从技能所在目录推断业务。

## 来源与画面

源分镜的具体文件、版本和逐镜正文是唯一内容真源，使用[公共模板](../templates/导演分镜表模板.md)。Agent先提取本页完整内容并编写提示词，不让模型凭项目名、路径、旧视频或旧图补镜头。

统一白底、黑灰铅笔速写、简洁细线表格、清晰简体中文；六镜页默认横向4:3，已有用户明确样式优先。每格取景服从源镜头画幅，整表画布不改变成片规格。只画清主体数量、构图、位置、朝向、视线、动作及空间，不刻画发丝、材质和纹样。

简化不能改变已设人物身份。每页明确姓名、性别、年龄感、发型、服装轮廓与参考对应；有适用且获准的参考图就实际传入，并跨页保持一致，不照搬参考图多视图格数或摄影风格。无图时从已有文字提取，不编造未知设定。输入资格和返修换源由调用方图片业务管理。

固定八列及顺序只在公共模板维护。一镜一行，镜号使用原编号。景别、运镜忠实提取；情绪与动作可以概括但不增写行为、改变因果。同镜的起始、关键和结束节点可在同格并列、加箭头，不冒充新增镜头。台词、音效、时长保留完整原文字段，包括换行、说话者、画外声、单位与精度；明确无写无，缺项回源核对，不能只取第一行。

## 分页与版本

每页最多6镜，表头不计。按同一制作范围的播放顺序连续分页，不按P段数量代替镜数，不跨业务指定场次或制作对象混排。文字多可减少镜数、扩大画布或调整列宽，不删固定列或文字。末页只放实际余数，不补空镜。先明确总页数和全范围覆盖，再逐页生成；每页重复页头、完整表头，显示制作对象、源分镜版本、镜号范围与页码／总页数。

源分镜版本、图表版本、候选编号、媒体资源版本分开记录。每个图表版本只对应一个源分镜版本；同一来源下候选编号从1递增。采用是候选状态，不新增制作轮次；不从生成时间、媒体版本或视频R号猜来源。实际文件与登记位置由业务模板指定，公共模板不规定复制媒体或创建正式目录。

## 反馈与确认

用户看图提出的分镜修改先回写分镜脚本，并同步受影响的时长、分段和索引。涉及故事、台词、人物动机或必要因果时，由调用业务先同步上游，再更新分镜。后续制作按更新后获确认的分镜脚本执行。图中文字或姿态生成错误按源稿纠图。返修具体页的画面问题时，在修改前和新图送审前执行[图片返修看图](../../../../AGENTS.md#图片返修看图)。

继续通过图表审阅时更新受影响页及必要接续；用户明确不继续出图时用修订文字送审。局部修改只交实际更新页，保留未变页原文件、版本、来源及批准事实；在原业务记录说明更新页、仍适用页和缺页，不把单页说成完整新版。源版本、镜号或分页变化时核对旧页正文与页头适用性，不改写旧来源。浏览按来源及单一图表版本选候选，混合版本完整性通过逐页原记录说明，不为适配展示强制重画整套。

用户对本次送审范围表示“这版分镜通过”，正文内容确认和图表页面采用引用同一决定，不重复询问。只确认画法、局部或明确不采用图表时按限定范围记录。静态表不证明动态表演、语速、资产外观或视频已获批准，也不自动授权下游生成。

## 交付与核对

提示词、实际输入、参数、原生输出和审阅按调用业务保存；批准时保持原生字节和规格，不为正式登记重新生图、缩放或超分。旧候选与批准事实保留，不另建一套执行或采用台账。

默认在调用业务指定的网页导演分镜表入口送审，先核对条目、顺序、来源和原文件入口。对话说明完成范围、实际版本、待审状态和入口，不重复嵌入整套图片；用户明确要求对话展示时按指定范围展示。网页核验并告知入口即为送审，不自动采用；入口异常说明问题，不声称已收录。对外PDF等交付由业务接入决定。

生成前按[制作计划模板](../templates/导演表制作计划模板.json)把本批输入写入原执行资料；它是固定版本执行输入，不是第二份可编辑分镜。使用同一计划逐页装配提示词，禁止校验后另用未经同步的文字。

```sh
python .agents/skills/studio-storyboard/scripts/director_sheet_check.py --plan /实际执行资料/导演表制作计划.json
```

路径相对计划文件解析，必须指向真实源稿；Agent核对source_version与该源稿记载的版本一致，脚本不从各业务元信息中猜版本。检查页序、最多6镜、八列、授权范围内的镜头覆盖与顺序，以及景别、运镜、台词、音效、时长原文一致性；业务补充字段通过extra_fields明确提供。该只读检查不生成图片，不判断构图、身份或图片实际文字质量，不代替用户审阅。Agent另核对提示词完整性、输入资格、人物一致性与页头，实际结果按业务授权范围审阅。
