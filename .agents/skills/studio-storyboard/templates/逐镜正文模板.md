# 逐镜正文模板

写法及核对读取[分镜写作规范](../references/分镜写作规范.md)。将下方镜头块填入调用业务指定的正文位置，镜头标题可带该业务的完整编号。每个镜头按同一顺序填写字段；实际不用的声音等写“无”或“不适用”。业务补充接在基础字段之后。

```markdown
#### SH001｜镜头名称

**镜号**：<调用业务的完整镜号>

**时间**：<MM:SS-MM:SS秒；例如00:00-00:03秒>

**时长**：<秒>

**景别**：<按规范选择标准名称；同镜连续变化用“→”连接>

**机位/构图**：<关联文档中已确定的机位标识；明确实际入画人物全名；观察位置／高度／角度及轴线侧别、当前画面左右／纵深与环境落点、取景对象及裁切；按本镜需要选择必须看清的脸／肢体／接触／物件，不要求所有连续性事实同框；实际对视高度、正面或侧面取景及局部入画者的清晰范围与遮挡关系>

**运镜**：<跟随对象或揭示目标、运动开始时点、摄影机运动／变焦／焦点转移的方向／必要幅度／速度、起始与结束构图；说明俯身／起身／移动各阶段怎样保留需要辨认的内容；固定足够时写固定镜头，人物动作另填情绪/动作>

**起始画面**：<开镜瞬间可见的构图、人物位置、相对镜头的身体／头部朝向、姿态／表情、可见双手与持物、关键环境状态及动作进度；承接前镜真实结果，不复演已完成动作；不复制画外持物或动作事实>

**情绪/动作**：<以上游内容为依据细化本镜可见表演；触发与反应时点、相对镜头的起点／路径／终点、身体与头部转向、视线／喊话对象；决定结果的接触／握持、支撑／发力、分离／交接与结果及持物归属；参考差异、数量／位置、显隐、先后／并行及声音／口型切换；同一次状态变化不重新表演，画外事实按上方规则分工>

**结束画面**：<切走前瞬间可见的构图、人物位置、身体／头部最终朝向、姿态／表情、可见双手与持物、关键环境状态及尚在进行的动作；保留下一镜需要承接的结果；画外接续事实另在既有分段状态维护>

**台词**：<实际说话者及上游文稿中本镜承载的台词原文；每次接话单独一行，使用“说话人（必要的OS/VO或画外说明）：台词”；同一人再次接话另起一行。必要时写听者、跨镜续说与切换位置；无则写无>

**音效**：<具体环境声、动作声等；配乐安排在本片声音章节注明>

**转场方式**：<本镜到下一镜的切换类型、目标镜号、目标人物全名与具体接续点；直接切、动作匹配切、视线切或声音跨镜等按实际需要选择；场／集末写结束方式及下一场实际开始状态，不虚构模型已获前场上下文>
```
