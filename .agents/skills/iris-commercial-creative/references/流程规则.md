# 创意与音画流程与规则

阶段一至三按2026-10-30用户确认的统一口径执行。

## 流程与接续

读取制作简报 → 构思并选择方向 → 展开主线 → 设计视听 → 编写音画 → 核对 → 整理交付 → 回写反馈。

输入：当前简报、已选方向和有效反馈。输出：创意与音画工作稿、创意方案与音画脚本。按本次范围判断生产资料、交付整理和客户确认，不要求整阶段全部重做。

## 执行要点

从简报形成可比较的少量创意方向，说明每种怎样串联重点、采用何种角色/叙述关系及制作成本。选择后用[创意与音画模板](../templates/创意与音画工作稿.md)展开，画面、实际台词、发声者、屏幕文字和时间对应。客户只需简要介绍时不要把PPT逐页读成视频；完整覆盖还是突出部分能力由本单决定。

先写核心视觉变化与动作因果：谁遇到什么问题、助手/产品如何介入、信息或行动发生什么变化。角色互动若是核心，不用纯旁白加图标替代。新增角色可在原结构内局部接入；保留用户批准的未受影响内容。

时长按段相加，跨段台词只读一次；旁白、人物提问、助手回答各有职责，不重复解释。文本估算不是实测语速。声音数量和是否入镜由本单设定。

文字分为业务内文（网页、纸张、卡片）、说明性叠字/标题、逐字对白字幕三类。逐类决定在生成、合成或人工完成，不能由一句“字幕后期加”推导出所有业务内容留白。用[文字与声音表](../templates/文字与声音表.md)保持归属明确。

对外稿按[对外交付规范](../../iris-commercial-video/references/对外交付.md)。客户反馈先标出修改范围、上下游影响和保留项，再修正文；改稿不自动更新批准状态或重生成媒体。

完成：故事和重点表达准确，台词、画面与文字互相对应，时间完整，并指向当前选定方向。

## 交付整理与完成

从当前有效生产资料和真实成果填写本阶段交付模板；先回写实质修改，再整理新版本。按[跨阶段交付规则](../../iris-commercial-video/references/对外交付.md)审阅Markdown、批准具体版本后，调用共用PDF导出工具；图片直接嵌入，音视频附件按文件名对应。生产完成、交付稿完成、用户批准导出和甲方确认分别记录。

音画段落不是镜头。当前方向已明确时直接展开，不重复比较；已有视觉探索注明是方向示意还是具体方案。声音、文字分类及跨段统计可用[文字与声音表](../templates/文字与声音表.md)。
