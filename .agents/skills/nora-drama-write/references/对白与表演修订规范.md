# 对白与表演修订规范

### 编剧补充与表达润色

本技能负责Nora单集剧本与修订；场景因果、人物策略和对白方法按当前任务选读。方法资料中的通用目录、场景编号、生产标签、配置与解析脚本不替代Nora模板，也不取消已有制作前检查、记录和审批。对白与场景的删改以[逐集制作规范第2节](单集剧本制作规范.md#2-本集故事剧本)为准，保留观众理解核心因果所需的交流、有效的直接表达、沉默与余韵，不把“能演的不说”或“每句必须承担冲突”当作统一删减标准。

以本集大纲、制作前检查、人物资料及正文为依据，按[剧作手艺](script-craft.md)落实短剧场次及集间因果。对白与中文表达按[共用诊断与润色](../../studio-creative-techniques/references/对白与场次表演方法.md#诊断与润色)处理，依据[本集核对范围](#对白诊断范围与接续)确定受影响的场次和接续。协作优先级及格式边界执行[业务工作约定](../../nora-serial-drama/references/业务工作约定.md#外部技能协作与规则优先级)，山音方法按[范围与适配](../../nora-serial-drama/references/山音方法适配规范.md#山音方法的范围与适配)合并落实。

修订后的台词、节奏、统计及时长按本规范对应章节复核；正文维护及下游接续按[职责分工](../../nora-serial-drama/references/创作职责与接续规范.md#剧本分镜与提示词的职责分工)执行，已有制作任务时同时按[制作返修的上游归属](../../nora-serial-drama/references/制作返修接续规范.md#制作返修的上游归属)核对同步范围。

### 对白诊断范围与接续

对白诊断及剧本交付前的交流、人物口吻、因果和情绪检查共用以下范围；检查方法仍按上方编剧补充及下方台词、动作章节执行，不因缩小读取范围省略适用检查。

- **首次完整检查**：本集首次形成完整稿、整体重写、全局调整人物声音，或没有可核实的整集初次诊断依据时，检查本集完整对话及相邻动作，并读取相关人物设定、关系、知情状态、当下处境和必要的上下集承接。
- **局部表达修改**：已有适用的整集检查依据时，改措辞、语气或接话，至少连读从触发事件到交流落点的完整交流及相邻动作，不只抽查改动句。人物资料读取与本次交流相关的部分；判断声音差异确需对照时，选读已有代表性对话，不默认重读整集或全部人物资料。
- **影响扩大**：改动涉及人物目的、关系、知情状态、承诺或关键事实，沿影响检查相关场次和上下集交接，核对后续回应与行动是否仍成立；影响遍及全集或暂时无法可靠界定时，回到整集检查。发现新问题时按实际影响扩展，不因原任务只改一句而跳过必要接续。

同一范围内的对白诊断、表达润色和文本自检合并执行；订正后复查改动及必要接续，不按技能名称再做一遍。仅改错字、格式或制作记录，且没有改变语义、语气或接话关系时，不触发对白诊断。

检查范围、所依据正文的入口、订正结果和未解决项并入既有编写依据、工作稿或审阅记录，不另建报告或台账。接续任务或换会话时，先按读取入口查明适用规则，定位已有结论对应的正文与检查范围，再对照当前实际内容及人物设定、知情状态等依据；未变且结论仍适用的部分可复用，变化部分按上述范围复查。仅版本号相同、口头说已检查或只有用户批准，不代替可核实的检查依据；缺少哪部分依据就补查相应范围，无法确认已完成整集初次诊断时按首次完整检查处理。原有统计、时长重核及受影响下游同步仍按本规范执行。

### 台词设计、节奏与统计

本集默认由充分展开的人物对白组织主要叙事。声音分类、原句及括注按[共用剧本写法](../../studio-screenplay/SKILL.md#声源与正文写法)，用本集剧本模板维护实际正文。声音应让观众听懂本集核心事件和因果，具体阶段归属按[职责分工](../../nora-serial-drama/references/创作职责与接续规范.md#剧本分镜与提示词的职责分工)执行。

**旁白默认不引入，只有用户明确要求时才使用。** 获授权时写明叙述者，并在编写依据引用授权。现场画外交流和人物内心独白按实际剧情选择。改写已给的旁白时核对知情范围及表达动机，避免把叙述者的事实写成角色当时知道的事。生成阶段文字按[视频生成全程无字幕](../../nora-serial-drama/references/画面文字与字幕规范.md#视频生成全程无字幕)执行。

台词与表演按以下要求一起编写，落实到现有正文，不新增字段或独立检查表：

- **交流展开完整**：把大纲中的事件和人物目的展开为当场有来有回的交流，写出对方怎样回应、人物据此怎样继续解释、追问、反驳、争取、退让或作出选择；按场景实际需要选用，不要求凑齐这些方式。不能用“二人商量后决定”“她解释清楚了”等动作概述省掉承担剧情的交流，也不能只写提问与最终答案，漏掉使态度或决定成立的中间回应。扩写增加交流的具体过程、人物色彩和情绪变化，不能擅自新增关键事实、人物经历、知情内容或剧情结果。
- **核心因果能听懂**：在文本层面暂不依赖屏幕细字和动作说明，核对各类台词是否讲清本集核心困境、关键因果转折和处理结果。开场及时交代谁遇到了什么事、为什么着急或尴尬；关键转折说清新发现及其影响。让人物在求助、追问、解释、核对、认错等真实交流中说出必要信息，少用没有明确所指的“这个”“那份”代替首次交代。画面可以显示同一证据、突出反应，不要求逐字朗读全部屏幕文字。纯视觉包袱、刻意保留的信息差或明确采用的无对白段落仍可由画面承担，不为声音完整提前泄露悬念。
- 对白、口吻与情绪表演按[共用对白与场次表演](../../studio-creative-techniques/references/对白与场次表演方法.md)编写。台词与场景里的表演一起完成，必要交流写入本集正文供分镜引用。

### 人物性格与当下处境的台词适配

按[共用口吻与接话方法](../../studio-creative-techniques/references/对白与场次表演方法.md#人物口吻与接话)落实本集已有设定、关系和知情状态。实际人物口吻、台词原文及重要变化归故事剧本。

### 说话与倾听时的身体表演

按[共用表演方法](../../studio-creative-techniques/references/对白与场次表演方法.md#信息行动与表演)写本集交流中的重要姿态和持续状态。分镜承接到起始画面、情绪/动作和结束画面，提示词按实际入镜范围保留相应表演。缺项先回相应来源订正，并同步受影响镜头、段落及同版中文参考。

### 动作、情绪与标点的联动

按[共用口吻与接话](../../studio-creative-techniques/references/对白与场次表演方法.md#人物口吻与接话)及[表演方法](../../studio-creative-techniques/references/对白与场次表演方法.md#信息行动与表演)落实声情和触发点，按[对白诊断范围与接续](#对白诊断范围与接续)随本集文本合并自检。表演动作和原台词分别写入现有正文，台词旁的括注用于语气及声源提示。分镜处理实际口型及接续。

送审前核对本集核心因果是否可听懂，有必要的交流是否完整。按[共用留白方法](../../studio-creative-techniques/references/对白与场次表演方法.md#声音与留白)核对连续无对白段及有意的视觉表现，将需说明的留白写入既有“其他备注”或审阅记录。场次声音的戏剧事实归剧本，已确认的起止和跨镜关系交分镜。统计、实际时长及分段分别按下文、[对白与动作时长核对](../../nora-serial-drama/references/层级编号与时长规范.md#对白与动作时长核对)和[视频分段与连续表达](../../nora-drama-storyboard/references/视频分段规划规范.md#4-场次内视频分段与本集索引)核对。

在故事剧本“其他备注”中按场次及整集统计入镜对白、现场画外对白、内心独白、叙述旁白及合计，并简述语言与动作并行、重要留白及待验证容量。四类各自统计，同一句只计一次；实际再次说出时另计，跨镜续说不重复。汉字、字母、数字各计一个字符，排除标点、空白、说话者、声源及表演提示、动作、画面文字、字幕与非语言声。内容可辨的群众话语按实际声源计入，模糊人声计环境声。字数用于比较语言密度，时长另按本业务时长规则核对。修订对照按既有审阅流程记录。

在“其他备注”中按需写“供下集承接的结束状态”，只补下一集必需且原计划不足以说明的事实：结束时间地点、人物／关系、谁知道什么、物品与伤势、未完成行动；无变化可引用，不逐人重复全部设定。它是正文摘要，不是独立事实来源；与正文冲突时核对并同步。批准修订影响承接时更新说明，涉及分集计划实质变化时同步受影响大纲；不新增全局追踪表或记忆文件。前集未写成的内容不能记成已发生。用户明确采用与剧本不同的成片情节时，依据其决定维护文本，不通过agent自行审片推断新剧情。

尚未建立的资料如实标注，不伪造入口。角色名全文统一，群戏可写“群众若干”等。

人物造型按[开发流程第5节](../../nora-drama-assets/references/人物资料卡规范.md#不可逆外形变化与基础造型)处理；在剧本、分镜和所需素材说明中展开本场适用造型及临时伤妆、污渍等状态与其延续、恢复。涉及资料卡调整时按所链接规则同步，参考图制作时机、顺序与复用执行[人物制作分工](../../nora-drama-images/references/核心参考图制作规范.md#固定制作流程与阶段分工)。

场次划分后，整理本集空间、状态及取景需求，读取[场景规范第1节](../../nora-drama-assets/references/场景资料卡规范.md#1-阶段归属与制作顺序)接续资料卡与环境图任务，分镜形成后按该规范第4.2节归纳实际机位、核对复用与缺口，并按第4.3节在既有分镜及分段映射落实实际选图。总览与机位用途及状态职责由该规范第4.0节维护。

单集故事剧本明确后，按[道具规范第1节](../../nora-drama-assets/references/道具资料卡规范.md#1-制作时机与资产身份)区分文字表达与需建卡、制图的实际需求，再处理对应设计缺项及素材复用；实际使用的资产状态与版本在后续素材映射中落实。

统一特殊标注：

- 动作描述以 `△` 开头；对白为“角色名：台词”；语气、神态和表演提示放括号。
- 台词和声源提示按[共用剧本写法](../../studio-screenplay/SKILL.md#声源与正文写法)填写，逐镜发声和口型按[心理独白与开口对白的切换](../../studio-storyboard/references/分镜写作规范.md#心理独白与开口对白的切换)落实。
- 换场、时间跳跃、闪回前空行并重新标注；闪回另起行写“闪回”，结束写“闪回结束”。短暂回忆可标“插入镜头”，不因插入而丢失返回现实的说明。
- 空镜用 `【空镜：场景描述】`。原稿中的字幕先按[视频生成全程无字幕](../../nora-serial-drama/references/画面文字与字幕规范.md#视频生成全程无字幕)明确处理，不将其直接写成模型绘制要求；剧情确需的场景内文字另写载体、准确原文及出现时点。
