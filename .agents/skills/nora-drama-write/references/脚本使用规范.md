# 脚本使用规范

## Nora正文与原生方法格式

Agent编写和核对Nora整集剧本、对白及声源，使用本阶段正式模板；脚本不生成创作内容，不决定审阅或批准。scripts中的索引、估时及声音清单检查保留原生方法格式，不直接解析并批准Nora正式剧本，不因它们存在而创建另一套项目配置、节奏档案、分集卡或配音清单。

仅在已明确输入格式、输出位置和本次适配用途时使用。Python 3.9+、标准库；路径从当前目录解析，以下实际调用时使用绝对路径，将示意文件替换为本次隔离或过程附件。原生字段和声源语法按[格式参考](screenplay-format.md)、[方言参考](production-format-dialect.md)读取，不能自动覆盖Nora的对白/VO/OS规则。

| 脚本 | 明确输入与结果 |
| --- | --- |
| screenplay_index.py | UTF-8原生剧本；保存字节定位JSONL，不写回原剧本。output明确给出候选位置；source-ref为项目相对来源；authority=candidate只表示候选定位，不是批准。previous-index与previous-source仅在对应真实旧版存在时提供；不为省事用no-previous重编下游身份 |
| duration_estimate.py | 实际原生剧本及从它生成的index，必要时显式提供原生project配置；只按已有声明估计，不创建short-drama.json或代替Nora实际朗读/表演测时 |
| voice_sheet_check.py | 明确声音JSONL、对应index及原生剧本；核对机械覆盖与关联，不检查中文台词表演质量或批准配音 |

```sh
python3 .agents/skills/nora-drama-write/scripts/screenplay_index.py '/原生格式剧本.md' --output '/隔离附件/候选索引.jsonl' --source-ref '实际相对来源.md' --authority candidate
python3 .agents/skills/nora-drama-write/scripts/duration_estimate.py '/原生格式剧本.md' --index '/隔离附件/候选索引.jsonl'
python3 .agents/skills/nora-drama-write/scripts/voice_sheet_check.py '/隔离附件/声音记录.jsonl' --index '/隔离附件/候选索引.jsonl' --screenplay '/原生格式剧本.md'
```

使用者读取实际标准输出及退出码；非零或标明review-required时处理具体缺项，不当作内容通过。screenplay_index附加fail-on-review时，落盘后需要审查会退出2；不能借缺少该参数忽略输出中的待审信息。脚本结果是技术附件，不替代本集制作前检查、剧本、统计和批准记录。正式剧本修订后按真实来源更新对应技术附件，不把旧索引挂到新稿。

运行`python3 .agents/skills/nora-drama-write/scripts/selftest.py`执行现有14项隔离自测，覆盖原生索引、估时、声音清单及来源变化。原生自测通过不等于具备Nora模板的自动索引/估时适配；本阶段正式语义检查仍由Agent按业务规范完成。
