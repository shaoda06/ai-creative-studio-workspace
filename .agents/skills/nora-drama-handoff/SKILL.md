# Nora 分段交付与完集收尾

媒体原件、上传参考音视频及修改版本统一按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存；本技能继续维护原业务记录和采用。输入、审核、采用及导出引用准确版本，不因阶段再次复制媒体。

读取项目约定、正式分镜索引及当前采用记录，按[分段交付与完集复盘规范](references/逐集目录与资产管理规范.md)执行当前收尾事项。技术文件存在不等于已采用；交付不新增审批，也不将分段完成记为整集成片或公开发布。

Agent 核对范围、批准依据、缺项及复盘结论。AiMixer 分段由 [drama_delivery.py](scripts/drama_delivery.py) 按正式索引选择当前采用文件、核对页面版本并给出播放顺序。Songssx 从本集生成说明工作稿读取当前采用的整场文件；网页轮次预览按原轮次核对。

需要剪映草稿时，将明确文件清单交给[共用剪映工具](../studio-jianying/SKILL.md)，工具只执行打包。实际剪辑、字幕、音乐和发布按用户授权另行处理。阶段采用交制作阶段。
