# Nora 分段交付与完集收尾

读取项目约定、正式分镜索引及当前采用记录，按[分段交付与完集复盘规范](references/逐集目录与资产管理规范.md)执行当前收尾事项。技术文件存在不等于已采用；交付不新增审批，也不将分段完成记为整集成片或公开发布。

Agent核对范围、批准依据、缺项及复盘结论；[drama_delivery.py](scripts/drama_delivery.py)按正式索引选择当前已采用版本、核对页面文件版本并给出业务播放顺序和交付名，不生成媒体。后台继续复用该选择器，负责访问控制和下载响应。

需要剪映草稿时，将明确文件清单交给[共用剪映工具](../nora-jianying/SKILL.md)，工具只执行打包。实际剪辑、字幕、音乐和发布按用户授权另行处理。导演包制作与阶段采用交制作阶段，不在本阶段重复实现。
