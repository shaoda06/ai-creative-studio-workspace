# 逐集目录与资产管理规范

## 5. 分段交付与本集完成


### 分段交付

- 交付按正式分镜索引中的场次与分段播放顺序组织，不按文件名字典序推定剧情顺序。逐项引用各P已采用的后处理文件、具体R编号及原工作稿中的采用依据；复用分镜索引、分段工作稿和项目进度，不新增场次或整集成片说明、合成任务及独立交付台账。
- 后处理采用视频沿[视频阶段的正式路径](../../nora-drama-production/references/逐集目录与资产管理规范.md#4-视频执行输出审核与采用)交付，保留一采、二采及后处理的来源关系、真实规格和文件入口；不为交付改名、移动至另一套正式视频库或重复复制。不以最大R、目录最新文件或生成成功代替批准。
- 提供分段视频的预览或原文件入口，并注明实际播放顺序。网页连续播放只用于浏览，不生成合并文件，也不代替用户审核或剪辑交付。


### 本集完成条件

本集正式分镜索引范围内的所有场次、所有分段均已完成后处理并按[自动采用](../../nora-drama-production/references/逐集目录与资产管理规范.md#后处理自动采用)完成录入与记录收尾，当前采用文件已保存、入口可用、来源和批准依据已记入对应工作稿；完成上述分段交付及项目进度更新后，才能将本集制作标记为“已完成”。此状态表示本集分段制作与交付完成，不表示已导出整集成片；不要求额外的场次成片、整集成片或再次批准同一批分段。

仅一采或二采获批、部分后处理尚未采用、文件尚未取回或当前采用版本未确定时，不符合本集完成条件。返修或替换已采用分段时，保留旧批准事实，核对受影响分段与下游来源，并据实际待办更新本集状态，不将旧批准套用于新输出。场次推进顺序及环节审批统一读取[开发流程第二部分第7节](../../nora-drama-production/references/视频阶段与返修执行规范.md#7-生成视频验收与衔接修改)。


### 完集复盘与经验维护

本节为本集制作完成后的收尾工作，由本集制作／收尾Agent执行；未收齐本集结果时先记录已解决问题，全部后处理完成并采用后统一复核。顺序为：后处理完成并采用 → 本集制作完成与交付 → 问题复盘 → 参考或规则维护 → 本集收尾结束。制作完成状态不因复盘待办改为未完成，也不阻塞已采用视频交付；复盘未完成时，在既有进度的“下一步”注明，完成后移除该待办。

采用收尾报告在本集制作完成时返回`retrospective.status`和现有生成说明工作稿入口：`pending`及`next_action=episode-retrospective`由本集收尾Agent继续执行下列复盘；`completed`及`next_action=deliver-completed`复用已完成结论。完成下列工作后，在该工作稿当前内容区填写`- 完集复盘状态：已完成`并关联实际结论；不是先写状态再补复盘。仅有历史复盘标题不代表当前完成。已采用身份发生变化后，按报告的当前复盘状态复核受影响部分，不重复无变化范围；不另建复盘文件或阶段。

1. **汇总实际问题**：从本集既有审看意见、讨论、返修和执行记录定位问题、处理方法、失败尝试及用户确认的结果。复用已有核验，不自动重看整集、抽帧、试听、启动对照或重新生成；需要新的媒体分析或执行时沿原授权边界处理。接受瑕疵不等于修复，未解决的问题保留实际状态。
2. **对照已有经验**：按现象检索[制作问题与解决方案参考](../../nora-serial-drama/references/制作问题与解决方案参考.md)，核对模型、模式和输入条件，先归并已有条目；无对应条目且具有复用价值时再新增。问题在制作中解决后按下述归属维护，完集时补漏、核验证据程度并订正过时结论，不重复搬入完整过程。
3. **决定归属**：普遍适用且可执行的流程缺口，修改所属规则的唯一真源；特定模型／输入／场景下的办法，归问题参考；用户已确认的本剧外观、表演偏好及制作约定，归项目定位、对应资料卡或项目约定入口，注明长期、本集或局部适用范围，不将个案扩大为全剧规则；已有规则未执行到位，记录具体漏掉的输入核对或执行接续并落实原入口，不重复增加规则；多项改动后有效，记录有效组合，不指定未经证实的单一原因；未验证判断留在原实验／返修记录并标为待验证，不作为默认解法。每集都复盘，但不要求每集新增条目或规则。
4. **记录与维护**：在本集既有生成说明工作稿中记录问题、结果、对应参考条目、规则变更或无需变更的结论，以及原始依据链接；详细参数、实际任务身份与完整提示词留在原执行记录。共享参考的简短验证结论与本地证据按其[维护方法](../../nora-serial-drama/references/制作问题与解决方案参考.md#维护方法)关联，不新建复盘台账。常规归并随已授权收尾执行；改变制作流程、审批或默认生成配置时说明影响并沿现有授权处理，不能由参考条目暗改通用规则。
5. **收尾检查**：规则或参考有改动时，执行[维护自动复查](../../studio-entry/维护规范.md#维护落地后的自动复查)，核对入口、上下游和证据边界；同步核对正式生成说明、工作稿当前摘要和项目进度，清除现行说明中的过期准备／待审状态；只更新当前状态与入口，不改写历史阶段的当时事实。浏览入口按原同步规则维护。历史生成输入、批准事实和已采用视频不随复盘重写。简要报告复盘结论和仍需处理的事项；未解决但已接受的问题可保留结论，不以强制修复作为复盘完成条件。


### 已有合成资产

用户在剪辑软件中完成最终剪辑拼接后，导出的发布成片使用项目级[发布成片目录](../../nora-serial-drama/references/文件版本与工作稿规范.md#成片交付目录)。

现行目录不设置 `06-生成结果/`，不维护成片说明。获授权整理旧目录时，将退役说明留存于所属单集 `其他资料/历史版本/`，同步仍需追溯的引用，再移除当前说明和已清空的旧目录；已有合成视频、工作稿、执行附件、审阅与批准事实按各自真实用途保留，不因移除说明一并删除或重新合成。未获整理授权的旧项目仍按真实入口读取；已有成片的批准不能替代当前分段版本的批准。
