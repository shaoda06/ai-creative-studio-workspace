# 场次修改轮次模板

<a id="修改轮次模板"></a>

业务规则见[修改轮次](../../nora-serial-drama/references/场次版本组合规范.md#场次修改轮次)，调用方法见[登记工具](../references/修改轮次登记规范.md)。一份计划对应一次批次，`scenes`只列改动场次，由工具展开其余沿用场次；没有既有组合的场次须给完整方案。路径相对项目根，时长为秒，阶段填实际工作流对应值，R按原身份独立计数。

逐段执行的[完整场次方案](../../studio-h3-aimixer/references/Nora逐段场次制作与登记.md#完整场次方案)和[局部替换方案](../../studio-h3-aimixer/references/Nora逐段场次制作与登记.md#局部替换方案)按兼容专项填写。

## Songssx 完整场次方案

本次已确认使用整场工作流时，在本轮对应的 `scenes.C001` 条目填写分镜、该场全部 P，以及与 Songssx 清单 `record_dir` 相同的 `songssx_execution`。该目录位于本集的执行附件目录内。所有 P 的阶段填「场次生成」，共用本场一个 R，时长与清单里的逐 P 计划新增时长一致。

```json
{
  "storyboard": {"file": "09-剧集制作/EP003/03-分镜脚本/EP003-C001-场次分镜.md", "version": "v04"},
  "songssx_execution": "09-剧集制作/EP003/其他资料/执行附件/EP003-C001-R001-场次生成",
  "segments": [
    {"id": "P001", "duration": 14, "stage": "场次生成", "run": "R001"},
    {"id": "P002", "duration": 11, "stage": "场次生成", "run": "R001"}
  ]
}
```

整场后处理的新轮次保留该场原 `songssx_execution`，增加 `songssx_postprocess`，填写本集执行附件目录下后处理任务的 `record_dir`。各 P 的 `stage` 填「后处理」，共用该次后处理的 R，保留原 P 顺序和时长。局部返修接回后的后处理，以来源轮已登记的本地整场主播放为源；轮次脚本从来源轮引用该文件。网页按[共用派生整场主播放](../../studio-workspace-browser/references/业务接入规范.md#songssx-派生整场主播放)读取该执行的单一整场 MP4。

保存文件为`EP编号-修改轮次.json`，头部为`episode`、`rounds`。每轮含`number`、带时区`created_at`、`note`、共同`script`、完整有序`scenes`及`changed_scenes`；各场保存分镜、完整分段和适用的`changed_segments`，文档引用指向留存副本。旧场次文件、原R审阅与任务记录不改。

跨工作流另开整集制作轮次时，填写全部场次的完整分段方案。若本次是用户明确选用的逐段兼容方案，原场次曾关联整场执行时在对应场次填写 `"songssx_execution": null`，由轮次工具移除继承的整场路径。

本批 AiMixer 任务填写工具返回的同一`scene_modification_round`整数，任务各自的`scene`、实际选中范围和请求时长保持原含义。Songssx 清单使用对应场次的 `songssx_execution` 路径作为 `record_dir`。
