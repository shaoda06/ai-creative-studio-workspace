# 完整重做规范

## 完整重做的范围与完成要求

分镜重做与局部修订的内容要求使用[共用分镜规则](../../studio-storyboard/references/分镜写作规范.md#完整重做与局部修订)。Nora 的输入是当前批准剧本、各场分镜和相关人物、场景及资产依据；整集重做覆盖本集全部场次。用户举出的某段或某秒用来定位问题，具体改稿范围按完整要求确认。

本轮先明确有效剧情、原台词、画风及目标时长，再按共用规则重新设计镜头、估时及分段。生成段限制按[层级与时长](../../nora-serial-drama/references/层级编号与时长规范.md#1-层级编号与时长)执行。剧情或决定因果的动作变化按[上游归属](../../nora-serial-drama/references/制作返修接续规范.md#制作返修的上游归属)先处理。

新稿使用本业务场次模板，关联旧稿与镜号并同步场内时码、P表、段内时间表和本集索引。待下游按新版更新时在原记录标明待同步。按本业务的审阅及修改轮次接续，已有文件与任务沿[逐集目录规范](../../nora-serial-drama/references/逐集目录与资产管理规范.md#6-旧项目兼容)追溯。
