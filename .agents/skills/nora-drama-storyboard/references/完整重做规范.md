# 完整重做规范

## 完整重做的范围与完成要求

1. **范围按用户的完整要求确定**：用户要求“整集／整场完整重做”“重新设计分镜”或“不要保留原镜长和分段安排”时，以其指定的整集或整场为本轮分镜重新设计范围。用户举出的某段、某秒或某个动作是问题线索，不能据此缩成该处及相邻镜头的局部修补。读取指定范围的完整已确认剧本、当前分镜及相关人物、空间、状态依据；整集重做须覆盖本集全部场次。本轮获授权改动已涉及场次调度、镜头顺序、镜长或分段结构的大幅变化时，按受影响的完整场次／指定范围重新设计，不因用户只举了局部问题就套用小改流程。只有范围明确、结构不变的小修改才局部修订，并检查相关接续。

2. **旧安排不作为默认约束**：旧镜数、镜长、分段数、分段边界及旧稿计算出的总时长只用于追溯，不直接沿用为必须保留的条件。稳定编号用于关联历史，不代表镜头内容和播放排列不能调整；拆、并、增、删镜及分段变化保留新旧对应，不删除旧稿、任务或批准事实。已确认的剧情、人物、视觉方向和本轮明确要求的硬性规格仍须遵守，不借分镜重做擅改故事；旧稿总时长与当前目标时长或硬性要求分开判断。不能为了复用旧提示词、已生成视频或缓存而保留不合理的安排。大改重建正文：旧稿作为追溯、反馈对照与新旧关联，不能在旧分镜或旧提示词上继续叠加局部补丁。以对应已确认剧本重新组织场次分镜，新分镜确定后再据其重写受影响范围的提示词；已确认剧情、原台词、人物、画风及有效素材依据继续保留。提示词发现剧情或关键动作缺项时回到剧本／分镜处理，不另编一套内容。

3. **先设计表演，再核镜长，最后分段**：依据剧本重新梳理事件先后、人物互动及反应，设计能表达这些内容的镜头和逐镜起止画面、转场；再按[对白与动作时长核对](../../nora-serial-drama/references/层级编号与时长规范.md#对白与动作时长核对)估算实际表演所需镜长，最后按[分段规则](视频分段规划规范.md#4-场次内视频分段与本集索引)划分生成段。[生成分段时长上限](../../nora-serial-drama/references/层级编号与时长规范.md#1-层级编号与时长)不是填满目标；有意义的对白、行动、反应或停顿结束后及时切走，不用空等、重复动作或无意义动作撑时长，也不裁掉必要反应来凑段长。不能先固定旧P或旧秒数，再把新内容塞回原格。

4. **按完整范围判定完成**：送审前从头到尾连读本轮全部场次，核对因果、并行动作、人物反应、起止画面、转场及节奏，处理发现的问题，并同步镜长、场内时码、P分段表、段内时间表、本集索引及必要来源引用。只改提示词、补字段或修用户举出的例子，不能记为“完整重做完成”。全范围重新核定后有些安排仍合理的可以保留，说明依据，不为显得改过而强迫改变每镜。检查范围、重设计结果及待决项并入既有工作稿或审阅记录；下游因等待分镜批准而尚未同步时明确标注待同步，旧资料不冒充新版依据。新版分镜先按既有流程交用户审核，文本重做不自动授权视频生成。
