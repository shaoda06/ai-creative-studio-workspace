# 手绘导演分镜表业务接入

## 1. 用途与询问时机

本阶段提供当前集、场次、源分镜文件与版本、用户制作范围及资产输入，调用[公共导演表制作规则](../../studio-storyboard/references/导演分镜表制作规范.md)和[版式模板](../../studio-storyboard/templates/导演分镜表模板.md)。是否制作的询问、分页、图文核对和确认含义均执行公共规则。

内容提取、分页与提示词由分镜阶段负责，图片执行交[图片阶段](../../nora-drama-images/SKILL.md)。能力选择及返修输入按[图片提示词规则](../../nora-drama-images/references/图片提示词规范.md#当前参考图生成选型)，不因调用公共规则增加能力选择询问。

## 2. 来源与内容接续

来源为本场次文字分镜。角色、服装与场景输入由本项目已有资料提供；源稿、身份对应和实际参考写入原场次工作稿及执行附件，不另建正式正文。

## 3. 制作范围

以单场为分页范围，完整场次编号作为公共模板的制作对象。整集制作逐场准备计划，不跨场合页；片头片尾使用各自制作对象。

## 4. 讨论反馈与正文同步

按[创作职责](../../nora-serial-drama/references/创作职责与接续规范.md#剧本分镜与提示词的职责分工)决定反馈回写剧本还是场次分镜；修改后版本、范围和审阅沿本场原流程。公共规则中的正文确认和图表采用引用同一用户决定，写回原场次工作稿。

## 5. 保存、记录与交付核对

本表不另建独立正式分镜文件或专项会话。对应场次分镜工作稿中记录用户是否需要及范围、来源分镜文件与版本、页数、页内镜号、图片链接、反馈与正文修改入口；沿用已有讨论和审阅区，不复制第二套镜头正文。

**生成候选**：原生图片保存到本制作对象的`其他资料/工作稿/素材/`，命名为`{完整场次编号}-手绘导演分镜表-v{两位图表版本}-第{两位页码}页.png`。提示词、实际输入、请求及执行凭据保存到同对象的`其他资料/执行附件/`。候选和历次执行资料保留，不因采用而删除或改写。正集、片头和片尾各自在自身制作目录保存，不互相混放。

**正式采用**：依据公共规则和本业务记录的采用决定或用户单独作出的具体页面／整套批准，将对应原生图片复制到本制作对象的`03-分镜脚本/导演分镜表/`，正式名为`{完整场次编号}-手绘导演分镜表-第{两位页码}页.png`，保持原字节和实际规格，不为正式归档重新生图、缩放或超分。采用清单使用[固定模板](../templates/手绘导演分镜表模板.md#采用登记)，维护在原场次工作稿中，登记每页镜号范围、来源分镜版本、图表版本、候选与正式入口及批准依据；原图片生成／审阅记录同步正式入口和当前采用状态。正式图片是源分镜的辅助展示，不新增一份独立分镜正文。

**替换与历史**：替换已有正式页前，将被替换原图保存到本对象既有`其他资料/历史版本/`，文件名保留完整场次、当时图表版本、页码和实际留存时间，再复制已批准新图并更新采用清单及关联记录。源分镜变动后，旧表仍保留对应的原来源版本；新旧版本不得混称同一套已批准图片。正式目录只放当前采用页，不混入候选、旧版和执行附件；其唯一入口由[逐集目录规范](../../nora-serial-drama/references/逐集目录与资产管理规范.md#2-正式文件与目录)登记。

导演表采用及旧版替换后，按[图片状态收尾](../../nora-drama-images/references/核心参考图制作规范.md#852-图片采用替换与归档后的状态收尾)处理被替代候选、当前摘要和网页待审显示。

**来源与候选登记**：在原场次工作稿中按固定模板登记来源分镜版本、图表版本和候选编号，公共版本规则用于填写这三个字段。采用清单按具体页面关联候选与正式图。

**网页入口**：在“剧集制作 → 对应制作对象 → 场次 → 导演分镜表”查看。来源分镜版本、候选编号与采用页由上方业务记录明确提供；没有对应版本图片时保留空态，不用其他版本顶替。页面的整合本集、轮次选择、翻页、全屏、记录与原图下载交[浏览服务的导演表展示规范](../../../../工作区浏览服务/docs/组件与页面实现.md#导演分镜表浏览)，业务字段输入见[导演分镜表输入](../../nora-serial-drama/references/项目浏览入口规范.md#导演分镜表输入)。交付时核对实际条目、顺序、文件入口与源记录，不以文件存在代替网页收录。

交付前执行公共规则的制作计划校验与内容核对。文件规格沿现有图片交付流程，结果展示执行下方[网页交付](#51-网页交付)；是否可调用看图能力仍按[主技能边界](../../nora-serial-drama/references/业务工作约定.md#看图能力调用边界)，制作本表不另行取得查看其他图片或视频的授权。写入后按[交付前同步检查](../../nora-serial-drama/references/项目浏览入口规范.md#交付前同步检查)核对本表及原工作稿入口。

### 5.1 网页交付

按公共规则在“剧集制作 → 制作对象 → 场次 → 导演分镜表”送审。交付前按[浏览入口](../../nora-serial-drama/references/项目浏览入口规范.md#导演分镜表输入)核对来源版本、候选与采用页。网页确认后回写原图片审阅记录；看图权限按一级业务约定，不扩展到无关媒体。
