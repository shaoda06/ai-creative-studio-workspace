# 固定脚本接口规范

## 修改轮次登记

业务登记由[D08调用规范](修改轮次登记规范.md)维护；使用所属阶段脚本一次登记本集完整组合，旧scene_rounds命令仅兼容。

新视频任务输入映射仍使用字段`scene_modification_round`，值为该单集共同轮号，并填写`screenplay_version`、`scene_storyboard_version`及选中组的`duration_seconds`（兼容既有`durationSec`）。准备报告保存所引用场次在共同轮次中的组合，校验选中组身份、版本和计划时长；生成长于成片时，每段额外填写`playback_duration_seconds`（如3），保留`duration_seconds`为实际模型请求（如4）；轮次`duration`仍为成片3秒，生成说明记录采用0–3秒及余量用途。工具分别检查两种时长，并拒绝请求短于成片；未传新字段的旧式同长任务保持原检查。未选中组仍可保留原缓存时间线，不用它确定播放候选。后续增加其他轮次不会使该报告失效。只有原先已登记的旧任务保留旧场次轮次及无此字段的恢复兼容，不改原执行证据、不补造归属；旧报告不能用于跳过新任务准备。

共享调用检查见同一D08规范；实际视频准备和恢复继续使用原执行入口。
