# 场次分镜制作规范

## 3. 场次分镜脚本

接续已选参考图片时，先执行[已选原图的接续](../../nora-serial-drama/references/创作职责与接续规范.md#已选原图的接续)，核对实际素材入口及本阶段采用范围；后续素材映射引用该入口和具体版本，不以大纲中的图片名称或网址代替本地文件。

全剧共用片头片尾的上游内容依据及无实景字段填写，见[共用制作规则](../../nora-serial-drama/references/逐集目录与资产管理规范.md#全剧共用片头与片尾)；场次拆分、分镜和分段继续执行本规范。

开始编写或修订时，先按[职责分工](../../nora-serial-drama/references/创作职责与接续规范.md#剧本分镜与提示词的职责分工)核对本场剧本依据及内容范围，再按本节落实镜头设计。

分镜引用项目资产或视图时，按[引用链接规则](../../nora-serial-drama/references/项目浏览入口规范.md#5-输入格式与解析依赖)在引用处写清名称、编号及对应文件／章节链接；视图编号与版本号分开表达。镜头的机位、方向和布局须用具体空间关系写清，不能只写“沿V008方向”等内部简称。后续转写提示词按[项目引用与模型标签](../../nora-video-prompts/references/视频提示词制作规范.md#项目引用与模型标签)处理；分镜阶段不预设尚未确定的模型输入序号。

逐镜写法、字段和内容核对统一读取[共用分镜](../../studio-storyboard/SKILL.md)与[写作规范](../../studio-storyboard/references/分镜写作规范.md)。

### 分镜方法补充

按[共用分镜的按需方法](../../studio-storyboard/SKILL.md#按问题选读)处理当前问题。Nora 的山音方法按[业务适配](../../nora-serial-drama/references/山音方法适配规范.md#山音方法的范围与适配)合并到同一稿件。首帧和素材安排分别按本阶段对应规范接续。

### 场次分镜的填写与接续

保存位置、场头、来源剧本、场景参考及批准依据使用[场次模板](../templates/场次分镜模板.md)和[逐集目录](../../nora-serial-drama/references/逐集目录与资产管理规范.md#2-正式文件与目录)。正文采用共用逐镜模板，镜头时间从本场00:00起算。

剧本及场头地点显示实际地点名称并链接对应SC资料卡。场景图未就绪时可先编写分镜，视频提交前按素材规范补齐实际采用字段。按[共用剧本的声源写法](../../studio-screenplay/SKILL.md#声源与正文写法)识别台词和声源，按[本集对白与表演](../../nora-drama-write/references/对白与表演修订规范.md)核对人物表演依据。普通对白和独立听者反应优先考虑单人取景，其余按本场信息、动作和已确认风格选择。

创作变化按[上游归属](../../nora-serial-drama/references/制作返修接续规范.md#制作返修的上游归属)处理；逐镜写法与核对使用共用规范。完成当前稿后按[文本自检](../../nora-drama-review/references/文本自检与订正规范.md#文本交付前的自检与订正)和[修改轮次](../../nora-serial-drama/references/场次版本组合规范.md#场次修改轮次)交付。

### 场次与剧集之间的转场和接续

涉及跨集、跨场或叙事层次切换时，先按[接续中的继承与变化](../../nora-serial-drama/references/主控操作规范.md#接续中的继承与变化)确定适用设定，再设计转场；下方状态延续要求适用于已经确定需要承接的时空与事件，不将现实设定自动套入幻想、梦境或戏中戏。

编写剧本与场次分镜时，连着检查前场结束和本场开头；新一集还要回读上一集的结尾。核对观众能否理解经过了多久、到了哪里、人物为什么开始当前行动，以及哪些状态继续保留，不能只靠场头写了“次日清晨”就认为画面已经交代清楚。

时间、地点或行动阶段改变而开头缺少交代时，安排必要的短镜头或声音衔接，让观众先辨认新的时空和行动起点，再进入主要事件。可用清晨光线及环境声、人物走出房门或抵达新地点、承接前场物件的动作等；选能完成交代且符合节奏的表现，不逐次补齐全部生活过程。转场不等于必须使用黑场、淡入淡出或额外特效，也不规定固定秒数。现有开场镜头已能交代变化，或前场悬念与动作需要立即接续时，可以直接切入；跨集连续事件不因集号变化自动跳时、复位或重演已经完成的动作。

例如，前场夜间以人物说“明早再种菜”结束，下一场清晨可先用约3秒表现她推开房门走入院子，配合晨光和鸟鸣，再接解种袋的镜头。这个例子只说明时间与行动的过渡；黑土已铺好的剧情依据及门、穿戴、持有物等状态仍须按[镜头状态规则](../../studio-storyboard/references/分镜写作规范.md#镜头状态的变化延续与参考差异)核对，不能用转场掩盖未交代的关键变化。

过渡内容落实到现有剧本动作及分镜模板对应字段，逐镜边界按[起止画面与转场方式](../../studio-storyboard/references/分镜写作规范.md#逐镜起止画面与转场方式)填写；新增独立切镜使用独立镜号，保持已有编号，纳入所属P段及镜号映射。短过渡镜头可以少于4秒，但生成分段仍按[段长规则](../../nora-serial-drama/references/层级编号与时长规范.md#1-层级编号与时长)规划；插入后按[时长核对](../../nora-serial-drama/references/层级编号与时长规范.md#对白与动作时长核对)同步镜头、分段、场次及整集计划，不把原段加长到超限。涉及新增行为或改变事件因果时，按[返修归属](../../nora-serial-drama/references/制作返修接续规范.md#制作返修的上游归属)先同步剧本；取景、切镜与节奏的调整由分镜落实，并同步受影响的首帧、提示词和素材需求。

每场分镜写完后、送审前检查前后场接续；整集分镜写完后连读所有场次边界及上集结尾、本集开头和下集接点。将需要补充的过渡或仍未交代的状态记入现有修订／审阅记录，不另设转场审批阶段。

### 声景与配乐

本节适用于分镜的声音安排及后续模型提示词。默认不让模型生成环境音或持续背景底声，包括室内底噪、机器嗡鸣、空调声、街道声、远处人群交谈和无明确发声者的杂声；现实、幻想及室内外场景使用同一默认边界。只有本次任务、已确认剧情或明确声音设计要求时，才安排对应环境声，并限定声源与出现区间，不因场景名称自动铺底。

默认保留已指定的人物对白、画外现场对白、旁白／心理声音，以及承担动作信息、因果或节奏的必要离散音效。动作音效写明具体声音及发生点，不为每个动作自动添加一串脚步、衣料和碰撞声。BGM只在本次任务或已确认声音设计明确需要时填写；未安排时不添加配乐，不用“低频氛围音”等模糊词变相生成音乐或持续底声。

“音效：无”表示不新增动作或特效声，也不默认延续环境底噪；已列出的对白、旁白仍按原文发声。无对白、不新增人声、无环境音与完全静音分别说明：去掉环境声不等于删除人物对白或必要音效，完全静音才表示全部声音关闭。

逐镜声音与模型整体声景、音乐字段保持一致；去环境音的要求覆盖整段，不在其他镜头、summary或整体声景中重新加入环境底声。音色参考只保留所需音色，不复制素材中的背景杂声。引用前段音视频时核对是否会带入不允许的底声；导演台上下文及输出模式按[段间声音衔接核对](../../studio-h3/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#61-局部返修时的前后衔接)处理，不以空Audio槽认定没有声音输入。

### 模型转写与实际输入

已确定的镜头和素材按[视频提示词接续](../../nora-video-prompts/references/视频提示词制作规范.md#模型正文的内容核对)转写并核对；声音默认边界沿本文件声景规则，实际输入和上下文按[H3导演台](../../studio-h3/SKILL.md)核对。
