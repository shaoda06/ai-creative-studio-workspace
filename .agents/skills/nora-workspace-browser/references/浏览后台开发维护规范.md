# 浏览后台开发维护规范

修改前读取[浏览服务局部指令](../../../../工作区浏览服务/AGENTS.md)，核对当前分支和未提交改动。代码修改、Git提交和正式服务发布分别按实际授权执行；正式运行必须使用既有托管启动器。

| 修改内容 | 直接规范 |
| --- | --- |
| 服务与接口、依赖和隔离检查 | [开发与验证](../../../../工作区浏览服务/README.md#开发与验证) |
| 公共组件和页面展示 | [组件与页面实现](../../../../工作区浏览服务/docs/组件与页面实现.md) |
| 开发记录 | [记录规范](../../../../工作区浏览服务/docs/开发记录规范.md)、[模板](../../../../工作区浏览服务/docs/开发记录模板.md) |
| 版本与正式发布 | [版本规范](../../../../工作区浏览服务/docs/版本记录规范.md)、[服务发布](../../../../工作区浏览服务/README.md#开发环境与正式环境) |

业务类型、布局、批准条件和记录写入留对应业务；模型特有装配留模型工具。只改通用接口或调用关系，不为单个项目增加公共特殊分支。检查实际调用方和受影响失败恢复，保留真实任务状态，不重写历史输入。

自动化验证使用隔离工作区和模拟服务，不能写真实项目或提交生成。涉及UI时完成局部指令要求的公共组件与浏览器检查；没有UI变化则说明依据，不为纯后端拆分重做全站视觉检查。修正规范、模板或脚本后完成其唯一真源、引用和接口检查，正常已通过项不重复验证。
