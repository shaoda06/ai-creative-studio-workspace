# 浏览服务使用规范

本浏览服务仅支持桌面浏览器，不再维护或验收手机、平板及其他低于桌面下限的布局。最低桌面显示分辨率为1366×768；浏览器缩放100%，实际内容区须至少1280×640 CSS像素。系统缩放或浏览器工具栏使内容区不足时，以内容区为准。桌面端保留窗口变化、滚动、弹窗边界及鼠标键盘操作的通用适配。小屏设备能够打开页面，不代表其布局受支持。

服务入口、系统托管和日志按[浏览服务README](../../../../工作区浏览服务/README.md#日常启动)。使用已配置的服务，不另起一份队列或监控器。后台关闭、网页关闭和Agent会话结束各有生命周期；不能把关闭网页当作任务取消。

scripts/browser_tasks.py从项目所在目录的上级查找本工作区实际任务服务配置，使用真实Codex调用上下文及服务token，不输出凭据。提交由[ComfyUI工具](../../nora-comfyui/SKILL.md)调用；查询从工作区根执行：

~~~sh
python3 .agents/skills/nora-workspace-browser/scripts/browser_tasks.py status --group-id 实际任务组ID
python3 .agents/skills/nora-workspace-browser/scripts/browser_tasks.py report --notification-id 实际通知ID
python3 .agents/skills/nora-workspace-browser/scripts/browser_tasks.py retry-collection --task-id 实际本地任务ID
~~~

参数和恢复动作见--help。状态、通知ID和任务ID均取自真实记录，不构造。report读取现成结果并确认收到，不代表向用户交付或用户采用；正常流程不重复登记。只有对应失败时才读取原附件或执行修复。

业务写入后由其接入规范核验实际展示。图片技术任务没有业务展示要求时返回not_requested；已有业务候选仍须按业务规则完成网页同步。同步失败保留技术成果，恢复同步而不重新生成。


## 项目空间与统一入口

服务在代码所属工作区统一启动，首页直接提供共用工具及已登记的一级项目空间。登记资料目录无需另外启动服务；目录可以分开，浏览与监控仍归同一公共后台。业务阶段不得另建服务启动入口或任务页。

本机登记保存在服务代码目录的`runtime/workspaces.json`，具体格式与启停见浏览服务README。每个空间的任务数据库及执行附件保留原位置，由统一进程接管，不能同时运行旧监控器。切换前核对任务及已有后台，切换后核对原任务ID、远端prompt_id、结果和客户端配置，不以重新提交代替恢复。

Agent从所属资料目录发现`runtime/task-service.json`。`url`为统一服务地址，`api_prefix`指定登记空间的API前缀；未设置时为`/api`。客户端自动装配前缀，不手工改用另一空间的token。只读连接通过对应空间的`service`接口核对资料根目录。公共资产、提示词和风格库从统一首页访问，不要求先进入某项业务。


## 共享工具真源定位

`runtime/task-service.json`属于当前资料工作区，`api_prefix`用于选择其项目空间；它不表示本目录安装了另一套后台或全部模型工具。提供端的`tool`字段指向实际服务代码目录，其父目录的`.agents/skills/`是共享执行工具和统一入口的真源。当前空间的自有业务/PDF工具仍从本空间技能目录读取；不要把空间根目录与服务代码根目录混为一谈。

已有明确提供端位置时直接读取其同名技能；需要定位时，从当前工作区调用本地只读客户端：

```sh
python3 .agents/skills/nora-workspace-browser/scripts/browser_http.py --workspace '/实际工作区根目录'
```

Python使用当前工作区已配置环境。--workspace必填，相对路径按当前目录解析；--timeout为每次只读GET超时秒数，默认30。命令先验证当前空间ready及workspace，再返回version、workspace、tool、workspace_skills和provider_skills，不输出token、不写配置或文件、不登记/提交任务。读取provider_skills下的nora-video/SKILL.md进入统一工具登记，再读对应同名技能；本地兼容文档的相对真源路径均以这个目录为基准。

缺少配置、服务未就绪、空间不符或连接失败时直接报告问题；已有明确提供端与可读源码时仍可继续独立的离线说明工作，不从不完整副本猜测依赖已安装。启动/修复仍按已登记提供端的运行说明操作，不在资料目录另起后台。独立离线安装需要完整依赖和资源时另列缺项，不用复制短剧业务规则填充工具。

跨空间调用时，将提供端说明中的技能相对路径换成provider_skills下对应脚本的绝对路径，继续使用调用方实际工作区、项目、请求和输出位置；必要的Python依赖可用提供端已配置环境，不复制虚拟环境。脚本安装位置不决定业务资料归属，不能为运行提供端脚本而切换到提供端项目或使用其token。

跨工作区的一级业务或外部工具（例如Iris的商业入口及PDF）按服务代码目录内runtime/workspaces.json的name/path登记定位，再读该根目录的AGENTS、README及同名技能；不从另一个空间的工作目录猜路径。Nora主入口内的Iris提供方指这一登记空间，不要求把其业务或PDF复制到Nora。未登记或实际根目录不可读时列明缺项，不能用旧客户归档或短剧目录充当入口。
