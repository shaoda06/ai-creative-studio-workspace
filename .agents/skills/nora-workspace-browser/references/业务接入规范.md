# 业务接入规范

业务阶段维护内容、类型、规格、来源资格、记录格式和采用。后台接收明确请求及结果适配，只维护执行、持久化和展示机制。业务接入模块是代码模块，不是三级技能。

图片结果适配由backend/services/image_tasks.py明确分发：technical只核对请求和文件；serial-drama及未指定adapter的既有计划调用短剧图片业务接入。未知适配快速报错，不执行任意传入脚本。

图片任务清单准备由backend/services/submission_plans.py按同一显式适配分流：technical复用调用工具已装配API及技术映射；原短剧计划调用D06的drama_image_plans，不在后台再实现图种、布局或资料卡规则。技术清单接口见[统一分配](../../nora-comfyui/references/固定脚本接口规范.md#nora统一分配与提交)。

短剧图片的准备、候选、批准、正式保存和业务投影在[图片阶段](../../nora-drama-images/SKILL.md)维护。backend中的image_closeout、imagegen_results、local_images是同一业务实现的兼容入口，不保留第二份可编辑规则。

技术完成、业务登记、网页同步和用户采用分别处理。业务登记失败恢复原记录；网页只读取实际资料，不以文件存在或任务成功推断批准。共用参数和文件路径保持验证，不能借业务解耦移除来源、认证或不可逆写入保护。

调用方没有业务展示记录时，后台可返回技术成果及文件链接，不强制创建短剧结构。现有业务展示接入的字段含义按所属业务规范，公共组件及交互由浏览服务统一维护。

项目总索引的共用格式读取由scripts/workspace_project_index.py提供；D01项目登记脚本按同一格式追加条目，项目发现、展示和排序仍由后台负责。旧project_index导入只兼容转调，不保存另一份解析或登记实现。
