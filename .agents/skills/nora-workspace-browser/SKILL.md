# 工作区浏览服务与任务后台

按当前动作读取，不为提交任务加载全部开发资料。

| 当前任务 | 入口 |
| --- | --- |
| 运行、启动停止、服务发现及同步 | [服务使用](references/浏览服务使用规范.md) |
| 提交、任务组、报告及原任务恢复 | [ComfyUI工具](../nora-comfyui/SKILL.md)及scripts/browser_tasks.py |
| 业务资料与图片展示接入 | [业务接入](references/业务接入规范.md) |
| 修改代码、接口、公共组件或发布 | [开发维护](references/浏览后台开发维护规范.md) |

后台执行已备任务，保存技术事实，按明确结果适配调用业务登记。Agent负责理解和创作，脚本负责装配及操作；用户决定采用。技术完成、业务登记和展示同步分开恢复，通知不代表采用。

通用任务接口不要求人物卡、EP编号或短剧模板。业务专用记录和展示转换由对应业务接入维护；后台只调用已经登记的适配，不接受任意脚本路径。H3等模型的格式、时间线与结果解释由相应共用工具维护；后台保存任务事实并调用明确的业务适配，未指定adapter的旧任务保持原业务语义。

业务脚本需要核对实际网页同步时，可用scripts/browser_http.py建立本机只读连接并检查服务工作区；具体对象、采用及完成字段由业务验证，不在HTTP工具里判断。
