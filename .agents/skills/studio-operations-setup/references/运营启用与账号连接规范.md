# 运营启用与账号连接规范

## 发布意向与配置

新项目定位、商业需求建档或首次运营时明确“发布／暂不发布／待确定”。已明确的直接沿用。暂不发布可在项目定位或制作简报写“暂不发布到社交媒体”，说明无则写“无”；无需建立空配置。启用后使用[模板](../templates/项目运营配置模板.md)将发布意向、平台、账号、后台入口和Chrome profile写入调用业务指定的账号配置位置，相关作品引用同一份配置，不重复维护账号表。调用方已有固定记录结构时，按其映射将账号身份、浏览器配置和默认选项写入现有字段或决定记录，不强制创建公共模板文件或增加固定章节；已有记录按调用方规则解析当前有效值。仅在实际需要连接或代发时补齐本次必要信息，不把账号配置作为发布资料准备的前置问卷。计划发布与各作品实际发布分开，后者归发布记录。

同一项目的不同平台可共用专用profile；同一平台的不同账号使用不同profile。配置记录用户可辨认的profile名称及可用稳定标识，不记录浏览器工具临时连接编号；账号显示名称与可取得的稳定账号标识分别记录，不猜测缺项。账号密码、Cookie、登录令牌不写入配置或共享技能。

首次启用检查profile是否存在、扩展是否连接、实际登录账号及后台权限。每次读写后台前核对profile与页面账号身份，未登录或身份不符时停在当前入口，由用户完成必要登录／验证；已有明确授权直接沿用，不重复要求确认。浏览器无法读取时按真实限制说明，允许以用户导出数据补充，不编造连接成功或账号数据。

启用运营时，按[业务范围与对象映射](../../studio-social-operations/references/运营与制作接续规范.md#业务范围与对象映射)在配置登记调用方规则入口、配置归属、状态入口、发布对象及资料位置；按同规范的[运营会话接续](../../studio-social-operations/references/运营与制作接续规范.md#运营会话与制作接续)复用或创建实际入口。配置不复制状态表或批准事实。

## 发布选项配置

用户确定的各平台发布选项写入当前账号配置的“发布默认设置”或调用方映射的原决定记录，记录平台、页面设置项及选定值。按阶段04的[平台发布指南](../../studio-publication/references/发布准备与记录规范.md#平台发布指南)逐项登记，包括AI内容声明、下载／保存权限、可见范围等本次已确定的选项；真实账号、具体选择和变更依据留在项目内，不固化为所有项目的统一默认。AI声明仍须符合实际内容。

已有明确选择直接沿用；用户更改时更新项目配置，并区分后续发布默认值与当前作品实际保存值。未核实的当前作品不能仅因配置已更新就记为已修改；页面原本已符合时记录只读核对，不重复提交。未确定的选项按当前任务确认，不把平台预选项当成用户选择。

推荐发布时段记录平台、时区、报告或后台依据和适用范围；尚无依据明确写“暂无”。具体日期时间的批准只记录在本次发布说明，按[排期建议与授权](../../studio-publication/references/发布准备与记录规范.md#排期建议与授权)执行，不将推荐时段当作持续代发授权。

## 浏览器任务与收尾

全部运营阶段使用[共用浏览器工具](../../studio-browser-operations/SKILL.md)。本阶段提供正确profile、实际账号和授权范围；工具管理本次页面与清理，不决定发布。

## 平台选择与检查记录

配置中的默认主封面版式按[封面阶段](../../studio-cover-images/SKILL.md)确定；推荐发布时间来自后台及运营报告，不把固定时段写成跨项目默认。连接检查记录时间、账号、profile与可访问入口，未验证填“待核实”。仅登记已做检查，不为更新配置无故访问或改动所有账号。
