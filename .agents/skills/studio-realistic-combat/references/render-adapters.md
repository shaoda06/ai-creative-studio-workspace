# Seedance 2.5 / 2.0 投喂封装 (Render Adapters) · 打戏侧适配

> 本文件提供 Seedance 打戏封装示例。实际生成分段、时码、声音及排除要求按所选模式和工具填写；业务核对按[共用视频提示词](../../studio-video-prompts/SKILL.md)。

---

## 一、 时长预算协议

1. **单组时长**：按本次 Seedance 版本及工具允许的时长，结合实际动作、台词与反应安排分段。
2. **时长预算**：根据拟定时长与各段内容估算组数，保留必要的攻防过程及接点。
3. **单组内容**：核对本组的画幅风格、参考主体、时间轴及所需声音。排除要求按工具字段和项目约定填写。
4. **镜头与生成分段**：按正式分镜保留固定、运动和切镜选择，转写时读取当前模型工具的模式指南；不能通称“模型不支持组内硬切”而把多镜强改成连续运镜。

## 二、 版本语法对照（投喂前核对）

| 语法项 | Seedance 2.5 | Seedance 2.0 |
|---|---|---|
| 音效标记 | 官方字符：音效 `<>`、台词 `{}`、音乐 `()`、字幕 `【】`；社区 `[SFX: ...]` 亦可 | 无官方字符，音效写入镜行 `声音：` 文字描述，**默认由模型生成** |
| Hit-Stop | 允许三件套（1~2 帧微停顿+接触点火花+双刃咬死震颤声） | **禁顿挫词**（顿挫/阻尼/弹开），打击感靠接触瞬间画面本身 |
| 运镜 | 单段可写复杂连续运镜与转场 | 按已选镜头和当前模型指南转写，固定机位也可采用 |
| 蓄力 | 可写压缩收束蓄力 | 按剧情呈现蓄力，不预设静止段不可用 |
| 参考图 | ① 全能参考模式（参考图组锁形象，默认）② 首尾帧模式（first_frame+last_frame，与参考图互斥） | 单参考图绑定锁定形象，**无首尾帧** |
| 参数行 | 不使用——model 写进【画幅风格】句尾 `model=` | 同左 |
| 台词 | 走声音层 `{}`，不写进口型 | 写入台词栏锁口型节奏，模型生成对白（默认视频内出） |

## 三、Seedance 封装示例

> 末帧接续状态写入实际需要的镜头。章节和标签以所选工具为准。

以下示例已选末帧接续，并按该示例需要设置停留。

```text
【画幅风格】
16:9 横屏, 实拍影视质感, 阴天冷光/暖色武馆光等一句光影基调, 人物皮肤质感真实, 镜头稳定, 微动作自然。model=seedance-2.5（或 seedance-2.0）

【场景资产】
@SCN-xxx（参考图3）

【核心人物】
@CHR-xxx（参考图1，声线锁：低沉微哑男声）；@CHR-yyy（参考图2，声线锁：冷冽干脆男声）

【站位声明】
@CHR-A（画面左 · 背靠空间锚点 · 侧身45°朝右 · 重心前压切入架势）、@CHR-B（画面右 · 依托空间锚点 · 正面朝左 · 持械姿态）；轴线锁定：左A右B，当前人物关系保持可追踪；位移仅限本镜声明路径（A: 锚点→中央对决区；B: 锚点→中央对决区）

【时间轴分镜】
00:00-00:04 [镜头1] 中景 · 45°斜拍平视 · 快速平摇。动作描述与接触受力。声音：…。台词：…。
00:04-00:08 [镜头2] 近景 · 侧面45°平视 · 跟拍跟镜。动作与受力。声音：…。台词：【角色A："…"】（2.5 台词字符）或无。
00:08-00:12 [镜头3] 特写 · 正面30°微仰 · 急速推镜。情绪拐点与破防。声音：…。台词：…。
00:12-00:15 [镜头4] 全景 · 30°斜侧仰视 · 急速拉镜→定镜收束。收势/悬念收尾；第 13.5 秒起镜头运动收束、人物停止大幅动作，末 1 秒全体人物保持姿态与站位、动作完全静止、画面定格（供末帧截图）。声音：…。台词：…。

【音效】
环境音列举（默认由模型生成；2.5 可走官方 <> 字符；仅用户明确指定"不出台词/走后期"才写后期层）

【本例的排除要求】
画面不加字幕和水印，音频保留现场声音。
```

### 镜行书写规则（硬约束）
- 镜行格式：`00:00-00:05 [镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`；
- **每镜行尾必带行内 `声音：` 与 `台词：`**（无台词写"台词：无。"）；
- 镜行**不写"跟随@谁"**（跟随目标融进动作描述，如"镜头随其位移横移"）；
- 动画中带神态：`他甩棍转身的瞬间冷笑，棍梢带出一道风声`（动作中神态的示例，独立静止特写也可采用）；
- **段末拍法**：按[硬切与末帧接续](../../studio-storyboard/references/分镜写作规范.md#硬切与末帧接续)选用。上面的定格写法只用于选定末帧起拍并确实需要停留的示例，接续所需的站位、持物与受力状态要可辨。换机位硬切时，可在对手后撤尚未站稳时结束，下一镜从同一次后撤的下一拍开始。剪辑余量及是否裁掉停留由实际方案决定。

### 站位声明（一行式 · 每段必写）
- 四要素（每人一段括号）：位置（画面左/右/中）+ 依托物（空间锚点）+ 朝向 + 姿态；
- 轴线行：多镜同场景必写 `左A右B`（或对调后全段保持），轴线变化时交代可理解的空间依据；
- 位移行：逐人写 `起点→终点`，每步有动作原因（攻击/闪避/击退），**禁瞬移**；
- 静态段写 `全员原位，无位移`；
- **禁画图**：禁 V3 俯视 ASCII 空间图/坐标表/初始图+位移因果链（太复杂模型理解不了）。
- **多人同场（2~4 人）升级为三行制**（主轴行 + 从轴行 + 全员动态行），格式与范例见 `multi-opponent-rules.md` §八；1v1 场景仍用本节一行式。

## 四、 音效与声音排布（2.5 / 2.0 分版）

### Seedance 2.5（官方字符）
- 音效 `<>` 叠在时间轴对应秒段，必须具体，禁"震撼音效"；
- R1 可用音效词库（写实向）：

| 场景 | 可投喂音效 |
|---|---|
| 破空拳/扫腿 | `<Air-cut Whoosh 重型破空呼啸>` |
| 拳脚命中 | `<Impact Thud 沉重受击闷响>` / `<Bone Snap 骨骼受力脆响>` |
| 格挡/架招 | `<Block Clash 格挡碰撞闷响>` |
| 近身缠斗 | `<Scuffle Grunt 缠斗喘息闷哼>` |
| 环境破坏 | `<Shatter 玻璃碎裂>` / `<Crack 地面龟裂>` / `<Rubble 碎石滚落>` |
| 摔投 | `<Body Slam 重物砸地闷响>` |
| 追逐脚步 | `<Running Footsteps 急促脚步>` |

- **声音事件时间线**：音效按事件排时间线序列，每个动作事件对应一个音效事件：`拔刀鸣（0.5s）→ 破空呼啸（1.2s）→ 交击爆鸣（2.0s）→ 冲击爆破（2.5s）`；
- **空间纵深音**：远层事件用低频闷响+混响，近层用高频脆响+干声；
- **死寂转余响**：绝杀命中后先留 0.3~0.5s 死寂，再放环境余响（碎石滚落/风声/耳鸣），比全程轰鸣更有打击重量。

### Seedance 2.0（文字描述 · 默认视频内出）
- 音效/台词以文字描述写入镜行 `声音：`/`台词：`，**默认由模型生成**；
- 禁 `[SFX:]` 标记、禁顿挫词；
- 台词文本写入台词栏锁口型节奏；仅用户明确指定"不出台词"才写后期配音说明。

## 五、 资产锚点规则（@CHR/@SCN）

- 使用 `@CHR_name` / `@SCN_name` 明确对应资产图，**严禁无主代词**（"他/她/神秘人"）；
- 多参考图（角色+服装+场景混投）必须**逐实体**写绑定：`严格保持 @CHR-A 的脸型与发型（参考图1），只改变服装为……（参考图2）`；
- **真人脸红线（官方硬约束）**：参考图严禁含真人人脸，一律动漫/CG/绘画风格；
- **素材标注用途**：每份参考素材标注（锁定外貌/动作/音色/运镜），禁只丢图不说明；
- **2.0 参考图仅锁定形象**：禁投 `first_frame`/`last_frame`，禁写首尾帧相关。

## 六、 负面词与自检（S5 机检）

### 排除要求示例
```text
【项目明确需要时】
画面：禁字幕、禁水印（含 Logo）；
音频：禁背景音乐、禁旁白。

【按镜核对的常见偏差】
画面：角色变形 / 手部异常 / 服装变化 / 分身 / 复制人 / 慢动作升格 …
文字：文字 / UI / Logo / 角标 / 可读文字 / 真实 UI
```
按本次实际输出要求选择相关项。出现角色、肢体或服装问题时，优先把正确的主体、归属和动作写清。

### S5 机检清单（出稿前逐项过）
1. **字数门禁**：**只计【时间轴分镜】段正文**的中文 ≤500 字/组，不含另六个模板段——**本条是字数统计口径的唯一真源**。来源：Seedance 官方指南建议提示词 ≤500 中文字 / 1000 英文词（**官方建议值，非平台硬字段上限**，各入口字段上限实测在 800~2500 字符量级），动机是文本过长会分散模型注意力致元素丢失。参考区间（贴门禁线）：4 镜稿 320~480 字、5 镜稿 400~500 字；超限时**压缩描述而非删镜**，因果链不断；
2. **时长**：对照本次所选 Seedance 版本和实际工具可接受的时长；
3. **版本语法**：2.0 无 `[SFX:]`/顿挫词/首尾帧；2.5 用官方字符；
4. **画幅一致性**：所有镜行/构图词与锁定画幅一致（16:9 禁"垂直安全区/上下叠压"竖屏词，9:16 禁横屏构图词）；
5. **正文完整**：按所选工具核对时间轴、声音与台词；接续状态写清实际发生位置；
6. **站位声明**：四要素+轴线+位移行齐全，禁 ASCII 图；
7. **镜长节奏**：检查停留与切点是否符合内容，不按相同镜长比例重排，不要求覆盖三个时长取值。
8. **动作描述**：检查必要动作、受力与空间是否清楚；对峙、蓄势、静止等词不自动判错，写实程度按项目约定。
9. **多人关系**：按 `multi-opponent-rules.md` §十检查人物和动作可读性，不套人数、镜数或主角每镜在场的配额。
