## 目录结构与资料存放

`projects/`保存独立业务项目；`综合资料/`在需要跨项目资料时建立。技能、模板和共用工具由总目录维护，本目录不复制技能库或另启后台。

## 项目索引入口

项目总索引位于 `projects/项目总索引.md`，首次项目建档时按[共用项目总索引]({{skills}}/studio-workspace-browser/references/项目总索引规范.md)建立；已有索引时在此提供链接，不复制项目清单。

## 工作区专用约定

通用约定见[总工作区AGENTS]({{studio}}/AGENTS.md)。本地项目、素材、账号与连接配置不进入公共分发仓库；项目特有约定经确认后写入所属项目。

## 项目接续与相关资料

先读本文件，再读项目README和唯一进度文件；再按当前剧集、阶段及授权接续。初始化方法见[工作区初始化]({{skills}}/nora-drama-positioning/references/工作区与初始化规范.md)。任务库和连接由[统一后台]({{skills}}/studio-workspace-browser/references/任务运行资料维护规范.md)管理。
