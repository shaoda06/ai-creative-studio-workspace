# Nora项目README规范

## 归属与结构

本规范维护Nora连续短剧项目的说明入口。项目目录结构沿[初始化规范](项目初始化规范.md)及其引用的业务结构真源；不由一级子工作区规范规定剧集、人物或制作目录。已有角色资产、独立篇章等项目按已确认的项目类型和专用约定保留结构，不因整理README重新建档或补造阶段。

项目根目录只有一份`README.md`作为项目说明、专用约定和资料导航入口，不另设项目AGENTS.md。项目进度仍以`项目进度.md`为准，定位、采用、授权和执行事实仍归各自原记录。

## 固定写法

使用[项目模板](../templates/项目README模板.md)。一级标题写实际项目名，固定六个二级标题依次为：项目说明、项目专用约定、目录与资料入口、进度与版本入口、接续要求、历史与特殊事项。

- 项目说明：实际类型、用途及业务技能入口。角色资产或独立合集如实说明，不写成有贯穿故事的连续剧。
- 项目专用约定：已确认的本项目例外、默认选择及适用范围；没有独有约定时注明沿业务规范。按需设三级小节，不抄共享制作规则，不把会话创建视为生成授权。
- 目录与资料入口：链接实际定位、索引、剧集及运营资料；未建资料注明待建立，不创建无内容的链接或填空正文。
- 进度与版本入口：链接唯一项目进度及真实版本来源。README不另维护当前集号、任务状态、待办和会话分工表；项目长期版本例外属于专用约定。
- 接续要求：先读所属工作区README和本文件，再读项目进度及本次对象，进入当前阶段；已有项目不重走初始化。
- 历史与特殊事项：只保留必要说明与历史入口，无内容时注明暂无；不将历史批准、旧参数或快照当作当前授权。

固定的是二级章节与信息边界，不限制专用约定的必要细节。现有章节可降低标题层级后归入相应章节，原标题文字和锚点保留；同一条规则只保留一个有效正文，其余改为引用。迁移不改业务正文版本、素材采用或历史执行事实。

## 新建与维护

新建项目时，初始化脚本使用模板生成README骨架，不覆盖已有README、不生成AGENTS或后续创作正文。Agent随后填写已确定内容；保存定位和项目进度后补齐对应链接，未定项明确注明。已有README的整理按本次授权进行，日常初始化不自动重写旧项目说明。
