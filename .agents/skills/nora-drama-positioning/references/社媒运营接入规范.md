# 社媒运营接入规范

本规范维护Nora业务如何调用[公共社媒运营](../../studio-social-operations/SKILL.md)：项目与剧集关系、目录、建档时机和专用执行适配。账号连接、图片设计、发布及复盘方法归公共运营阶段，不在此复制。

## 对象与状态

账号配置归实际Nora项目，剧集通常以EP编号作为发布对象；片头、片尾或其他独立作品沿已有真实身份，不为运营另建项目。制作资料沿原项目，项目状态入口为`项目进度.md`；专用项目按其README已确认约定执行。业务代号不替代平台作品ID。初次接入及对象变化时，在运营配置引用本规范和实际项目入口。

## 目录与创建时机

| 内容 | Nora位置与创建时机 |
| --- | --- |
| 账号配置 | 首次启用运营时建立`10-社交媒体资料/项目运营配置.md`，各剧集引用同一份配置 |
| 个人页资料 | `10-社交媒体资料/个人页资料/账号视觉索引.md`及`其他资料/工作稿/{平台}-{账号代号}-主页视觉-工作稿.md`，实际制作时建立 |
| 封面资料 | `10-社交媒体资料/封面资料/封面索引.md`及`其他资料/工作稿/封面制作-工作稿.md`，按封面配套选择和实际内容建立 |
| 图片执行记录 | 各视觉资料的`其他资料/执行附件/`，按对象和真实生成记录分组 |
| 发布成片 | `98-成片交付/{发布对象代号}/成片/`；初始化单集时建立，片头片尾按实际需要建立 |
| 发布材料 | 对应`98-成片交付/{发布对象代号}/`中的`发布说明.md`、`发布文案.md`，准备发布时填写，封面和成片引用准确资源版本 |
| 发布事实 | `10-社交媒体资料/发布记录.md`，核实实际公开后记录 |
| 发布执行附件 | `10-社交媒体资料/其他资料/执行附件/`下本次任务目录 |
| 复盘及采集 | `10-社交媒体资料/运营复盘/{发布对象代号}/{发布对象代号}-运营复盘报告-YYYYMMDD.md`及`采集资料/{YYYYMMDD-HHmmss}/`，实际采集与报告时建立 |

项目初始化沿[项目初始化规范](项目初始化规范.md)，成片位置沿[成片交付目录](../../nora-serial-drama/references/文件版本与工作稿规范.md#成片交付目录)。公共运营的README接入要求不另建Nora项目模板。账号、用户决定与真实状态只留项目；未启用或未发生的事实不预填。

## 媒体版本与图片命名

实际媒体归本项目`资源/`，索引和工作稿引用准确版本，不复制到正式图、候选、发布或历史目录。不同内容的处理结果保留来源关联；已有逻辑地址及资源映射继续可追溯，不借规则维护移动真实文件。

Nora既有图片身份和命名沿[文件版本规范](../../nora-serial-drama/references/文件版本与工作稿规范.md#素材与执行附件)。个人页逻辑身份为`个人页资料/头像/{平台}-{账号代号}-头像.{扩展名}`或`个人页资料/背景图/{平台}-{账号代号}-背景图.{扩展名}`，相对10号运营目录；原生候选标识为`{正式名去扩展名}-候选-vNN-原生.{扩展名}`，尺寸版使用`{正式名去扩展名}-候选-vNN-{宽}x{高}.{扩展名}`。封面逻辑身份为`封面资料/正式封面/{套组名称}-{平台标记}-{横版或竖版}封面.png`，候选标识为`{正式名去扩展名}-候选-vNN.png`。这些名称用于既有工具身份核对，不要求另外保存一份同内容媒体。旧媒体地址与历史记录不因规则更新改名。

## 执行与展示适配

- Nora封面沿[图片固定接口](../../nora-drama-images/references/固定脚本接口规范.md#imagegen子代理交接与固定收尾)，使用真实封面对象、修订轮次、工作稿和输入版本；Imagegen与Qwen均沿各自现行接口，不借用其他类型。
- 个人页的`kind:社交媒体`只用于[只读命名核对](../../nora-drama-images/references/固定脚本接口规范.md#图片的只读命名核对)，不调用不支持该类型的生成收尾。提示词与真实结果记原个人页工作稿，模型调用与资源保存使用共用工具。
- 当前[个人页展示适配](../../studio-profile-images/scripts/profile_browser_projection.py)和[封面展示适配](../../studio-cover-images/scripts/cover_browser_projection.py)读取上表固定索引、工作稿和本项目资源；脚本安装位置不赋予其任意业务目录或跨项目读取能力。现行表头、审阅标题和状态字段保持原模板，不通过复制媒体或扩大路径权限适配其他结构。
- 项目展示核对沿[浏览入口](../../nora-serial-drama/references/项目浏览入口规范.md#交付前同步检查)。公共运营交付真实记录与文件入口，不把未支持的栏目记为已接通。
