# Nora 工作区初始化

工作区结构遵循[总层规范](../../studio-entry/references/一级子工作区结构与README规范.md)。本阶段维护Nora自己的初始化入口、业务README模板及项目目录说明。

在新下载的Studio总目录执行：

```sh
python3 .agents/skills/nora-drama-positioning/scripts/workspace_init.py --workspace 'workspaces/Nora Workspace' --register
```

脚本使用Python标准库，按[共用初始化与分发](../../studio-entry/references/一级子工作区结构与README规范.md#初始化与分发)补齐本地README和projects入口。

`--register`按[运行资料规范](../../studio-workspace-browser/references/任务运行资料维护规范.md)登记空间。省略时只创建资料区，浏览服务按[安装与启动](../../../../工作区浏览服务/README.md)单独管理。

确定项目范围后调用本阶段project_init.py，传入workspaces/Nora Workspace/projects下的实际项目路径。项目与剧集初始化沿[项目初始化规范](项目初始化规范.md)。
