# Nora 工作区初始化

工作区结构遵循[总层规范](../../studio-entry/references/一级子工作区结构与README规范.md)。本阶段维护Nora自己的初始化入口、业务README模板及项目目录说明。

在新下载的Studio总目录执行：

```sh
python3 .agents/skills/nora-drama-positioning/scripts/workspace_init.py --workspace 'workspaces/Nora Workspace' --register
```

脚本仅使用Python标准库，创建本地工作区README和projects入口。已有文件、项目、配置和独立Git目录保留原样；重复执行只补缺，不用模板覆盖业务决定。综合资料按实际需要建立。

`--register`按[运行资料规范](../../studio-workspace-browser/references/任务运行资料维护规范.md)接入同一个浏览服务；省略时只创建资料区。登记不复制凭据、不创建任务、不启动或重启服务。完成所需业务的初始化后，再按[浏览服务安装与启动](../../../../工作区浏览服务/README.md)加载登记。

确定项目范围后调用本阶段project_init.py，传入workspaces/Nora Workspace/projects下的实际项目路径。项目与剧集初始化沿[项目初始化规范](项目初始化规范.md)。

公共仓库提供模板、脚本和流程，生成的workspaces资料区全部留本地。真实项目需要另行备份，不依赖公共仓库。
