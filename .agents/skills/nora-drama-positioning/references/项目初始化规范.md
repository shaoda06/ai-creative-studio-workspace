# 项目初始化规范

项目README的固定章节、专用约定和状态边界按[项目README规范](项目README规范.md)及其模板维护。项目模式的初始化脚本仅在README不存在时创建说明骨架，保留已有内容，不创建AGENTS.md；目录初始化不预填创作正文。

### 2. 创建项目目录

执行本节前先按[技术测试资料归属](../../nora-serial-drama/references/文件版本与工作稿规范.md#技术测试资料归属)判断本次是否为真实短剧创作；工具或流程验收进入该规则的隔离验证分支，不直接套用下方正式项目创建步骤。

项目工作区的本地媒体依赖按[README的FFmpeg初始化与运行](../../../../README.md#ffmpeg初始化与运行)落实。

项目初始化时按[工作区 ComfyUI 配置](../../studio-comfyui/references/ComfyUI-服务配置与任务提交规范.md#工作区-comfyui-配置)复用共用服务设置；完整工作区已运行浏览服务时，可通过“任务进度→编辑”添加或修改节点，也可由Agent按用户确认内容维护同一份配置，不在项目根目录创建配置。

基本定位阶段按[本业务运营接入](社媒运营接入规范.md)提供目录、账号归属与作品映射，再调用公共运营明确社交发布意向。基本定位明确后，由agent调用[固定初始化脚本](#项目与单集目录初始化脚本)，在 `projects/` 下统一创建[项目基础结构](../../nora-serial-drama/references/文件版本与工作稿规范.md#项目基础结构)及[综合资料的固定分类](../../nora-serial-drama/references/文件版本与工作稿规范.md#综合资料存放规则)，同时按[共用项目总索引](../../studio-workspace-browser/references/项目总索引规范.md)登记项目；不逐项手工创建或临时编写建目录代码。配套目录按下方选择建立，其余分类、资产和逐集子目录按对应规范的时机建立。用户简化创作流程时仍执行基础目录初始化，空目录不代表阶段已开始或需要补写内容；用户另有明确目录要求时按其范围处理。

立项时先按[可选配套安排](项目定位与画风规范.md#封面与片头片尾的可选安排)明确封面、片头、片尾各自的选择，再把已确定“需要”的项传入同一次项目初始化：封面建立 `10-社交媒体资料/封面资料/`；片头、片尾分别建立 `09-剧集制作/片头/`、`09-剧集制作/片尾/` 及各自01至05准备目录。“不需要”或“待定”的项不传选择参数、不建对应目录。除项目README入口骨架外只建目录，不预填封面索引、内容稿、工作稿或其他空白文件，也不启动制作或生成；后续改为“需要”时按新选择补建，复用已有目录和内容，取消选择不自动删除已有资料。已有项目的纯接续仍沿用实际入口，不据此批量补建。

本步骤在项目基本定位阶段会话内完成。会话安排及已有入口的补登，执行[会话创建提醒](../../nora-serial-drama/references/会话与进度管理规范.md#剧名或代号确定后的会话创建提醒)。创建项目根目录和顶级目录后，保存本阶段定位，按 [会话组织与项目进度](../../nora-serial-drama/references/会话与进度管理规范.md) 在项目根目录建立 `项目进度.md`；项目名称或临时代号确定后，由主控按该规范完成自身会话改名及进度入口名称同步。不提前生成后续阶段尚未完成的创作资料。除综合资料的固定分类及当前初始化对象所需的[成片交付目录](../../nora-serial-drama/references/文件版本与工作稿规范.md#成片交付目录)外，工作稿、历史版本和执行附件首次有对应内容需要保存时才创建，不随项目初始化预建空目录。

### 项目与单集目录初始化脚本

入口：[project_init.py](../scripts/project_init.py)。Python 3.9+，仅标准库，由agent直接调用，不依赖或接入网页后台；登记与格式读取统一调用[共用索引脚本](../../studio-workspace-browser/scripts/workspace_project_index.py)。项目创建时机由[第2节](#2-创建项目目录)维护，单集创建时机由[逐集目录规范第1节](../../nora-serial-drama/references/逐集目录与资产管理规范.md#1-单集根目录与过程文件)维护。

在工作区根目录运行，将项目名和集号替换为本次实际值；独立安装时替换脚本路径：

```sh
# 项目初始化：12个固定顶级目录、成片交付根目录、综合资料分类及总索引。
python .agents/skills/nora-drama-positioning/scripts/project_init.py --project 'workspaces/Nora Workspace/projects/项目名称'

# 三项均已确定需要时；只需要部分配套时，仅保留对应参数。
python .agents/skills/nora-drama-positioning/scripts/project_init.py --project 'workspaces/Nora Workspace/projects/项目名称' --cover --intro --outro

# 开始本集：该集根及01至05准备目录，同时创建98号本集成片导出目录；项目根必须已存在。
python .agents/skills/nora-drama-positioning/scripts/project_init.py --project 'workspaces/Nora Workspace/projects/项目名称' --episode EP001
```

| 参数 | 含义与路径基准 |
| --- | --- |
| `--project` | 必填，明确的项目根目录；相对路径从当前工作目录解析，也可传绝对路径，支持中文与空格。 |
| `--episode` | 可选，EP001至EP999，或固定名称“片头”“片尾”；省略时初始化项目骨架，指定时初始化该制作对象准备目录及98号本集成片导出目录，不预建其他集。 |
| `--cover` | 项目模式可选开关，已确定需要封面时传入，创建封面根目录；默认不传、不创建。 |
| `--intro` | 项目模式可选开关，已确定需要片头时传入，创建片头根及01至05准备目录；默认不传、不创建。 |
| `--outro` | 项目模式可选开关，已确定需要片尾时传入，创建片尾根及01至05准备目录；默认不传、不创建。 |

三个配套开关可独立组合，只能用于项目模式，不能与 `--episode` 同时使用。脚本只依据传入参数建目录，不自行推断定位中的选择；agent负责按真实选择传参。项目初始化只建立`98-成片交付/`根目录；单集初始化提前建立该集的`成片/`导出目录，片头、片尾交付目录按实际需要建立。具体创建时机见[成片交付目录](../../nora-serial-drama/references/文件版本与工作稿规范.md#成片交付目录)。

脚本创建目录，并在项目模式维护上方[共用项目总索引](../../studio-workspace-browser/references/项目总索引规范.md)；保留已有文件、目录和历史入口，重复运行只补缺失目录和项目索引条目。新项目初始化获授权后直接执行；已有项目仅在获授权补齐目录时执行，不借接续或只读查询自动整理。它不创建定位、项目进度、配置、人物／场景等业务索引或其他空白正文，也不移动资料或连接任何服务；这些内容仍由agent按当前任务和模板保存。目录路径被文件占用或链接越出项目时，报告具体冲突并停止，不覆盖冲突对象。

标准输出为JSON：`mode`为`project`或`episode`，`project`为实际绝对路径，单集模式含`episode`；`created`和`existing`分别列出本次创建和复用的相对目录，`.`表示项目根。项目模式另含 `project_index`（总索引绝对路径）和 `index_added`（本次是否新增条目）。退出0表示本次目录及总索引登记完成，1表示路径、制作对象或配套参数组合、I/O错误，2表示命令行解析错误；失败可能已创建部分目录，解决所报问题后可再次运行。成功只表示目录及项目登记就绪，不代表创作、配置或审批完成，不另建目录日志或状态文件。

维护此工具时在临时目录验证新建、配套的独立选择与组合、后续补建、重复调用及用户导出文件保留、总索引首次创建／分类表末尾追加／重复不改写、单集不改索引、无占位文件、参数组合错误及冲突停止；测试不使用真实项目：

```sh
python -B -m unittest discover -s .agents/skills/nora-drama-positioning/scripts -p 'test_project_init.py' -v
```

新建项目时初始化脚本同时建立`资源/资源索引.json`并启用资源版本管理；业务目录继续保存索引、文稿和执行记录，不再预建工作稿媒体副本目录。已有项目不因补目录切换存储机制，须按已授权的[资源迁移流程](../../studio-workspace-browser/references/项目资源与版本管理.md)完成检查和切换。
