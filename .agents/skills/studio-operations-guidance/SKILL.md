# Studio 后续制作参考与指导

首次接入或对象变化时，按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)读取调用方提供的账号配置、实际对象、资源版本和记录入口；直接调用本阶段也沿用该映射，不决定工作区或项目结构。

读取[复盘参考与采用规范](references/复盘参考与采用规范.md)。输入为当前任务、相关复盘和既有采用记录；输出按[复盘输出映射](../studio-social-operations/references/运营与制作接续规范.md#复盘输出映射)回填原记录，无指定结构时直接写入当前工作稿或发布说明，不新建制作台账。复盘形成时不强制启动调整；实际制作和发布准备时主动读取并判断适用性。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
