# Viggle Remake 换人和换背景

先明确原片版本、要换的表演者和背景、要保留的动作、构图、运镜、切点和声音，以及本次准备或生成的范围。调用业务提供人物造型、场景和中间成片的选择依据，负责结果审阅与采用。

## 分流和执行顺序

- 只换人，进入 [Swap 换人](../studio-h3-remake-swap/SKILL.md)。只换背景，进入 [Edit 换背景](../studio-h3-remake-edit/SKILL.md)。
- 两项都要做时，沿用用户指定的顺序或已采用的中间片。人物已经换好时，直接以该版本进入 Edit。背景已经换好时，以该版本进入 Swap。
- 两项都从原片开始且顺序未指定时，先按 [Edit 的素材适配检查](../studio-h3-remake-edit/references/Viggle-Remake换背景流程.md#1-核对源动作和目标场景)确认场景能承接源动作。通常先 Swap 定人物，再 Edit 换背景。人物辨识度或穿搭准确性需要作为最后一轮重点，且 Swap 样片能保住新背景时，可先 Edit 再 Swap。

## 生成分辨率询问

Swap 和 Edit 装配生成请求前确认本轮输出分辨率。已有明确选择时直接沿用。尚未指定时，Agent 用选项弹窗问「这次视频生成用哪个分辨率？」两套工作流共用以下文案，只显示与本轮源视频方向一致的三档，按预览、高清、超清的顺序展示。

横屏原片

- 横屏｜832×480｜预览
- 横屏｜1280×736｜高清
- 横屏｜1920×1088｜超清

竖屏原片

- 竖屏｜480×832｜预览
- 竖屏｜736×1280｜高清
- 竖屏｜1088×1920｜超清

确认后按预览 480、高清 736、超清 1088 将短边数值填入画布或 API 的 `#54`，使用装配脚本时显式传入 `--short-edge`。如果源视频的短边已经等于所选档位且宽高都是 32 的倍数，节点会保留源尺寸。遇到这种情况，按实际宽高填写选项中的分辨率。同轮要合片或续接的片段使用同一分辨率。

## 原声是否参与生成

Swap 和 Edit 在装配前都核对本轮是否要参考原视频音轨。源片有音轨且用户尚未指定时，用选项弹窗显示以下问句和选项。

**生成时是否参考原视频的声音？**

- **参考**（原视频中的人物有说话、唱歌等发声动作，需要口型跟随声音）
- **不参考**（原视频只有背景音乐，或希望减少原声对人物口型的影响）

选择「参考」时，打开 `#72`，脚本传 `--audio-conditioning source`，原声参与模型生成。选择「不参考」时，关闭 `#72`，脚本传 `--audio-conditioning silent`。模型使用静音条件，取回的视频段为静音，合片时用 `join` 封回规范源片的原声音轨。即使只做一个片段，也用同一分段计划裁回正文并封回原声。

优先保留原画面的嘴部动作时，推荐「不参考」。按用户已明确的选择及适用轮次直接装配，记录在本轮实际请求中。源片无音轨时可关闭该开关。

## 两轮之间的交接

- 每轮使用相应模式的权重、采样设置、参考图和提示词。第二轮的源视频是第一轮选定的实际结果。同步实际段号、保留区间、分辨率、原始音轨和参考图版本。以该中间片的实际画面重新选定下一轮参考帧。
- 分别核对每轮改动目标及应保留内容。换人后换景时重点看脸、穿搭、动作和脚下接触。换景后换人时重点看新场景、地面关系和人物身份。按调用业务的审阅与授权接续。
- 测试工作流时，画面以对应模型的实际输出为准。合片按原片区间裁回，并封装原声音轨。执行记录注明两轮使用的实际源片、输出版本与任务 ID。

两项共用 [Viggle Remake 提示词规范](references/Viggle-Remake提示词规范.md)。只准备时交回所选模式与顺序、素材绑定和待执行的提示词。提交、恢复和取回使用[共用 ComfyUI 工具](../studio-comfyui/SKILL.md)。
