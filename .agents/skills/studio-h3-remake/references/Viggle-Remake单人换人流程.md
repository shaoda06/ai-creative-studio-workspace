# Viggle Remake 单人换人流程（试行稿）

用于把已有视频中的一名表演者换成目标角色，按原片保留动作、镜头、背景和声音。每次 Remake 请求处理一个片段，多个片段由调用方负责切分、提交和合片。

- [画布](workflows/Viggle-Remake-单人换人-双参考图.workflow.json)与[API 模板](workflows/Viggle-Remake-单人换人-双参考图.api.json)使用同一组节点编号。当前 Swap 采样使用 `#15`，备用 Edit Sigma `#33` 保留在画布上。Edit 模式使用对应的 Edit 权重与 Sigma。
- 基准使用 Swap INT8、Euler 六步、24 fps、短边 480、Mystic 去油 LoRA 0.35。工作流内的预设值仅作为本模板起点。[Viggle 官方 ComfyUI 说明](https://huggingface.co/Viggle/Viggle-Remake/blob/main/COMFYUI.md)

## 1. 确定换人目标和参考图

- 从原片及用户说明确定要换的表演者。同框有其他人时，在提示词写清原片里可辨认的目标，以及其他人物的保留要求。
- 调用业务提供同一角色的两张参考图及各自分工。按实际输入顺序编号为 `<Picture 1>` 和 `<Picture 2>`，共同定义一个 `<Subject 1>`。模板以第一张提供面部、第二张提供体型与穿搭为例，按实际素材和目标调整。双三视图作普通参考时 `pins` 留空。
- 提示词按 Viggle 官方六段顺序写成目标成片描述。各段可复用同一份正文和造型图。原片里辨认人物的线索或镜头安排改变时，调整该段正文，时码从段内 00:00.000 起算。[Viggle 官方提示词指南](https://huggingface.co/Viggle/Viggle-Remake/blob/main/PROMPTING.md)

## 2. 规范源片和确定分段

1. 将视频转换为恒定 24 fps，再以帧记录保留区间和顺序。优先沿原片切点分段。连续镜头超过单段上限时，再在该镜头内拆段。
2. 每段最多保留 345 帧，约 14.38 秒。用 `#66` 填写预计保留帧数除以 24 得到的秒数。`#67` 按 `17N+5` 向上取整、封顶 345 帧，输入范围按 4–15 秒计算。短于 4 秒的片段可填 4 秒并补齐到 107 帧，最后按实际保留帧数裁回。
3. 用实际计算结果核对每段源片帧数。需要补齐时，在该段尾部补够生成所需的画面，并记下原片保留帧数与补齐帧数。`#42` 读取片段开头的指定帧数，源文件至少要有这么多帧。比如保留 8.25 秒即 198 帧，送入 209 帧，取回后只留前 198 帧。[Viggle Conditioning 源码](https://huggingface.co/Viggle/Viggle-Remake/blob/main/comfyui/ComfyUI-Viggle-Remake/nodes.py)

## 3. 逐段装配和提交

从 API 模板为每段准备任务副本。用服务器实际上传名填文件字段，原始素材及其版本按调用业务记录。

| 节点 | API 输入字段 | 填写内容 |
| --- | --- | --- |
| `#62` | `file` | 当前段的 24 fps 源片 |
| `#9`、`#64` | `image` | 按实际顺序绑定 `<Picture 1>`、`<Picture 2>` |
| `#34` | `value` | 当前段的完整六段英文提示词 |
| `#66` | `value` | 当前段拟保留的时长，单位为秒 |
| `#54` | `value` | 视频画布及普通参考图的短边设定 |
| `#12` | `seed` | 本段实际使用的种子，API 模板给出固定数值 |
| `#65` | `filename_prefix` | 本段的输出前缀，按实际段号区分 |

经生成授权后，通过[工作区共用 ComfyUI 提交入口](../../studio-comfyui/references/ComfyUI工具调用规范.md)上传、逐段提交和取回 `#65` 的 MP4。当前画布按片段独立采样，各段共用的造型和提示词仍需在合片时核对一致性。

## 4. 取回、合片和返修

1. 先检查每段是否可解码，核对帧率、帧数、尺寸及对应段号。按记录裁去补齐帧，保留原始生成结果供复核。
2. 按原片顺序拼接保留区间，再按原片区间合回原音轨。核对总帧数、片段顺序、切点、音轨起止和音画同步。
3. 按调用业务及实际查看授权审阅单段与接缝。重点核对脸和妆容、发型、穿搭鞋履、动作跟随、构图和背景。用户选定返修片段后，可重跑该段，再替换合片中的对应区间。结果取回、内容审阅和采用按调用业务记录。
