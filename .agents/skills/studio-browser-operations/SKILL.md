# Studio 浏览器操作

Agent按当前工具实际说明执行界面操作；工具完成点击、读取和标签管理。没有另设网页自动化脚本；不把业务判断编码进公共浏览器工具。

## 浏览器任务与收尾

适用于获授权的浏览器任务，业务对象、目标账号与动作范围由调用阶段提供。使用当前工具支持的浏览器API及其说明，不在技能写死临时浏览器ID或工具实现。

1. 在正确Chrome profile中建立本次任务标签组，名称简短且能辨认项目和工作；任务新开的页面放入该组。先识别用户原有页面、窗口和组，不能把它们当成本次临时资源。工具自动创建的任务组直接复用；同一任务不重复建组。
2. 优先新开任务页，不随意移动用户原有页面。临时页面用完即关闭；只保留继续工作需要的页面。不得因整理组而退出账号、删除profile或关闭整个Chrome。
3. 工作结束关闭本次新开的页面，移除本次创建的标签组；窗口也是本次新建且已无需要保留的页面时一并关闭。用户原有窗口和页面保留。若平台自动清理标签页，仍核实组与临时窗口是否残留。
4. 关闭前处理上传中、未保存编辑及草稿状态，区分本次测试内容与用户原有内容；不误发布，不把清理权限扩大为删除作品或丢弃用户工作。遇到需要额外授权的确认按当前工具规则处理。
5. 等待用户登录、验证或明确交接时，只保留必要页面和任务组，说明保留原因；恢复后完成工作并继续清理。中断或报错时也检查本次资源，确实无法清理则说明剩余页面／组及原因。
6. 收尾核对本次标签页、标签组、临时窗口，只有工作与清理均完成才报告浏览器任务完成；未验证关闭成功不能声称已清理。工具不支持任务组或窗口操作时说明具体限制，不伪造成功，也不采用未经支持的绕行操作。
