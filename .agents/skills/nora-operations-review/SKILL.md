# Studio 作品复盘与管理

适用于Nora、Iris及已明确归属的运营项目。首次接入或对象变化时，先按[运营与制作接续](../studio-social-operations/references/运营与制作接续规范.md)确定项目、作品、发布对象和状态入口；直接调用本阶段也沿用该映射。

采集与比较先读[数据采集与核对SOP](references/数据采集与核对SOP.md)；形成报告按[运营复盘报告规范](references/运营复盘报告规范.md)和[固定模板](templates/运营复盘报告模板.md)。输入为发布记录、后台证据、实际发布成片及先前建议采用记录；输出为可追溯采集资料和正式报告。报告完成后建议由[阶段06](../nora-operations-guidance/SKILL.md)在实际制作时使用，不主动发起返工。

Agent负责内容、事实解释与适用性判断；脚本和工具只执行已明确输入的机械处理。按已确认授权进入本阶段，不重新走其他运营阶段。
