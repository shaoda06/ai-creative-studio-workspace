# 本地音频处理规范

## 明确输入与技术结果

输入为源文件绝对路径、起点秒数、连续长度秒数和未占用输出位置。起点与长度由调用方明确提供，终点为两者之和；工具不自行选择人物声音、改动内容或套用业务时长。原文件只读，不补静音、循环、拉伸、混音或改变语速。其他处理需要调用方给出相应实际范围。

使用本机已记录的FFmpeg和Python路径；依赖规则见[工作区运行说明](../../../../README.md#ffmpeg初始化与运行)。过程文件按调用方明确位置保存，试切可用系统临时目录；不自行创建业务目录或登记素材。

## 读取、连续裁剪与解码

以下为PowerShell命令，变量填写实际绝对路径和数值。POSIX终端使用相同FFmpeg参数，按实际shell传入参数；路径含空格时正确引用。

```powershell
$taskFfmpeg = '<FFmpeg可执行文件的绝对路径>'
$taskPython = '<Python可执行文件的绝对路径>'
$taskAudioSource = '<源音频的绝对路径>'
$taskAudioStart = '<已确定起点秒数>'
$taskAudioLength = '<已确定连续长度秒数>'
$taskAudioOutput = Join-Path ([System.IO.Path]::GetTempPath()) ('nora-audio-' + [guid]::NewGuid().ToString() + '.wav')
if (Test-Path -LiteralPath $taskAudioOutput) { throw '输出位置已存在，停止当前处理。' }
& $taskFfmpeg -hide_banner -nostdin -n -ss $taskAudioStart -i $taskAudioSource -t $taskAudioLength -map 0:a:0 -vn -c:a pcm_s16le $taskAudioOutput
if ($LASTEXITCODE -ne 0) { throw '裁剪失败，停止当前处理。' }
```

POSIX终端的同参数调用如下；先检查目标占用，正常执行后再做下方的格式与完整解码核对：

```sh
task_ffmpeg='/实际FFmpeg绝对路径'
task_audio_source='/实际源音频绝对路径'
task_audio_output='/实际未占用输出绝对路径.wav'
task_audio_start='本次起点秒数'
task_audio_length='本次连续长度秒数'
if [ -e "$task_audio_output" ]; then printf '%s\n' '输出位置已存在，停止当前处理。' >&2; exit 1; fi
"$task_ffmpeg" -hide_banner -nostdin -n -ss "$task_audio_start" -i "$task_audio_source" -t "$task_audio_length" -map 0:a:0 -vn -c:a pcm_s16le "$task_audio_output"
```

`-ss`为起点，`-t`为长度而非终点；`-map 0:a:0`选择首条音轨，`-vn`不输出视频，`pcm_s16le`输出16位PCM WAV。未指定`-ar`或`-ac`，沿用源采样率与声道数。执行前先确认明确输出位置未占用，`-n`继续提供不覆盖保护。不能只凭退出0判断已产生新文件：实际工具在同名拒绝时也可能返回0并报告already exists/Exiting；出现该输出时停止，不把已有文件记为本次新结果。输出失败时保留错误，不将残缺文件记作成功。实际处理视频音轨另须有相应输入及授权，不能借本音频命令扩大范围。

对源文件或输出文件完整解码时，运行下方FFmpeg命令，将输入替换为当前被核对文件。对PCM WAV读取帧数、采样率与声道，并以帧数除以采样率得到时长，不用播放器整数时长代替实测。

```powershell
& $taskPython -X utf8 -c "import sys,wave; w=wave.open(sys.argv[1], 'rb'); print('seconds=', w.getnframes()/w.getframerate(), 'rate=', w.getframerate(), 'channels=', w.getnchannels(), 'frames=', w.getnframes(), 'bytes_per_sample=', w.getsampwidth()); w.close()" $taskAudioOutput
if ($LASTEXITCODE -ne 0) { throw '读取音频文件失败，停止当前处理。' }
& $taskFfmpeg -hide_banner -nostdin -i $taskAudioOutput -map 0:a:0 -f null -
if ($LASTEXITCODE -ne 0) { throw '完整解码失败，停止当前处理。' }
```

非WAV源文件可用已记录的ffprobe读取实际格式、流信息及持续时间，再用FFmpeg完整解码；不把读取元数据成功当作完整解码成功。返回实际执行参数、结果路径、格式与测量值及原始错误。裁剪、WAV读取和完整解码均成功才表示对应技术步骤完成，目标内容是否合适、允许时长及采用条件由调用方核对。

调用方确定技术结果保存目标时，复制同一已核对文件并保留原字节；目标已存在时停止并报告，不再次裁剪、转码或覆盖。技术工具不修改人物资料、业务索引、批准记录或下游输入映射。

过程检查文件与实际输入/结果的保存边界按[临时资料生命周期](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#临时资料生命周期)执行。只用于检查的中间文件在本次临时目录处理并随操作收尾清理，实际被提交的图像/音轨、候选和交付产物继续保留，不按“过程”名称自动删除。
