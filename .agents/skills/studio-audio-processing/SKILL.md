# Studio 音频处理

调用方提供实际源文件、已确定的起点与长度、允许的编码及输出位置；Agent理解这些输入并调用[本地音频处理规范](references/本地音频处理规范.md)中的命令。FFmpeg执行确定性的读取、裁剪和解码，不判断选段是否适合业务。

使用已记录的FFmpeg和Python运行路径，不安装或升级依赖，不连接后台队列。返回实际文件、参数、格式、采样率、声道、帧数、实测时长及解码结果。技术完成不代表声音内容已审、已获采用或模型输入资格通过；业务阶段维护这些决定和记录。
