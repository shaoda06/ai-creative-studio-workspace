# Studio 浏览服务与任务后台

浏览页和持久任务后台由工作区统一服务提供，一个入口访问已登记的项目空间和共用能力。任务数据各归所属空间，任务库及连接配置集中在总服务runtime/workspaces；业务资料和采用记录留项目。业务阶段只提供接入，不自建服务或监控器。服务代码目录由`/api/service`的`tool`确认。

按当前动作读取，不为提交任务加载全部开发资料。

| 当前任务 | 入口 |
| --- | --- |
| 运行、启动停止、服务发现及同步 | [服务使用](references/浏览服务使用规范.md) |
| 新增空间、任务库位置、备份迁移及退役 | [运行资料维护](references/任务运行资料维护规范.md) |
| 提交、任务组、报告及原任务恢复 | [ComfyUI工具](../studio-comfyui/SKILL.md)及scripts/browser_tasks.py |
| 业务资料展示及按媒体清单下载剪映包 | [业务接入](references/业务接入规范.md) |
| 修改代码、接口、公共组件或发布 | [开发维护](references/浏览后台开发维护规范.md) |
| 缓存、日志占用、隔离测试媒体及整理快照 | [存储与测试媒体维护](references/存储与测试媒体维护.md) |
| 项目图片、视频、上传音视频、返修版本及历史迁移 | [项目资源与版本](references/项目资源与版本管理.md) |

后台执行已备任务，保存技术事实，按明确结果适配调用业务登记。Agent负责理解和创作，脚本负责装配及操作；用户决定采用。技术完成、业务登记和展示同步分开恢复，通知不代表采用。

通用任务接口不要求人物卡、EP编号或短剧模板。业务专用记录和展示转换由对应业务接入维护；后台只调用已经登记的适配，不接受任意脚本路径。H3等模型的格式、时间线与结果解释由相应共用工具维护；后台保存任务事实并调用明确的业务适配，未指定adapter的旧任务保持原业务语义。

业务脚本需要核对实际网页同步时，可用scripts/browser_http.py建立本机只读连接并检查服务工作区；具体对象、采用及完成字段由业务验证，不在HTTP工具里判断。
