# ComfyUI-任务监控提示词模板

版本：v1.16；更新日期：2026-11-02。

## 1. 使用方式

用于编写后台通知后结果处理的交接提示词，或用户主动要求复查既有任务的处理提示词；日常查询与正常通知直接沿[对应处理分支](../references/进度查询与结果处理规范.md)执行，无需另填本模板。不创建生成监控heartbeat。技术策略的唯一真源为[任务监控规范](../references/ComfyUI-任务监控规范.md)。按任务填写，不伪造远端ID或完成事实。复制提示词时将下方规则入口占位符替换为本机实际安装路径及章节；只复制本次适用的媒体分支，不把模板相对链接带入项目或新会话。

## 2. 任务填写区

```text
项目及阶段：{项目、任务类型、审批和当前授权}
本地任务ID：{后台UUID}
远端任务ID与地址：{已经取得的真实值，未提交填写未提交}
来源会话：{真实会话ID与名称}
记录入口：{原执行目录内的执行档案.json；旧布局保留原附件；逻辑凭据按共用读取接口访问}
成果保存目标：{入队时明确的本机文件路径和输出对应关系}
本批真实任务与预期范围：{既有执行清单入口；仅计算本次实际任务和成果}
任务组ID及固定成员：{工具回执中的group_id和成员入口；历史无组任务明确注明}
对话通知要求：{默认按整轮业务范围汇总；填写已有的用户明确例外，无例外时沿默认规则}
通知ID：{本次批次UUID；主动查询无通知时填不适用}
当前问题：{最新结果、失败阶段或需要复查的具体事项}
工具入口：{提供端技能绝对目录}/studio-workspace-browser/references/固定脚本接口规范.md 的“后台任务查询与结果处理”及本次动作小节
规则入口：{提供端技能绝对目录}/studio-workspace-browser/references/ComfyUI-任务监控规范.md；异常入口：{提供端技能绝对目录}/studio-workspace-browser/references/进度查询与结果处理规范.md
业务入口：{当前业务及阶段的实际技能或项目约定；明确收到结果后回到哪个业务阶段}
```

## 3. 共用固定正文

工具调用先读[后台工具的共用条件](../references/固定脚本接口规范.md#后台任务查询与结果处理)，再按动作选择[状态查询](../references/固定脚本接口规范.md#后台状态查询)、[最终报告读取](../references/固定脚本接口规范.md#后台最终报告读取)、异常时的[兼容待审登记](../references/固定脚本接口规范.md#后台视频待审登记)或[取回重试](../references/固定脚本接口规范.md#后台取回重试)；具体业务处理按下方正文及媒体分支执行。

```text
先执行监控规范“跟进与通知”的默认整轮汇总规则，优先按groups核对本组固定成员、进度和缺项，历史任务再用rounds与原记录。有通知ID时调用browser_tasks.py report，读取后台已保存的最终报告，工具在同次读取自动确认收到；部分正常成功静默接收，在既有共同记录保留结果入口及尚未交付状态；达到整轮交付条件后连同此前已读结果一次汇报，并记录实际交付范围。report的读取回执及new_task_ids不代替整轮交付记录。报告指出业务同步未覆盖项时由Agent处理，不重做已完成的技术收尾。正常结果不再次查询status或展开完整日志。异常按groups[].issues合并，按失败阶段读取对应证据；沿原授权、原ID先静默修复，只有需用户决定、超出授权或确实无法继续时才合并汇报影响与待决项。处理后查一次最新组状态，接续同类后到成员；不另建轮询或heartbeat。需要最新状态时优先用browser_tasks.py status --group-id，排查单项用--task-id；取回失败用原本地ID请求retry-collection，不重新生成。正常结果按下方媒体分支处理；用户新决定另按其实际范围处理，不擅自启动下一阶段。
```

## 4. 图片处理分支

```text
先按共用监控规则核对固定任务组和实际通知要求，普通图片整批就绪后读取report及delivery。已有业务适配完成的技术核验、记录和网页同步不重复执行；technical结果只证明技术成果，候选登记、展示及采用由填写区业务入口接续，不补建其他业务目录。超分完成同样通知Agent，按共用“超分完成接续”交回业务入口，按已有批准与处理授权补齐正式登记和同步，不重复询问已明确授权。异常沿原证据和授权恢复；是否查看画面按本次授权，技术成功不代表用户批准。
```

## 5. 视频处理分支

```text
先按共用监控规则确定交付时机，依据固定任务组的实际报告和调用方业务阶段处理结果，不重复技术收尾。technical视频交回当前业务，不推定已完成采用、完集或客户交付。异常沿填写区共用恢复入口及当前业务处理，保留已有成果和用户决定；缺项单列。
```
