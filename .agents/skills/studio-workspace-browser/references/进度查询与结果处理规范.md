# 进度查询与结果处理规范


## 进度查询与结果处理

本规范适用于ComfyUI后台任务；Imagegen原生任务的实际返回、保存及恢复使用[Imagegen工具](../../studio-imagegen/SKILL.md)，候选登记与采用由实际调用业务接续。按本次动作直接进入下方一个分支。工具的共同调用条件见[后台任务查询与结果处理](固定脚本接口规范.md#后台任务查询与结果处理)，已读时复用；普通后台任务不加载 `comfyui-api`、上传提交说明或生成准备规范。获授权直接调用远端接口时，才读取随包[comfyui-api](../../studio-comfyui/dependencies/comfyui-api/SKILL.md)及对应固定工具章节，不把该分支作为后台不可用时的自动回退。

不创建同任务轮询或heartbeat，不自动重生成。已提交任务沿用原地址及任务ID；恢复不等于准备新的生成。


### 主动查询进度

已有组ID时优先使用`browser_tasks.py status --group-id`读取全组计数、状态和问题成员；需排查具体问题再按子任务ID查询。按[后台状态查询](固定脚本接口规范.md#后台状态查询)调用工具，读取实际状态和更新时间，沿[原任务地址规则](../../studio-comfyui/references/ComfyUI-服务配置与任务提交规范.md#已提交任务的地址与恢复)及[查询方式](ComfyUI-任务监控规范.md#11-待提交跟进方式与间隔)汇报。仅查进度不进入结果交付、创作或提交准备分支。


### 异常与恢复

定位失败阶段，先读原报告和实际工具规范；业务问题参考及经验留存由调用阶段维护，公共恢复只处理原任务技术事实。

异常通知先执行[同组异常交接与静默修复](ComfyUI-任务监控规范.md#3-跟进与通知)：同类问题合并处理，可在原授权内解决的先静默修复，仅需用户决定或确实受阻才汇报。

有通知时先读最终报告，按其中失败阶段查对应证据；状态不足以判断时再用[后台状态查询](固定脚本接口规范.md#后台状态查询)，无通知的恢复任务先查状态。只有取回失败才使用[后台取回重试](固定脚本接口规范.md#后台取回重试)。直接定位[异常检查与连接恢复](ComfyUI-任务监控规范.md#31-异常检查与连接恢复)、[故障补做授权](ComfyUI-任务监控规范.md#33-故障补做授权与额度)的对应情况；登记或网页失败按[公共结果收尾](ComfyUI-任务监控规范.md#后台结果收尾与通知)复用已完成部分和既有重试额度，业务记录修复返回实际调用阶段。诊断需要时使用随包[comfyui-troubleshooter](../../studio-comfyui/dependencies/comfyui-troubleshooter/SKILL.md)，修复沿下方[已有授权的登记修复](#已有授权的登记修复)判断，不把已有授权重新交给用户确认。

取回错误若已确认是登记的output根目录与原终态导出路径不符，按[取回配置修复](固定脚本接口规范.md#后台取回配置修复)仅修复原任务取回元数据，再接续原取回；不改原生成输入或重新生成。


#### 已有授权的登记修复

本节适用于已有成果的登记、关联记录和网页核验失败。technical只恢复技术取回/文件核验，不改为短剧候选或采用；其他已登记业务按自己的适配恢复。具体登记、采用与阶段字段由调用业务提供，不因媒体类型选择某个业务的模板或命令。准备阶段预检全部关联更新的字段、原文唯一性、支持的填充标记及项目进度范围；实际登记保留并发变化检查。正常成功时“不重复登记”的要求不限制异常恢复。

用户已授权保存、采用或同步本批成果时，完成这些动作所需的本地登记修复属于原授权，由Agent自行处理，不让用户选择内部命令或再次确认已经批准的图片。先定位报告中的失败阶段，保留失败报告及经过，复用原任务、原成果、实际批准依据和已完成项，仅恢复未完成的登记或核验；使用原适配已登记的修复入口，业务采用或定稿交回原调用阶段。恢复只接续原授权范围内尚未完成的登记、采用、留档或网页核验，保留原生成关联、请求和批准，不重新生成或超分。

文字修复先修正关联更新计划，不放宽阶段保护。修复请求填写实际原因和基于当前原文的完整替换文字，保留用户修改；原报告、原更新及修复请求保留。新增写入文件、改动用户确认或批准依据、源文字再次变化时停止，不自动覆盖。登记与网页核验实际完成后再报告修复完成。

修复不得更换已选成果、改变批准状态或扩大项目、对象与阶段的写入范围。需要新增生成或费用、缺少真实批准依据、涉及新的创作选择，或确实无法保留用户修改时，才向用户说明具体影响并请求相应决定；可在原授权内解决的命令和记录问题由Agent继续处理。


### 结果处理交接正文

需要编写结果处理的交接提示词或接续既有监控提示词时，使用[结果处理模板](../templates/ComfyUI-任务监控提示词模板.md)。日常查询和正常结果直接执行上方对应分支，不另加载模板。
