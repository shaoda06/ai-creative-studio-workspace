# 项目总索引

本规范是工作区级项目清单的格式、登记、分类排序与展示规则唯一来源，使用[项目总索引模板](../templates/项目总索引.md)及[共用脚本](../scripts/workspace_project_index.py)。业务建档技能决定项目名称、目录和建档时机，调用共用登记；[归档技能](../../studio-archive/SKILL.md)负责项目状态与对话处理，调用同一索引同步。项目内部的剧集、作品、视频和资产索引由各业务维护。

## 位置与身份

索引固定命名为 `项目总索引.md`，放在被列出项目的共同父目录：Nora、Iris 为工作区的 `projects/`，Chloe 为工作区根目录。其他工作区按其实际项目布局确定父目录，不从技能安装位置推断。工作区 README 的“项目索引入口”只链接本文件，不复制另一份清单。

项目名称填写实际项目目录的完整名称，不填写路径、链接、别名、状态或显示序号前缀。项目由工作区和目录共同识别；索引编号只是分类内的展示位置，不是永久 ID，不改变 Iris 的 C 编号等业务标识或文件夹名称。

## 格式与排序

使用模板中的“进行中”“已归档”两节及两张表，即使分类为空也保留表头，不写占位项目。表头与列顺序以模板为准；已归档表的原因从项目 README 同步。每个项目只出现一次，两表分别从 `01` 连续编号，允许两类各有 `01`。

表内行顺序决定该分类的显示顺序；调序时移动整行并连续编号。网页按分类独立生成同一顺序的序号，归档原因筛选保留归档表序号，不针对每种原因再次编号。项目卡片与项目切换菜单使用相同序号和真实目标，归档项带状态及原因。

项目根 README 中的[归档标记](../../studio-archive/SKILL.md#标记索引与浏览页)是管理状态和原因的唯一来源，未标记按进行中；索引两表及原因是同步结果，不通过移动行来归档或恢复项目。

## 登记与维护

- 新建：业务目录和 README 建立后，同一任务内登记；加入进行中表末尾。重复登记不重复添加、不改变已登记项目的分类内顺序。单集、作品、视频和资产的创建不登记为工作区级项目。
- 归档／恢复：先更新项目 README，再同步索引；离开原表、追加到目标表末尾，两表分别重新编号。目标表中原有项目顺序保留。修改归档原因只同步原行，不移动位置。
- 调序、正式更名或移除：按用户授权修改条目及对应业务入口，核对真实目录；索引操作本身不改名、删除目录或启动制作。更名时直接修正原行名称，保留其位置。
- 补登记和格式迁移：保留已登记项目在各自分类内的相对顺序，遗漏的实际项目按目录名称顺序补到所属表末尾；失效条目移除，重复条目先核对并解决。旧单表或有序列表转换为模板的两表，保留额外说明文字；不因只读浏览自动改写。

索引文件留所属资料区，按其 Git 规则处理，不强制加入公共仓库。状态文件与制作进度不因显示编号变化而重写。

## 共用脚本

从总目录执行，示例参数替换为实际目录：

```sh
# 业务建档后登记一个项目；Nora 初始化脚本已直接调用同一函数。
python .agents/skills/studio-workspace-browser/scripts/workspace_project_index.py register --project 'workspaces/Iris Workspace/projects/C001-项目名称'

# Chloe 具名项目使用 nested；其初始化脚本已直接调用。
python .agents/skills/studio-workspace-browser/scripts/workspace_project_index.py register --project 'workspaces/Chloe Workspace/项目名称' --nested

# 归档、恢复或获授权迁移后，按 README 同步整个索引。
python .agents/skills/studio-workspace-browser/scripts/workspace_project_index.py sync --root 'workspaces/Nora Workspace/projects'
python .agents/skills/studio-workspace-browser/scripts/workspace_project_index.py sync --root 'workspaces/Chloe Workspace' --nested
```

`register_project(project, nested=False)`供业务脚本调用，返回是否新增条目；`sync_index(root, nested=False)`同步实际项目并返回索引路径。`nested`表示该目录下直接放置具名项目，项目内包含 README、综合资料与 projects；不把内部视频登记到工作区总索引。脚本不修改项目状态、制作资料或 Codex 对话。

## 浏览读取与核验

共用脚本提供读取与排序，后台只读使用。索引缺失时按实际目录名称排序；未登记的项目接在所属分类末尾，失效项目不显示。旧单表／有序列表保留只读兼容，业务登记及同步使用现行模板。

每个工作区列表提供“查看项目总索引”只读弹窗，读取 `/api/workspaces/{space}/project-index`；项目列表由 `/api/workspaces` 提供，Nora 的 `/api/projects` 与 `/api/project-index` 保留同源入口。核对两个分类的顺序、编号、原因、卡片及切换菜单目标，切换工作区时索引不得串用。单纯更新索引与 README 无需重启服务。
