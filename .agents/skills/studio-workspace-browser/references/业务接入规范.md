# 业务接入规范

业务阶段维护内容、类型、规格、来源资格、记录格式和采用。后台接收明确请求及结果适配，只维护执行、持久化和展示机制。业务接入模块是代码模块，不是三级技能。

图片结果适配由backend/services/image_tasks.py明确分发：technical只核对请求和文件；serial-drama及未指定adapter的既有计划调用短剧图片业务接入。未知适配快速报错，不执行任意传入脚本。

图片任务清单准备由backend/services/submission_plans.py按同一显式适配分流：technical复用调用工具已装配API及技术映射；原短剧计划调用D06的drama_image_plans，不在后台再实现图种、布局或资料卡规则。技术清单接口见[统一分配](../../studio-comfyui/references/固定脚本接口规范.md#nora统一分配与提交)。

短剧图片的准备、候选、批准、正式保存和业务投影在[图片阶段](../../nora-drama-images/SKILL.md)维护。backend中的image_closeout、imagegen_results、local_images是同一业务实现的兼容入口，不保留第二份可编辑规则。

技术完成、业务登记、网页同步和用户采用分别处理。业务登记失败恢复原记录；网页只读取实际资料，不以文件存在或任务成功推断批准。共用参数和文件路径保持验证，不能借业务解耦移除来源、认证或不可逆写入保护。

调用方没有业务展示记录时，后台可返回技术成果及文件链接，不强制创建短剧结构。现有业务展示接入的字段含义按所属业务规范，公共组件及交互由浏览服务统一维护。

项目总索引的共用格式读取由scripts/workspace_project_index.py提供；D01项目登记脚本按同一格式追加条目，项目发现、展示和排序仍由后台负责。旧project_index导入只兼容转调，不保存另一份解析或登记实现。

## 项目媒体清单与剪映下载

登记项目空间的资料树识别以`.jianying.json`结尾的显式剪映媒体清单，在文件旁复用公共下载按钮提供jypack及按需ZIP。列资料、打开预览不生成包；用户点击下载时后台调用提供端studio-jianying的同一export_archive，返回下载并清理本次临时包，不另建业务打包器。

清单沿用共用剪映工具的name/media结构；文件路径由后台在当前项目内解析，包内名称及时间线由调用业务明确：

```json
{
  "name": "本次剪辑交接",
  "media": [
    {"file": "media/选用视频.mp4", "member": "01-选用视频.mp4", "timeline": true}
  ]
}
```

file使用当前项目内文件，优先项目相对路径；member为包内相对路径，不能越界、重复或占用草稿JSON名；timeline默认true，false只放素材箱，至少一项进入时间线。清单是本次明确组合的技术输入，一个可复用交接组合保留一份，不是另一份业务采用真源；当前业务负责实际采用与顺序，不按文件较新自动更换素材。

只读下载接口为`GET /api/workspaces/{space}/projects/{project}/jianying-download?path={清单项目相对路径}&format=jypack`，format只支持jypack/zip，默认jypack。资源绑定所属空间，清单及媒体均经既有项目文件边界解析；不接受其他项目、隐藏路径或越界链接。新入口不需要EP/人物卡，不修改项目采用或完成状态。

后台复用工具的媒体读取、归档成员与时间线检查；请求缺文件返回404，清单/打包输入错误返回409，不提供残包。修正原清单或补回同一输入后可重试原下载；未点击不会自行打包。HTTP成功和结构核对不声称已在剪映客户端导入，常规下载不逐包打开客户端。Agent调用打包仍需用户明确要求，测试或工具开发的隔离验收按各自授权。

## 导演包按需下载

`.director.json`重建清单由共用H3定义，项目资料树复用FileLink与DownloadButton提供“下载导演包”。点击`GET /api/workspaces/{space}/projects/{project}/director-download?path={项目相对清单路径}`，先核对项目文件边界，再调用同一原生导出能力。返回临时ZIP，发送结束、失败或取消后清理文件及请求目录；服务启动清理上次意外退出遗留。无EP、人物卡或短剧前置要求，不提交生成。原素材、清单、API、画布和来源记录保留，用户保存到浏览器下载目录的文件不清理。
