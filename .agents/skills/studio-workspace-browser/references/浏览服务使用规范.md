# 浏览服务使用规范

浏览服务只支持桌面；支持范围、最低分辨率及缩放判断统一按[支持设备与桌面下限](../../../../工作区浏览服务/README.md#支持设备与桌面下限)执行。

服务入口、系统托管和日志按[浏览服务README](../../../../工作区浏览服务/README.md#日常启动)。使用已配置的服务，不另起一份队列或监控器。后台关闭、网页关闭和Agent会话结束各有生命周期；不能把关闭网页当作任务取消。

scripts/browser_tasks.py从项目所在目录的上级查找本工作区实际任务服务配置，使用真实Codex调用上下文及服务token，不输出凭据。提交由[ComfyUI工具](../../studio-comfyui/SKILL.md)调用；查询从总目录调用同一脚本，并明确任务所属资料空间：

~~~sh
python3 .agents/skills/studio-workspace-browser/scripts/browser_tasks.py status --group-id 实际任务组ID --workspace "实际资料空间根目录"
python3 .agents/skills/studio-workspace-browser/scripts/browser_tasks.py report --notification-id 实际通知ID --workspace "实际资料空间根目录"
python3 .agents/skills/studio-workspace-browser/scripts/browser_tasks.py retry-collection --task-id 实际本地任务ID --workspace "实际资料空间根目录"
~~~

参数和恢复动作见--help。状态、通知ID和任务ID均取自真实记录，不构造。report读取现成结果并确认收到，不代表向用户交付或用户采用；正常流程不重复登记。只有对应失败时才读取原附件或执行修复。

业务写入后由其接入规范核验实际展示。图片技术任务没有业务展示要求时返回not_requested；已有业务候选仍须按业务规则完成网页同步。同步失败保留技术成果，恢复同步而不重新生成。


## 项目空间与统一入口

服务在代码所属工作区统一启动，首页直接提供共用工具及已登记的一级项目空间。登记资料目录无需另外启动服务；目录可以分开，浏览与监控仍归同一公共后台。任务侧栏全局展示登记空间的任务与历史，资料页切换不限制可见性；详情与操作按任务实际归属接续，节点配置所属空间单独选择。业务阶段不得另建服务启动入口或任务页。

本机登记保存在服务代码目录的`runtime/workspaces.json`。每个空间的任务库及连接配置集中在总服务`runtime/workspaces/{运行标识}/`，项目执行附件仍在原项目，由统一进程接管。位置、新增空间、备份恢复和退役按[运行资料维护](任务运行资料维护规范.md)，不以重新提交代替恢复。

Agent按实际资料路径匹配总服务登记，读取对应集中运行目录的`task-service.json`。`url`为统一服务地址，`api_prefix`指定登记空间的API前缀；未设置时为`/api`。客户端自动装配前缀，不手工改用另一空间的token。只读连接通过对应空间的`service`接口核对资料根目录。公共资产、提示词和风格库从统一首页访问，不要求先进入某项业务。


## 共享工具真源定位

总服务`runtime/workspaces/{运行标识}/task-service.json`属于对应资料空间，api_prefix用于选择其任务数据。提供端tool指向实际服务代码目录，其父目录.agents/skills是全部业务技能和公共工具的统一真源；Nora/Iris资料目录不另建技能库或服务。已有明确总目录时直接按同库链接读取，不为常规业务额外调用定位接口。

需要核对实际空间及服务时，从总目录调用本地只读客户端：

~~~sh
python3 .agents/skills/studio-workspace-browser/scripts/browser_http.py --workspace "实际资料空间根目录"
~~~

该命令核对空间ready及workspace，返回实际服务tool和总技能库位置；不输出token、不写配置、不提交任务。默认Nora数据根与总目录分离，不能将其workspace字段误当作公共技能或提示词根。

提交使用实际project选择资料空间；查询、通知报告和恢复使用browser_tasks子命令的--workspace参数选择该空间连接。省略参数仅沿用默认Nora空间；不能用默认Nora连接查询Iris任务。通知已给出实际空间时原样使用，不从任务ID猜测或跨库尝试。

缺少配置、服务未就绪或空间不符时报告具体问题，按总服务运行说明处理，不另起后台或复制工具。总目录中的业务与PDF均用同库相对链接；资料目录只保存其项目、配置和任务事实。

## 资料展示同步

已接入网页的资料由所属业务规定触发时机、展示条目、业务状态和核验接口。实际修改者在本批交付前核对本次源文件、关联引用及实际解析结果；已有工具报告明确覆盖且输入未变的项目直接复用，不因自动写入重复整套检查。

核验使用正确的资料空间及项目接口，确认本次条目、版本、状态与链接；文件存在、HTTP成功或服务就绪不单独证明内容已同步。数据接口已足以核对时不要求重复截图。只读查询不写资料；仅规则文字变更且不影响解析或现有输出时，不触发业务资料同步。

同步异常保留已完成成果，报告具体缺项并给出源文件入口；并发更新先读取最新资料，不能覆盖另一会话更新或在页面补造状态。恢复同步不重新生成，不改变已确认业务事实。交付区分源资料已保存、解析已核对、运行服务已同步，未完成项如实说明。具体映射及业务核验入口见[业务接入](业务接入规范.md#资料变更与解析接入检查)。
