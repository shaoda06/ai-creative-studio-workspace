# AiMixer导演台返修与输出业务接续规范

1. 按[同场反馈的返修范围与提交](视频阶段与返修执行规范.md#同场反馈的返修范围与提交)确定本轮 P 清单。把意见对应到组内 Shot 或时间点，按[上游职责](../../nora-serial-drama/references/制作返修接续规范.md#制作返修的上游归属)同步剧本、分镜、提示词或素材。已执行请求按当时资料追溯。
2. 按[Nora 缓存与返修接续](缓存与返修接续规范.md#返修来源和二采资格)确定业务来源与批准。种子沿[Nora 场次种子约定](ComfyUI-H3视频执行规范.md#场次基准种子与实际任务种子)确定。技术装配、选择运行与缓存检查按[共用 AiMixer 规范](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#711-返修选择运行操作)执行。若核对发现其他段受影响，将具体分段及影响纳入本轮说明，按实际授权决定范围。
3. 取回本轮实际结果，在原记录登记新任务 ID、各 P 的 R 编号和对应旧版本。送审及进入二采按[场次制作循环](视频阶段与返修执行规范.md#场次制作循环)执行。
