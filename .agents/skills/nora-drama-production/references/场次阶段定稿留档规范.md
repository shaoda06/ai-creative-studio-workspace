# 场次阶段定稿留档规范

## 5. 保存与交付


### 5.1 场次各阶段定稿留档

本规则适用于 AiMixer 的一采、二采场次画布留档。常规制作按获批视频和原执行记录接续。

从正式分镜索引按顺序读取全部当前采用身份，再沿审核和执行记录定位实际 API、画布、冻结正文及素材。来源缺项或必要配置冲突时保留已有采用并说明具体原因。

用户明确要求保存可复用的场次画布时，使用[固定场次工具](固定脚本接口规范.md#场次阶段批准后的定稿留档)保存以下小体积资料：

- **场次画布**：`EP编号-C编号-阶段名定稿.workflow.json`。保留实际节点、连线、模型链、SIGMAS、控件及AiMixer 导演台内容；由多个来源整理时注明整场汇总，不能称为某次实际执行原件。
- 汇总API与来源记录放在最前P的实际共同执行附件，场次画布只存[逐集目录规范](逐集目录与资产管理规范.md#4-视频执行输出审核与采用)规定的一处阶段目录。源请求、原API／画布、素材和批准事实继续保留。

汇总保留全部当前获批P段且每段一次；正文、标签、原组ID、时长和配置对应实际来源，根时间线与编辑区同步。一采与二采分别使用各自获批配置；整理汇总副本不改源文件，不重新生成视频。不同来源的必要控件、种子、模型链、尺寸等冲突时不静默统一；只有用户明确授权配置分批时才能按原请求中的批次处理。

相同来源复用原场次画布，已完成的留档再次读取时保留后续制作进度。来源改变时递增三位留档序号，无序号首版视为001，历史清单也占用原编号。历史留档继续按当时资料追溯。
