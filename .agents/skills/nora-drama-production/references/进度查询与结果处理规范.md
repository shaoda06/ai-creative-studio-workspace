# 进度查询与结果处理规范

### 正常视频结果

收到后台通知时先按[后台通知接续](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#后台通知接续)读取规则及最新report，不先发开场提示。按[整轮汇总规则](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#3-跟进与通知)核对本轮范围、共同记录中的已接收报告和交付情况；结果读取回执只表示本次接收，不能代替整轮交付记录。新任务组不会逐项发送正常成功通知，优先使用`groups`核对完整成员；历史逐任务通知的部分成功仍静默接收。整轮齐备时包含此前已读结果一起交付，不把should_notify_user=false当作跳过未完成交付的依据，也不只汇总new_task_ids。reused只表示通知ID曾被确认，不能代替实际结果去重。

`video-scene-generation` 的结果及以该整场源片提交的后处理，按[Songssx 整场接续](视频阶段与返修执行规范.md#songssx-整场候选采用与后处理)交付与登记。按报告和原执行记录确认实际整场文件及对应轮次，使用同一工作稿接续。下面的分段待审、二采接续及按 P 采用用于 AiMixer。

按[视频完成通知后的精简收尾](ComfyUI-任务监控规范.md#视频完成通知后的精简收尾)读取报告并进入对应阶段的处理入口；报告提示业务记录尚需接续时，按[技术记录与业务记录的分工](../../nora-serial-drama/references/会话与进度管理规范.md#技术记录与业务记录的分工)完成具体未覆盖项。完成通知按上述整轮范围汇总；异常进入[异常与恢复](#异常与恢复)。报告及采用收尾确认本集制作完成时，接续[完集复盘](../../nora-drama-handoff/references/逐集目录与资产管理规范.md#完集复盘与经验维护)；复盘复用后台已有核验，不重复结果登记，部分正常完成不触发整集复盘。

### 异常与恢复

技术异常按[公共恢复规则](../../studio-workspace-browser/references/进度查询与结果处理规范.md#异常与恢复)沿原任务处理；业务诊断可检索[制作问题参考](../../nora-serial-drama/references/制作问题与解决方案参考.md)，需要沉淀的结论进入[完集复盘与经验维护](../../nora-drama-handoff/references/逐集目录与资产管理规范.md#完集复盘与经验维护)。视频后端故障按[后端故障后的视频接续](ComfyUI-任务监控规范.md#51-后端故障后的视频接续)核对缓存及所缺成果。

AiMixer 逐 P 的待审登记和采用分别使用[后台视频待审登记](../../studio-workspace-browser/references/固定脚本接口规范.md#后台视频待审登记)及[视频批准一次收尾](固定脚本接口规范.md#视频批准的一次收尾)。Songssx 恢复后按[整场采用](视频阶段与返修执行规范.md#songssx-整场候选采用与后处理)核对原任务、整场文件和工作稿，只补原授权内的未完成项。
