# ComfyUI-任务监控规范

### 视频完成通知后的精简收尾

适用于通知所含任务的预期视频已保存的结果。汇报时机先执行[整轮汇总规则](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#3-跟进与通知)，再按本节处理报告；单任务结果齐备不代表整轮可交付。后台保存技术收尾、待审登记及网页核验报告后通知来源会话。Agent调用一次[report](../../studio-workspace-browser/references/固定脚本接口规范.md#后台最终报告读取)，同次读取自动确认收到；依据任务阶段进入一采／二采的[人工审核交付](逐集目录与资产管理规范.md#视频结果人工审核)或[后处理自动采用](逐集目录与资产管理规范.md#后处理自动采用)。数量和入口使用`delivery.video_count`及`delivery.tasks[].review_url`；历史报告无delivery时沿用原格式。除对应阶段规定的采用收尾外，不重复登记、核验或读取完整状态；不另调用`ack`、`register-results`。异常按报告中的失败阶段处理。


### 视频待审登记与网页核验

技术取回、持久重试、报告与通知按[公共结果收尾](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#后台结果收尾与通知)执行。业务适配按[视频人工审阅区模板](../templates/视频人工审阅区模板.md)维护各P、R、阶段成果与待审区，保留用户反馈、决定、旧版本和采用关系；共同状态归共同入口，各P只维护自身成果与审阅。网页按[交付前同步检查](../../nora-serial-drama/references/项目浏览入口规范.md#交付前同步检查)核对受影响剧集。

报告未覆盖的业务摘要按[记录分工](../../nora-serial-drama/references/会话与进度管理规范.md#技术记录与业务记录的分工)接续，生成说明与项目进度的既有分工不变。异常进入[业务恢复](进度查询与结果处理规范.md#异常与恢复)。

### 后处理完成汇报

本轮获授权的常规及定制项目全部完成后统一汇报：实际处理了什么、分段数量、本轮全部产物的数量与用途、最终规格及成果入口。明确区分已完成、无需执行和未完成，不将计划参数当成实测值，不将“技术完成”写成Agent的视觉质量结论。定制项目尚未完成时，只记录当前进度；异常按[公共恢复规则](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#3-跟进与通知)先静默修复，需用户决定或确实受阻才说明，不把常规工作流成功当作整批后处理交付。

依据现成后台报告、采用收尾报告及定制处理执行记录汇总，不为补充汇报重复取回、测量媒体、登记或刷新网页。精简report未列出实际处理参数时，定点读取本任务已有执行记录或完整报告；不据此新增重复技术核验。多产物按[同轮次后处理产物](逐集目录与资产管理规范.md#同轮次后处理产物)登记后汇报，列出本轮全部产物及默认展示项，说明播放关联；不按文件数增加剧情分段或候选。


## 5. 视频处理

视频按[任务完成后取回全部成果](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#2-留档与收尾)执行。原生 AiMixer 导演台的最终报告、原始组序、阶段和本机目标映射按[AiMixer 导演台成果映射](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#732-任务完成后取回全部成果)核对；合并导出及后处理按实际保存节点输出。网页按P、R、阶段和用户批准事实展示成果。

文件留存及已有文件处理按[成果保存与已有文件](逐集目录与资产管理规范.md#成果保存与已有文件)，后台职责按[视频执行分工](ComfyUI-服务配置与任务提交规范.md#视频执行分工)。收到通知进入[精简收尾](#视频完成通知后的精简收尾)；下一阶段进入[场次制作循环](视频阶段与返修执行规范.md#场次制作循环)。


### 5.1 后端故障后的视频接续

由后台执行[异常检查与连接恢复](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#31-异常检查与连接恢复)的原ID核对。原ID丢失时保留已有本机文件和证据，进入状态待核对，不扫描猜测远端目录、不将潜变量缓存当成MP4成果、不把原执行登记成功。Agent从记录复查所缺成果与来源缓存，向用户说明可接续范围；新的返修／二采仍核对实际执行地址、原AiMixer 导演台节点和获批输入，不自动改投备用端、清缓存或重做一采。
