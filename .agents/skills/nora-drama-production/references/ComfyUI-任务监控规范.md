# ComfyUI-任务监控规范

### 视频完成通知后的精简收尾

预期视频已保存时，复用按[共用报告读取与业务交回](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#报告读取与业务交回)取得的本轮报告和审阅入口。Songssx 按[整场审核与采用](视频阶段与返修执行规范.md#songssx-整场候选采用与后处理)接续。AiMixer 按任务阶段进入分段[人工审核交付](逐集目录与资产管理规范.md#视频结果人工审核)或[后处理自动采用](逐集目录与资产管理规范.md#后处理自动采用)。业务阶段采用和留档按原记录执行。


### 视频待审登记与网页核验

技术取回、持久重试、报告与通知按[公共结果收尾](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#后台结果收尾与通知)执行。AiMixer 业务适配按[视频人工审阅区模板](../../studio-h3-aimixer/templates/视频人工审阅区模板.md)维护各P、R、阶段成果与待审区，保留用户反馈、决定、旧版本和采用关系；共同状态归共同入口，各P只维护自身成果与审阅。网页按[交付前同步检查](../../nora-serial-drama/references/项目浏览入口规范.md#交付前同步检查)核对受影响剧集。

报告未覆盖的业务摘要按[记录分工](../../nora-serial-drama/references/会话与进度管理规范.md#技术记录与业务记录的分工)接续，生成说明与项目进度的既有分工不变。异常进入[业务恢复](进度查询与结果处理规范.md#异常与恢复)。

### 后处理完成汇报

按[共用报告读取与业务交回](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#报告读取与业务交回)汇总技术结果。Nora以本轮已授权的常规及定制处理范围判断交付齐备，定制处理仍在执行时记录进度，异常按[共用跟进规则](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#3-跟进与通知)处理。交付说明实际处理的场次、分段及产物用途。AiMixer 多产物按[同轮次后处理产物](逐集目录与资产管理规范.md#同轮次后处理产物)登记后说明默认展示项和播放关联，分段和候选仍按本轮业务对象登记。


## 5. 视频处理

视频按[任务完成后取回全部成果](../../studio-workspace-browser/references/ComfyUI-任务监控规范.md#2-留档与收尾)执行。原生 AiMixer 导演台的最终报告、原始组序、阶段和本机目标映射按[AiMixer 导演台成果映射](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#732-任务完成后取回全部成果)核对；合并导出及后处理按实际保存节点输出。网页按P、R、阶段和用户批准事实展示成果。

文件留存及已有文件处理按[成果保存与已有文件](逐集目录与资产管理规范.md#成果保存与已有文件)，后台职责按[视频执行分工](ComfyUI-服务配置与任务提交规范.md#视频执行分工)。收到通知进入[精简收尾](#视频完成通知后的精简收尾)；下一阶段进入[场次制作循环](视频阶段与返修执行规范.md#场次制作循环)。


### 5.1 后端故障后的视频接续

按[共用原任务恢复](../../studio-workspace-browser/references/进度查询与结果处理规范.md#后端故障后原任务无法确认)核对原 ID、现有文件及所缺成果。Songssx 按本场原执行轮次核对整场 MP4。AiMixer 接续或返修依赖缓存时，核对原节点、已获批生成来源和可用缓存，按[原缓存接续](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#approved-cache-resume)处理。
