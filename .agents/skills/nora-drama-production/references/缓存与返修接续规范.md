# 缓存与返修接续规范

本规范维护 Nora 使用 AiMixer 时的来源、编号、批准及记录位置。实际操作按共用 AiMixer 规范执行。

## 返修来源和二采资格

- 局部返修先明确 EP/C/P/R 与阶段，在本轮生成记录引用指定实际执行、需改的分段、原有素材版本和批准依据。按[实际执行快照与素材路径](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#611-局部返修的执行快照与素材路径)装配，将已核实的复用与新上传范围写入[原任务清单和输入映射](../../nora-serial-drama/references/固定脚本接口规范.md#一次装配与批量入队)。
- 结构或配置变化时，说明受影响的前后 P 及已批准来源，按[制作变更时的缓存保护](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#751-制作变更时的缓存保护)核对。已有历史文件和审批保持当时的关联。
- 二采由[场次制作循环](视频阶段与返修执行规范.md#场次制作循环)决定准入。将已获批的实际一采版本与本轮分段逐一对应，按[获批一采缓存的远端复用](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#752-获批一采缓存的远端复用)核对。来源不明或缓存不可用时在既有执行记录登记缺项与影响，由用户决定后续范围。

## 素材与业务对象约定

在既有输入映射记录 AiMixer 组与 EP/C/P、源任务、输入版本的对应。组序和各组技术身份按[AiMixer 节点与任务结构](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#1-节点与任务结构)核对。分镜或段范围变化时，同步本版分镜索引和提示词。

段间引导的音视频作用按[AiMixer 前后衔接](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#61-局部返修时的前后衔接)核对。按[声景与配乐](../../nora-drama-storyboard/references/场次分镜制作规范.md#声景与配乐)确定允许的声源；无对白段需分别明确是否允许前段尾音、是否禁止新增可辨人声，以及明确需要的动作声或已指定环境声，并核对实际前组版本、衔接设置和[AiMixer 音频输出模式](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#31-音频参考与输出模式)。独立Audio槽为空不等于没有音频条件；发现无台词段出现人声时，将前段上下文列为核对项，不直接认定它就是原因。不能自动关闭衔接、重做一采或整段静音；用户明确选择静音时，如实记录环境声与动作声也会随之移除，采用仅表示用户接受该处理范围。

缓存名由调用方提供；短剧约定使用`{项目目录名}-{EP编号}-{C编号}`，例如`示例项目-EP003-C001`；集号和场号沿用项目的EP、C编号。Agent在准备场次任务副本时填写并同步画布与API中的`cache_name`，脚本不自动生成场次缓存名。缓存名不添加随机后缀、阶段、R编号或批次编号。历史任务按原执行身份接续。实际工作流与既有输入映射保存此值，不另维护命名台账。按[AiMixer 缓存命名约束](../../studio-h3-aimixer/references/ComfyUI-AiMixer导演台节点使用规范.md#75-缓存检查与清理接口)检查完整名称。项目目录名不符合约束时使用项目已确定的稳定合规简称，没有简称时先确认，保留完整集号和场号，不依赖服务端替换或截断来区分场次。实际目录取服务端规范化后的名字，记录实际缓存身份。
