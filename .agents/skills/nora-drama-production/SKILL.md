# Nora 视频制作

媒体原件、上传参考音视频及修改版本统一按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存；本技能继续维护原业务记录和采用。输入、审核、采用及导出引用准确版本，不因阶段再次复制媒体。

按项目规则、当前分镜及已备提示词进入本次阶段。先按[工作流选择](references/ComfyUI-H3视频执行规范.md#0-制作策略与工作流配置)确定本次导演台，再按[阶段与返修](references/视频阶段与返修执行规范.md)组织生成、审核和后处理。短剧 P/R 身份、候选、采用、种子和留档由本阶段维护。

直接执行时按[核心请求核对与生成](../studio-video-production/SKILL.md#请求核对与生成)落实本场提交，取回后按[候选交回](../studio-video-production/SKILL.md#候选与技术结果交回)获取结果与依据。本阶段组织场次审阅、返修及后续执行决定。

Agent确定实际对象、内容与来源用途，完成语义核对，沿用本次有效授权；脚本装配记录、选择已采用来源和更新状态，不编写剧情或凭任务成功批准内容。[视频提示词阶段](../nora-video-prompts/SKILL.md)负责正文与中文对应；镜头与段长问题返回D08。

直接执行已备正文时，复用已有技法使用说明。本轮首次实际采用未验证写法且尚未告知的，按[首次使用提示](../studio-creative-techniques/references/学习与反馈维护规范.md#首次实际使用时的提示)补充观察重点。收到针对实际效果的具体技法反馈时，按候选的P段、R版本和制作阶段找到实际请求与原审阅意见，再按[反馈复核](../studio-creative-techniques/references/学习与反馈维护规范.md#实际反馈复核)更新相应参考。反馈原话及采用依据留在本场记录。

场次确定继续生成或技术后处理后，按[核心执行入口](../studio-video-production/SKILL.md#按业务决定调用执行工具)提供获批来源、目标与授权。制作脚本见scripts，旧命令路径兼容调用同一实现。后台业务适配可使用服务的文档事务和结果事实，内容及采用规则由本阶段维护。

AiMixer 接续按[缓存与返修接续](references/缓存与返修接续规范.md)确定来源和批准。用户明确要求保存场次画布时，按[场次画布留档](references/场次阶段定稿留档规范.md)处理。[交付收尾](../nora-drama-handoff/SKILL.md)在本集交付资料齐备后处理交接与复盘。

局部返修按[原工作流确定返修范围与提交方式](references/视频阶段与返修执行规范.md#同场反馈的返修范围与提交)。AiMixer 兼容任务按[AiMixer 导演台业务接续](references/AiMixer导演台返修与输出业务接续规范.md)核对 P/R、输出归属和实际运行组序。

收到后台结果或恢复原任务时，进入[本阶段结果接续](references/进度查询与结果处理规范.md)，落实待审、后处理采用及完集收尾。
