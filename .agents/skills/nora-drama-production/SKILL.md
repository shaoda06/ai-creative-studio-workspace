# Nora 视频制作

媒体原件、上传参考音视频及修改版本统一按[项目资源与版本](../studio-workspace-browser/references/项目资源与版本管理.md)保存；本技能继续维护原业务记录和采用。输入、审核、采用及导出引用准确版本，不因阶段再次复制媒体。

按项目规则、当前分镜及已备提示词进入本次阶段；流程与审批见[阶段与返修](references/视频阶段与返修执行规范.md)，配置选择和来源约束见[执行约定](references/ComfyUI-H3视频执行规范.md)。短剧P/R身份、候选、采用、整场批准、种子策略及留档由本阶段维护，不写入共用工具的业务前提。

Agent确定实际对象、内容与来源用途，完成语义核对，沿用本次有效授权；脚本装配记录、选择已采用来源和更新状态，不编写剧情或凭任务成功批准内容。[视频提示词阶段](../nora-video-prompts/SKILL.md)负责正文与中文对应；镜头与段长问题返回D08。

共用[H3工具](../studio-h3/SKILL.md)处理模型格式、时间线、素材绑定与导演包，[视频处理](../studio-video-processing/SKILL.md)按明确目标处理技术参数，[后台](../studio-workspace-browser/SKILL.md)入队、监控、取回与通知。制作脚本见scripts；旧命令路径兼容调用同一实现。后台业务适配可以使用服务的文档事务和结果事实，内容及采用规则仍由本阶段维护。

[缓存与返修接续](references/缓存与返修接续规范.md)维护来源、组序与批准，[场次定稿](references/场次阶段定稿留档规范.md)维护用户明确要求时的整场范围和重建资料，ZIP只在点击下载时临时生成，不自动生成或作为阶段门槛。[交付收尾](../nora-drama-handoff/SKILL.md)在本集当前分段齐备后处理交接与复盘。技术完成不等于采用，不自动授权下一阶段。

局部返修范围、P/R及输出归属还按[导演台业务接续](references/导演台返修与输出业务接续规范.md)落实，再提供明确运行组序给共用工具。
