# 脚本使用规范

## 两类脚本

[轮次登记](修改轮次登记规范.md)直接使用Nora现行剧本、分镜及版本组合，由本阶段维护。Agent决定方案，脚本保存明确结果，不重新设计镜头。

storyboard_check.py是保留的原生格式机检，输入coverage JSON与shots JSONL，可另给keyframes JSONL、screenplay-index JSONL及实际原生project配置。它不直接读取Nora场次分镜模板，也不承担SH/P内容覆盖、台词完整性或模型生成效果的语义判断。只在本次任务明确需要原生格式核对且输入输出已适配时使用，不为运行它创建SHOT/REF/PLAN或另一份正式分镜。

Python 3.9+，仅标准库，路径从当前目录解析。示意命令替换为本次实际绝对路径：

```sh
python3 .agents/skills/short-drama-storyboard/scripts/storyboard_check.py '/隔离附件/coverage.json' --shots '/隔离附件/shots.jsonl' --keyframes '/隔离附件/keyframes.jsonl'
```

coverage和shots必填；keyframes、screenplay-index与project按实际核对范围提供。未提供的输入不能宣称已完成对应核对；project仅接受已有适配配置，不创建short-drama.json。读取实际输出和退出码，错误按具体记录处理，不把机械通过当作分镜批准或视频输入就绪。原生schema只作参考，Nora正式身份和编号仍由业务规范维护。

运行`python3 .agents/skills/short-drama-storyboard/scripts/selftest.py`执行现有13项原生隔离自测，覆盖时长运算、关键帧与覆盖关系；Nora轮次脚本的单独检查见其调用规范。两类检查均不提交生成任务。
