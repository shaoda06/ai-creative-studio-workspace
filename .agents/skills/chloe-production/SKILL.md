# Chloe 视频制作

接续本条生成、返修或资产补缺时，先核对[项目专用约定](../chloe-commerce-video/references/会话组织与接续规范.md#项目专用约定的记录与执行)，再按[会话组织与接续](../chloe-commerce-video/references/会话组织与接续规范.md)确定视频会话及相关资产入口。

随后读取本视频 README、脚本及制作记录。固定写法按[资料规范](../chloe-positioning/references/固定资料写法规范.md)，分段、轮次、审阅、恢复、采用及网页映射按[视频制作流程与记录](references/视频制作流程与记录.md)。

按[共用视频制作核心](../studio-video-production/SKILL.md#生成资产与提示词)接续本条实际输入、正式提示词、请求核对与生成。按[候选交回](../studio-video-production/SKILL.md#候选与技术结果交回)接收候选和技术结果，本阶段组织整片审阅、返修、后续执行与采用。

开始或继续提示词准备、生成及返修任务时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取适用建议及已有T记录；执行中的T关联、分段和准确输出及原用户审阅依据的交回按[阶段记录落点的视频制作项](../chloe-review/SKILL.md#阶段记录落点)执行。

视频生成提示词按[固定文件规范](references/视频制作流程与记录.md#视频提示词文件)及[模板](templates/视频提示词模板.md)保存模型正文与中文参考，制作记录只链接原件。

确认本条视频的画幅、分段和声音；画幅不设默认。使用 H3 时按[共用工作流选择](../studio-h3/SKILL.md#h3-工作流选择)进入对应工具，已有确认直接使用。实际使用 AiMixer 时，按[共用 AiMixer 配置选择](../studio-h3-aimixer/references/参数与基准规范.md#标准版配置选择与装配前询问)确定装配与后处理方案。镜头参考按[共用用途与绑定](../studio-storyboard/references/分镜写作规范.md#镜头参考图与首帧)判断。需制作镜头图时，由本视频会话调用[镜头参考图流程](../chloe-assets/references/镜头参考图制作流程.md)，完成用户批准、2倍超分、尺寸核对及正式登记后绑定准确版本。

按[整片制作与审批](references/视频制作流程与记录.md#配置与整片推进)接续本次工作流的候选及批准。使用 AiMixer 时，按一采与二采的分段结果组织整片审阅。用户负责视频内容审阅。

整片满足接续条件后，按[核心执行入口](../studio-video-production/SKILL.md#按业务决定调用执行工具)提供获批来源、目标与授权。任务使用 technical 适配、明确真实项目和准确输入，制作记录引用原请求、后台状态和技术报告。

AiMixer 后处理按已有报告核对尺寸、帧率、时长及音轨等本次技术要求，合格后自动登记正式采用，依据引用二采批准与处理报告；异常只报告差异，不自动改参数或裁切。二采原文件已满足已确认处理规格时，按[直接沿用规则](references/视频制作流程与记录.md#无需后处理时直接沿用)核对并采用准确二采版本，不建立空的后处理执行、输出或轮次。采用组合交[剪映交接](../chloe-handoff/SKILL.md)，人工后期前仍为制作中。

资料更新后运行固定资料检查和本阶段 `scripts/chloe_production.py check --project <视频项目绝对路径>`。网页使用完整公共制作工作台，本技能只维护资料映射，不维护另一套播放器、审阅控件或任务监控。

收到后台通知后先区分任务类型。镜头图片超分按[镜头图接续](../chloe-assets/references/镜头参考图制作流程.md#5-批准后2倍超分与自动采用)完成图片尺寸核对、正式登记及汇报。视频任务按[视频结果接续](references/视频制作流程与记录.md#后台结果接续)组织整片审阅或按已确认流程接续后处理。

Songssx 使用[整场清单与自动登记](references/结果自动登记.md#songssx-整场任务)。AiMixer 使用[逐段结果登记](references/结果自动登记.md#逐段任务提交时的关联)。收到通知后沿原轮次接续审阅、异常或已授权的下一阶段。
