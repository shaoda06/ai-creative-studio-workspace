# Chloe 视频制作

接续本条生成、返修或资产补缺时，先核对[项目专用约定](../chloe-commerce-video/references/会话组织与接续规范.md#项目专用约定的记录与执行)，再按[会话组织与接续](../chloe-commerce-video/references/会话组织与接续规范.md)确定视频会话及相关资产入口。

随后读取本视频 README、脚本及制作记录。固定写法按[资料规范](../chloe-positioning/references/固定资料写法规范.md)，分段、轮次、审阅、恢复、采用及网页映射按[视频制作流程与记录](references/视频制作流程与记录.md)。

开始或继续提示词准备、生成及返修任务时，按[复盘建议接续](../chloe-review/SKILL.md#建议接续与验证回填)读取适用建议及已有T记录；执行中的T关联、分段和准确输出及原用户审阅依据的交回按[阶段记录落点的视频制作项](../chloe-review/SKILL.md#阶段记录落点)执行。

视频生成提示词按[固定文件规范](references/视频制作流程与记录.md#视频提示词文件)及[模板](templates/视频提示词模板.md)保存模型正文与中文参考，制作记录只链接原件。

确认本条视频的画幅、分段和声音；画幅不设默认。当前 AiMixer 工作流按[共用 AiMixer 配置选择](../studio-h3/references/参数与基准规范.md#标准版配置选择与装配前询问)确定配置与后处理方案，已有确认直接使用。镜头参考按[共用用途与绑定](../studio-storyboard/references/分镜写作规范.md#镜头参考图与首帧)判断。需制作镜头图时，由本视频会话调用[镜头参考图流程](../chloe-assets/references/镜头参考图制作流程.md)，完成用户批准、2倍超分、尺寸核对及正式登记后绑定准确版本。

按[整片制作与审批](references/视频制作流程与记录.md#配置与整片推进)推进已确认的一采、二采、后处理或局部返修，用户负责视频内容审阅。

执行使用[公共通信](../studio-comfyui/SKILL.md)、[持久任务后台](../studio-workspace-browser/SKILL.md)、[H3](../studio-h3/SKILL.md)及[视频技术处理](../studio-video-processing/SKILL.md)。任务使用 technical 适配、明确真实项目和准确输入；资源不为适配而复制。原请求、后台状态和技术报告保持唯一，制作记录只链接原件。

后处理按已有报告核对尺寸、帧率、时长及音轨等本次技术要求，合格后自动登记正式采用，依据引用二采批准与处理报告；异常只报告差异，不自动改参数或裁切。二采原文件已满足已确认处理规格时，按[直接沿用规则](references/视频制作流程与记录.md#无需后处理时直接沿用)核对并采用准确二采版本，不建立空的后处理执行、输出或轮次。采用组合交[剪映交接](../chloe-handoff/SKILL.md)，人工后期前仍为制作中。

资料更新后运行固定资料检查和本阶段 `scripts/chloe_production.py check --project <视频项目绝对路径>`。网页使用完整公共制作工作台，本技能只维护资料映射，不维护另一套播放器、审阅控件或任务监控。

收到后台通知后先区分任务类型：镜头图片超分按[镜头图接续](../chloe-assets/references/镜头参考图制作流程.md#5-批准后2倍超分与自动采用)完成图片尺寸核对、正式登记及汇报，不推进视频轮次；视频任务才按[视频结果接续](references/视频制作流程与记录.md#后台结果接续)回写原执行并进入对应整片审阅或后处理采用。

任务提交前按[视频结果自动登记](references/结果自动登记.md)填写原任务计划的业务接续参数。后台完成固定回写和技术采用；通知仅接续整片审阅、异常或已有授权的下一阶段，不重复登记。
