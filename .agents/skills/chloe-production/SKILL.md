# Chloe 视频制作

读取当前工作区 README、本视频 README、脚本及制作记录。固定写法按[资料规范](../chloe-positioning/references/固定资料写法规范.md)，分段、轮次、审阅、恢复、采用及网页映射按[视频制作流程与记录](references/视频制作流程与记录.md)。

确认本条视频的画幅、分段和声音；画幅不设默认。按[公共 H3 配置选择](../studio-h3/SKILL.md)确定配置与后处理方案，已有确认直接使用。参考图片能直接引用时引用准确版本，需要特定构图时交[资产阶段](../chloe-assets/SKILL.md)准备镜头参考并取得批准。

整条视频统一推进：一采齐备后交用户审阅，整条通过后接续二采；二采齐备后交用户审阅，整条通过后接续已确认后处理。批准即授权已确认的下一阶段，不重复询问。局部返修只处理有问题的分段，其余引用已有候选。Agent不代替用户做视频内容审阅。

执行使用[公共通信](../studio-comfyui/SKILL.md)、[持久任务后台](../studio-workspace-browser/SKILL.md)、[H3](../studio-h3/SKILL.md)及[视频技术处理](../studio-video-processing/SKILL.md)。任务使用 technical 适配、明确真实项目和准确输入；资源不为适配而复制。原请求、后台状态和技术报告保持唯一，制作记录只链接原件。

后处理按已有报告核对尺寸、帧率、时长及音轨等本次技术要求，合格后自动登记正式采用，依据引用二采批准与处理报告；异常只报告差异，不自动改参数或裁切。采用组合交[剪映交接](../chloe-handoff/SKILL.md)，人工后期前仍为制作中。

资料更新后运行固定资料检查和本阶段 `scripts/chloe_production.py check --project <视频项目绝对路径>`。网页使用完整公共制作工作台，本技能只维护资料映射，不维护另一套播放器、审阅控件或任务监控。
