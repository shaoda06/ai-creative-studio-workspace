# Chloe 视频制作与返修

创建或更新固定资料前，读取[固定资料写法规范](../chloe-positioning/references/固定资料写法规范.md)及其对应模板；完成后运行其中的检查命令，保持章节、字段和状态写法一致。

输入为本条脚本、已明确的素材版本、实际可用模型与本次授权。读取[资产引用规则](../chloe-assets/references/资源存储与引用规范.md)和[制作记录模板](../chloe-creative/templates/制作记录模板.md)，为每次任务保存准确输入和输出关系；新任务不改旧引用。

根据本条镜头编写模型专用正文，明确主体、商品动作、构图、镜头、声音和时间安排。H3按[共用H3技能](../studio-h3/SKILL.md)确定标准版配置与方向并按实际模式编写，其他模型按其现行工具说明；不继承Nora或Iris的固定轮次、时长、画幅或生成配置。提交前说明实际分段、参数及本次范围，已有明确授权直接沿用。

实际参考先解析本地共用引用；使用支持这些文件的工具。现有后台若要求所有输入在单项目内，不复制共用资产来绕过，也不借用Nora/Iris生产适配。新空间尚无完整自动生产适配时明确缺项；业务规则可先用于准备，但不把准备完成记为已提交。

产出按共用资源机制保存到本视频资源区，候选、失败、取回及处理记录按真实情况登记。检查模特、商品外观、衣服细节、动作、声音和镜头要求；原资料错误回选品，镜头表达错误回创意，参考图错误回资产，生成结果错误在本阶段返修。保留已采用组合，不反复生成掩盖上游问题。

视频后处理使用studio-video-processing，明确源版本和目标；真实执行与业务采用分开。用户采用片段后交剪映交接，不默认合成最终视频或发布。

本阶段的单次执行完成不代表整条视频已制作完成；策划到人工后期均保持视频状态为制作中。需要用户决定或受阻时只更新处理状态、当前问题与下一步，按固定资料规则留存依据。
