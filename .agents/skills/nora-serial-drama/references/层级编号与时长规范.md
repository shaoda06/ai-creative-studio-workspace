# 层级编号与时长规范

## 1. 层级、编号与时长

共用片头、片尾使用“片头”“片尾”替代EP前缀，其目录、编号及正集统计边界见[全剧共用片头与片尾](逐集目录与资产管理规范.md#全剧共用片头与片尾)。其余场次、镜头、分段及修改轮次规则相同。

已有剧集需要拆成多集或顺延后续集号时，先按[拆集与集号调整](../../nora-drama-episodes/references/分集大纲规范.md#已有剧集的拆分与后续集号调整)处理切点、对应关系及关联收尾，再使用本节编号与时长规则落实本集文档。

- 本集故事剧本按场次编排，交接与批准见[豆包台词润色交接](../../nora-drama-write/references/台词润色交接与回稿规范.md#豆包台词润色交接与回稿检查)。剧本确认后按[共用视频制作流程](../../studio-video-production/SKILL.md)接续。剧情正文维护在整集剧本，镜头正文及视频分段维护在各场次分镜；不另建独立分场剧本或分段分镜，不以剧情梗概代替完整剧本和分镜。
- 单集目标时长按[开发流程基本约定](阶段流程与接续规范.md#基本约定)，已有项目明确规格优先。场次、镜头与 P 段的关系按[共用制作层级](../../studio-storyboard/references/分镜写作规范.md#制作对象场次与分段)。先按剧情、表演和镜头接续规划各段，再按选定模型与工作流核对生成段时长。使用 H3 时按[生成段时长](../../studio-h3/SKILL.md#生成段时长)核对，单镜时长按内容安排。
- 场次编号 `EP001-C001`（场头可显示 `1-1`），分段编号 `EP001-C001-P001`。`C` 是拍摄场次，`SC` 是项目级统一场景资产，包含一次性地点并可跨集复用，不混用。场次在单集内连续，分段在所属场次内连续。用于跨文件关联的分镜索引“场次”“分段”栏填写完整编号，例如`EP001-C001`、`EP001-C001-P001`，不能以`C001`、`P001`替代。显示标签、段落简称，以及已由上层字段明确集／场归属且既有接口规定使用短编号的轮次记录，仍可使用`P001`；不将显示简称写入要求完整身份的字段。
- 场次镜号使用 `EP001-C001-SH001`，每场从SH001开始，按本版实际播放顺序连续编号；同场跨P分段不重置，另一场独立从SH001开始。H3提示词内部每P从 `[Shot 1]` 开始，对应关系写入本版场次分镜的段内时间表。
- 场次分镜是整场方案的版本。增删、拆合、移动或重做镜头后，重新整理本场完整镜号，使正文顺序与SH数字顺序一致，不跳号、不用末尾追加的编号插入前文。已确认镜头仍可修订；原批准对应原场次版本及其范围，不将单镜编号固定不变当作返修限制。同步本版转场目标、镜头链接、分段表、索引、提示词镜头对应及受影响的准备资料；编号整理本身不授权生成或重新生成媒体。
- 历史追溯使用场次、分镜版本和当次镜号。已执行视频继续关联当次冻结分镜、提示词和素材，不把旧视频换挂重新编号的现行版本，不改原请求、执行证据或批准事实。旧格式 `EP001-SH001` 在历史资料中按原文保留；其他现有场次仅在获授权修订或整理时应用新编号，不因规则更新批量迁移。
- 各镜时长之和等于分段计划时长，各段之和等于场次计划时长，再汇总为本集计划时长。容量按下方[对白与动作时长核对](#对白与动作时长核对)判断。生成段超出选定工作流的可执行范围时，优先在自然切镜、动作或语句完成处调整分段，必要时修订上游。较短内容可与同场相邻内容合理组合，保留必要的表演时长。
- 分别记录计划时长、实际请求时长及输出文件的帧数与实测时长。保留已有成片、历史请求与执行记录。
- 最终片头、片尾或剪辑成片需要 3 秒等较短时长时，分别记录生成时长和成片时长，安排完整动作及必要余量，再按明确剪辑方案取用。

### 对白与动作时长核对

按[公共时间与分段规则](../../studio-storyboard/references/分镜写作规范.md#时间与分段)确定表演容量。本业务将核对结果同步到受影响的场次分镜、分段表及段内时间表。

**语速参考（仅用于初步估算）**：下表作为中文台词的规划起点，按本句实际说话方式选用或调整；情绪标签不强制决定快慢，已有角色语速校准或对应音频实测依据时优先采用实际依据。

| 说话方式 | 初估语速（字／秒） | 参考场景 |
| --- | --- | --- |
| 平静叙事对话 | 4 | 日常对话、陈述 |
| 轻松调侃 | 4.5 | 轻松交流、打趣 |
| 愤怒激动 | 5–5.5 | 连贯争辩、激动质问 |
| 低沉犹豫 | 3–3.5 | 克制表达、欲言又止 |
| 威严宣告 | 3.5 | 郑重宣布、下令 |
| 快节奏催促 | 5.5–6 | 急促催促、紧张交流 |

初估计量与实际测时按[公共对白估时](../../studio-storyboard/references/分镜写作规范.md#对白估时)执行。上表只供本业务中文台词初估。台词统计的字符数和有明确输入条件的原生估时脚本，分别读取[对白统计](../../nora-drama-write/references/对白与表演修订规范.md#台词设计节奏与统计)和[脚本使用规范](../../nora-drama-write/references/脚本使用规范.md)。

补充或修订穿脱、操作、显隐过程及对白后，重新核对受影响内容；未改变镜号或计划总时长不等于容量已验证。已有选定声音的实测依据时据其核对，尚未测时记录计划依据与待核对项。确需调整时同步镜长、场内时码、分段表和段内时间表，按既有修订与审批规则处理，不以省略必要状态变化来凑时长。参考素材的输入容量另按[参考输入规划与分段可执行性](../../nora-drama-storyboard/references/视频分段规划规范.md#参考输入规划与分段可执行性)核对，不与表演时长混为一项。
