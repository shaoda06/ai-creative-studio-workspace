# 画面文字与字幕规范

### 视频生成全程无字幕

视频生成从第一帧到最后一帧禁止任何语言的字幕，包括对白、内心独白和旁白的台词字幕、翻译字幕、叠加式时间／地点／身份说明，以及独立字幕卡、过场字幕卡或标题卡。禁止跨镜出现、短暂闪现或在片头片尾补字幕；无对白片段也执行同一要求。

常规任务的完整模型正文默认明确全程禁令，例如 `No subtitles, captions, translations, overlay text or title cards in any language, from the first frame to the last.`；中文参考版保持同一范围。出现字幕时，按下节的[提示词对照](#生成字幕问题的提示词对照)处理获授权的省略例外，不统一删除现有禁令。对白及VO／OS的原句仅作为发声内容，按对应模型要求保留声音标签，不要求模型将发声内容写在画面上。输入提示词、参考说明和例子中的字幕要求与本条冲突时，按本条清理实际生成要求，不能用“少量必要字幕”放宽。

字幕与剧情中的实体文字载体分开处理。确需让观众读取牌匾、文件、聊天界面或系统道具界面时，在既有动作／分镜中明确具体载体、准确原文和用途，再按[画面文字布局](#画面文字的布局与可读性)安排构图与可读性；不能把原稿字幕改称“界面提示”或“场景信息”后绕过字幕禁令，也不为避开字幕而擅自新增文字载体。一般旁白信息优先用现有情节、人物有依据的言语或动作表达。

原稿确有叠加字幕或字幕卡需求时，标明其不进入生成画面；是否以非字幕叙事替代或另行后期添加，按用户已确认方向处理，未明确的创作取舍先确认，不擅改已批准剧情。生成阶段无字幕不构成后期添加授权。用户反馈生成结果出现字幕时，记录为该具体输出不符合本条的内容问题；技术成功不等于满足禁令，不能据此自动批准或进入后续阶段。仍由用户人工审核，不增加Agent抽帧、OCR或视频初审，不自动重生成。

### 生成字幕问题的提示词对照

生成画面无字幕是结果要求，正文中的字幕禁令是可调整的提示词写法；写入禁令不保证结果无字幕，省略禁令也不放宽结果要求。

- **优先建议的条件**：用户反馈生成结果出现字幕，且实际拼接的完整正文已有字幕禁令时，主动优先建议只删除该禁令做一次对照。没有禁令可删、已有稳定有效写法或已有其他明确线索时，按实际问题选择，不机械套用。
- **对照范围**：在已有明确授权范围内，只删除实际模型正文中的字幕禁令及中文对应句，不补另一条同义禁令；其余提示词、台词、种子、音色、参考素材、时长、模型、LoRA和生成配置保持不变。核对公共区与本组的拼接范围，不把局部对照扩大到其他分段。需要尝试新种子时另作对照，不与删句同时改变；生成仍按既有授权边界执行。
- **记录与判断**：把删除范围、授权、比较来源和人工反馈保存在既有制作记录及内容核对中，按[检查工具接口](../../nora-video-prompts/references/固定脚本接口规范.md#h3正文与内容核对检查)记录省略例外，不把说明写进模型正文。有效结果只支持相应模型、文本、种子及配置组合；不能据此断言禁令必然诱发字幕、某个台词词语必然触发字幕，或字幕LoRA无效。经人工确认的有效写法可按授权保留在该具体任务范围，不自动推广到其他任务，不改历史记录或已提交版本。

### 画面文字的布局与可读性

按[共用画面文字写法](../../studio-storyboard/references/分镜写作规范.md#画面文字与实现归属)安排准确原文、构图、出现时间和可读性。Nora 的固定界面设计及条目含义见[道具界面规则](../../nora-drama-images/references/道具图片制作规范.md#虚拟界面固定元素与剧情内容)。本阶段允许的场景内文字、后期处理、用户核对及字幕禁令按[视频生成全程无字幕](#视频生成全程无字幕)执行。
