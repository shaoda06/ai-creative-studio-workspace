# 制作返修接续规范

### 制作返修的上游归属

视频制作中的创作修改按[职责分工](创作职责与接续规范.md#剧本分镜与提示词的职责分工)确定剧本或分镜入口，并同步受影响的提示词及素材；生成未执行已确认内容，或参数、接线、后处理出现问题，修订提示词、参考输入或执行设置，不因此自动改写故事。问题源于资产设计时，回对应资料卡维护。

确定修改入口前，先对照用户反馈与该次冻结的实际请求，检查完整模型正文、参考文件及用途、前段音视频上下文、实际模型链与设置；不以05最新版或节点标题代替当次输入。分清已写错／漏写、与参考或其他章节冲突、模型未执行正确描述，以及用户新增的创作要求。正文已明确闭口、赤脚或动作顺序时，不能仅由结果不符反推“未写”，也不反复叠加同义禁令而跳过冲突检查。

在既有记录中区分已知事实、疑点与验证结果，说明拟改哪一处及希望解决什么。提示词修订围绕已定位的问题；技术原因尚不明而需对照时，在已有授权范围内尽量只改一个待验证因素，保留可比较的来源。一次正常或同时改动多项后变好，不记为根因已确认，不据此统一改动其他段或正式基准；明确执行错误按`comfyui-troubleshooter`只读排查。此处不新增生成、审片或实验授权。

局部变更须区分输入／执行方式与创作内容，保留未被用户撤销的已确认设计；不能由素材组织改变推定动作、运镜或效果也被取消。

H3一采返修方案同时按[种子策略](../../nora-drama-production/references/ComfyUI-H3视频执行规范.md#场次基准种子与实际任务种子)判断是否主动建议换种子尝试，条件与执行边界由该节统一维护。

返修按既有授权和审批要求处理，先按下方[完整重做的范围与完成要求](../../nora-drama-storyboard/references/完整重做规范.md#完整重做的范围与完成要求)确定整体或局部范围；局部返修仅更新受影响内容，并检查相邻分段及场次衔接，不能将此默认用于已明确要求的完整重做。新输出仍须用户审核，历史任务及批准事实保留，不因归属判断自动重生成。导演台任务的选择运行、缓存复用及衔接处理读取[返修选择运行操作](../../nora-h3/references/ComfyUI-MiniMaxH3导演台节点使用规范.md#711-返修选择运行操作)，不在提示词文档维护另一套执行规则。
