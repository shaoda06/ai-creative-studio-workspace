# 技能依赖与协作规范

只在选择依赖、核对平台能力、获取缺失技能或命中辅助任务时读取相应章节。已由阶段规范明确指定且可用的技能，直接读取实际入口及本次所需参考，不必先读完整依赖表。协作优先级见[主入口](业务工作约定.md#外部技能协作与规则优先级)。

## 适用平台与技能依赖

本技能的创作规则、模板与配套ComfyUI客户端可独立分享。完整工作区另外提供FFmpeg初始化说明、项目浏览服务和风格库；使用这些能力时才需要相应工作区资源。其他平台还须提供会话与监控能力，缺失时说明受影响操作，不宣称已安排跟进。分享清单与外部资源边界见[分享边界](../../studio-entry/维护规范.md#分享边界与本机时间)。

本表只维护Nora任务的依赖使用条件，不统计整个工作区的技能数量。业务入口已明确时直达；独立技能来源、版本、许可及本地适配来源统一见[公共依赖登记](../../studio-entry/维护规范.md#6-依赖获取与适配资料)。

## 辅助技能的条件调用

| 技能 | 条件 |
| --- | --- |
| `stop-that-shit` | 明确调用，或维护中需要判断额外机制、范围扩大、反复验证的必要性 |
| `stss` | 决策方案中存在防御性赘述，或用户明确要求处理 |
| `find-skills` | 用户寻找技能，或核对已有能力后仍缺少本次专用能力 |
| `vercel-react-best-practices` | 本次实际开发或审阅React／Next.js工具 |
| `fastapi` | 本次实际开发或审阅FastAPI后端 |

命中后按名称读取实际技能，并选读[工程适配说明](../../studio-entry/维护规范.md#辅助技能的工程适配)；普通创作不加载开发技能，不为使用技能改换技术栈。

## ComfyUI节点资源

后处理采用[正式RIFE工作流](../../nora-drama-production/references/ComfyUI-H3视频执行规范.md#1-当前固定基准与任务副本)时，所需独立节点及保留的ZIP由[节点与安装包登记](../../studio-entry/维护规范.md#comfyui节点与安装包)维护；准备任务直接复用已安装的兼容接口，缺失或获准部署时才读取安装验证步骤。节点源码目录或安装包存于`studio-comfyui/dependencies/ComfyUI节点资源/`，与技能安装分别管理，不通过安装技能自动部署到ComfyUI。

使用者须提供支持配套工作流的ComfyUI环境；本技能不自动安装模型、节点或服务端依赖。获明确授权的节点部署按上述登记执行。保留执行规范要求的只读核对；错误如实报告，不自动替换模型、修改服务环境或用远端工作流覆盖本地基准。
