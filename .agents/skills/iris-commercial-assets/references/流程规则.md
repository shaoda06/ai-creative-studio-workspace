# 资产准备流程与规则

图片、声音等媒体的保存和版本按[共用资源与版本](../../studio-workspace-browser/references/项目资源与版本管理.md)执行；本阶段在资产清单维护具体用途、客户意见和采用。

按下列规则组织样例、衍生资产与分批交付。具体风格、图种、数量、规格、工具和采用版本由当前订单确定。

## 流程与接续

依据当前分镜与声音，盘点已有材料 → 明确用途及缺项 → 复用或补做所需资产 → 按条件验证样例、审阅和扩展 → 登记实际版本及采用 → 按范围交接 → 按需整理对外材料、回写反馈。

按本轮实际范围进入，不要求简单任务重走全阶段或制作角色、场景、道具等全套资产。输出为一份业务资产清单、实际材料及必要制作记录；需要对外整理时再形成资产视觉稿。

## 执行要点

### 资产组织与最少补缺

仅维护一份[资产清单](../templates/资产清单与制作说明.md)，实际涉及的角色、场景、道具、界面、二维图形和声音统一登记。每项说明对应镜头、具体用途、所需视角/状态、已有或缺少的材料，以及如何进入制作。区分视频参考、合成图层、声音、沟通展示和中间材料；展示页不自动成为视频输入。

镜头参考图按[共用镜头参考方法](../../studio-storyboard/references/分镜写作规范.md#镜头参考图与首帧)判断用途和缺项。其他资产也先复用符合用途的版本。实际补做的镜头、用途和缺项登记在本单资产清单；排版或合成素材按本单指定的交付形式准备。

### 样例验证与衍生

排参考图制作批次时，按[共用制作顺序](../../studio-creative-techniques/references/图片参考与修订方法.md#多张参考图的制作顺序)在原资产清单的「基准与衍生关系」中安排依赖。

新建视觉方向、关键视觉尚未确定或发生变化时，先做少量代表样例，经用户审阅认可后再扩展必要资产；数量按实际项目，不固定张数。已有有效基准且当前授权覆盖时直接接续，不重复做样例或增加审批。

按[共用图片参考与修订](../../studio-creative-techniques/references/图片参考与修订方法.md#保留项与修订)处理画面反馈及本次输入，说明保留内容与改变范围，落实到本单资产清单和原制作记录。已认可的本单视觉基准及变体采用范围继续按本阶段办理。

编写或实质修订资产图、首帧图提示词时，按[技法转写](../../studio-creative-techniques/SKILL.md#提示词转写)选用所需表情或镜头方法，将构图与可见状态落实到实际图片正文。收到指定候选的具体技法反馈时，结合原制作记录和实际提示词按[反馈复核](../../studio-creative-techniques/references/学习与反馈维护规范.md#实际反馈复核)更新对应参考。

角色换装、视图和状态各记录实际采用文件；一次批量审阅可以明确多个资产/版本的采用范围，逐项记录对应关系即可，不要求每张图单独确认。主图获选不自动覆盖全部变体，较新版本不自动替代已选版本。

### 内容、来源与采用

原生图及尺寸处理结果通过共用资源／PNG入口保存到本订单资源区，接收实际返回路径及资源编号／版本；同一图片的修订显式沿用编号，采用只更新原资产清单与批准依据，不再复制到采用目录。实际来源、客户范围和原批准事实保持独立。

首张实际生成结果通过共用`project_resources.py import --origin generated --producer <实际执行记录>`登记，保存返回的资源编号／版本；同一A资产同一图种的返修必须带原`--resource-id`，并以`--parent`指定实际编辑源版本。用户上传原件用`user_upload`，技术处理用`process`；模型与完整实际返回值仍留原执行JSON，不因登记存储补造生成事实。Agent后续接续读取原资产记录中的编号，不按新候选文件名另起资源。

内容服从当前脚本。需表现混乱或报价资料时，纸面呈现相应内容和层叠；不把这个例子变成所有图片都必须报价或不能留白。精确业务文字按本单分工提供内容或卡片参考，不虚构产品能力、价格、数量或客户信息；界面修改遵守简报的可改范围。

声音沿第三阶段的声音设计，记录真实音频或有效声源标识。外来素材记录真实来源、文件及用途，不虚构生成流水。

返修图送审前按[图片返修看图](../../../../AGENTS.md#图片返修看图)复核，结论写原制作记录。采用时保留原文件与来源，更新清单及受影响的下游引用。技术通过、PDF收录、用户采用与甲方确认分别记录；Agent依据现行决定定位版本、组织输入和处理反馈，不推定采用或客户批准。

## 分批交接与完成

按明确范围分批交接资产。可并行准备声音表及无需实际参考的提示词提纲。正式提示词按[共用生成资产与提示词](../../studio-video-production/SKILL.md#生成资产与提示词)接续，缺项影响记到对应镜头或生成段。

| 当前情况 | 应说明的范围与结果 |
| --- | --- |
| 准备中／待绑定 | 列明缺项、对应镜头和影响；可以继续不依赖缺项的准备，不能写成全部资产已齐备或受影响任务已可提交 |
| 本轮资产已具备并交接 | 本轮所需材料有有效版本，内容符合当前分镜，来源/用途/采用依据和接收入口清楚；写清本轮覆盖范围，不扩成整项目完成 |
| 全范围齐备 | 当前项目约定范围内所需资产均已具备、必要选择已有依据；用户采用、甲方确认和后续执行仍按各自实际事实记录 |

这些是业务记录中的表达，不新增后台状态机或脚本字段。实际交接填写文件/版本、输入职责、缺项限制及实际接收方；标签、槽位和远端路径继续在[视频生产任务](../../iris-commercial-production/SKILL.md)中核对，不以“已发路径”代替真实输入关联。干净生产材料不被带水印PDF展示页替代。

## 模板填写与记录

| 模板 | 填写条件与边界 |
| --- | --- |
| [资产清单与制作说明](../templates/资产清单与制作说明.md) | 准备本轮时写清项目/版本、分镜声音依据、范围及有效决定入口；实际资产项列清镜头、用途、准备状态、文件版本和使用依据。详细说明、衍生及交付部分按实际需要展开 |
| [资产制作记录](../templates/资产制作记录.md) | 制作发生时保留必要业务关联和技术事实入口，可放同批已有主记录；已有提示词、参数、请求/响应和结果只引用，不重复抄写。不强制每资产/每任务新建独立文档 |
| [资产视觉稿](../templates/资产视觉稿.md) | 有对外整理需要时，写清版本/日期、本轮范围、实际成果及用途；视角/状态、方案比较、需决策事项和未展示范围按实际情况填写，不凑空章节或新增问题 |

复杂资产按需展开，不要求所有资产一样详细或每类齐备。尺寸、比例、格式、透明/分层、声音区间及工具参数按使用或执行需要补齐。负责人/接收方仅按实际安排填写，不虚构人员。

需求项数、实际制作任务数、产物数、衍生和预览分别统计已发生范围，可引用现有记录；不把文件总数当作生图次数，也不提前填写成功、采用或发送。用户意见、替代关系、下游影响、交付版本及客户确认在事实发生后回写或引用唯一作品状态；不为模板生成重复流水或空表。

## 交付整理与完成

从当前有效生产资料和真实成果整理需要的对外内容，实质修改先回写来源，再整理新版本。按[跨阶段交付规则](../../iris-commercial-video/references/对外交付.md)审阅Markdown、批准具体版本后调用共用PDF工具；图片直接嵌入PDF，音视频按随附文件名对应，原生产材料保留。

本轮生产完成、对外稿整理完成、用户批准导出、甲方确认分别记录。无对外需要时不要求生成资产视觉稿或PDF，已有有效批准按其范围接续。业务完成条件不替代生成、打包、发送或维护的实际授权。
