# 场景资料卡规范

<a id="场景资料与参考图规范"></a>

<a id="61-场景资料卡"></a>

本阶段维护场景身份、固定空间、状态和七章资料卡，图片制作与采用交D06；当前取景需求由D08提出。

## 1. 阶段归属与制作顺序

场景原图、机位补图及环境状态图统一执行[项目资产与逐集引用](../../nora-serial-drama/references/逐集目录与资产管理规范.md#项目资产与逐集引用)；候选与已采用图均关联所属SC，逐集只引用具体版本。

所有实际出现的场景统一管理，不区分通用、集内或一次性场景。D04场景资料模块根据故事大纲中已明确、需要独立设计的地点建立基础设计，维护布局、空间连接、陈设及连续性；未明确的未来地点不预建。第六章尚无场次时如实标注待逐集补充，不虚构EP／C编号。

D06场景图片制作按[图片用途与状态归属](../../nora-drama-images/references/场景图片制作规范.md#40-图片用途与状态归属)区分总览／基础图和机位场景参考图。总览素材按当前场景设计需要准备或复用；机位图在场次分镜形成、实际取景需求明确后按[视图规划](../../nora-drama-images/references/场景图片制作规范.md#42-视图规划与复用)准备，不因场景卡确认或场景首次出场就预制全套图片。D04与D06可按不同资产的准备情况并行推进，单个场景先确认必要设计再制图。逐集会话提出需求、选用适用版本并准备视频；交接沿用既有资料与进度，不另建场次会话。

按以下顺序协作：

1. 逐集会话根据本集故事剧本划分场次，明确空间、动作和状态需求；D04检索场景索引、资料卡及已有图片，复用同一地点，新增地点才分配SC编号。
2. D04补齐当前所需的固定空间设计；有总览素材设计需求时，由D06依[图片用途与制作规则](../../nora-drama-images/references/场景图片制作规范.md#40-图片用途与状态归属)准备，已有适用图直接复用。不为未明确的未来地点预制图，也不要求先做齐机位图才能写分镜。
3. 逐集会话形成镜头正文与分段规划后，与D06按[视图规划与复用](../../nora-drama-images/references/场景图片制作规范.md#42-视图规划与复用)完成机位归纳、查缺、必要补图及审核；必要的新可见结构回D04补清。机位方案在资料卡第六章维护，本次镜头选择在场次分镜维护。
4. 视频准备前按[场次采用记录](../../nora-drama-images/references/场景图片制作规范.md#43-场次采用记录与提示词边界)落实镜头、机位、图片及生成组对应关系。首帧另按[首帧规范](../../short-drama-storyboard/references/首帧参考图规范.md#1-制作复用与画面要求)判断；无需环境图片与尚未就绪分别记录。

新场次引入后补齐其资产依据，不能用“尚无通用场景卡”跳过建卡；一次性地点也按本规范管理，但不扩大到剧中仅提及、未实际呈现的全部地点。

### 场景身份与状态

- SC 编号在同一项目从 SC001 连续分配，不按集或场次重启。创建前先查索引及同名／别名，不能仅因名称写法不同另建同一地点。
- 同一地点的多个场次共用一份资料卡。昼夜、天气、装修、陈设或损毁变化记录在原卡，不单纯因状态变化新增 SC。
- 房间内桌边、窗边通常是同一场景的功能区域；需要独立维护布局与连续性的空间才另建资产。场次编号不等于场景编号。
- 后续补充和修订以原卡及已批准图片为依据，保持空间连续性；涉及推翻既有布局或影响已制视频时，先确认影响，再修改及检查下游引用。
- 已有项目保留实际有效资料及历史审批。旧名“通用场景资料卡”或旧路径不自动迁移；获准整理后才更名为本规范文件名并同步引用，不另建第二份权威资料卡。

## 2. 固定目录、命名与版本

所有场景资产集中在项目根目录的 `04-场景资料/`，D04、D06和逐集制作负责人共用这份资产来源，不另存一套本集场景卡或正式场景图。工作稿内部按[工作稿管理规则](../../nora-serial-drama/references/文件版本与工作稿规范.md#工作稿管理规则)存放。

```text
04-场景资料/
├── 场景索引.md
├── SC001-场景名/
│   ├── SC001-场景名-资料卡.md
│   └── 参考图/
│       ├── SC001-EP001-C002-V001-场景参考图.png
└── 其他资料/
    ├── 工作稿/
    │   └── 素材/
    ├── 历史版本/
    └── 执行附件/
```

正式文档：`场景索引.md`、`SC{三位编号}-{场景名}-资料卡.md`。版本、更新日期和确认状态写在文档内；索引只保存身份与入口，不复制正文或进度，使用固定四列：

使用[场景索引模板](../templates/场景索引模板.md)填写固定四列。

图片名称、视图编号及候选版本由[场景图片规则](../../nora-drama-images/references/场景图片制作规范.md#2-图片命名与视图身份)维护。

工作稿、历史版本和执行附件集中在 `04-场景资料/其他资料/`，不在每个场景目录内重复建立。首次产生相应内容前检查规定路径，已有则复用，缺少则按固定名称创建；不预建空分类目录，不另建同义目录。无法归类的新增类型先提出建议，经用户确认补充规范后才创建。

工作稿、图片候选、历史版本及跨对象决定的命名读取[工作稿管理规则](../../nora-serial-drama/references/文件版本与工作稿规范.md#工作稿管理规则)，不另维护一套过程文件公式。

## 3. 场景资料卡固定模板

资料卡头部按[正式内容文档的共用头部](../../nora-serial-drama/references/文件版本与工作稿规范.md#正式内容文档的共用头部)填写；确认状态使用该节规定的简短选项，适用范围、依据、图片审批及过程说明归各自字段和记录。

使用[场景资料卡模板](../templates/场景资料卡模板.md)中的固定正文；本节保留适用范围与填写规则。

### 填写规则

场景描述、连续性约束与修改过程按[描述性正文与修改要求](../../nora-serial-drama/references/文件版本与工作稿规范.md#描述性正文与修改要求)在写入前区分。

1. 场景范围明确，但不机械细分。一个房间的桌边、窗边通常作为功能区域；需要独立维护布局与连续性的空间，再考虑单独建卡。关联场景只记录实际关系，不为填表新增资产。
2. 布局以稳定的物件关系、空间连接和固定观察基准描述，例如“站在入口面向室内”；明确门连接的通道、床所靠墙面及矮几与床头的关系。不要把某镜头的画面左右作为永久布局。编写场景图或首帧提示词时，按[统一方向参照](../../creative-techniques/references/镜头语言参考指南.md#13-统一方向参照)换算为当前画面位置，不直接使用东南西北。空间尺度写到足以支持人物活动与比例一致即可，不强制提供建筑施工级尺寸。
3. 基准与变化分开。第二、三章描述基准空间及环境，第四章记录适用状态及场次依据，第五章记录跨状态约束；逐镜变化与动作进度在场次分镜维护，职责见[第4.0节](../../nora-drama-images/references/场景图片制作规范.md#40-图片用途与状态归属)。损毁、装修等持续变化不能在后续场次无故复原。
4. 不因状态变化新增场景编号。昼夜、天气或损毁状态原则上归入同一场景卡；未确定集号时，以剧情阶段或事件说明适用范围。
5. 第六章的6.1按视图维护一份方案，6.2按实际场次追加需求并注明场次编号，保留已有场次的有效依据，不用新场次需求覆盖旧内容。视图规划与复用执行[第4.2节](../../nora-drama-images/references/场景图片制作规范.md#42-视图规划与复用)，同一视图的机位方案只维护一处，各场次引用视图号。复用入口指向已批准图片；尚无图片如实标注。实际提示词、节点参数、任务编号与生成结果只写入生成记录，不混入资料卡。
6. 缺项填写按[固定结构与补充写法](../../nora-serial-drama/references/文件版本与工作稿规范.md#固定结构与补充写法)执行；没有额外状态时，不强造变化状态。环境与配套细节按[第3.1节](#31-环境与配套细节设计)主动设计，不能把用户未逐项列出等同于不存在。

### 3.1 环境与配套细节设计

制作场景资料卡及场景参考图时，应主动根据场所用途、时代、生活条件、剧情状态和取景范围，设计主体周围的环境、配套用品及使用痕迹。用户未逐项列出普通生活细节时，仍应提出合理的场景设计，并明确其位置、数量尺度、材质与摆放状态；不能只写一个孤立的主物体，再让生成模型自行补全周围环境。

- **环境与空间连接**：室外考虑地面、道路、围合、植被及可见天空、远景，明确它们与主体的连接、距离和遮挡；室内考虑墙地顶、门窗、功能区域及家具靠墙关系。按场所和取景选择适用内容，不要求每张图都有天空、远山或全套陈设。
- **配套用品与生活痕迹**：根据场所实际用途选择工具、容器、储物、家具及装饰，写清摆放或悬挂位置、数量尺度和相互关系；材质、磨损、整洁或杂乱程度应符合时代、生活条件与剧情阶段。贫穷、破旧、干净、杂乱分别描述，不能把“穷”一律画成污脏、把“干净”一律画成空无一物。
- **画面层次与动线**：从完整设计中选择本机位可见的前景、中景和背景，使细节服务于场景身份、空间可信度和主体辨认；保留必要活动空间与通道。近景只呈现可见部分，不为增加细节强塞全景或堆满物件。
- **设计记录与确认**：环境连接及陈设位置写入资料卡第二章，材质、生活痕迹和氛围写入第三章，随剧情变化的内容写入第四章，本次可见范围写入第六章。普通细节随场景设计方案或图片候选整体审阅，不逐件询问；已确认内容按既有连续性约束保留，不因主动补充而改变固定布局、关键物件数量或剧情状态。涉及新增建筑、出入口、重要剧情道具等内容时，另行确认。
