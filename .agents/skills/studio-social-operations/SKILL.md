# Studio 社交媒体运营

与Nora连续短剧、Iris商业视频同级的业务入口。这里只组织运营阶段与接续，具体做法由下表二级阶段维护。先确定所属资料区、项目、作品及当前动作，读取工作区README、项目README和原有状态入口；Iris具体作品还需读取作品README与作品状态。按[工作区全局约定](../../../AGENTS.md#项目规则读取与适用)执行，不因使用运营技能搬动项目资料。

首次接入、跨业务调用或当前对象变化时，读取[运营与制作接续规范](references/运营与制作接续规范.md)，确定作品身份、发布包位置、成片来源及状态归属。已有明确映射直接复用，不默认加载全部阶段。六个阶段沿用现有技能标识，均适用于Nora和Iris，不由名称前缀限定项目归属。

| 当前任务 | 入口 |
| --- | --- |
| 发布意向、平台账号、Chrome profile、后台连接与浏览器清理 | [01 运营启用与账号连接](../nora-operations-setup/SKILL.md) |
| 头像、主页背景设计与采用 | [02 个人页准备](../nora-profile-images/SKILL.md) |
| 项目通用封面、单作品封面、横竖适配与采用 | [03 封面制作](../nora-cover-images/SKILL.md) |
| 最终成片核对、发布包、手动发布交接或获授权定时发布、发布记录 | [04 发布准备与记录](../nora-publication/SKILL.md) |
| 后台数据、账号活跃时段、成片分析和正式运营报告 | [05 作品复盘与管理](../nora-operations-review/SKILL.md) |
| 当前制作或发布准备如何参考既有报告 | [06 后续制作参考与指导](../nora-operations-guidance/SKILL.md) |

会话建立、职责及状态登记按[运营会话与制作接续](references/运营与制作接续规范.md#运营会话与制作接续)。项目结构与README由[运营启用阶段](../nora-operations-setup/references/运营项目README规范.md)维护，已有创作项目沿用原项目入口。

实际操控浏览器前读取[共用浏览器操作](../studio-browser-operations/SKILL.md)，各阶段提供真实账号与授权范围。运营启用、客户交付、分析建议和技能维护均不构成发布、修改已发布作品、额外生成或自动调度的授权。
