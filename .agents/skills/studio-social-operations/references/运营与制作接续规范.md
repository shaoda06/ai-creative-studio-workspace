# 运营与制作接续规范

## 业务范围与对象映射

公共运营负责账号核对、视觉物料、发布、数据采集与复盘的方法。调用业务负责工作区与项目归属、账号与作品的关系、建档、目录、状态入口及执行适配。运营不根据工作区名称选择目录，不要求一种项目或作品编号，也不创建第二个制作项目。

接续时从调用方规则入口和实际运营配置取得当前任务需要的信息：

- 账号配置的所属对象、位置、目标平台和实际账号；配置可以归账号、项目或其他业务对象，多件作品可以引用同一份配置。
- 发布对象代号、内容与采用依据、实际成片和封面的具体版本；业务代号与平台作品ID分别记录。
- 当前状态、发布资料、发布事实、视觉索引与工作稿、执行附件、报告和采集证据的实际入口。
- 媒体保存与读取方式，以及实际可用的生成、登记和网页展示适配。

使用[运营配置模板](../../nora-operations-setup/templates/项目运营配置模板.md)填写必要信息或引用已有同等记录，不另建重复台账。具体位置由调用业务提供，模板不规定目录。账号配置仅维护一份，各作品引用；批准、状态和数据仍归各自原记录。缺少哪项就补齐哪项，不自行选择工作区、猜路径或复制共用素材。

## 接续入口

| 时点 | 读取与落实 |
| --- | --- |
| 首次启用运营或连接实际账号 | [阶段01](../../nora-operations-setup/SKILL.md)核对配置、账号和可访问入口；建档由调用业务负责 |
| 制作脚本、镜头、剪辑、封面或发布材料 | [阶段06](../../nora-operations-guidance/SKILL.md)筛选相关报告，采用与验证目标写原工作稿 |
| 已采用制作素材交接 | 制作业务核对素材版本与顺序；仍待人工剪辑时如实记录 |
| 最终成片交接与准备发布 | [阶段04](../../nora-publication/SKILL.md)核对文件、文案、封面、选项及排期，整理发布材料 |
| 材料就绪且发布方式明确 | 阶段04交接手动发布或执行已授权代发，记录真实状态 |
| 作品发布后 | [阶段05](../../nora-operations-review/SKILL.md)依据后台证据和实际成片复盘 |

制作完成、客户验收、人工成片确认、发布材料就绪与公开发布分别记录，不互相代替。已有授权直接沿用，阶段路由不增加重复审批。

## 项目目录与创建时机

目录、文件命名、README、状态文件和初始化时机由调用业务的建档规则维护。公共技能只说明资料需要表达什么，不规定具体目录或是否预建空目录。已有项目按其规则接续，独立运营任务也使用调用方明确的资料范围，不由运营技能自行选择资料区或创建项目。

发布材料需要准确成片引用、文案、封面版本、发布选项及执行记录；采集需要时间、统计口径、原始证据和报告引用。可沿已有文件记录或使用对应模板，避免同时维护两份账号、状态或发布事实。初始化不填入尚未发生的执行结果。

## 运营会话与制作接续

- 优先复用适合的既有会话；新建会话按用户明确授权，配置账号或建立文件不授权创建会话。
- 接续材料包括业务规则入口、配置、实际发布对象、来源版本、状态及当前待办；不因会话交接启动生成、采集、发布或调度。
- 运营结果写回调用方指定记录。报告中的建议由实际制作阶段筛选采用，不主动发起返工；跨会话依原文件接续。

## 素材、状态与展示

媒体按调用方明确的资源归属和[共用资源版本规则](../../studio-workspace-browser/references/项目资源与版本管理.md)保存；账号级共用资源与作品资源的读取须有实际支持的适配。记录来源对象、资源编号、具体版本及可用文件入口，不以“最新”替代已执行任务的真实输入。

采用、展示、输入绑定和发布留档均引用原版本，不复制到候选、正式、发布或历史目录。不同内容的实际处理结果保留来源关联；独立任务的记录不因字节相同合并。同一任务重试沿用原身份。只有明确需要自包含交付时，才按授权临时装入媒体；保留清单及采用关系，临时包按工具规则清理，用户编辑过的交付文件不当缓存删除。

运营图片按[图片制作与采用](运营图片制作与采用规范.md)处理。生成与处理使用共用工具，业务专用登记方式由调用方提供，不借用不支持的对象类型或伪造作品身份。

资料展示使用[共用浏览服务](../../studio-workspace-browser/SKILL.md)。调用方的适配负责解释业务目录和记录；固定目录适配不代表支持任意目录或跨项目资源。未支持时提供实际文件与记录入口并说明限制，不通过复制媒体或放宽文件访问边界伪装接通。公共网页修改按明确授权处理。
