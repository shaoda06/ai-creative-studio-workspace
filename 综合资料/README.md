# 工作区综合资料

保存总工作区跨业务共用、尚未明确归属或隔离技术验证资料。资料区跨项目与具体项目的归位按[总工作区资料归属](../AGENTS.md#工作区结构)及所属业务规范执行，不统一套用某个业务的阶段目录。

本目录不替代已有正式产出、执行记录、技能资源或历史版本的位置。技术验证按[技术测试与隔离验证](../.agents/skills/studio-entry/维护规范.md#技术测试与隔离验证)，技术中间资料按[临时资料生命周期](../.agents/skills/studio-workspace-browser/references/ComfyUI-任务监控规范.md#临时资料生命周期)。公共模板只跟踪本说明，本机资料继续按Git忽略规则保存。
