# W525：造型说明保留空值展示

日期：2026-11-07
状态：已完成
关联版本：v0.8.253，已发布

## 修改原因

用户要求未明确隐藏的信息即使无内容也显示无。

## 具体改动

造型说明改为左侧固定名称值行，空内容按文档中的无展示；同步规范，不再按缺项词隐藏。来源说明仍按明确约定不显示。服装图输入目前只有工具槽位，尚未补造自动识别规则。

## 验证结果

复用既有信息列表样式，未修改公共组件或组件内部样式。构建、三档桌面造型页验证通过；固定检查断言造型说明显示无。公共组件自动检查0项需修正、0项待人工判断，三档布局检查通过；正式页面已核对显示“造型说明：无”，服务v0.8.253且ready为true。
