# W480：历史任务附件接入项目归档

日期：2026-11-04
状态：已完成
关联版本：v0.8.192

## 修改原因

业务资料完成迁移后，旧目录仍承担历史任务附件的文件读取。移除旧目录前需要切换实际文件入口，保留原任务记录。

## 具体改动

- 在目标资料空间按原空间和任务 ID 登记项目内的历史归档。任务详情从归档读取原相对路径，并返回目标空间文件地址。
- 输出状态和事件继续按原任务记录解释。归档读取复用现行的文件范围和执行档案检查，任务库和队列沿用原流程。

## 验证结果

- 使用隔离的两个项目空间验证源目录移除后，任务详情能从目标归档读取结果和执行附件，原任务记录保持一致。
- 公共组件复用检查：本次改动在任务详情接口和工作区登记，前端沿用原任务详情、预览和下载组件。版本字段随正式发布更新。
