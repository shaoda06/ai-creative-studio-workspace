# W656：执行当前 Songssx 准备校验

日期：2026-11-11
状态：已完成
关联版本：未发布

## 修改原因

Songssx 准备报告可在输入和来源未变时复用。需要让复用报告的待提交任务也经过当前的装配检查。

## 具体改动

重新准备时，先用共用 Songssx 装配校验核对请求，再复用旧报告。待提交任务检查准备报告时，也按当前装配规则检查。镜号、切镜时码和参数校验在 Songssx 技能脚本维护。

## 验证结果

- 101 项离线测试通过。新增用例覆盖镜号、重叠边界、尺寸限制及旧准备报告的复用。用隔离清单核对整场 3600 帧边界。
- 后台回归使用 macOS 物理临时目录 `/private/tmp`，统一测试夹具中的路径写法。测试模拟 ComfyUI 通信。
- 公共组件复用检查：变更范围为后台执行检查、测试及共用技能。差异核对无前端文件，组件复用与浏览器布局检查不涉及本次变更。
