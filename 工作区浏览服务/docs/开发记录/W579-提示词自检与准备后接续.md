# W579：提示词自检与准备后接续

日期：2026-11-08
状态：已完成
关联版本：v0.8.296（已发布）

## 修改原因

准备完成后的提示容易被理解为必须增加用户提示词审阅，混淆Agent自检、执行授权与生成结果审阅。

## 具体改动

公共H3规则统一提示词由Agent编写、自检和留档；已有生成授权覆盖当前方案时直接接续，用户要求只准备时保持准备状态。后台准备成功的下一步改为continue-caller-workflow，由调用方按当前授权和阶段接续，不增加用户提示词审阅，也不自动入队。公共通信规范说明该返回值。项目当前提示按同一口径清理，历史事实不改写。

## 验证结果

公共提交测试56项通过，Chloe隔离制作链路3项通过，覆盖准备不入队、缺授权阻断、已有授权接续及原任务恢复。首次运行因macOS临时目录别名及测试进程缺少FFmpeg失败，使用规范化临时目录和已有FFmpeg路径后相关测试通过。正式构建使用已有Node 24通过（系统默认Node 26执行npm异常）；托管重启后服务v0.8.296且ready=true，实际只准备调用返回continue-caller-workflow，未登记新任务。两项公共技能校验、项目资料及制作轮次校验通过。规则入口、章节链接和旧提示残留检查通过；未提交真实生成。

- 公共组件复用检查：本次仅修改公共规则、后端返回提示及项目资料，没有前端组件、样式或布局改动；无需UI组件及三档视觉回归。
