# W481：Iris 阶段主文件与采用素材展示

日期：2026-11-04
状态：已完成
关联版本：v0.8.193，已用于正式浏览服务

## 修改原因

Iris 已统一项目目录和阶段产出，网页需要将现行文件与已采用版本放在对应栏目，工作稿和历史资料保留查阅入口。

## 具体改动

- 按阶段目录识别主文件，多版本时以项目状态表指向的文件为准。只有一份符合阶段命名的文件时，提供主文件入口。资料来源、工作稿、历史版本和执行记录按需展开。
- 从现行资产清单读取采用记录。预览通过项目文件入口打开精确的资源版本，也支持已迁移旧路径的资源引用。全部项目文件和资源仍可分别浏览。
- 视频制作沿用批次列表与审阅页面，提供生产任务主记录的快捷入口。历史归档与只读批次继续按原记录显示。

## 验证结果

- 29 项隔离接口及资源测试通过，覆盖指定版本优先、旧版排除、采用与待审区分及旧素材地址解析。Iris 页面在 1280×640、1366×768、1920×1080 通过隔离验收，覆盖文档预览、折叠资料、素材预览和批次审阅，审阅意见写入仅在模拟环境检查。
- 公共组件复用检查：Iris 页面复用原文件树、文件与素材预览、图片卡片和视频审阅组件。暂存快照检查通过，三档桌面布局及公共组件展示用例通过。人工检查了业务页面的折叠入口和素材卡片，样式只安排业务容器，公共组件规格沿用现有示例。
