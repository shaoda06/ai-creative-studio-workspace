# W641：Chloe造型面部三视图接入

日期：2026-11-09
状态：已完成
关联版本：v0.8.349（已发布）

## 修改原因

造型面部图和全身定装图需要呈现同套穿搭的最终妆发，并在造型详情独立展示。角色视频参考需要核对两张图的准确版本和配套关系。

## 具体改动

- 造型流程先用基础正面图和定妆参考制作面部三视图，再用正式面部图、基础全身图和同套参考制作全身定装原图。两张候选获批后各自做2倍超分并按尺寸登记。遮面图从正式全身原图制作，用户确认遮面范围后登记。视频角色输入用同套正式面部图与配套的正式遮面图。
- 同步造型模板、图种校验、镜头参考与制作入口。会话职责移除基础模特遮面，将造型面部、全身和遮面纳入服装与造型。
- 造型详情右列上方独立展示16:9面部三视图及同类其他版本，下方保留全身原图与遮面切换。复用现有媒体卡、全屏看图与折叠记录。
