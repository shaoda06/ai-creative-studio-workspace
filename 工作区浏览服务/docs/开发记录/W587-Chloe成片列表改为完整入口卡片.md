# W587：Chloe成片列表改为完整入口卡片

日期：2026-11-08
状态：已完成
关联版本：v0.8.302（已发布）

## 修改原因

成片与发布列表使用紧凑选集按钮，状态与文件数量散在按钮外，点击区域和信息范围不一致。改为完整的作品入口卡片。

## 具体改动

成片列表改为直接复用EntryCard；编号与名称为标题，状态和成片目录数量为说明，整张卡片带箭头并进入当前项目的发布详情。容器改为双列，仅调整容器列数，不覆盖公共卡片样式。保留空列表和读取失败重试。

## 验证结果

已有成片发布页隔离测试在1280×640、1366×768、1920×1080通过；补充卡片标题、状态数量、两列排列、准确作品链接及Enter进入详情的断言，原复制、下载、预览和切换检查通过。已查看真实资料的本地预览截图。

公共组件复用检查：人工确认直接使用EntryCard，未复制卡片、覆盖组件样式或改变其他使用处；实现说明已补充使用位置。暂存静态检查无违规，公共组件三档桌面检查通过。正式构建、托管重启和/API服务核对完成：版本0.8.302，ready=true；真实页面的整卡手形光标、双列布局和具名项目内跳转验证通过。
