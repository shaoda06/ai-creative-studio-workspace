# W511：分镜时码与资料来源提示

日期：2026-11-07
状态：已实现，待发布
关联版本：未发布

## 修改原因

Iris 分段制作中的常驻时码说明在分镜脚本和修改意见中重复，正常的资料来源也占用一行。

## 具体改动

计划和执行时码说明随分镜跳转按钮悬停显示。常规资料省略来源行，保留实际缺失、回退和沿用其他版本的提示。

## 验证结果

Iris 制作工作台与生产记录共 33 项后端测试通过。隔离浏览器在 1280×640、1366×768 和 1920×1080 验证分镜脚本与修改意见中的时码提示、镜头跳转、普通提示词隐藏来源行，以及沿用记录仍显示来源。

- 公共组件复用检查：两个标签沿用同一镜头导航，直接使用 PointerTooltip 的悬停与键盘聚焦行为。无新增容器、样式或交互，既有公共展示规格适用。
