# W514：人物特征表格固定列宽

日期：2026-11-07
状态：已完成
关联版本：v0.8.241

## 修改原因

人物特征表格随内容自动分列，空白资料下左列过宽。要求左40%、右60%。

## 具体改动

公共Rich增加可选fieldTable两列字段表规格，固定列宽并允许连续长文字换行。Chloe只在人物特征章节启用，其他表格默认排版不变。公共展示页、组件覆盖说明和布局检查同步；不改资料或模板。

## 验证结果

正式构建及1280×640、1366×768、1920×1080三个桌面尺寸模特页检查通过，实测表格左列比例为40%（容许边框像素误差），原导航与预览正常。公共布局检查增加字段表格比例和连续长文字换行用例，静态和三档布局检查均通过。

人工复用检查：通过公共组件显式规格实现，无页面后代样式覆盖，未增加新组件。

统一启动器重启8782后v0.8.241、ready=true。正式模特信息页已核对左40%、右60%的实际表格效果，原四个子标签保持。
