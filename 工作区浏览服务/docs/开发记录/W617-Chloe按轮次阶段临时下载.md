# W617：Chloe按轮次阶段临时下载

日期：2026-11-08
状态：已完成
关联版本：v0.8.330（已发布）

## 修改原因

资源下载受正式采用及交接清单限制，一采、二采已有视频仍不能下载，且未跟随当前轮次。

## 具体改动

按当前轮次和阶段读取原视频，点击时生成临时视频ZIP或剪映草稿包，发送完成或中断后清理；不复制源媒体、不写采用和交接记录。其他工作区保留原接入方式。

## 验证结果

- Chloe制作、历史交接与新增轮次下载共27项检查通过；原公共视频下载、剪映与Iris工作台56项检查通过。覆盖三阶段、未采用候选、准确轮次、原字节及时间线顺序、缺失/空轮次、正常响应/中断/打包失败清理；源媒体与资料快照未变化。
- Chloe及Iris三档桌面UI通过，验证轮次切换、阶段按钮可用性、下载失败重试及两种下载接收；不写真实业务数据。
- 公共组件复用人工核对：沿用SceneDownloads、DownloadButton、TabSelect与公共消息；只通过ProductionAccess可选能力启用轮次范围，不添加布局或覆盖CSS。默认接入不启用该能力。静态检查0项需修正、0项待人工判断，公共组件三档浏览器检查通过。检查中发现默认缓存键受到新轮次参数影响，已改为仅启用轮次能力时追加参数，其他工作区保留原缓存键。

- 正式构建和托管重启完成，service与release均为v0.8.330、ready=true。实页第2轮一采、第3轮二采、第4轮后处理均显示2段及可用ZIP/剪映按钮；其他阶段没有本轮视频时禁用，不跨轮串包。
