# W462：复用视频冻结PNG并合并历史输入副本

日期：2026-11-02
状态：已完成
关联版本：v0.8.173（已发布）

## 修改原因

视频任务默认将相同参考PNG复制到各自输入目录，长期迭代累积大量相同文件。用户授权先调整后续保存，再整理任务输入副本；正式资产、候选图和项目历史快照不在本批清理范围。

## 具体改动

`nora-drama-production/scripts/generation_context.py`在POST前保存时，按大小及完整字节比较同项目执行附件中的冻结PNG。相同则直接记录已有文件路径，不另复制；不同则保存新版本。已有任务的关联及本任务已有副本优先保持，避免重试改变输入路径。每个任务的身份、提示词、分镜、槽位、实际原始来源和批准继续独立记录；显式整套资料复用及音视频留存沿原接口。保存或复用的任务输入PNG去除写权限，不关联可修改的正式或候选图片，不跨项目共享。

历史整理仅处理五个Nora项目的任务输入：153组、1,230个路径，将1,077份重复磁盘文件替换为同项目冻结输入的硬链接，所有原路径保留。按唯一inode计算，分配占用减少4,350,693,376字节；输入映射、请求、采用和导演包重建清单不改写。详细路径、原文件元数据、项目统计及结果保存在本地`综合资料/工作区占用审计-20261102/任务输入PNG合并记录.json`，不加入公共仓库。

## 验证结果

输入留存和导演包隔离测试67项通过，覆盖新轮自动复用、同大小不同内容、同内容不同文件名、槽位与原来源保留、正式图更新、重试关联稳定、项目隔离及原导演包下载行为。测试使用临时项目，没有提交真实视频生成。

历史合并前逐文件比对原审计校验值及完整字节。合并后发现一组四个路径与原审计值存在单字节差异，原因未确定；已从独立保留且校验值与原审计一致的候选原图恢复该组。随后全部1,230个路径重新逐文件校验通过，确认内容符合原审计、同组共享inode且无写权限；603份输入映射及导演包清单的原始字节保持不变。未将修复来源与任务输入硬链接。

真实原生导演包导出使用同一项目的现存重建资料，在内存验证副本中将两项同字节素材指向合并后的冻结输入；原生导出及包内媒体完整字节核对通过，包大小4,175,993字节，临时验证包已清除，未改写项目清单、未调用视频生成。

补充提交流程测试33项中28项通过，5项失败；使用修改前的原保存模块复跑，五个同名用例仍失败，涉及退役脚本路径、macOS临时目录规范路径及旧分镜路径。本次未改动这些既有问题，不宣称整套提交流程测试通过。

- 公共组件复用检查：本次只修改业务保存模块、测试、规则和版本元信息，没有前端组件、样式、交互或解析字段变化；现有页面按同一`references.file`读取项目内路径，无需界面适配。

正式前端构建通过，发布前确认Nora与Iris无进行中或待提交任务，使用统一托管启动器重启。`/api/service`确认v0.8.173、ready=true、正确工具及资料目录。五个项目各抽取一个合并后的旧输入路径，经真实HTTP读取均为200且字节校验符合原审计；真实HTTP导演包下载4,175,993字节，ZIP完整性通过，响应后临时导演包目录为零。审计HTML已标明两批清理结果及旧统计的快照性质。未推送。
