# W681：Songssx自动装配可编辑参考视频

日期：2026-11-14
状态：已完成
关联版本：v0.8.408（已发布）

## 修改原因

导演台可通过视频参考重绘画面并锁定原声。标准装配和后台复核只允许局部返修使用视频轨，普通场次无法通过统一任务入口提交视频参考。

## 具体改动

标准场次清单接入可编辑参考视频、源截取区间、时间线选区和视频原声。装配及后台复核按每个 GEN 的实际采样窗口核对素材与提示词标签。仅用视频参考的 GEN 可省略图片。沿用现有上传和整场 MP4 取回，制作页从实际请求及上传映射读取当前 GEN 绑定。使用方法见 [Songssx 可编辑参考视频](../../../.agents/skills/studio-h3-songssx/references/ComfyUI-Songssx导演台使用规范.md#可编辑参考视频)。

## 验证结果

- 9 项 Songssx 后台测试、5 项通用视频测试、4 项 Chloe 视频链路测试和 8 项装配与返修脚本测试通过。隔离验证覆盖共享资料任务登记、素材探测、上传路径回填和复用、视频轨与 GEN 交集、提示词标签、原声开关、旧任务及双边界返修。
- 使用已成功生成任务的配置重新准备，归一化远端素材路径和轨道片段 ID 后，逐节点比较与原 API 请求一致。新入口的远端提交使用隔离验证，未重复提交原任务。
- 两个受影响的技能入口通过校验。公共组件复用检查限于本次差异，制作页沿用公共参考素材组件已有的视频预览和下载行为，未修改前端组件或样式。
