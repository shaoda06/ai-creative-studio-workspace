# W527：模特子标签间距与返回入口对齐

日期：2026-11-07
状态：已完成
关联版本：v0.8.255，已发布

## 修改原因

用户要求返回造型列表与子标签同排靠右，子标签离上方路径导航更远、下方内容更近。

## 具体改动

使用页面导航外框同排排列UnderlineTabs与返回链接，移除内容区独立返回行；外层增加28px上间距，内容沿用面板16px上间距，保留内容区和制作记录原排列。仅调整容器，不修改公共标签样式。

## 验证结果

前端构建与三档桌面模特／造型UI检查通过，验证返回入口同排居中靠右、标签上方间距大于下方及原有内容操作。公共组件复用人工核对：只新增页面布局容器，UnderlineTabs内部样式及公共页面保持原样；自动检查0项需修正、0项待人工判断，三档公共组件布局检查通过。实际页面核对模特信息间距和造型返回链接同排靠右通过；服务v0.8.255且ready为true。
