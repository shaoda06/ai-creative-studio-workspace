# W471：全量规则审计整改与旧转接页退役

日期：2026-11-03
状态：已完成
关联版本：不涉及服务发布（现行规则、模板及离线业务CLI整改）

## 修改原因

全量规则审计确认12组职责、路由、重复维护及旧入口问题，另有3组优化建议。按用户授权逐项纠偏，保留既有业务决定、项目例外、实际执行和批准历史。

## 具体改动

- 纠正总入口被当执行器、Nora依赖职责表、共用通知对Nora业务的默认绑定。
- 桌面支持规则、审查分级和Iris交付顺序各归唯一维护者；Nora图片模板维护归D06，共用动作方法只维护专业方法和通用阅读边界。
- 两项目人物封面引用直达D06，50份旧转接页移到技能历史归档；保留仍有实际职责的一级业务状态/工作稿模板。
- 修复当前项目目录说明、章节与重复导航，统一安装布局和托管平台说明；小序和禾禾README保留方案分离约定，动态状态仍归原项目进度。
- 模板的技术参数改为按能力与已有档案填写；内置Imagegen离线准备CLI的新条目省略其没有的远端参数/ID字段，原提示词、输入、授权、五节结构和结果/采用登记保留。Qwen种子读取与旧记录不变。
- PDF通用水印数值只在工具布局资源维护，Iris保留品牌配置。W470已提交后定向核对台词建议的业务真源、模板及界面接入，不重复运行未改的UI功能。
- 完整迁移清单的在用链接改为当前位置；迁移前已退役来源改为文字标签，保留来源事实，不再提供失效跳转。

本次没有修改被正式后台导入的服务实现或前端代码；Imagegen业务CLI在每次命令中读取，故无需构建前端、递增服务版本或重启后台。
