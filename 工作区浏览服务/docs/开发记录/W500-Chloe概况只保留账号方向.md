# W500：Chloe概况只保留账号方向

日期：2026-11-07
状态：已完成
关联版本：v0.8.228，已发布

## 修改原因

账号概况包含过多运营配置、统计和策略字段，增加了不必要的填写与核实。用户要求只保留必要账号方向，发布平台允许扩充；品类和收益随商品变化，不在账号层重复维护。

## 具体改动

账号定位的账号方向仅保留发布平台、目标人群、内容风格。发布平台可填写多个，人群和风格使用自由描述；待确定值不阻塞无关制作，不默认逐项追问。品类和实际收益条件随商品、选品维护。

正式页与示例页直接读取账号方向章节，沿用同名标题与原始字段；删除运营接入、统计、待办及人物声音策略展示。同步模板、初始化、校验、业务技能与工作区说明，取消账号运营配置默认文件。实际旧定位与占位配置保存在综合资料中带20261107-135633时间戳的归档文件；技能原文按所属历史版本目录留存，归档不参与现行解析。

视频资料、成片、发布及复盘继续按所属资料维护；运营复盘以用户提供的资料为依据，不默认自行采集后台。共用资源存储与具体版本引用保持原规则。
