# W619：资源库图片视频标题

日期：2026-11-08
状态：已完成
关联版本：v0.8.331（已发布）

## 修改原因

图片和视频资源卡标题仍为机器文件名，需要从已有业务资料显示可读名称。本次只调整标题。

## 具体改动

共用图片按已有资产说明中的参考版本显示“资产名称 · 用途”，商品图片读取原始素材。作品专用图片读取该版本生成记录的用途，未提供时保留原文件名称信息。视频按制作记录中的执行编号及输出槽位，精确对应分段、阶段和输出版本，显示“作品名称 · 分段 · 制作阶段”。复用原display_name字段和卡片标题位置，不改原文件、详情、其他卡片信息及其他工作区。

## 验证结果

- 后端10项检查通过，包含图片资产用途、专用图片生成用途、同一视频不同版本一采与后处理区分、只读和原文件名保留。
- 资源库三档桌面检查通过，核对图片／视频／音频标题、筛选、详情、预览和下载；真实资料只读核对确认图片与视频均取得可读业务标题。
- 公共组件复用人工检查：仅传入AssetMediaCard已有title属性和原h3标题，未新增或覆盖公共组件、样式及交互，三档业务检查通过。暂存静态检查0项需修正、0项待人工判断，公共组件三档桌面检查通过。
- 正式构建通过，统一启动器重启后服务ready=true、前后端版本均为v0.8.331。实际页面图片业务标题和历史视频一采／二采／后处理标题正确，无页面异常。
