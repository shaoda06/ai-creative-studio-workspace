# W621：资源库标题搜索

日期：2026-11-08
状态：已完成
关联版本：v0.8.332（已发布）

## 修改原因

资源卡已显示可读业务标题，搜索仍只匹配文件名、登记名称和资源编号，用户按看到的标题无法找到素材。

## 具体改动

图片、视频和音频统一将现有display_name加入搜索，保留原搜索字段及分类、归属筛选。搜索框提示改为“搜索标题、文件名或资源编号”。不新建索引或记录。

## 验证结果

- 后端11项检查通过，覆盖三种媒体完整标题、用途关键词、原文件名大小写、准确资源编号与版本、分类／归属组合及分页、只读。
- 三档资源库桌面UI检查通过，搜索图片／视频／音频可读标题均得到预期卡片，保留原文件名搜索、筛选、详情及下载。
- 公共组件复用人工检查：只修改原SearchField提示文字及只读接口匹配字段，未新增样式、组件或交互；三档业务检查通过，暂存静态检查0项需修正、0项待人工判断，公共组件三档桌面检查通过。
- 随协调版本构建发布后，正式服务ready=true、前后端版本均为v0.8.332；实际页面三类标题、原音频文件名及准确编号搜索均返回预期资源，无页面异常。
