# W507：Iris 视频制作轮次入口

日期：2026-11-07
状态：待发布
关联版本：v0.8.235，待发布至本地浏览服务

## 修改原因

F001 视频制作页的「查看生产任务」实际打开各轮历史。页头同时保留了重复的制作脚本入口，历史轮次需要能从记录定位各自的脚本。

## 具体改动

作品可以单独登记「轮次记录」。制作页复用既有文档预览打开索引，隐藏重复的制作脚本按钮，并按轮号列出与现行稿不同的脚本链接。原有独立生产任务继续作为生产计划入口。

## 验证结果

Iris 制作工作台 22 项后端测试、TypeScript 构建检查及 1280、1366、1920 三档桌面的隔离页面测试通过。历史脚本链接可打开当轮原文，未登记轮次记录的作品仍可打开原生产任务。

- 公共组件复用检查：暂存源码静态检查 0 项需修正、0 项待人工判断。制作工作台仅变更入口的条件和文案，沿用 PreviewContext、既有文档弹窗和链接样式。未修改公共组件规格、样式或展示示例。
