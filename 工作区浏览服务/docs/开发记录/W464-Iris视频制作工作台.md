# W464：Iris视频制作工作台

日期：2026-11-03
状态：已完成
关联版本：v0.8.175、v0.8.176、v0.8.177（已发布，最终验收v0.8.177）

## 修改原因

W463只增加了目录分页，用户进一步明确需要Nora剧集制作页的实际视频审阅能力。Iris应按真实商业批次与分段复用播放器、版本选择、参考、生成文字及修改意见，不创建短剧EP目录。

## 具体改动

Iris生产阶段增加只读业务投影，以已提交装配记录和实际请求读取批次、分段、候选及来源；H3实际请求的镜头与槽位解释归共用工具，网页使用ProjectProduction组织既有播放器、参考、候选切换、普通/宽屏和修改意见组件。不要求建立EP目录；原文件保留制作资料入口。历史Nora归档只读复用原解析与上下文，不重开已交付项目。

公共服务显式登记production_adapter，提供所属空间的生产资料、上下文和意见接口；意见字段与原Nora共用，抽取字段后Nora保留原保存路径和规则。意见按分段、阶段和R版本放在项目一份JSON内，复用原同源限制、文件边界、原子写入及文字冲突处理。未关联分镜快照不以当前稿补造；未读取正式采用时显示业务记录待核对，不推定采用。
