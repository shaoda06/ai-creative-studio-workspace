# W461：任务侧栏全局汇总与跨资料区详情

日期：2026-11-02
状态：已完成
关联版本：v0.8.172（已发布）

## 修改原因

Iris页面的任务侧栏只读取Iris记录，同一远端队列中的Nora任务因此被误判为外部提交，无法打开详情。任务监控应属于统一工作区，浏览资料区不应限制可见任务。

## 具体改动

全局监控汇总登记空间的任务与历史，共用远端节点按地址去重。任务保留实际归属，详情、操作和队列排序使用所属空间接口；资料导航与节点配置不充当任务筛选条件，不移动或合并原任务库。

## 验证结果

修改前实际只读复现：Nora存在1条登记任务，Iris读取同一远端队列的1条任务时未匹配任何登记记录。Browser plugin not available，使用现有Playwright隔离流程。63项后端隔离检查通过，涵盖全局汇总、同节点去重、历史搜索分页、同ID不同空间与正确资源链接，以及原队列/详情/配置权限。真实组件在1280×640、1366×768、1920×1080内容区各验证Iris/Nora两种页面归属，6组全局任务与详情检查通过；未知远端提交仍按真实未登记来源显示。Iris页面操作Nora任务的3档隔离队列回归通过，每档15次模拟操作含暂停、恢复、转移、排序及失败恢复；所有写请求均断言为Nora所属接口。原滚轮隔离、任务组详情、资料区导航检查通过。已查看截图，未见溢出或控制台错误。

- 公共组件复用检查：沿用TaskCard、LocalQueueCard、TaskDetailDialog、TabSelect、UnderlineTabs及公共消息；无新增CSS或手写通用控件。真实展示示例补充资料区来源标签，覆盖表同步全局监控和详情/操作归属。最终暂存差异已人工核对，提交钩子的静态检查及三档桌面布局检查全部通过。
