## 修改原因

套装选材需要更大的图片预览，三个装配页需要在生成前预留导出文字空间。套装和视频的素材条目可用对象编号和标题交接。

## 具体改动

- 套装选材每行三张卡，图片按原比例铺满可用宽度。加号卡按常见的 4:3 服装图卡片预留尺寸。
- 套装和视频下方的双栏各占一半，栏间距统一为 32 CSS 像素。三页的导出文字框统一为 520 CSS 像素，长内容在框内滚动。
- 套装和视频的素材条目列出对象编号及标题。交接词指明应查找的正式采用图或已登记播放版本。
- v0.8.400 将造型装配也统一为对象编号和标题，由 Agent 据此查找正式采用的参考图。
