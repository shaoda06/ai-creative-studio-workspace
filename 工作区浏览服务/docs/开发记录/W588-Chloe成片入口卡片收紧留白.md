# W588：Chloe成片入口卡片收紧留白

日期：2026-11-08
状态：已完成
关联版本：v0.8.303（已发布）

## 修改原因

成片列表入口卡片上下留白及两行间距偏大，需要降低整体高度。

## 具体改动

公共EntryCard新增可选compact规格，Chloe成片列表启用。上下内边距18px，标题及说明移除额外外边距，两行间距6px；左右内边距和默认卡片不变。展示页和实现说明同步。

## 验证结果

成片页隔离测试及公共展示在1280×640、1366×768、1920×1080通过，核对紧凑规格18px内边距、6px行间距和默认卡片23px内边距。初测发现全局padding覆盖紧凑规则，已提升组件变体选择器优先级，复测通过。布局检查器自检通过，构建通过。

公共组件复用检查：静态检查无违规；样式仅在EntryCard内部声明compact规格，没有页面后代覆盖，展示页直接调用同一组件。正式服务0.8.303、ready=true，真实卡片高度约97px，标题与说明间距6px；截图与作品跳转已核对。
