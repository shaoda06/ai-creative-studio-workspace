# W695：Chloe姿态装配

日期：2026-11-16
状态：已完成
关联版本：v0.8.423、v0.8.424、v0.8.425、v0.8.426（均已发布）

## 修改原因

Chloe 的姿态资料需要用与套装装配一致的操作来选取和组合，姿态卡每行显示五张。

## 具体改动

在共用资产的装配区增加「姿态装配」，位于造型装配和视频装配之间。与套装装配共用选材区、带移除按钮的卡片、原图预览和双栏导出区。已选区和选择弹窗每行五张，已选数量独立于列数。

选择弹窗使用姿态参考表中已收录的图文。支持分类筛选、分页和跨页多选，确认时按编号复核。导出列出所选编号、名称和定姿原文，顺序与已选清单一致。

## 验证结果

TypeScript 和三档桌面 Chloe 浏览器回归通过。隔离测试覆盖弹窗和已选区的第六张换行、筛选后保留暂选、跨页确认、按顺序导出原文、放大预览、移除及旧导出失效。

8782 正式服务 v0.8.423 已就绪。通过局域网确认弹窗与已选区均为五列，选择两条正式收录姿态后按顺序生成定姿文字，移除一条后选中数量更新并清空旧导出。

- 公共组件复用检查：暂存静态检查通过。人工核对 AssetSelectionDialog、AssetMediaCard、FullscreenImage、Pagination 和 CopyButton 的调用，展示页已登记新增使用位置。五列间距由装配网格负责。

## 六列与视频动作策划交接

已选区和选择弹窗改为每行六张。导出按选择顺序每行输出一组姿态编号和标题。接手的 Agent 按 Chloe 创意技能查用共用姿态参考表，结合镜头设计姿态与动作衔接。

TypeScript、暂存静态检查、三档桌面 Chloe 回归通过。人工核对沿用选择、预览和复制组件，布局与导出内容由装配页管理，Chloe 创意技能引用的参考表路径有效。8782 发布 v0.8.424 后，用七条已收录站姿确认选卡弹窗和已选区的第七张换行，并逐行比对导出的编号和标题。

## 随机选择与排序

在姿态选择标题右侧增加分类、数量、随机选择和随机排序。分类默认全部。随机选择从整个可用分类中抽取，数量为非负整数，超出可用数量时取全部，填零清空。排序重排已选卡片。两项操作都更新导出信息并清空旧导出，生成时按当前卡片顺序列出编号和标题。

TypeScript、3 项资产接口测试及三档桌面 Chloe 回归通过。隔离浏览器覆盖默认分类、非法数量、完整分类抽取、超量取全部、清空、重排和导出顺序。公共组件复用检查通过暂存静态规则，人工核对下拉调用 TabSelect，错误反馈调用公共消息，标题右侧的布局由装配页负责。

8782 发布 v0.8.425 后，正式页确认控件与标题同行靠右。抽取数量超过站姿库存时实际选中十条站姿，重排后导出逐行匹配卡片，填零后清空选区。

## 拖拽调整已选顺序

选中多张姿态后，可把卡片拖到另一张卡片的位置。落点有边框提示，放下后更新已选卡片和导出信息，清空旧导出，重新生成按新顺序列编号和标题。

TypeScript、暂存静态规则和三档桌面 Chloe 回归通过。隔离浏览器从图片实际拖拽跨行，核对新顺序、旧导出失效及重新生成的正文，并验证图片仍可点击预览。公共组件复用人工核对拖放事件位于装配页卡片容器，图片卡片、预览和复制继续调用公共组件。

8782 发布 v0.8.426 后，正式页随机选出三张，实际把第一张拖到第三张的位置，逐行核对导出与调整后的卡片顺序一致。
