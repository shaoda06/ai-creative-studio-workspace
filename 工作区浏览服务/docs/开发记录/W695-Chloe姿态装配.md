# W695：Chloe姿态装配

日期：2026-11-16
状态：已完成
关联版本：v0.8.423（已发布）

## 修改原因

Chloe 的姿态资料需要用与套装装配一致的操作来选取和组合，姿态卡每行显示五张。

## 具体改动

在共用资产的装配区增加「姿态装配」，位于造型装配和视频装配之间。与套装装配共用选材区、带移除按钮的卡片、原图预览和双栏导出区。已选区和选择弹窗每行五张，已选数量独立于列数。

选择弹窗使用姿态参考表中已收录的图文。支持分类筛选、分页和跨页多选，确认时按编号复核。导出列出所选编号、名称和定姿原文，顺序与已选清单一致。

## 验证结果

TypeScript 和三档桌面 Chloe 浏览器回归通过。隔离测试覆盖弹窗和已选区的第六张换行、筛选后保留暂选、跨页确认、按顺序导出原文、放大预览、移除及旧导出失效。

8782 正式服务 v0.8.423 已就绪。通过局域网确认弹窗与已选区均为五列，选择两条正式收录姿态后按顺序生成定姿文字，移除一条后选中数量更新并清空旧导出。

- 公共组件复用检查：暂存静态检查通过。人工核对 AssetSelectionDialog、AssetMediaCard、FullscreenImage、Pagination 和 CopyButton 的调用，展示页已登记新增使用位置。五列间距由装配网格负责。
