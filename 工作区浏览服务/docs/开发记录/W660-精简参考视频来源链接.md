# W660：精简参考视频来源链接

日期：2026-11-12
状态：已完成
关联版本：v0.8.385（已发布）

## 修改原因

参考视频详情的来源链接同时显示平台名和作品网址。长网址在信息栏内换行，平台名足以标识来源。

## 具体改动

有网址的来源使用平台名作为链接文字。用户提供等纯文本来源继续显示登记文字。

## 验证结果

- 参考视频后端回归 3 项通过，TypeScript 检查通过。
- 公共组件复用检查覆盖参考视频详情的来源行。沿用原有链接和信息栏结构，仅调整链接文字。没有新增组件、交互或样式覆盖，公共组件展示页无受影响的示例。隔离浏览页在 1280×640、1366×768、1920×1080 核对平台名链接、原网址及纯文本来源。
- 暂存快照公共组件检查和三档布局检查通过。正式构建完成，服务 v0.8.385 就绪，核对两条实际参考视频详情只显示平台名，链接地址与登记值一致。
