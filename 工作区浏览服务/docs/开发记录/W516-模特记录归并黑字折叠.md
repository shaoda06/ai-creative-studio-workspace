# W516：模特记录归并黑字折叠

日期：2026-11-07
状态：已完成
关联版本：v0.8.243，已发布

## 修改原因

模特记录分成四块绿色标题白框，用户要求沿用黑字折叠样式，以一个大折叠容纳四个小折叠。

## 具体改动

外层“资料与制作记录”，内层依次为关联资料、采用依据与时间、采用变更、执行记录；默认全部收起。去掉Chloe页绿色summary样式，使用已有全局details/summary规则。资料内容、媒体与其他模块不变。

## 验证结果

模特页面交互测试和前端构建通过；验证了外层唯一、四个内层顺序、默认收起、键盘展开及标题沿用正文颜色。公共组件人工检查：直接复用已有原生折叠与全局样式，仅调整业务DOM层级、删除页面覆盖，不新增公共组件或样式。

提交检查采用暂存区同版本脚本，公共组件静态检查及1280×640、1366×768、1920×1080布局检查通过；工作树中另一个会话的下载测试修改未混入。正式前端由暂存快照构建，统一启动器重启后/api/service返回v0.8.243、ready=true。正式M001页面已核对：外层默认收起，展开后四个黑字小折叠均收起，人物特征与其他导航保留。
