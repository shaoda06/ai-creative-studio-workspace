# W638：简化Chloe模特图片页

日期：2026-11-09
状态：已完成
关联版本：v0.8.346（已发布）

## 修改原因

基础模特只制作正面面部图和基础全身三视图原图。模特页将基础全身图移入原右列，并收窄模特说明的现行图种。

## 具体改动

模特图片页左列保留正面面部图，右列显示方形基础全身原图，两列继续对齐标题、图片和版本折叠。退役基础面部三视图和基础遮面的图种校验、页面入口及旧模特图片子标签。造型详情的定装原图和遮面版仍按造型用途切换。

现行模特说明的参考版本和当前采用只收录两种基础图。一次性移出已有说明中的退役图种条目，保留原稿、媒体与制作记录。

## 验证结果

图种规则、两项技能校验、前端类型检查和 11 项模特读取与图片登记测试通过。现行项目 8 份固定资料通过校验。扩展测试中，Windows 下另有一个剪映交接用例因原始 CRLF 文本匹配失败，该用例不涉及模特图片。

正式前端通过 pnpm 构建并由统一启动器托管重启。8782 返回 v0.8.346 且就绪。在 1366×768 的正式页面核对左右位置、两种基础图数据、全身图全屏解码与退出，以及造型原图和遮面版切换，浏览器无页面错误。

- 公共组件复用检查：暂存静态检查零项需修正。1280×640、1366×768、1920×1080 的公共组件浏览器检查及 Chloe 业务页隔离检查均通过。业务页验证两列对齐、方形预览、全屏、其他版本、空状态和造型遮面切换。人工核对继续使用 AssetMediaCard、UnderlineTabs 和 FullscreenImage，CSS 只清理业务布局的通栏规则。
