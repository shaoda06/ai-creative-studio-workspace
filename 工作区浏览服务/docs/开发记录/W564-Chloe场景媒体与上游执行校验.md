# W564：Chloe场景媒体与上游执行校验

日期：2026-11-08
状态：已完成
关联版本：未发布（业务校验修复）

## 修改原因

场景文档可误引用非图片资源，或填写不存在的上游执行编号，导致文档检查与页面读取结果不一致、处理来源无法追溯。

## 具体改动

场景说明的参考版本和当前采用仅接受PNG、JPEG、WebP图片，与页面支持类型一致；填写实际上游执行编号时，要求该编号存在于同一说明的执行记录中。无上游仍按既有缺项规则处理。

两项检查仅作用于场景说明，不调整其他资产类型的校验。文档字段及模板结构未变。测试使用临时工作区和既有静态媒体样本。

## 验证结果

- 场景与服装读取测试10项通过，包含音频／视频在场景参考、展示及当前采用中的拒绝检查，以及有效／缺失上游执行的文档与页面读取检查。
- Chloe固定资料和图片用途测试15项通过。
- 现有场景说明只读检查通过，无错误；未修改真实资产或执行记录。
- 公共组件复用检查：最终差异只涉及业务校验脚本、测试及本记录，无UI代码、布局或样式变更；不适用前端暂存自动检查和浏览器布局测试。
- 本次不构建或重启浏览服务。
