# W475：隔离验收副本与核验下载清理

日期：2026-11-04
状态：已完成
关联版本：不涉及服务发布（资料整理与工具用法维护）

## 修改原因

隔离验收留存了可从 Git 恢复的工具树和已完成核验的下载副本。用户要求清理指定的三处测试资料并保留原记录、独有素材和仍可使用的样稿。

## 具体改动

移除一份逐字节核对的历史 Krea2 工具树及可重建字节码，原实施记录补充指定提交和恢复方式。后处理样稿保留现有媒体清单和网页文件，清理可重建的构建缓存。两份 Mac 兼容验证 ZIP 在逐包复原核对后清除，原核验日志、三份原始草稿 JSON 和包内媒体固定版本引用按包保留。保留独有客户端对照样本及迁移证据。

共用存储规则明确使用现行工具或从 Git 提取实际依赖的历史路径。仅用于核验的下载、解压、校验沿用媒体准备命令的临时目录，使用空留存清单回收临时包。短剧下载收尾规则直接引用同一入口。

## 验证结果

15793 个工具文件与指定 Git 提交逐字节一致。实际样稿重复准备保持原媒体 inode、大小、修改时间及磁盘占用，样稿和媒体范围读取共 7 项通过。28 段原包媒体与固定版本一致，复原的两份 ZIP 与原包逐字节一致，已按留下的清单再次读取全部成员。

本地 HTTP 核验覆盖下载后校验成功和失败，两个临时目录均已回收。媒体准备与剪映下载专项 33 项通过，两项受影响技能格式验证通过。工作区约从 23.29 GB 降至 22.93 GB，详细资料和恢复清单保存在本机测试和审计目录。
