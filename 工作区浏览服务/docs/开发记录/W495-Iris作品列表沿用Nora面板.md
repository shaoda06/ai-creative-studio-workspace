# W495：Iris作品列表沿用Nora面板

日期：2026-11-07
状态：已完成
关联版本：v0.8.220（已发布）、v0.8.221（已发布）

## 修改原因

正式页核对发现 Iris 与 Nora 已共用制作条目和双列布局，但 Iris 的作品列表缺少 Nora 使用的白色内容面板。

## 具体改动

Iris 的视频制作列表沿用公共面板，面板内显示作品列表标题、统计和条目。Nora 的片头与片尾区只在剧集项目显示。作品状态、时长和点击后的制作入口沿用已有组件。

## 验证结果

- TypeScript 和正式前端构建通过。
- Iris 多作品制作页通过 1280、1366 和 1920 三档桌面隔离验证。列表使用共用面板，只显示作品内容；点进作品后首屏仍可看到播放器。
- 暂存快照公共组件检查无待修正项，三档公共组件布局检查通过。人工核对确认复用已有面板和制作条目，组件展示页无需增加真实项目数据。
- 正式服务 v0.8.220 就绪。C004 与 Nora 剧集列表的面板背景、边框、圆角、内边距和条目样式一致；Nora 保留「片头与片尾」，C004 只显示十部作品。F001 可正常进入制作详情并返回列表。

## 补充修正｜制作详情沿用 Nora 工作台

v0.8.220 只对齐了列表。用户在 C004 F001 指出详情仍有专属状态栏、紧凑间距、播放器下载按钮、页底资料面板，以及加载提示和候选切轮差异。

- Iris 详情接入 Nora 使用的页头路径、制作对象选择、时长和内容面板。移除状态折叠框、重复资料区及专用紧凑样式。作品状态从概况打开，生产资料从全部资料读取。
- 视频准备提示跟随分段条；播放器共用原文件入口，选中产物仍对应其实际原文件。已登记的画布、导演包和交接包沿用资源下载入口。
- 同一场次内选到与已登记轮次匹配的候选时使用 Nora 的切轮逻辑。临时预览其他候选仍可回到原组合。Iris 的整片轮次、采用依据和历史归档继续读取各作品原记录。

### 补充验证

- TypeScript 通过。Iris 多作品、早期生产批次及 Nora 整集轮次通过 1280、1366、1920 三档隔离验证。Iris 覆盖新旧轮次切换、同轮其他分段、未匹配候选预览、加载提示位置、原文件地址、资源下载、归档只读及返回列表。
- 公共组件人工核对覆盖 Breadcrumbs、TabSelect、分段条和播放器。复用公共样式与交互，公共展示页同步播放器入口和说明。
- 暂存快照静态检查无待修正项，三档公共组件布局通过。正式服务 v0.8.221 就绪。在同一浏览器视口核对 Iris C004 F001 与 Nora EP005，面板、分段间距、准备提示位置、播放器和素材折叠区的样式一致。F001 选候选二会切到第 2 轮，P002 同样播放 R002，返回最新恢复第 3 轮的 R005；资源下载入口正常。
