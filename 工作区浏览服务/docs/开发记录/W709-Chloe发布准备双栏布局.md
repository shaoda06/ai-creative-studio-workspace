# W709：Chloe发布准备双栏布局

日期：2026-11-18
状态：已完成
关联版本：v0.8.464（已发布）

## 修改原因

发布准备的成片、封面和文案散落在长页中。需要在同一位置分别查看信息和媒体。

## 具体改动

发布准备区域采用 4:6 双栏。左栏默认打开基础信息，显示标题、正文和话题，可切换挂品信息。右栏默认打开横版封面，可切换竖版封面和本次视频。两栏独立切换，原有资料选择和建议发布时间仍在发布准备区域，发布记录留在页面底部。

## 验证结果

- TypeScript 检查通过。隔离浏览器验证三档桌面的 4:6 比例、双栏对齐和底部发布记录位置，并覆盖标签的键盘与鼠标操作、封面预览、下载、文案复制和视频离开后的停止播放。
- 公共组件复用检查：两栏直接复用 UnderlineTabs、现有播放器、媒体卡、预览、复制和下载按钮。页面样式负责分栏、间距和内容排列，无公共控件样式覆盖。业务页三档桌面验证覆盖新用法，公共组件及展示实现沿用既有规格。
- 暂存快照的公共组件静态检查和三档桌面布局通过。正式构建通过，8782 在本机与局域网地址均就绪。两处均核对到五个标签及 4:6 样式，实际作品接口也返回成片、双封面及发布记录字段。
