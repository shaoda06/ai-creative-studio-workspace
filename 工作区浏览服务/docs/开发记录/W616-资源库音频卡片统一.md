# W616：资源库音频卡片统一

日期：2026-11-08
状态：已完成
关联版本：v0.8.329（已发布）

## 修改原因

音频卡片使用整行左右布局并嵌套另一张卡片，与图片视频不同，时长重复且留白分散。

## 具体改动

音频改为同一三列网格中的完整卡片，上方标题和试听区，下方版本、归属、时长及详情／下载。试听区复用原AudioPreviewButton及播放器状态，不生成假波形或新增资源，时长仅显示一次。原公共声音参考卡保持原样。

## 验证结果

- 三档桌面资源库UI检查通过，音频卡宽度与三列网格一致、无嵌套卡片、标题单份，试听按钮位于试听区中央；播放／暂停、切换筛选停止、详情与下载仍正常。
- 公共组件复用人工检查：直接使用AudioPreviewButton和useAudioPreview，未改公共组件及其样式；试听区仅管理容器与装饰音符，消除原两栏布局及AudioReferenceCard嵌套。检查三档截图及调用差异，未发现重复公共交互；暂存静态检查0项需修正、0项待人工判断，公共组件三档桌面检查通过。

- 构建通过，正式服务与前端版本均为v0.8.329、ready=true；实际项目两张音频卡片同列宽显示，播放和暂停正常，无页面异常。
