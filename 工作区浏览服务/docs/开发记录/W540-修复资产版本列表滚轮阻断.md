# W540：修复资产版本列表滚轮阻断

日期：2026-11-07
状态：已完成
关联版本：v0.8.267；正式服务随v0.8.268一并完成发布核对

## 修改原因

鼠标位于其他版本图片卡上时页面无法继续滚动。版本容器的overscroll-behavior:contain阻止滚动传递，即使内容未超过限高也阻断外层页面。

## 具体改动

移除Chloe模特、造型、服装共用版本列表的滚动隔离，恢复浏览器默认滚动传递。保留1050px最大高度、内部滚动条和版本倒序。

## 验证结果

公共组件复用人工检查：仅调整既有版本列表容器的滚动行为，未修改图片卡、预览或其他公共组件。前端构建及公共组件检查通过。隔离测试在1280×640、1366×768、1920×1080验证短列表滚轮传递、长列表内部滚动与底部继续滚动页面，保留最大高度和倒序。真实M001面部三视图V002卡上向下滚动时页面scrollY由742变832，向上由832回742。另一后台任务存在未提交修改时未强行重启；该任务完成发布后核对/api/service为v0.8.268、ready=true，包含本次修复。
