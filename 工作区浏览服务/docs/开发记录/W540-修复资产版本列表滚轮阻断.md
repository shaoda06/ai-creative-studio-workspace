# W540：修复资产版本列表滚轮阻断

日期：2026-11-07
状态：已完成
关联版本：v0.8.267；正式服务随v0.8.268一并完成发布核对

## 修改原因

鼠标位于其他版本图片卡上时页面无法继续滚动。版本容器的overscroll-behavior:contain阻止滚动传递，即使内容未超过限高也阻断外层页面。

## 具体改动

移除Chloe模特、造型、服装共用版本列表的滚动隔离，恢复浏览器默认滚动传递。保留1050px最大高度、内部滚动条和版本倒序。

## 验证结果

本机业务验收明细保留在本地原始记录。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
