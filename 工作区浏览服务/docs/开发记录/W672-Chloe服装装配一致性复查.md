# W672：Chloe服装装配一致性复查

日期：2026-11-13
状态：已完成
关联版本：v0.8.401（已发布）

## 修改原因

复查单件、套装及三个装配页的接入。服装详情缺少分类字段，部分现行说明沿用旧字段或引用口径，套装可用登记没有检查其来源记录。

## 具体改动

- 服装详情与列表从同一份说明读取分类。详情显示单件部位，或套装来源和组成与穿法。旧格式继续读取。
- 提取套装的可用登记核对原服装参考图。合成套装沿正式图的上游执行找到生图步骤，核对该步骤的 1–5 项准确图片输入。服装参考与采用均核对实际图片格式。
- 合并服装详情返回与列表的分类参数写法，装配复用卡片数据类型及正式展示图判断。同步资产规范、会话入口和公共组件使用位置。

## 验证结果

- 固定资料 20 项、服装等接口 18 项通过。隔离测试覆盖只登记超分输入、缺原参考、超过五项、来源完整时登记成功，以及历史格式和准确采用版本。目标工作区固定文档检查 85 项通过。
- 三档桌面装配和共用资产回归通过，覆盖分类详情、选材、导出、原图预览及历史版本。公共组件复用检查确认详情继续使用现有字段布局，选择弹窗、卡片及导航继续使用现有组件，展示页同步了使用位置。提交钩子扫描 4 个暂存前端文件，0 项需修正，三档公共组件与展示页检查通过。
- 正式构建与托管重启完成，8782 返回 v0.8.401、`ready=true`。正式页核对单件详情、组合筛选、服装返回位置、套装空态及单件选材，接口核对正式图片版本引用。
