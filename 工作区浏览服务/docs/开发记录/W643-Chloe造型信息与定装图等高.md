# W643：Chloe造型信息与定装图等高

日期：2026-11-09
状态：待发布
关联版本：未发布

## 修改原因

造型详情左侧信息框随参考图数量增长，底边与右侧图片区域不齐。需要保持两侧等高，并将溢出限制在造型参考图列表。

## 具体改动

造型信息框和右侧定装图片区拉伸对齐。参考区改名为“造型参考图”，其列表只在内容溢出时滚动，造型名称、模特、说明和参考区标题留在列表外。沿用现有参考图输入及全屏预览。

## 验证结果

- TypeScript和资产技能格式检查通过。隔离造型页在1280×640、1366×768、1920×1080验证等高、两张参考图放得下时不滚动、六张图时只滚动参考列表，造型信息和页面滚动位置保持稳定。
- 公共组件复用检查：人工核对新增样式仅负责造型信息框与参考列表布局，图片卡及全屏预览继续复用，未覆盖公共组件样式。暂存快照检查由提交钩子执行。
