# W499：Chloe账号接入字段精简

日期：2026-11-07
状态：已完成
关联版本：v0.8.225、v0.8.226（已发布）；v0.8.227（已发布）

## 修改原因

账号接入面板同时展示连接细节和发布默认约定，字段过多。概况只保留日常判断需要的账号状态。

## 具体改动

v0.8.227按用户要求将页面模块标题“抖音账号接入”改为文档原章节名“账号接入”；运营接入规范补充直接对应章节的模块沿用原章节名，不添加平台前缀或自行改名。

v0.8.226按用户补充同步精简文档：账号接入固定为连接状态、视频发布、商品挂载、核对时间，删除原发布默认选项整节；账号身份、资料映射和核对与变更保留。视频发布使用待核实／可发布／不可发布，商品挂载使用待核实／可挂载／不可挂载，拒绝仅写已核实。

Chloe技能入口、填写规范、运营映射、账号模板、实际本机配置、两套示例、后端投影和前端直接字段读取同步更新。核对依据归原变更表，本条文案、标签、发布时间归视频发布资料；不再用页面别名掩盖旧文档字段。初始化和检查脚本从模板读取结构，无需复制另一份字段定义。真实配置原先全为未核实，保持这些事实；未生成核对事件或实际账号操作。

保留连接状态、视频发布、商品挂载三个主要字段，核对时间作为底部说明；去掉连接细节与发布约定的展开区。v0.8.225只精简页面；v0.8.226进一步按上述结构同步文档。
