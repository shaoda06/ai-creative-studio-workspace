# W704：Chloe成片文件类型与重命名

- 日期：2026-11-17
- 状态：已完成

## 修改原因

成片目录需要分开显示文件名和后缀，并能在列表里直接修改文件名。

## 具体改动

在文件名与分辨率之间显示实际文件后缀，文件名列显示主体。点铅笔原位编辑，回车或勾号保存，Esc 或取消按钮退出。同名提示留在本行。后端按原后缀改名并同步作品内现行 Markdown 链接。
