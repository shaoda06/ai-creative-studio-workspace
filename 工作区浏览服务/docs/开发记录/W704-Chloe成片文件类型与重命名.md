# W704：Chloe成片文件类型与重命名

- 日期：2026-11-17
- 状态：已完成
- 关联版本：v0.8.456（已发布）、v0.8.457（已发布）

## 修改原因

成片目录需要分开显示文件名和后缀，并能在列表里直接修改文件名。

## 具体改动

在文件名与分辨率之间显示实际文件后缀，文件名列显示主体。点铅笔原位编辑，回车或勾号保存，Esc 或取消按钮退出。同名提示留在本行。后端按原后缀改名并同步作品内现行 Markdown 链接。

## 验证结果

- 发布接口 11 项隔离测试通过，覆盖文件字节、同名限制、项目链接同步、读写权限及文档写入失败回滚。历史 Windows 只读文件删除问题沿既有记录。
- 三档桌面隔离测试覆盖六列表格、回车提交、Esc 取消、同名提示和勾号保存。
- 公共组件复用检查覆盖成片表格与行内输入。暂存静态检查无待修项，三档公共组件浏览器检查通过。人工核对沿用公共表格、下载、预览和原生表单输入，页面样式负责名称及行内操作的排布。
- 正式版 8782 返回 v0.8.456 且就绪。核对实际成片的名称主体、文件后缀、行内输入和 Esc 取消，正式项目文件未写入。

## 重命名图标对齐

名称区域使用弹性行布局将重命名铅笔固定在文件名单元格右侧，适用于不同长度的文件名。页面布局复用现有按钮与输入。

- 三档桌面隔离测试核对每行右对齐。公共组件暂存静态检查及三档浏览器检查通过。对齐由文件名区域负责，沿用公共按钮与输入规格。
- 正式版核对 3 行铅笔的右边界一致，并验证行内编辑可打开和取消。

## 成片目录操作同排

v0.8.458 将操作列从 278 像素加宽到 324 像素，文件名列使用剩余宽度。操作行固定同排，表格保留横向滚动空间。

- 类型检查和三档桌面成片页测试通过。隔离请求延迟时验证「正在准备…」、同排行高和按钮边界，随后确认浏览器下载的名称与内容；旧布局在 1280px 可复现换行。
- 公共组件复用检查覆盖成片表格、预览和下载入口。改动只调整列宽和业务容器排布，继续使用公共下载按钮及其准备状态；暂存静态检查无待修项。
