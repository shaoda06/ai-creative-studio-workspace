# W653：Songssx场次生成离线接入

日期：2026-11-11
状态：已完成
关联版本：v0.8.373（已发布）

## 修改原因

为 Songssx SelfLift 增加独立的场次装配及单文件取回，先验证 Nora 的三 GEN 场次，保留 AiMixer 旧任务与业务阶段。

## 具体改动

- 拆分 H3 共用规则、AiMixer 使用与缓存、Songssx 装配。将 Songssx 标准画布和 API 登记为正式 H3 基准。Nora 新制作默认使用 Songssx，AiMixer 可选。已有任务及其接续使用原请求与画布。
- 接入现有清单准备、上传绑定、队列、取回、重启恢复和通知。Songssx 使用整场 MP4 的通用取回凭据，使用不同于 AiMixer 一采、二采的任务类型。
- 《小序和禾禾》EP001 C001 在隔离项目装配，采用原分镜和四份参考图。P001→P002 为直接切镜，P002→P003 使用 22 帧原生接续。联调输出与业务采用资料隔离。

## 验证结果

- 离线准备时，三个 GEN 通过固定检查，生成窗口分别为 [0, 345)、[345, 537)、[515, 775)，计划成片 775 帧，24 fps。
- 模拟真实任务库验证准备、上传绑定、重启复用上传凭据、单文件取回和基础结果登记。受影响后台 312 项回归、技能与工作流 162 项回归通过。原 fork 的时间线编译函数独立确认 345／192／260 帧及 22 帧重叠。
- 后台全量 1505 项中有 8 项失败、4 项报错、3 项跳过。8 项失败及 4 项报错均在改动前的 `b1a7c043` 隔离快照中按同名用例复现。
- LoRA 权重对齐：AiMixer 的 Mystic 去油改为 0.35，标准画布、一采装配脚本及第六步询问同步。Songssx 的动作速度改为 3.00，保留旁路。36 项相关回归通过；重新装配隔离样本，确认速度节点保持旁路、接缝为 0／22 帧，成片计划仍为 775 帧。
- 2026-11-11 实机联调通过。预检确认 RTX 4090 节点上的工作流接口、模型和两项启用的 LoRA 均与装配一致。隔离后台提交 1 个场次任务（3 个 GEN），从提交到生成结束耗时约 2177 秒（36分17秒）。后台取回 1 条场次 MP4，完成技术收尾并发出组通知。本轮交付该候选供用户审阅。
- 用户验收首场联调的两处接续。实测输出为 1920×1088、24 fps、775 帧。切换默认工作流后，177 项相关回归通过。正式服务启动后核对了 Songssx 和 AiMixer 的任务类型、四份画布及 API 下载，以及一条已完成的历史 AiMixer 任务。
- 公共组件复用检查：未涉及前端源码、公共组件、样式或制作页，依据为本次最终差异；制作页和展示页不在本次验证范围。
