# W677：Chloe接入Songssx整片制作

日期：2026-11-13
状态：已完成
关联版本：v0.8.402（已发布）

## 修改原因

Chloe 的结果登记和后处理校验依赖逐段采样阶段，Songssx 的整片无法沿现有制作页完成送审和后处理。

## 具体改动

- 整场输出只登记一个资源版本。各分段沿原 GEN 时码关联同一文件，在共用制作页查看分镜、参考素材、候选和意见。已接回或静音的派生整片可作为该轮主播放。
- 后处理根据实际批准的源片与目标规格接续，检查来源和时长，技术通过后按原授权采用并生成单条整片的剪映交接清单。
- 业务技能保留素材用途、审阅、采用和记录规则，模型输入、任务字段、视频裁剪及浏览交互引用相应共用入口。修正 Windows 读取 Chloe 固定资料 JSON 时的编码。

## 验证结果

- 70 项隔离回归覆盖整片登记、批准约束、GEN 分段、本地派生主播放、后处理、交接及原逐段流程。20 项固定资料检查通过，另核对真实制作资料的 UTF-8 读取和已有候选引用。
- 公共组件复用检查：现有制作工作台、分段参考区、整片播放器和下载接口接收相同的数据结构。改动位于业务投影及后台，未增加页面组件或样式覆盖。Chloe 制作页的隔离浏览器回归覆盖三档桌面尺寸。
- 8782 已构建并通过托管启动器重启，服务返回 `v0.8.402` 和 `ready=true`。在正式工作台核对已有原片与静音审阅版的媒体范围请求，浏览器实际加载最新审阅版、GEN 参考素材和发布页时长。
