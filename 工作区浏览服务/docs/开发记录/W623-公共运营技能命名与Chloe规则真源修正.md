# W623：公共运营技能命名与Chloe规则真源修正

日期：2026-11-08
状态：已完成
关联版本：v0.8.335（已发布）

## 修改原因

公共运营阶段仍使用业务工作区前缀；Chloe存在跨业务规则引用、旧页面说明及项目README重复规则。声音原始参考允许视频，但资源库未从声音说明读取视频的业务标题。

## 具体改动

- 审计67个现行顶层技能入口的名称和职责，确认六个公共运营阶段需改名：nora-operations-setup → studio-operations-setup、nora-profile-images → studio-profile-images、nora-cover-images → studio-cover-images、nora-publication → studio-publication、nora-operations-review → studio-operations-review、nora-operations-guidance → studio-operations-guidance。同步目录、name、默认调用、现行规范和后台导入；未保留旧技能转接入口。其余带业务前缀的技能属于对应业务阶段。第三方技能保留来源名称；已有Nora节点注册类名、软件包名及历史记载属于接口或追溯标识，不随技能改名破坏兼容。
- 总层AGENTS和工作区结构规范引用唯一命名规则；新增要求：技能提炼为公共能力时同次检查并迁移名称和调用，不允许只扩大职责而遗留业务前缀。各工作区业务技能各自维护完整规则，技术能力引用公共维护者。
- Chloe声音、镜头图与制作入口移除其他工作区业务规则引用。概况明确源章节与“作品进度”的映射；视频流程的旧下载分组说明改为引用现行展示规则。
- Chloe项目README模板及本地项目入口移除复制的制作参数和页面布局，保留项目实际约定并链接维护者；同步初始化规范及相关声音规则引用。改动前正文保留在本地历史目录，历史执行事实不改写。Nora本地工作区README的一处公共运营入口同步新路径。
- 视频声音原参考按声音说明的准确资源版本读取名称及用途；复用原display_name搜索，不改文件名、不新增状态或名称记录。补充后端和三档桌面回归。
- 保留现有Git历史及既有开发记录，本项不清理或推送远端历史。
