# W659：Songssx场次绑定独立参考音频

日期：2026-11-12
状态：已完成
关联版本：v0.8.384（本机正式服务已发布）

## 修改原因

Songssx 的标准场次清单只接受参考图，已有的独立参考音频能力无法从工作台提交。

## 具体改动

场次清单可为每个 GEN 指定有序的参考音频路径。装配器登记实际音频文件和上传槽位，设置音色参考模式，核对音频时长、数量和提示词标签。

## 验证结果

- 5 项场次后台测试和 4 项装配规则测试通过。隔离夹具验证了双音色换序、上传路径回填、标签错误拦截和暂停时无上传或提交。
- 正式构建通过，本机服务版本为 v0.8.384 且已就绪。实际业务任务准备检查通过，后台返回暂停状态和空的远端任务 ID。
- 公共组件复用检查：代码差异限于场次装配和测试，前端仅修改版本号，无 UI 组件、页面样式和交互变更。
