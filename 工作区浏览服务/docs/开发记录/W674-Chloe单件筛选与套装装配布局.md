# W674：Chloe单件筛选与套装装配布局

日期：2026-11-12
状态：已完成
关联版本：v0.8.398（已发布）

## 修改原因

套装装配需要沿用造型装配的加号卡与双栏导出。服装库和单件选择弹窗需要按服装部位筛选。

## 具体改动

- 套装装配每行五列，加号卡随选中项移动，满五项时换到下一行并可打开弹窗调整选择。底部左侧列出导出信息，右侧显示导出文字。
- 服装库分为套装与单件，复用原卡片和详情。套装详情返回套装页，未分类的旧资料在单件页未勾选筛选时仍可查阅。
- 单件列表和选择弹窗使用配饰的复选框筛选样式。弹窗使用固定工具条，筛选时保留隐藏卡片的勾选及计数。
