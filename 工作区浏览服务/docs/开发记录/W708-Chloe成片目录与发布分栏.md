# W708：Chloe成片目录与发布分栏

日期：2026-11-18
更新日期：2026-11-19
状态：已完成
关联版本：v0.8.462（已发布）、v0.8.463（已发布）、v0.8.474（发布记录子页已核验）、v0.8.476（已发布）

## 修改原因

作品详情把成片文件管理和发布准备放在同一页。将两类操作拆成独立子页，保留作品列表和现有发布流程。

## 具体改动

作品详情默认进入「成片目录」，保留文件表格、上传、行内改名、预览、下载和删除。「发布」集中展示本次成片、封面、标题、正文、话题、挂品、建议时间与发布记录。发布标签可通过地址直接进入，支持刷新和浏览器前进、后退。两个子页复用现有详情接口。

v0.8.463 将顶部「发布」标签改为「发布记录」，原有直达地址及页面内容沿用既有实现。

作品详情增设独立的「发布记录」子页，集中显示原有发布安排、进展及作品链接。「发布资料」展示平台、文案、挂品、封面和本次视频，沿用原发布页直达地址。点击记录中的「查看发布资料」可进入对应的 Q 资料。

记录卡片将「查看发布资料」移到标题右侧并复用 LinkButton。字段名加粗，计划和实际发布时间按浏览器时区显示到分钟，原始时间保留在时间元素及业务记录中。
