# W708：Chloe成片目录与发布分栏

日期：2026-11-18
状态：已完成
关联版本：v0.8.462（已发布）

## 修改原因

作品详情把成片文件管理和发布准备放在同一页。将两类操作拆成独立子页，保留作品列表和现有发布流程。

## 具体改动

作品详情默认进入「成片目录」，保留文件表格、上传、行内改名、预览、下载和删除。「发布」集中展示本次成片、封面、标题、正文、话题、挂品、建议时间与发布记录。发布标签可通过地址直接进入，支持刷新和浏览器前进、后退。两个子页复用现有详情接口。

## 验证结果

- TypeScript 检查通过。三档桌面隔离浏览器测试通过，覆盖两个子页的内容边界、标签切换、链接刷新和前进后退、发布资料选择、离开后停止播放、成片文件操作及空态和失败重试。
- 公共组件复用检查：子页导航直接调用 UnderlineTabs，沿用共用播放器、媒体卡、下载、复制和弹窗。变更限于业务内容的排列及挂载，未覆盖公共组件样式。用现有发布页隔离测试增补了新标签的正常、键盘和容器边界检查。 暂存快照的公共组件静态检查和三档桌面布局检查通过。
- 正式构建通过。8782 返回 v0.8.462 且就绪。实际 Chloe 作品在局域网地址打开时显示成片文件表，直达「发布」时显示对应成片、封面和发布记录。
