# W645：Chloe共用资产封面与双栏图片对齐

日期：2026-11-09
状态：待发布
关联版本：v0.8.353（待发布）

## 修改原因

共用资产列表的固定高度图片框会在竖图两侧留出背景。场景详情也使用了这一图片框，且信息框和图片框高度不同。

## 具体改动

模特、造型、发型、服装和场景入口封面复用图片卡片的原图比例规格，沿用原列表网格。模特详情的当前图和其他版本按原图比例铺满。场景详情复用发型与服装的等高双栏和参考图列表，参考图、正式图和其他版本按原图比例显示，标题显示“场景图片”，实际尺寸在卡片上读取。

## 验证结果

- TypeScript、Chloe资产技能格式及隔离页面测试通过。1280×640、1366×768、1920×1080均验证入口封面铺满、模特与场景详情等高、参考图溢出滚动、其他版本、全屏、空态和失败重试。
- 公共组件复用检查：复用AssetMediaCard现有原图比例、入口和紧凑规格，以及造型详情双栏和FullscreenImage。人工核对无重复实现或页面样式覆盖，展示页同步使用位置。暂存快照静态检查0项需修正、0项待人工判断，三档桌面公共组件布局检查通过。
