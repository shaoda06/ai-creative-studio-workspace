# W532：RTX图片尺寸对齐与正式采用

日期：2026-11-07
状态：已完成
关联版本：v0.8.260（已发布）

## 修改原因

RTX节点将目标宽高取整到8的倍数，林舒E003返回2176×2896，而原校验要求2172×2896。用户明确接受节点实际输出、不裁切，并要求同步规则和校验、采用V003。

## 具体改动

图片技术适配启用RTX直接输出的8像素对齐校验，保留实际宽高；普通生成、DENOISE/DEBLUR及既有业务适配继续原精确尺寸规则。更新Chloe制作流程、资产规范、模特与服装模板及公共工具规范。V003仅修改采用引用，保留原图和实际处理历史，不改变原任务输入。

## 验证结果

45项共用资产、图片技术边界及原图片业务收尾测试通过，覆盖向上／向下半值取偶数、错误尺寸拒绝及同任务恢复。8份Chloe固定资料校验通过。正式前端构建通过。

公共组件复用检查：本次只涉及技术校验与规则模板，无前端组件、样式或页面行为变更；暂存差异人工核对无重复实现或组件覆盖，提交钩子三档桌面公共组件检查通过。正式服务返回v0.8.260、ready=true。
