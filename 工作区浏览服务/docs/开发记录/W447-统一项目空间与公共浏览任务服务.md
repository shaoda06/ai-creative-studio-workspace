# W447：统一项目空间与公共浏览任务服务

日期：2026-11-01
状态：已完成
关联版本：v0.8.158（已发布）

## 修改原因

公共浏览能力应提供工作区统一入口、一级项目空间和共用工具，不应由商业生产阶段另建服务与任务页。本次归并入口与服务，保留各项目资料及已有任务的归属。用户补充要求暂不处理手机适配取消，本批以桌面接入验收为范围；H3真实生成验收继续暂缓。

## 具体改动

- 首页统一展示共用资产、提示词、风格库和工作流，以及已登记的一级项目空间；顶部菜单也能进入空间及具体项目。原短剧项目地址继续可用。
- 公共服务按runtime中的本机登记读取各空间的项目、文件和原任务库。通用文件边界、目录树与Markdown渲染归公共后台，短剧专用解析仍由业务投影维护。商业项目不要求短剧目录或EP编号。
- 任务侧栏复用同一套队列、节点、历史及详情界面，按空间传递接口和查询缓存归属；编辑节点、操作和拖拽时禁止切换空间，打开的节点表单不会随页面导航被重置。
- 通用任务处理函数与权限检查复用，按本次请求选取对应TaskStore、凭证和项目文件；成果链接返回所属空间，不改写原任务记录。客户端支持登记的api_prefix，旧配置仍可用。
- 正式8782服务已接管商业原任务库。切换前确认没有进行中任务，保留私有配置和数据库备份；旧商业8783托管项停用并归档，业务阶段的独立服务、任务页和对应测试撤下，业务接入规范改为使用共用工具。
- 共用组件展示页增加真实Preview的静态项目空间示例，组件覆盖表与维护入口同步更新。现有手机CSS和响应式规则保留，没有实施手机适配取消。
