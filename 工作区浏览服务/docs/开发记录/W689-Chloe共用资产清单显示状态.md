# W689：Chloe共用资产清单显示状态

日期：2026-11-15
状态：已完成
关联版本：v0.8.413（已发布）

## 修改原因

Chloe 共用资产的清单卡片缺少资产状态。用户需要直接从清单识别制作中和可用的资产。

## 具体改动

模特、发型、服装（单件和套装）、配饰、造型和场景把已登记的资产状态传给公共入口图片卡片。状态在标题旁显示，制作中沿用蓝色状态标记，可用沿用绿色状态标记。卡片链接向辅助技术提供状态说明。

## 验证结果

TypeScript 检查和 Chloe 清单隔离浏览器用例通过。在 1280×640、1366×768、1920×1080 核对六类资产的状态、无图占位、长标题、详情导航、模特试听和读取失败重试。

- 公共组件复用检查：暂存自动检查读取 7 个前端源文件，0 项需修正，0 项待人工判断。人工核对三个列表入口仅传入业务状态，公共卡片统一渲染标签，沿用公共状态样式。公共组件展示页和覆盖表同步更新。三档桌面暂存快照验证标签未被截断，标题仍为单行，试听及详情链接正常。
- 正式服务构建并经托管启动器重启。`/api/service` 返回 `0.8.413` 和 `ready=true`。在 1366×768 打开 Chloe 各类真实清单，逐卡对照接口返回的状态和颜色，确认状态在标题旁完整显示，造型可正常进入详情和返回清单。浏览器只报告站点 `favicon.ico` 的 404。
