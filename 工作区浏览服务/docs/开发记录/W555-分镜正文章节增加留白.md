# W555：分镜正文章节增加留白

日期：2026-11-07
状态：待发布
关联版本：v0.8.283（待发布）

## 修改原因

分镜正文章节连读不易区分，需要增大下一镜标题上方留白，保持镜头内部行距及正文不变。

## 具体改动

公共 Rich、Document 增加 spacedHeadings 选项，在视频制作分镜正文启用。非首个二、三级标题上方间距40px，首标题与内部段落沿用原样式。公共展示页增加真实组件示例。

## 验证结果

首次检查发现原文首标题前有其他节点，:first-child不能识别首标题；改用标题兄弟关系，仅对已有前置标题的后续标题增加留白，等待复测。公共组件复用检查：以Rich规格实现，Document传递配置，未添加业务后代CSS覆盖；真实展示示例和三档快照检查已加入，提交时验证。
