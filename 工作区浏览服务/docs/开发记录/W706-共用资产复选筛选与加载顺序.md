# W706：共用资产复选筛选与加载顺序

- 日期：2026-11-18
- 状态：已完成
- 关联版本：v0.8.460（已发布）

## 修改原因

声音分类使用单选页签，配饰等列表已有复选筛选。加载提示在部分列表位于筛选条上方，Krea2 风格库加载时会遮住搜索区。

## 具体改动

配饰、服装（套装风格、单件部位）、姿态、声音及装配选材统一调用 CheckboxFilters。默认显示全部，标题行右侧的「清空」清除分类勾选，保留名称搜索与装配中的选材。套装的「管理」放在清空左侧，装配页「重置」继续管理整组素材。配饰、服装、姿态和声音的筛选容器在首次加载时先显示，加载提示随后显示在内容区。Krea2 风格库使用筛选区下方的列表加载提示。

## 验证结果

- 人工核对筛选样式与清空交互由公共组件维护，分类选项、搜索与分页由各业务传入。资源库、共用资产编号搜索、运营复盘、提示词、分集大纲、参考素材和任务历史的内容加载已位于各自控件下方。
- 声音列表通过三档桌面隔离验证，覆盖首次加载顺序、默认全部、多选、清空保留搜索、试听、空态及错误重试。TypeScript 检查通过。
- Chloe 导航与装配隔离测试通过，覆盖配饰、服装、姿态、筛选保留、装配选材和套装风格管理。
- 公共组件复用检查通过。暂存源码静态检查无问题，三档桌面布局与 220 像素窄容器验证标题、管理及清空的对齐，核对空选禁用、多选、键盘操作和清空。
- 正式构建通过，8782 返回 v0.8.460 且就绪。浏览器以实际资料核对配饰、套装、单件、姿态和声音的勾选、清空及加载顺序，另核对 Krea2 风格库加载提示在搜索区下方。
