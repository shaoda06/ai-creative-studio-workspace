# W463：Iris项目分类分页导航

日期：2026-11-02
状态：已完成
关联版本：v0.8.174（已发布）

## 修改原因

Nora项目有页头项目栏目分页，Iris三个项目使用通用FilesProject仅渲染整棵FileTree，没有注册项目栏目。用户明确本次关注分页导航，不扩为资产/分镜/生成记录专门展示重构。

## 具体改动

通用项目资料页复用Nora使用的TabNav和HeaderControlsContext，按实际顶层目录提供分页，保留项目概况与全部资料入口。内容及预览继续使用FileTree/Preview，不改业务目录、制作流程或项目资料。

## 验证结果

TypeScript检查通过；隔离浏览器按三个Iris项目目录形态、1280×640／1366×768／1920×1080完成9组分页检查，栏目切换、项目概况、全部资料、文档预览及换项目重置通过，无写入、脚本错误或横向溢出。现有统一首页→空间→项目→文档／图片／视频导航回归通过。
