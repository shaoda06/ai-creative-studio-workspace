# W662：统一资源选择卡片与全屏预览

日期：2026-11-12
状态：已完成
关联版本：v0.8.390（已发布）

## 修改原因

装配弹窗里的图片和参考视频都需要先预览再选择。原来部分卡片用整卡点击选中，部分卡片使用标题右侧的选择按钮，参考视频卡片也缺少全屏播放入口。

## 具体改动

- AssetMediaCard 的选择规格统一使用右上角按钮，点图片打开 FullscreenImage，点视频封面打开复用 Dialog 和 ReleaseFilmPlayer 的 FullscreenVideo。
- 两个装配页共用 AssetSelectionDialog，统一弹窗外壳、确认区和滚动行为。Dialog 的 Esc 只关闭接到取消事件的最上层弹窗，返回后保留暂选。
- 参考视频列表提供与详情相同的准确播放地址，封面与播放器使用同一登记版本。公共组件展示页直接复用真实卡片和弹窗，更新覆盖表及公共样式检查归属。

## 验证结果

- 参考视频接口 3 项、公共组件静态规则 7 项及 TypeScript 检查通过。三档桌面的装配回归验证图片预览、视频全屏播放、Esc 返回选择、确认、取消及不可用资源过滤。
- 公共组件复用检查：人工核对两页只提供资料、选择条件和业务操作，卡片按钮、预览与弹窗确认区由共用组件提供。提交钩子扫描 12 个暂存前端文件，0 项需修正。展示页的图片与视频选择按钮位置和尺寸、缺少媒体时禁用、全屏查看或播放、Esc 及关闭返回、暂选保留均通过三档桌面检查。
- 正式构建和托管重启通过，局域网服务回报 v0.8.390 已就绪。实际页面验证右上角选择与封面播放分离、已登记视频全屏播放及确认，以及造型装配图片全屏查看并返回选择。
