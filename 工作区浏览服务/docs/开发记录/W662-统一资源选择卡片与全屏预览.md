# W662：统一资源选择卡片与全屏预览

日期：2026-11-12
状态：已完成
关联版本：v0.8.390（已发布）、v0.8.391（已发布）、v0.8.394（已发布）、v0.8.395（已发布）

## 修改原因

装配弹窗里的图片和参考视频都需要先预览再选择。原来部分卡片用整卡点击选中，部分卡片使用标题右侧的选择按钮，参考视频卡片也缺少全屏播放入口。

## 具体改动

- AssetMediaCard 的选择规格统一使用右上角按钮，点图片打开 FullscreenImage，点视频封面打开复用 Dialog 和 ReleaseFilmPlayer 的 FullscreenVideo。
- 两个装配页共用 AssetSelectionDialog，统一弹窗外壳、确认区和滚动行为。Dialog 的 Esc 只关闭接到取消事件的最上层弹窗，返回后保留暂选。
- 参考视频列表提供与详情相同的准确播放地址，封面与播放器使用同一登记版本。公共组件展示页直接复用真实卡片和弹窗，更新覆盖表及公共样式检查归属。
- v0.8.391 全屏视频增加可点击关闭的暗色背景，预览退出时暂停视频。视频装配允许再次点击已选项取消，并确认清空原选择。两张造型预览在未选时也各保留一个带标题的框，参考视频预览补齐标题。
- v0.8.394 共用选择弹窗把确认按钮移到关闭左侧。配饰类型筛选移到标题栏下方，随共用弹窗标题区固定在顶部。资源列表可在下方滚动。
- v0.8.395 在共用弹窗工具条上方增加一条通栏横线，颜色和宽度与下方分隔线一致。
