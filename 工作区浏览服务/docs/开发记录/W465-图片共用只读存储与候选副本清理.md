# W465：图片共用只读存储与候选副本清理

日期：2026-11-03
状态：已完成
关联版本：v0.8.178（首次接入）；v0.8.179（补充异常收尾，已发布）

## 修改原因

用户要求清理已核对的204份候选副本，并修正以后重复复制的写入机制。相同原生结果、同尺寸处理输出及正式保存不应反复占用磁盘；更新正式图必须保留旧候选及任务输入的原始内容。

## 具体改动

共用`image_files.store_png`按实际字节复用同项目只读PNG，保留各自路径，不建立哈希索引或第二套素材库。原生Imagegen保存、Qwen/RTX取回检查、相同或不同尺寸的本地处理、正式发布与旧图归档均接入；视频任务首次冻结已有只读图片也共享同一数据，不再另存一份。外部工具原图不与项目硬链接，项目之间保持隔离。

正式图使用新文件原子替换路径，旧候选、归档及任务输入保留原inode和字节；已有目标变化时停止，禁止原地覆盖共享图。提供带实际项目参数的共用CLI，Nora采用规则、Iris资产规则与PNG目录快照规则均指向这一入口。Windows只读目标替换及临时硬链接清理保留原共享文件保护，已做分支模拟验证，本机实际环境为macOS。

按原核对清单合并204份已有候选副本，减少786,001,920字节（约786 MB），不扩展到原清单以外的正式图。完整本地清理记录为`综合资料/工作区占用审计-20261102/候选PNG合并记录-20261103.json`，不加入公共仓库。

## 验证结果

图片存储、技术图片边界、图片登记采用、Imagegen接续及视频输入留存共128项隔离检查通过；新增存储10项在最终补充分支后复核通过。独立Imagegen CLI命名与结果登记11项检查通过。覆盖相同内容复用、不同内容不覆盖、正式图更新与旧版本归档、旧候选和任务输入不变、相同尺寸处理共用inode、不同尺寸另存、跨项目隔离、原下载凭据与防并发覆盖。测试使用macOS规范临时根`/private/tmp`，避免既有夹具的`/var`路径别名差异；没有提交真实生图或视频生成。

已有204份副本合并后397个相关路径逐文件校验符合原审计值，1,649份引用文档原始字节保持不变；136个关联正式路径的字节、inode、mtime与权限均未改变。业务批准、原生结果与处理记录保留。当前代码与既有文档入口已检索，实际函数调用均提供明确项目；未改动非PNG文档备份及其他媒体流程。

- 公共组件复用检查：本项涉及图片文件保存与业务规则，没有前端组件或交互修改；发布版本元信息按标准构建核对。

正式前端构建通过；发布前核对Nora与Iris均无进行中或待提交任务，使用统一托管启动器重启，`/api/service`确认v0.8.178、ready=true与实际工具目录。六个受影响项目各抽取一个原候选路径，真实HTTP均返回200且字节符合原审计。没有重启远端节点、提交真实生成或推送。

补充异常收尾及未发布临时源排除用例后，以v0.8.179完成最终构建与托管重启；再次核对服务ready=true、版本及六个项目旧路径HTTP字节一致。Windows分支的目标冲突模拟同时验证原共享文件只读保护恢复；本项不宣称已在Windows真机执行。
