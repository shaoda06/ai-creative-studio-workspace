# W449：取消手机适配并统一桌面支持标准

日期：2026-11-01
状态：已完成
关联版本：v0.8.159（已发布）

## 修改原因

用户确认Nora保留连续短剧和社媒运营两个一级业务，授权按W448审计方案取消手机端适配，同步桌面最低分辨率、现行规范和测试，检查后加载正式代码。Iris技能改名、旧资料迁移及H3真实生成不在本批。

## 具体改动

- 删除37条手机／下限外宽度分支，将意见导出避让并入桌面默认；保留1279px头部换行、1500px大桌面、减少动画及粗指针输入目标尺寸。没有增加设备封禁或新访问限制。
- 提示词取消手机分步状态与返回键；TabNav移除mobileLayout参数、手机网格样式及调用／示例，保留桌面导航、键盘、滚动和未保存保护。
- 服务AGENTS、README、组件实现规范及共用浏览使用／维护规范明确仅支持桌面。最低显示1366×768、100%缩放，实际内容区至少1280×640 CSS像素；既有带日期历史记录保留当时事实。
- 公共提交检查和25份相关界面runner调整桌面矩阵；故障注入转到最低桌面，按实际高度核对全屏和菜单边界。过期夹具补齐空间登记、封面资产结构和原生剪贴板模拟，保留复制、文件、任务、媒体异常、旧轮次、意见冲突与失败恢复验证。
- 将UI脚本中依赖特定真实项目的“分集索引可显式指向正式剧本”断言移入临时目录的解析测试，保留原语义。依赖真实资料的只读回放不写项目，模拟保存只发生在浏览器内存。
- 桌面控制台检查发现Project的两个缓存观察查询缺少queryFn；沿用对应节／集的同一读取接口并保留enabled:false，避免开发告警且不增加独立请求。尝试skipToken时回归暴露共用缓存刷新问题，已改成明确读取函数后复验。
- 未改Iris业务技能名称、物理目录、旧商业资料、任务数据库或H3链路；Nora连续短剧与运营两个一级保持。

## 验证结果

- TypeScript和正式构建通过；130项后台／解析／文件隔离检查通过，包含从UI脚本移入的临时目录正式剧本索引案例。
- 26项界面runner通过。公共组件在1280×640、1366×768、1920×1080内容区检查普通／宽屏、菜单、长内容、下载、正常／空／禁用／错误／重试与鼠标键盘行为；反向注入字号继承、容器越界、消息超宽、关闭入口、输入及导航故障，均能被同一断言拦截，移除后恢复通过。未跳过Git钩子或删除功能边界检查。
- Browser plugin not available，使用仓库现有Playwright及Chrome。21项使用本地模拟响应，5项读取现有只读资料后在浏览器内存改造响应；入口服务器拒绝写请求，保存模拟只发生在内存。媒体空文件造成的预期Range错误由对应夹具单列；没有提交真实生成、写入真实项目或读取结果报告确认通知。
- 三档截图包含真实公共组件展示、普通／宽屏、长内容与输入；最低档冲突恢复需要先关闭可手动关闭的持久错误提示，确认关闭不取消核对或丢失草稿，再保存。正式8782加载后完成三档33个页面／状态的只读核对：统一首页→项目空间→项目资料，以及公共工具、短剧页和任务历史；页面身份正确、正文非空、无报错层、控制台错误、整页横向越界、写请求或外部请求。最低档提示词和常用桌面首页截图已查看。
- 发布前Nora空间无在途任务，商业空间存在运行及排队任务，曾先等待；随后核对现行持久恢复机制，按统一启动器短暂重启。两空间同进程返回v0.8.159、ready=true；原运行任务及排队任务的本地ID保留，运行任务的远端prompt_id保留，核对时状态分别继续running与local_queued。未暂停、取消或重提。

- 公共组件复用检查：人工核对全局及16份相关CSS、提示词状态、TabNav接口／调用、真实展示例、任务与制作组件及覆盖表。仅移除手机覆盖，沿用公共预览、菜单、消息、文件操作和布局实现，未增加业务页面私有覆盖。暂存静态检查21个受检源码文件，0项需修正、0项待人工判断；暂存快照三档公共布局及反向故障注入均通过。历史W和版本事实没有改写；当前说明、覆盖表和真实示例已同步。

## 未完成事项

Iris技能改名和旧商业资料迁移按用户要求后移；H3真实生成验收未提交。本次未实测其他桌面浏览器和所有操作系统，也不再声明支持手机布局。
