## 具体改动

- 任务侧栏读取后台已观察的节点。节点 URL 验证不创建 HTTP 客户端，实际 HTTP 请求才初始化传输层。

- 制作页共用参考卡读取缩略图，预览仍使用准确原件。当前视频使用范围请求，开启且开始连播后才预取下一段。带内容指纹的 JS/CSS 缓存并启用 gzip。

- 146 项后端回归通过，覆盖 Iris 三个并发请求只构建一次、修改轮次后更新，Chloe 未变化返回 304、新候选写入后刷新、候选上下文按准确版本读取，节点认证变化和重连。Nora 扫描缓存、取回与任务侧栏既有回归通过。
- 公共组件复用检查：沿用制作页和展示默认使用的参考素材、视频播放器、分段选择及任务侧栏。Chloe、Iris、Nora 和全局侧栏隔离浏览器用例通过，覆盖三档桌面，Iris 的 Range 测试夹具按真实文件服务行为返回 206。暂存快照静态规则和三档公共组件布局回归通过，TypeScript 检查及正式构建通过。
