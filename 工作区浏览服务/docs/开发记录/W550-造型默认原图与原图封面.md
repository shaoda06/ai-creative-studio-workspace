# W550：造型默认原图与原图封面

日期：2026-11-07
状态：已完成
关联版本：v0.8.279，已发布

## 修改原因

造型入口和列表封面默认使用遮面图，用户要求优先查看已采用原图。

## 具体改动

造型详情标签按原图、遮面版排列，无明确视图时默认原图，列表进入原图。封面只取当前采用的全身三视图原图，空态提示同步。显式遮面链接仍可打开，基础模特三视图原有默认不变；不改变资源采用记录。

## 验证结果

- 公共组件复用检查：沿用UnderlineTabs、AssetMediaCard，只改变调用参数和数据来源，没有新增样式或覆盖公共组件。暂存前端自动检查0项需修正、0项待人工判断；公共组件三种桌面布局检查结果见本次提交检查。人工核对无需修改公共组件展示页。
