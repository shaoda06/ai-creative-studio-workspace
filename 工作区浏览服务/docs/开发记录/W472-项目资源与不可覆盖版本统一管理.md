# W472：项目资源与不可覆盖版本统一管理

日期：2026-11-03
状态：已完成
关联版本：v0.8.186、v0.8.187（已发布）

## 修改原因

用户已确认：每个项目独立保存资源，共用管理工具；同一制作目标使用固定资源编号，每次实际产出作为不可覆盖版本；技术事实继续使用JSON，审核与采用继续使用业务Markdown。图片、视频及用户提供的参考音频、参考视频均按实际来源管理，不因审核、采用、输入冻结再次复制媒体。

## 具体改动

共用project_resources模块以项目资源编号／版本保存图片、视频及上传音视频；显式来源版本和实际处理区间写JSON，业务Markdown继续负责审核、采用和用途。固定生成、处理、输入关联、采用、导演包和剪映导出读取准确版本；相同任务重试复用输出身份，旧版本及历史地址不重绑定。图片与视频按同一机制返修；上传原件保留原字节和名称，独立选段及提取音轨另建资源并关联准确来源，同一选段降噪等新增版本。

新增项目资源页及导入／新版本界面，接通Nora资产、音视频、封面／账号图片、剧集制作及Iris生产读取；按原业务记录识别采用。新Nora项目初始化资源索引，Iris按共用CLI建档。现行规则同步资源位置和引用方式，保留业务编号、JSON／Markdown分工和原审核边界。

迁移工具分stage／finalize：先建立项目内资源、保留旧位置及小文档备份，核对原技术资料和网页投影后移除旧媒体入口与空目录。不同R、候选v及处理编号各保留实际产出版本；字节相同可共用项目内只读数据，不合并不同任务。完整封存快照、历史制作资料、原生交付、必要验证原件及归档只读项目保留；不处理.codex、任务库或依赖。

v0.8.187补齐Nora ProjectStore独立文件入口的资源映射，旧视频时间标记和历史替换版本仍读取准确原件；生成资料中的历史输入展示准确资源URL，解析缓存升级至27。原请求、输入、响应及批准事实保持原样。

8个项目的原资产采用、候选、待审和参考素材状态，以及22个剧集对象的迁移前后解析结果一致；30750个原技术文件的大小及修改时间不变。当前文档仅更新媒体引用和README存储约定，原小文档备份、迁移映射及逐项目结果保存在私有审计资料，不进入公共仓库。详细核对见工作区“综合资料／工作区存储审计／项目资源迁移-20261103／迁移核对.md”。一份既有无法完整解析的历史JSON原样保留，私有核对记录其位置与原因，不重写凭据。
