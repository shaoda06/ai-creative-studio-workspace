# W545：服装图片标注4比3与返修输入规则

日期：2026-11-07
状态：已完成
关联版本：v0.8.274

## 修改原因

用户将服装展示图规格改为4:3，并要求在服装图片标题括号内固定标注比例。图片返修默认回到原生成渠道和原始输入，避免逐版编辑累积变化。

## 具体改动

服装图片标题固定为服装图片（4:3）；服装制作规格同步为4:3。图片返修调整提示词后沿用原渠道，文生图保持文生图，参考生成使用当前制作步骤的原始参考，仅用户明确指定才编辑生成候选。
