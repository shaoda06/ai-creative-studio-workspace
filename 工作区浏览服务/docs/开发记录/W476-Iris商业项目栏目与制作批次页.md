# W476：Iris 商业项目栏目与制作批次页

日期：2026-11-04
状态：已完成
关联版本：v0.8.188

## 修改原因

Iris 项目原先按实际目录生成栏目。项目概况仅列入口文件，制作页直接打开最后一批视频，难以一眼看清项目进展及各批次的用途。

## 具体改动

- Iris 项目布局按资料区登记，独立于视频生产适配。顶部栏目按 Iris 业务流程组织。需求与参考分别展示客户原件和分析资料，创意、分镜及资产各有入口，审阅、交接、复盘和历史归档集中展示。
- 概况读取项目状态文件中明确写出的当前阶段与下一步，兼容历史项目的状态字段。资源版本、文档和媒体继续读取已有接口及文件。
- 视频制作列出真实批次、段数和制作阶段，点入后使用公共分段审阅。历史批次显示只读标记，保持原审阅边界。没有已登记制作资料的项目显示空状态。

## 验证结果

- 工作区和生产接口隔离测试覆盖 Iris 页面登记、生产资料和历史记录。Iris 隔离页面覆盖栏目、状态、预览、资源入口、批次切换和返回、已有修改意见读写与失败重试、历史只读及缺少资料时的展示。统一工作区导航回归覆盖普通资料空间、Nora 路由及全局任务栏。
- 公共组件复用检查：暂存源码静态检查无待修项，三档桌面公共组件布局检查通过。沿用 TabNav、TabSelect、FileTree、Preview、ResourceLibrary 和 SegmentWorkspace，样式限定于 Iris 的页面容器与批次排列。项目概况、批次列表和审阅界面在 1280×640、1366×768、1920×1080 内容区完成隔离浏览器检查。新布局依赖实际业务数据，公共组件展示页沿用原组件与规格。
