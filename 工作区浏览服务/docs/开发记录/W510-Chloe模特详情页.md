# W510：Chloe模特详情页

日期：2026-11-07
状态：已实现，待正式页核对
关联版本：v0.8.238，尚未发布

## 修改原因

用户要求点击整张模特卡进入详情页，展示当前采用、参考版本、身份特征、关联与制作记录；封面继续跟随唯一正面面部采用引用，暂不生成图片。

## 具体改动

AssetMediaCard的entry规格增加可选to，整卡使用链接且不嵌套图片按钮；其他规格与未传to的预览保持原行为。Chloe模特列表使用这一入口，详情页复用Breadcrumbs、UnderlineTabs、AssetMediaCard、Rich、FileActions和Preview。

当前采用显示正面面部和三视图，三视图默认遮面版，可切换原图；参考版本按用途分组，显示准确资源版本、来源、执行编号和采用标记。资产身份、人物特征使用原章节名；关联资料、采用变更、执行记录折叠展示，执行区包含输入、输出、审阅和返修。URL保存模特、用途、三视图选择及预览版本。

后端读取实际模特说明，媒体与文档只允许本说明及业务表中直接引用、本空间综合资料内的原文件；越界路径与符号链接被拒绝。无媒体时保留空态，不写入资料、不生成图片、不复制媒体。封面仍只用当前采用的正面面部准确引用。同步资产规则、运营接入说明和工作区README模板。

## 验证结果

后端7项测试通过，覆盖对象列表、候选与采用分离、准确原件引用、只读、错误文档、空间与路径边界。临时夹具核对文件内容未发生复制或改写。

隔离UI检查通过：有图与无图模特、整卡鼠标和键盘进入、候选预览、遮面与原图切换、刷新恢复、返回列表、错误重试，以及1280×640、1366×768、1920×1080三个桌面尺寸；测试图片仅在临时目录中构造，未写入真实模特。

公共组件人工核对：入口卡通过可选to复用链接行为，展示页提供真实调用；无嵌套按钮，详情图片与文档继续使用公共预览，业务CSS只分配容器位置。公共静态检查及暂存快照三个桌面尺寸布局检查通过；首次链接断言将测试用BrowserRouter误写成HashRouter路径，修正为真实href后通过。两个技能quick_validate及6份真实固定资料校验通过。正式服务核对待完成。
