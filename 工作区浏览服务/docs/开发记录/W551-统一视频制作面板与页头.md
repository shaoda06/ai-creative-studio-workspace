# W551：统一视频制作面板与页头

日期：2026-11-07
状态：待发布
关联版本：v0.8.280（待发布）

## 修改原因

三个工作区的视频制作应采用统一白色面板，并核对与业务内容无关的公共样式。Chloe 缺少面板，路径导航处于公共页头外，导致下方留白不同。

## 具体改动

Chloe 使用现有 panel 和堆叠 PageHeader，路径导航放在页头内；保留业务标签配置及全部内容。核对三个工作区面板、页头导航、内容标签及工具栏样式。

## 验证结果

三个工作区均通过1280×640、1366×768、1920×1080隔离页面检查：面板白色、圆角10px、内边距23px，制作标签距上方20px、工具栏gap为12px/20px、正文顶部20px，路径导航位于堆叠页头内且无额外下边距。Chloe 标签范围与章节读取、重试、跳转通过；Nora 轮次与跨场播放回归通过；Iris 使用 PRODUCTION_TABS_ONLY=1 检查原五标签、正文与修改入口，未运行无关项目概况全量测试。前端正式构建通过。

公共组件复用检查：检查三个调用入口及样式定义，只补齐现有 panel 和 PageHeader 调用，没有新增公共组件、CSS覆盖或复制制作UI；公共展示页规格不变。制作页中的标签、工具栏及分隔线已经共用，未发现需要额外修改的业务页样式分支。暂存自动检查及正式页面核对待完成。
