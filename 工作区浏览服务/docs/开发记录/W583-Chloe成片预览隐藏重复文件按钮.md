# W583：Chloe成片预览隐藏重复文件按钮

日期：2026-11-08
状态：已完成
关联版本：v0.8.299

## 修改原因

成片目录已提供下载入口，Chloe视频预览弹窗上方的查看和下载按钮重复，按用户要求移除该按钮组。

## 具体改动

公共Preview增加默认开启的showFileActions选项，Chloe成片与发布只在视频预览时关闭。保留原公共弹窗、播放器及关闭操作，目录下载和封面预览仍保持原行为，其他调用使用原默认值。

## 验证结果

成片页隔离测试在1280×640、1366×768、1920×1080全部通过：视频预览无文件按钮组，播放和关闭正常，目录下载、封面预览、切换与错误重试保持正常。独立公共Preview夹具确认默认查看与下载链接仍保留。正式Chrome页面核对视频播放、按钮隐藏及关闭通过，服务v0.8.299且ready为true。公共展示的仅播放视频示例在三个桌面尺寸下播放和Esc退出通过。TypeScript和正式构建通过。

- 公共组件复用检查：直接复用Preview和Dialog，通过显式选项控制FileActions；没有新建按钮、播放器或样式覆盖。隔离成片页面夹具覆盖关闭按钮组及封面预览；公共组件展示增加仅播放视频示例，覆盖表同步说明默认与关闭两种调用。
