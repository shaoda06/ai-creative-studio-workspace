# W484：Iris 制作脚本与分镜页内阅读

日期：2026-11-05
状态：已完成
关联版本：v0.8.200，已发布到正式浏览服务

## 修改原因

创意与音画、分镜与声音原先只列文件入口，需要额外打开才能读正文。两个栏目统一采用需求与参考的页内阅读方式。

## 具体改动

- 沿用项目状态确定现行制作脚本、正式剧本和分镜与声音制作稿，页内显示正文和表格。顶部可展开章节导航，确认的主文件有多份时可以切换。
- 旧版与过程资料折叠显示，只有归档的项目提供对应阶段的历史资料入口。历史入口保留原文件及预览方式。

## 验证结果

- 11 项隔离接口检查通过。1280×640、1366×768、1920×1080 三种桌面尺寸通过隔离页面检查，覆盖正文直显、章节跳转、导演表预览、读取重试、空态及归档入口。
- 公共组件复用检查：三栏共用 IrisDocumentReading 排列 Document、UnderlineTabs 和 Result，归档及其他资料继续使用 FileTree 和公共预览。人工核对仅调整业务阅读面板的容器样式，共用组件和展示示例的规格保持原样。暂存快照执行公共组件静态及布局检查。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
