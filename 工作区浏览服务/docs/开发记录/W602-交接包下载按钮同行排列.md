# W602：交接包下载按钮同行排列

日期：2026-11-08
状态：已完成
关联版本：v0.8.316（已发布）

## 修改原因

资源下载中视频包和剪映包纵向排列，用户要求同行且视频包在左。

## 具体改动

公共SceneDownloads的阶段交接包操作容器改为横向排列：左侧视频ZIP包，右侧剪映草稿包。各阶段使用同一实现，不改变其他资源列表、打包地址、禁用及下载逻辑。

## 验证结果

公共组件复用人工核对：沿用DownloadButton，只调整容器排列和按钮顺序；业务整页展示归属不变。静态检查0项需修正；1280、1366、1920三档公共组件检查通过，三个阶段均验证按钮同行且视频包在左，下载和禁用逻辑检查保持通过。正式v0.8.316构建已包含本次改动，ready=true；实际页面核对三个阶段按钮的纵坐标相同、视频包横坐标在左，未触发真实下载或项目写入。
