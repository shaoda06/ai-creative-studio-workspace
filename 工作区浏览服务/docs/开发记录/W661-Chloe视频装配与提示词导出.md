# W661：Chloe视频装配与提示词导出

日期：2026-11-12
状态：已完成
关联版本：v0.8.386（已发布）、v0.8.387（已发布）、v0.8.388（已发布）、v0.8.389（已发布）、v0.8.392（已发布）

## 修改原因

共用资产的装配页只提供造型图制作入口。需要在同一入口选取参考视频和模特造型，按需添加背景及额外要求，导出复刻提示词。

## 具体改动

- 在装配入口增加「造型装配」「视频装配」子标签，原链接默认进入造型装配。切换子标签保留两页各自的草稿。
- 视频装配左上播放参考视频，右上选择模特及其已采用的全身定装三视图原图，左下填写额外要求并导出，右下可选背景。背景留空时沿用参考视频的场景。
- 导出复用造型装配的生成与复制操作，写入素材身份、实际文件引用和额外要求。
- v0.8.387 核对两页的状态条件。造型装配沿用现有「可用」筛选。视频装配的模特、造型和背景按图片资产状态筛选，即使已有采用图，「制作中」的对象也不列出。参考视频完成登记并绑定准确播放版本后，列表接口和详情将其标为「可用」。
- v0.8.388 复查发现短时间重开弹窗可能沿用缓存中的可用对象。两页弹窗改为在打开时重新读取状态，读取完成前隐藏选项并禁用确认。同步组件说明的栏目表、两页装配、造型封面和参考视频状态。
- v0.8.389 选定造型后，上下预览该造型已采用的面部三视图和全身定装三视图遮面版。两张图均可放大，导出记录相同的准确版本与文件路径。
- v0.8.392 上排按 3:4:3 排列参考视频、造型图和背景，共享选择区与预览的行高。下排等宽，左侧额外要求，右侧导出。
