# W535：图片标题标注固定要求比例

日期：2026-11-07
状态：已完成
关联版本：v0.8.263（已发布）

## 修改原因

用户要求图片类型标题标注固定要求比例，与卡片内实际像素尺寸分开。

## 具体改动

模特图片标题改为“正面面部图（3:4）”“基础全身三视图（16:9）”，资源编号及版本仍接在后面。比例取自chloe-assets的模特与服装图片制作流程，使用固定文字，不读取或计算实际图片比例。遮面版和原图使用相同要求。

面部三视图与服装展示图的专用入口尚未接入；现有服装单视角及造型图未确认固定规格，不擅自标注16:9。本次不扩展图种展示。
