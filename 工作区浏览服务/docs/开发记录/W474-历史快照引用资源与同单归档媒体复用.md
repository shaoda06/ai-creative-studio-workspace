# W474：历史快照引用资源与同单归档媒体复用

日期：2026-11-03
状态：已完成
关联版本：不涉及服务发布（独立快照工具与资料整理）

## 修改原因

历史完整快照和同一订单的多份归档仍保存重复媒体。用户授权处理已核对的快照及同单历史副本，保留原记录和独有资料，并修正未来备份方式。

## 具体改动

新增共用project_snapshot.py的create、compact及restore入口。新整理快照只保存明确选定原记录和准确资源版本，媒体不入ZIP，原生包及模型缓存不嵌套打包；无法完整解析的外部JSON保留原字节并明确列出。已有完整快照仅在明确授权后逐项完整比较媒体与固定版本，原记录逐项字节比较、ZIP完整读取通过后再原位替换。恢复仅写新的独立目录，原项目和旧版本保持。

Nora快照规则移除PNG副本及通用完整压缩入口，链接共用工具；项目资源规则同步历史副本的明确授权边界，浏览技能入口可定位快照说明。检索现行脚本未发现另一套通用整项目媒体备份任务，不新增后台定时器。

授权快照完成转换：441项媒体改为固定资源引用，5881份原记录保持原字节；原快照文件名及链接保留，从约2.24 GB缩至29.8 MB。同一订单的三处历史目录中，935个重复媒体入口复用完整历史保留区内只读数据，原路径及执行凭据可继续读取，不删除或合并不同内容。只读目录仅在目标父目录临时开放替换权限，完成后恢复。原生交付包只共享完全相同的数据，未拆包或修改内部路径。

## 验证结果

7项新增隔离检查及15项已有资源／迁移检查通过：不重复装入媒体及原生包、JSON与审核原文保留、旧快照转换及按原路径恢复、V002存在时仍恢复V001、媒体不同或ZIP校验失败时原包不变、路径边界、同单历史链接的大小／时间及只读属性。最后的恢复入口及固定版本用例调整所影响的14项复核通过。两项受影响技能quick_validate通过，CLI帮助与规则中的参数一致。

三处历史目录4976个原文件的路径集合、大小和修改时间前后一致，935项媒体均与保留入口samefile且只读，父目录权限已恢复。迁移前任务监控没有执行中或排队任务；真实Nora及Iris历史图片、视频、jypack和原快照地址共7项范围读取HTTP 206。服务仍为v0.8.187、ready=true；不改网页／服务实现，不重启、不递增服务版本。

同一du口径，工作区约26.93 GB降至23.29 GB，减少约3.64 GB；详细逐项对照及原规则小文件保存在本机存储审计资料，不加入公共仓库。.codex、任务库、其他项目及独有文件未清理。初次历史媒体替换被只读父目录阻止，确认原因后只在授权范围临时开放所需目录并恢复；没有放宽共用保存接口的权限行为。
