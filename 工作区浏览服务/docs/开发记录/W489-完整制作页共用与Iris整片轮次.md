- Iris 按 C 项目下的 F 作品进入共用页。每轮引用具体分段版本、当时的剧本及分镜；临时选候选、任务重试和重新下载不建轮。整片及段级意见按作品保存，旧意见与页签草稿保留原归属。无登记组合时显示计划资料；缺片时停止连播。
