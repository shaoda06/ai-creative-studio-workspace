## 修改原因

Iris 仅复用了单段审阅组件，缺少 Nora 完整制作页的轮次、分镜、导演表、连播、整片意见和下载组织。用户要求提取完整公用页，同时 Nora 功能和操作保持不变。

## 具体改动

- 保存完整方案，先更新 Iris 规范和生产任务模板，再原样提取 Nora 完整页并通过隔离检查。`ProductionWorkbench` 复用原有组件；Nora 入口、接口、资料路径和操作偏好沿用。
- Iris 按 C 项目下的 F 作品进入共用页。每轮引用具体分段版本、当时的剧本及分镜；临时选候选、任务重试和重新下载不建轮。整片及段级意见按作品保存，旧意见与页签草稿保留原归属。无登记组合时显示计划资料；缺片时停止连播。
- 下载复用已登记交接清单、共用下载组件和后台脚本。浏览不打包，点击才生成并检查；剪映客户端无需逐包打开。

- Iris 同三档完成隔离多作品检查：候选浏览、旧轮来源、导演表全屏、分镜草稿及导出、段级和整片意见保存、失败恢复、缺片停止及恢复、宽屏与连播互斥、点击下载和作品切换。后端工作台、原 Nora 轮次与意见、剪映及导演包相关用例通过。
