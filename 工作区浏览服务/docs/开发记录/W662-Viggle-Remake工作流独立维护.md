# W662：Viggle-Remake工作流独立维护

日期：2026-11-12
状态：已完成
关联版本：v0.8.378（已发布）

## 修改原因

Viggle Remake 的换人画布、API 和分段流程集中到独立技能维护，工作台继续通过 Minimax-H3 分类提供原下载入口。

## 具体改动

画布、API 和分段流程迁到 `studio-h3-remake`，`studio-h3` 保留入口。共用目录定位将 Remake 技能的工作流登记到现有 Minimax-H3 分类，沿用文件名和下载地址。

## 验证结果

- 两套技能通过格式及相对引用核对。画布和 API 迁移前后逐字节一致，28 项基准检查和 6 项工作流下载接口回归通过。
- 正式服务重启后就绪，工作流目录仍列出 7 套资源。Remake 在 Minimax-H3 分类下唯一列出，原地址的画布及 API 下载与新目录源文件逐字节一致。
- 公共组件复用检查：改动涉及工作流目录定位和发布版本号。对照最终变更范围，无前端组件、样式或交互差异，工作流页面沿用既有下载组件和接口。
