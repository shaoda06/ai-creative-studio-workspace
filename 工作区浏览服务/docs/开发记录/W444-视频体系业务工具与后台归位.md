# W444：视频体系业务工具与后台归位

日期：2026-10-31
状态：已完成
关联版本：v0.8.155（已发布）；v0.8.154（曾加载，工作流列表验收未通过）

## 修改原因

Nora业务已覆盖连续短剧、商业与运营，旧主技能混合阶段规则、模型调用和后台脚本。按已确认的统一入口、一级业务、二级阶段及共用工具结构归位，保留自动化和旧任务语义；本轮包含用户明确纳入的H3，不提交真实模型生成任务。

## 具体改动

- 统一入口与维护归nora-video，连续短剧一级组织D01–D12；D09/D10/D11与运营六阶段维护实际业务规则、模板、脚本和展示适配，旧入口只导航/转调。
- H3、视频处理、剪映和浏览器操作成为共用工具；Agent负责内容与语义，脚本执行明确输入和记录，后台保存任务事实并分别恢复业务登记与展示。
- 视频technical适配不要求EP、人物卡或短剧mapping，技术通知不调用短剧整轮汇总；省略adapter的历史业务任务保留原语义，未知适配拒绝。
- 业务轮次、意见、输入来源、采用及投影迁至相应业务，通用事务、HTTP读取、通信和模型装配归工具。工作流/节点包/依赖代码及许可证保持，依赖文档只同步引用。
- 工作流列表与下载使用登记的逻辑分类和实际工具目录，沿用原分类URL并保留文件和目录边界；不再假设Qwen/图片处理资源物理位于旧主技能根内。
