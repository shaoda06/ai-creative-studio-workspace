# W701：Chloe 共用资产编号搜索

日期：2026-11-17
状态：已完成
关联版本：v0.8.436 已发布到正式服务 8782

## 修改原因

服装入口优先展示套装，把风格修改放回对应卡片，在共用资产导航按编号查找各类资料。

## 具体改动

- 服装默认打开套装。单件有独立页签参数，详情返回沿用来源页签。
- 套装卡片底部在公共媒体卡片内部使用已有风格下拉，标题和图片仍打开详情。
- 「参考视频」右侧新增编号搜索框，保留「装配」靠右。结果支持编号前缀和完整编号，直接打开现有详情，姿态详情可从页外直接打开。

## 验证结果

- 相关后端 40 项测试通过，覆盖不同资产编号、编号前缀、项目隔离、造型所属模特和未登记参考视频。
- 1280×640、1366×768、1920×1080 隔离浏览通过，覆盖服装默认页、单件详情回退、套装卡片内修改风格、编号搜索、页外姿态和视频详情跳转。
- 公共组件复用检查覆盖 UnderlineTabs 行内操作及 AssetMediaCard 内部底部操作。沿用 SearchField、TabSelect 和卡片既有样式。隔离暂存静态检查无待修项，真实组件展示及三档布局核对通过。
- 正式服务报告 v0.8.436 且就绪。实测服装默认进入套装，O001 的风格下拉可在卡片边框内打开，o002 搜索结果进入单件详情及返回单件页，RV001 搜索结果打开参考视频详情。
