# W606：Chloe作品列表按视频状态统计

日期：2026-11-08
状态：已完成
关联版本：v0.8.320（已发布）

## 修改原因

制作列表按业务阶段统计，和作品卡片的视频状态不同。用户要求制作与成片发布列表都按制作中、待发布、已发布统计。

## 具体改动

Chloe制作列表的workStatusLabel直接读取README现有视频状态，与卡片同源。公共制作页允许调用方指定统计标签顺序及零计数，Chloe使用三个现有视频状态；其他工作区不传该配置，保留原逻辑。成片与发布表头复用公共统计样式，统计其列表接口已有status字段。两页共用显示标签顺序，不新增或写入业务状态。

## 验证结果

README三种视频状态的后端同源及零写入检查通过。制作与发布列表三档桌面隔离测试通过：状态切换、混合状态总数、零计数、空列表及现有卡片导航／下载行为正常。公共组件人工核对：配置仅由Chloe传入，Iris和Nora未改数据或调用，默认统计分支保持原逻辑；显示使用既有production-statistics样式。Iris列表三档隔离回归核对仍显示原业务阶段统计；本次仅运行该列表检查，不将原脚本的完成提示作为其他Iris流程验收。TypeScript／Vite构建通过，正式服务v0.8.320 ready=true，两页实测均显示共1部、制作中1部、待发布0部、已发布0部。公共静态检查0项需修正，1280、1366、1920三档公共组件布局检查通过。
