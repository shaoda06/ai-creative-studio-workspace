# W669：共用整场后处理审阅

日期：2026-11-12
状态：已完成
关联版本：v0.8.397，已在本机正式服务发布。

## 修改原因

Iris 制作详情把整场后处理的 MP4 当作分段候选解析，要求输出名含 P 编号。整场任务入队后，作品详情接口因此返回 409，连带影响列表中的时长读取。Nora、Iris 和 Chloe 需要共用执行记录、准确源片及取回凭据的读取方式。

## 具体改动

整场后处理用轮次中的审阅产出引用执行目录和准确源片。共用读取器校验唯一源片与 MP4 输出，凭据与文件齐备后提供播放入口。Iris 在读取批次时将这类已登记任务交给整场读取器，分段任务继续读取原分段执行记录。Nora 原有 Songssx 整场播放器关联复用同一源片校验。三处业务规范指向同一登记规则。

## 验证结果

Iris、Nora 和 Chloe 的隔离后端回归共 124 项通过，覆盖整场任务待取回、凭据齐备后出现、轮次隔离、既有 Songssx 整场播放、分段候选和执行记录归属。正式前端构建通过。

正式服务报告 v0.8.397 和 ready。实际打开 F001，列表显示 30.2 秒，第 7 轮显示 R007 V003 的可点播审阅入口，MP4 分段读取返回 206。F002 制作详情正常返回 P001、P002、P003。
