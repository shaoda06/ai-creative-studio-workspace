# W490：入口卡片链接置底与Iris项目概况合并

日期：2026-11-07
状态：已完成
关联版本：v0.8.209（已发布）

## 修改原因

项目卡片的标题有长有短，同行入口文字上下错位。Iris 的项目说明和项目状态需要连续阅读，后续再决定展示哪些章节。

## 具体改动

公共 EntryCard 使用纵向布局，同行入口文字与箭头贴底。展示页并列长短标题卡片。Iris 项目概况在同一面板内先显示项目说明，再显示项目状态。两份文档各自使用 Document 的章节导航和 Result 的读取重试，本地源文件保留原样。

## 验证结果

- 隔离项目浏览器用例覆盖 1280×640、1366×768、1920×1080。长短标题实际换行，入口底边对齐，卡片可进入项目。概况两份正文同页显示，说明读取失败时状态照常显示，重新读取后章节导航能定位。空概况显示既有提示。
- 公共组件复用检查覆盖 EntryCard、Iris 概况和布局与搜索展示。暂存快照的静态检查无待修正项，三档桌面公共布局用例通过。人工核对确认贴底样式在公共卡片样式中实现，业务页面复用 Document、Result，展示页直接渲染真实 EntryCard。
- TypeScript 检查通过。
- 正式构建及托管重启通过，8782 返回 v0.8.209 和 ready=true。在浏览器核对项目列表卡片的底部间距一致，点击 C004 后在同一概况面板依次读到项目说明的 6 个章节和项目状态的 3 个章节。两份本地文档的校验值在发布前后一致。
