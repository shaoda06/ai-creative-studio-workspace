# W490：入口卡片链接置底与Iris项目概况合并

日期：2026-11-07
状态：已完成
关联版本：v0.8.209（已发布）、v0.8.211（已发布，含原拟 v0.8.210 的改动）、v0.8.212（已发布）

## 修改原因

项目卡片的标题有长有短，同行入口文字上下错位。Iris 的项目说明和项目状态需要连续阅读，后续再决定展示哪些章节。

## 具体改动

公共 EntryCard 使用纵向布局，同行入口文字与箭头贴底。展示页并列长短标题卡片。Iris 项目概况在同一面板内先显示项目说明，再显示项目状态。两份文档各自使用 Document 的章节导航和 Result 的读取重试，本地源文件保留原样。

两份文件的正文接入同一个 Document，页内只显示「项目概况」标题，删除分隔线和来源标题，原有章节按文件顺序进入同一个导航。

项目可分别指定两份来源文档需要从概况省略的二级章节。章节及其正文在生成导航前过滤。C004 的项目配置省略「目录与资料入口」和「进度与版本入口」。
