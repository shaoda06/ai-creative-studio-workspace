# W490：入口卡片链接置底与Iris项目概况合并

日期：2026-11-07
状态：已完成
关联版本：v0.8.209（已发布）、v0.8.211（已发布，含原拟 v0.8.210 的改动）、v0.8.212（已发布）

## 修改原因

项目卡片的标题有长有短，同行入口文字上下错位。Iris 的项目说明和项目状态需要连续阅读，后续再决定展示哪些章节。

## 具体改动

公共 EntryCard 使用纵向布局，同行入口文字与箭头贴底。展示页并列长短标题卡片。Iris 项目概况在同一面板内先显示项目说明，再显示项目状态。两份文档各自使用 Document 的章节导航和 Result 的读取重试，本地源文件保留原样。

两份文件的正文接入同一个 Document，页内只显示「项目概况」标题，删除分隔线和来源标题，原有章节按文件顺序进入同一个导航。

## 验证结果

- 隔离项目浏览器用例覆盖 1280×640、1366×768、1920×1080。长短标题实际换行，入口底边对齐，卡片可进入项目。概况两份正文同页显示，说明读取失败时状态照常显示，重新读取后章节导航能定位。空概况显示既有提示。
- 公共组件复用检查覆盖 EntryCard、Iris 概况和布局与搜索展示。暂存快照的静态检查无待修正项，三档桌面公共布局用例通过。人工核对确认贴底样式在公共卡片样式中实现，业务页面复用 Document、Result，展示页直接渲染真实 EntryCard。
- TypeScript 检查通过。
- v0.8.210 暂存快照的隔离用例覆盖三档桌面。两份正文连续显示在同一个 Document 内，重试后仍能读到两部分，合并目录中的章节按顺序排列，即使原文件的标题锚点同名也能各自定位。人工核对确认本次只编排 Document 和 Result 的调用，使用既有导航和错误提示样式。TypeScript 检查通过。
- v0.8.212 的接口回归通过 18 项。隔离浏览器在三档桌面尺寸确认已配置章节及附属正文从概况和导航省略，未配置项目显示原章节。人工核对确认过滤在 Iris 正文投影中完成，沿用 Document 和 Result 的导航、样式和错误处理。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
