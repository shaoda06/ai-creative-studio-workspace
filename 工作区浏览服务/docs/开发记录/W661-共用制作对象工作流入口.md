# W661：共用制作对象工作流入口

日期：2026-11-12
状态：已完成
关联版本：v0.8.377（已发布）

## 修改原因

W654 已提供正式制作记录选择页。共用工作台按对象类型只让 Nora 进入工作流判断，Iris 的制作读取也跳过了 Songssx 场次任务，导致 Iris 作品已有整场结果而视频制作页没有候选。

## 具体改动

共用工作台先选制作对象，再根据实际正式记录决定直达或显示选择页。工作流选择只影响浏览，轮次在进入后选择。Nora、Iris 和 Chloe 共用判断、播放器和轮次界面。后续工作区按[共用接入规范](../../../.agents/skills/studio-workspace-browser/references/业务接入规范.md#按制作对象选择工作流)提供对象及记录即可。

Songssx 整场候选和 GEN 时码读取从 Nora 的业务脚本移入通用工具。Iris 通过现有轮次、装配记录和准确视频版本关联整场候选，并沿用已有分段意见身份。共用下载按所选轮次的场次顺序取整场文件。

## 验证结果

107 项后端回归通过，包含 Iris 已接收和未提交的场次记录、原文件与 ZIP 内容一致、轮次意见、其他作品隔离及 Nora 原历史兼容。三个业务入口在 1280×640、1366×768、1920×1080 隔离检查通过。Nora 验证单套直达与双套选择，Iris 验证单套 Songssx 的整场播放、P 段切换和正确的轮次下载地址，Chloe 以隔离数据验证 AiMixer 直达和双套记录选择。TypeScript 检查通过。

正式服务 8782 已构建并重启，`/api/service` 返回 v0.8.377、ready=true。浏览器从 Iris 制作列表选择作品后直接进入 Songssx，默认打开最新轮。切换分段可在同一视频跳到该段起点，切换旧轮可打开其对应视频。两轮视频均通过范围请求，ZIP 和剪映草稿入口均可点击。
