# W547：服装采用图片仅显示尺寸

日期：2026-11-07
状态：已完成
关联版本：v0.8.276（已发布）

## 修改原因

服装正式图卡片仍显示文件操作和采用版本，用户要求与AI模特图片对齐，只保留尺寸。

## 具体改动

服装详情的当前采用卡片传入AssetMediaCard已有的showFileActions=false及showVersion=false，保留图片、尺寸和全屏预览；公共组件默认行为与其他调用不变。

## 验证结果

三种桌面尺寸的服装页面集成测试通过，覆盖仅显示尺寸、点击全屏及关闭、历史版本、空态。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
