# W536：接入面部三视图展示

日期：2026-11-07
状态：已完成
关联版本：v0.8.264（已发布）

## 修改原因

模特图片页缺少已定义的面部三视图展示。用户要求沿用基础全身三视图框体，并将基础全身三视图下移。

## 具体改动

上排保留左侧正面面部图，右侧增加面部三视图（16:9）；基础全身三视图移到右侧下一排。面部三视图通过既有用途读取当前采用及其他版本，沿用AssetMediaCard、UnderlineTabs、FullscreenImage和限高倒序版本列表；仅设原图视图，不新增遮面用途。资料只读且引用原件。

## 验证结果

公共组件复用人工检查：复用现有真实组件和四行subgrid框体，仅增加业务用途读取和容器定位，无组件样式覆盖。同步实现说明、技能展示边界及隔离页面测试。前端构建、公共组件静态与三档桌面布局检查通过。test_chloe_models_ui.mjs在1280×640、1366×768、1920×1080隔离资料下通过，覆盖面部三视图采用引用、其他版本、全屏预览及上下位置和宽度。正式服务version=0.8.264、ready=true；M001页面显示新增面部三视图框体及其他版本入口，基础全身三视图位于右侧下一排。真实面部三视图尚未采用，采用框正确显示空态。
