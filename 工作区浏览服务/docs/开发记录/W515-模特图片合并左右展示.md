# W515：模特图片合并左右展示

日期：2026-11-07
状态：已完成
关联版本：v0.8.242

## 修改原因

正面面部图与基础全身三视图需要在同一页左右查看；模特详情底部不再显示原说明的查看、下载按钮。

## 具体改动

子标签为模特信息、模特图片、造型。模特图片左列面部、右列基础三视图，容器按2:3分配空间，保留各自采用图、候选版本及三视图原图/遮面切换。旧face/body地址仍进入合并页，后续操作更新为images。四项记录保留，未删文档或图片；仅移除模特说明底部FileActions，媒体卡片操作及造型原文入口不变。同步技能与浏览说明。

## 验证结果

三档桌面隔离UI验证通过：图片左右排列、原图与遮面切换、各自候选内容、预览与刷新恢复、旧face/body链接进入合并页、模特说明按钮隐藏、信息字段比例及造型导航保持。首次对齐检查发现右侧panel外边距与左侧外容器不同，统一两列容器后通过。三视图单张卡片占满本列。正式构建与两个技能校验通过，现行规范旧标签口径已同步。

公共组件人工检查：复用UnderlineTabs、AssetMediaCard、Rich与Preview；业务CSS只布局两列容器，未改公共组件样式。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
