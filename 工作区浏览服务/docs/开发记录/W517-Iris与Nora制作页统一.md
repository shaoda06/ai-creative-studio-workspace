# W517：Iris 与 Nora 制作页统一

日期：2026-11-07
状态：已实现，发布验证中
关联版本：v0.8.244

## 修改原因

短测和后期轮次可同时包含沿用的分段底片和独立产出。原界面未就地显示两者关系，待启动作品的部分标签也会显示空白。

## 具体改动

制作页统一轮次选择、记录弹窗和原件预览。分段条按当前轮次解释进度，独立产出从原轮次索引读取。待启动作品保留所有适用标签，按资料实际情况显示占位。候选名称增加执行批次，双语提示词默认显示已有内容，资料问题只显示一处。导演表、资源下载、素材审阅和意见汇总采用共用文案与布局。

## 验证结果

隔离后端 53 项检查通过。Iris 工作台和 Nora 多场次轮次、连播、意见在三档桌面尺寸通过。正式项目抽查在发布后补记。

- 公共组件复用检查：使用已有的 TabSelect、Dialog、Preview、MessagePanel、DownloadButton 和镜头提示组件。变更属于业务页面的输入、标签和空状态，展示页继续使用相同控件和规格。
