# W517：Iris 与 Nora 制作页统一

日期：2026-11-07
状态：已发布并验收
关联版本：v0.8.245、v0.8.246

## 修改原因

短测和后期轮次可同时包含沿用的分段底片和独立产出。原界面未就地显示两者关系，待启动作品的部分标签也会显示空白。

## 具体改动

制作页统一轮次选择、记录弹窗和原件预览。分段条按当前轮次解释进度，独立产出从原轮次索引读取。待启动作品保留所有适用标签，按资料实际情况显示占位。候选名称增加执行批次，双语提示词默认显示已有内容，资料问题只显示一处。导演表、资源下载、素材审阅和意见汇总采用共用文案与布局。

## 验证结果

隔离后端 53 项检查通过。Iris 工作台和 Nora 多场次轮次、连播、意见在三档桌面尺寸通过。正式浏览页 v0.8.245 已打开 C004 F001 第 4、6、7 轮登记的视频，并核对 F002 全部空状态、C001 现行和只读归档、C002 交接包及 Nora EP005 三场次和本轮总体意见。

正式服务 v0.8.246 构建、托管重启及版本就绪检查通过。上述样本复核通过，并从 C004 F001 的轮次记录打开了现行分镜原文。

- 公共组件复用检查：使用已有的 TabSelect、Dialog、Preview、MessagePanel、DownloadButton 和镜头提示组件。变更属于业务页面的输入、标签和空状态，展示页继续使用相同控件和规格。暂存静态检查及 1280×640、1366×768、1920×1080 的公共组件浏览器检查通过。
