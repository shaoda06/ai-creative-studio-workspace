# W538：三视图图片区域按比例增高

日期：2026-11-07
状态：已完成
关联版本：v0.8.266（已发布）

## 修改原因

基础全身三视图占满整行后仍沿用260px固定高度，视觉过扁。图片区域需要随宽度保持16:9。

## 具体改动

AssetMediaCard增加可选aspectRatio展示规格，有图和空态使用同一比例，完整显示图片且不裁切；默认固定高度不变。Chloe仅对模特图片页的基础全身三视图启用16:9，造型和其他卡片保持原样。同步真实组件示例、覆盖说明及布局验证。

## 验证结果

公共组件复用人工检查：比例由公共组件明确参数控制，业务只传展示规格，无页面选择器覆盖。前端构建、静态复用检查、公共组件三档桌面测试及隔离模特页面三档测试均通过。新增断言验证有图／无图16:9、完整显示及取消350px图片高度上限。正式服务version=0.8.266、ready=true；M001页面已核对图片区域随整行宽度按16:9增高。
