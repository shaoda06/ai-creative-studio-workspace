# W650：修复资源媒体探测的中文路径编码

日期：2026-11-09
状态：已完成
关联版本：v0.8.361（已发布）

## 修改原因

Windows 后台以系统默认编码读取 ffprobe 的 JSON。视频路径含中文时，输出解码可能失败，已下载的文件因此无法完成资源登记。

## 具体改动

资源媒体探测显式按 UTF-8 读取 ffprobe 输出。

## 验证结果

- 关闭 Python UTF-8 模式，在隔离目录用 ffprobe 读取中文文件名的 H.264 视频，返回正确尺寸与时长。
- 正式构建完成，8782 返回 v0.8.361 且 ready 为 true。用原任务续接一条已下载的 H3 视频，工作台完成取回登记并核对一采入口。
- 资源测试中有三项 Windows 并发锁失败，已在修改前的代码上复现。取回测试中也有一项并发资源锁失败，其余 19 项通过。
- 公共组件复用检查：本次改动只涉及后端读取媒体信息及发布版本，暂存差异没有组件、样式或页面交互变化。
