# W596：Chloe作品列表标题与统计布局

日期：2026-11-08
更新日期：2026-11-19
状态：已完成
关联版本：v0.8.313；v0.8.480（编号倒序已发布）

## 修改原因

用户要求作品制作统计与“作品列表”标题同行靠右，并在标题行和作品按钮之间增加分隔线。

## 具体改动

公共ProductionWorkbench提供可选的列表标题同行布局，由Chloe启用；保留原统计内容与作品按钮。

Chloe「视频制作」按作品编号数值倒序显示，和「成片与发布」的口径一致。列表先排序再分页，公共制作页接收排好的作品列表。

## 验证结果

- Chloe制作页隔离测试通过，覆盖三档桌面、标题统计同行和靠右、分隔线、作品入口及详情导航。
- 公共组件复用检查：修改公共ProductionWorkbench的显式可选布局，Chloe仅传入开关；未复制统计和作品按钮，没有页面后代样式覆盖。
- 补充运行旧公共制作页测试，在详情“候选一”精确选项定位处超时；当前菜单显示“候选一 · R001”，与本次列表标题布局无关，未扩大范围修改该测试。
- 正式构建通过，8782已发布v0.8.313；实际页面统计右端与标题栏右端一致，分隔线为1px，原作品按钮和时长保留。
- 编号倒序通过 TypeScript 和三档桌面制作页回归测试，验证 V1000、V010、V009、V001 的显示顺序，以及列表摘要和详情导航。复用既有制作列表，变更限于 Chloe 传入的数据顺序。
- 暂存快照公共组件静态检查和三档桌面布局通过。
