# W592：Chloe成片删除与表格对齐

日期：2026-11-08
状态：已发布
关联版本：v0.8.307

## 修改原因

用户要求成片表格增加删除按钮，操作组居中，文件名左对齐且垂直居中。

## 具体改动

操作栏增加删除按钮，复用compact Dialog确认，提交中禁用按钮及关闭。成功刷新目录与作品列表数量，错误使用公共消息，保留确认框供重试。删除接口复用queue_write同源管理校验，只接受本作品成片目录的实际视频；删除前解析项目Markdown引用（含表格、普通链接及编码路径），仍被引用时返回来源文件。直接删除目标路径，不修改业务记录，不删除同内容的其他文件。

文件名单元格设置原生对齐属性，操作容器居中，6:4列宽和其余区域不变。

## 验证结果

后端8项测试通过，包括实际删除、同内容其他文件保留、未授权及跨源拒绝、发布资料与普通Markdown引用保护、越界符号链接、其他作品和非视频文件拒绝。三档桌面发布页检查通过：对齐、确认取消、失败重试、成功刷新、预览与原件下载、空态；仅测试夹具执行删除。

公共组件复用检查：复用Dialog、DownloadButton、Notifications及公共表格样式；CSS只调整操作容器排列，无新弹窗或消息样式。业务覆盖表同步。最终TypeScript／Vite构建通过，8782服务已载入v0.8.307。正式页面核对操作组居中及文件名对齐，确认弹窗取消后目录不变，拦截检查记录为零写入；真实成片未删除。
