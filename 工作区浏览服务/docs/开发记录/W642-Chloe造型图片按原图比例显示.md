# W642：Chloe造型图片按原图比例显示

日期：2026-11-09
状态：已完成
关联版本：v0.8.350（已发布）

## 修改原因

造型页服装参考及全身定装图受固定预览高度约束，图片左右出现空边。三个标注区域需要按卡片可用宽度展示，图片高度由原图比例决定。

## 具体改动

服装参考图及当前采用的造型面部图、全身定装原图／遮面版直接使用公共图片卡的原图比例选项。无采用面部图时沿用16:9占位。同步实现说明和版本记录。

## 验证结果

- TypeScript检查通过。隔离造型页在1280×640、1366×768、1920×1080下验证各图片的实际宽高、容器宽高、全屏预览和原图／遮面切换。面部夹具比例偏离16:9，用于核对展示按实际原图计算。
- 公共组件复用检查：人工核对三个区域均直接使用AssetMediaCard现有比例选项，无新增样式、覆盖或组件。暂存快照静态检查0项需修正、0项待人工判断，提交钩子的三档桌面公共组件浏览器检查通过。
- 正式构建和统一启动器重启完成，8782报告v0.8.350且已就绪。在1724×910正式页面实测服装参考和全身原图／遮面版宽度铺满、比例正确，面部空态为16:9。全屏预览与切换正常，无前端脚本错误。
