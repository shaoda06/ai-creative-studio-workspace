# W543：统一服装图片用途与展示入口

日期：2026-11-07
状态：已完成
关联版本：v0.8.272（已发布）

## 修改原因

服装图片已按业务生成正背面合成展示图，网页仍按正面、侧面、背面、细节筛选，导致两个候选版本不可见。用户确认文档用途分为服装参考图和服装展示图，页面仅保留服装展示图标签。

## 具体改动

文档、模板和校验统一为服装参考图、服装展示图；只有展示图可登记当前采用。O002原始参考和两个生成候选按新用途登记，媒体与执行历史不变。页面只显示服装展示图标签，旧purpose链接回到该标签；候选倒序限高查看，复用全屏看图，列表封面读取正式展示图。

## 验证结果

服装接口与字段校验4项测试、固定资料12项测试通过；实际工作区12份固定资料检查无错误。资产页面隔离浏览器回归通过1280×640、1366×768、1920×1080三档桌面，覆盖单标签、旧链接、参考图不混入、候选排序及滚动、点击放大和空图。

公共组件复用检查：人工核对只调整UnderlineTabs数据与AssetMediaCard占位文案和筛选，保留FullscreenImage原交互，没有新增组件实现、样式覆盖或展示规格；暂存自动检查0项需修正，公共组件三档桌面浏览器检查全部通过。前端构建通过；托管重启后/api/service返回v0.8.272、ready=true。真实O002页面已核对仅有服装展示图标签，其他版本按V002、V001显示，当前采用仍为空，用户上传参考仍在接口中准确保留。
