# W494：Iris与Nora共用栏目标题

日期：2026-11-07
状态：已完成
关联版本：v0.8.219（已发布）

## 修改原因

Iris 各栏目的标题分散在正文中，部分使用绿色局部样式。Nora 在项目页头通过公共路径显示当前栏目。

## 具体改动

Iris 的栏目名从顶部导航的同一份数据读取，在项目页头调用 Nora 使用的 PageHeader 和 Breadcrumbs。栏目名只在页头显示，正文继续使用描述资料或列表的标题。

登记空间的项目详情沿用项目页外层留白。Iris 制作区收紧相邻区块的距离，以保留小桌面首屏的播放器可见范围。

## 验证结果

- TypeScript 检查通过。Iris 多作品制作页、旧项目制作与概况、登记空间栏目导航均通过三档桌面隔离验证。逐项核对九个栏目随顶部导航更新，首屏仍达到播放器可见要求。
- 公共组件复用检查人工核对 PageHeader、Breadcrumbs 与制作列表。Iris 已有的专用标题样式移除，页面使用公共路径规格。真实展示页的纵向页头示例加入单层路径，布局检查与多层路径比较样式及边界。
- 暂存快照静态检查无待修正项，三档桌面的共用组件布局通过。
- 正式页实测 C004 九个栏目，当前位置的色值、22px 字号、字重 600 和行高均与 Nora「剧集制作」一致。Iris 正文未重复当前栏目名，视频制作仍显示作品入口。
