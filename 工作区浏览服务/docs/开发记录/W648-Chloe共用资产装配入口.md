# W648：Chloe共用资产装配入口

日期：2026-11-09
状态：已完成
关联版本：v0.8.356、v0.8.357（已发布）

## 修改原因

在 Chloe 共用资产标签栏预留装配入口，供后续定义装配页面内容。

## 具体改动

共用资产最右侧增加「装配」页签，沿用现有的下划线标签栏和地址参数。选中后显示空态，支持刷新、直达和浏览器返回。

右对齐调整为前六个资产页签靠左，「装配」在同一行单独靠右。复用 `UnderlineTabs` 的末项对齐规格，展示页增加对应示例。

## 验证结果

- Chloe 隔离导航测试通过。1280×640、1366×768、1920×1080 下核对标签顺序、按钮边界、空态、刷新和返回。测试接口由浏览器拦截，未触发真实业务请求。
- 公共组件复用检查：暂存前端自动检查及三档桌面布局检查通过。人工核对确认业务页继续调用现有 `UnderlineTabs`，新增项沿用公共交互、尺寸和选中样式，展示页现有示例覆盖同一规格。
- 正式前端构建通过，8782 已通过托管启动器重启。`/api/service` 返回 v0.8.356 且已就绪，正式 Chloe 页面只读核对装配位于最右侧，直接打开时显示选中状态和空态。
- 右对齐调整的公共组件复用检查和 Chloe 隔离导航测试均在三档桌面通过。公共展示核对首末项分别贴齐两端及选中后位置稳定，业务页核对七项同一行、装配与左侧标签留有间隔。人工核对确认布局由公共组件控制，业务页只启用该规格。
- v0.8.357 正式构建和托管重启通过，8782 服务已就绪。以正式页面只读核对六个资产页签与「装配」同排贴齐两端，装配仍可通过地址直接打开。
