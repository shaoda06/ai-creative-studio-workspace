# W640：Chloe共用发型资产与浏览入口

日期：2026-11-09
状态：已完成
关联版本：v0.8.348（已发布）

## 修改原因

Chloe 需要独立维护可供造型复用的发型资产，并沿服装页面的方式浏览参考图、正式图及其他版本。

## 具体改动

在服装左侧接入发型，复用服装的列表、左右详情、全屏预览及其他版本。正式图区域采用 16:9。发型说明使用 H 编号、固定用途和原有版本系统，旧项目缺少发型目录时显示空分类，首次建档按需建立。同步固定白模、文字及参考生成、候选送审、2 倍超分采用和造型输入规则。白模模板待后续制作及审阅。

## 验证结果

- Chloe 发型、服装、场景及模特的 23 项后端专项用例通过，覆盖旧项目空分类、首次建档、用途校验、正式封面、原件访问及候选版本。三项技能入口校验、项目 README 检查、规则链接和旧条款检索通过。
- Playwright 隔离夹具在 1280×640、1366×768、1920×1080 验证真实页面，覆盖标签顺序、卡片、空状态、左右详情、16:9 正式图、参考图全屏、其他版本及返回导航。无页面异常和非预期 API 请求。TypeScript 与隔离前端构建通过。
- 公共组件复用检查：暂存静态检查零项需修正，公共组件三档布局检查通过。人工核对使用原 ChloeReferenceAssets 与 ChloeReferenceAssetDetail，继续使用 UnderlineTabs、AssetMediaCard 与 FullscreenImage，主图使用卡片已有的比例参数。业务页面无额外样式或重复交互，公共组件及展示页沿用现有实现。

- 扩展回归的四项失败在修改前提交 68208243 上同样复现，分别涉及剪映交接测试的表格、Windows 缺文件与路径断言、项目排序。本次发型专项通过。
- 正式前端构建完成，统一启动器托管重启后，8782 返回 v0.8.348 且已就绪。正式项目页核对发型位于服装左侧，发型接口返回 200 和空列表，服装原有卡片和详情可进入并返回，页面无脚本异常。浏览器自动请求的站点图标仍返回 404，站点图标和 HTML 入口沿用原实现。
