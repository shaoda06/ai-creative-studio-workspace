# W635：提炼共用剧本声源与制作方法

日期：2026-11-08
状态：进行中
关联版本：不涉及服务发布

## 修改原因

纠正 Nora 现行声源术语错误，将重复的创作和制作方法归入公共技能。各业务继续维护各自交付格式、项目状态、批准和接续。本次范围为未来使用的现行规范与模板，使用新写的虚构样例核对。

## 具体改动

1. 新增公共剧本和场次正文模板。纠正 Nora 的声源、统计及转写说明，接入 Iris 音画流程和 Chloe 合并脚本。H3 按实际模式的官方写法转写。正文用独立括注说明声源，现有台词行格式继续供浏览页和逐镜读取使用。

2. 共用创作技法维护对白、表演、信息与留白，按各业务的正文、声音方案及审阅入口接入。共用分镜维护场景内文字、叠字与对白字幕的写法及实现归属；实际字幕政策、确认文案和业务核对保留在所属阶段。

3. 归并普通参考、镜头参考与固定首帧的判断，以及图片实际源输入、修订保留项和连续声音样本的准备。三套业务按原资产规格、模型输入条件、编号、候选及正式采用接入。

## 验证结果

- 公共剧本通过技能结构检查。三套业务的隔离新稿覆盖四类声源、原话、听者和开口提示。使用实际 Markdown 渲染器、Nora 对白匹配及 Chloe 结构化脚本读取核对。另通过 Nora 原生索引和估时等 16 项自测、共用导演分镜表 7 项校验及 Chloe 脚本和时码 2 项测试。
- 按当前 H3 官方基础模式和 Ref2VA 指南核对实际说话者、画外、独白及旁白的转写。媒体生成不在本次验证范围。
- 用虚构界面镜头核对场景内原文、后期叠字、台词及触发时点。共用逐镜读取器与 Markdown 渲染保持信息各自归位，Nora 的现行无字幕政策仍在适用入口。
- Chloe 模特及声音的 12 项隔离测试通过，涵盖准确版本、来源、采用与免复制。用自造波形核对连续裁剪、样本值、PCM 格式和完整解码，原件字节相同。固定首帧与普通参考按 H3 模式及实际槽位区分。
- 公共组件复用检查：目前差异为技能、模板和开发记录，前后端、页面布局与样式无需更新。通过受影响的相对链接及 Git 差异检查。
