# W262：普通刷新保留页面位置

日期：2026-10-22
状态：原记录未单列，以正文为准
关联版本：0.7.4

## 修改原因

原记录未单独说明，以下保留原有改动说明。

## 具体改动

用户在EP002审看页刷新后返回项目定位。实际复现：刷新前为EP002/C001第17轮P001，普通刷新后同一个URL显示项目定位。原因是refreshPosition只在useAppUpdate执行自动版本刷新前保存，普通刷新没有保存入口。

在现有refreshPosition模块监听pagehide，调用原saveRefreshPosition；沿用当前URL匹配、sessionStorage一次快照和useRefreshState，不另建路由／持久偏好，不改变应用内导航默认值。原自动更新调用保留；scroll恢复仍由既有ResizeObserver处理。仅保留已有位置字段，不把视频播放时间、未保存意见、弹窗或自动播放扩展为本次功能。
