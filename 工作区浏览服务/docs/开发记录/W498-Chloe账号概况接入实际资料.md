# W498：Chloe账号概况接入实际资料

日期：2026-11-07
状态：已完成
关联版本：v0.8.224（已发布）

## 修改原因

用户希望直接在正式账号概况中查看字段与排布。现有空白状态可以展示尚未填写的资料，无需等实际制作数据齐全后才接入。

## 具体改动

正式账号概况按登记空间读取账号定位、账号运营配置和各视频README，复用演示组件，每5秒读取更新。未填写字段显示原文待确定、待核实；视频为空时保留列名，不用演示数据填补。读取失败显示公共错误与重试。

账号接入面板按平台命名，直接展示可用操作范围和核对时间，并说明是记录的核对结果。页脚检查入口由当前栏目维护，避免父子页面重复显示。其他六栏目保持原样。

同步现有工作区README、README模板及运营接入规范的已支持范围，未改字段结构、填写规则或账号事实，没有复制资源或示例资料到正式工作区。

## 验证结果

- 模板读取和工作区接口4项测试通过：登记路径隔离、实际文档更新、其他空间及未知空间拒绝、只读入口、格式错误和文件缺失明确报错。
- 两套Chloe浏览器用例在1280×640、1366×768、1920×1080通过：正式空白状态、表头、单一页脚检查、七栏目导航、示例切换、长内容及错误重试。截图`/private/tmp/chloe-overview-KZTlSd`。

- 公共组件复用检查：人工核对正式与演示页共用ChloeAccountOverview，继续使用TabNav、PageCheckStatus、Result；未新增CSS或公共组件覆盖。页面表与组件覆盖说明同步，暂存静态检查0项需修正，三档桌面公共组件浏览器检查全部通过。
