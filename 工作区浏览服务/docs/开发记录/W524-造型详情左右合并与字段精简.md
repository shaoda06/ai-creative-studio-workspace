# W524：造型详情左右合并与字段精简

日期：2026-11-07
状态：已完成
关联版本：v0.8.252，已发布

## 修改原因

用户要求造型详情改成左侧信息、右侧图片，取消重复的子标签和固定搭配问卷。

## 具体改动

左侧40%显示名称、所属模特及可选说明，右侧60%保留定装三视图、原图与遮面切换、准确版本、全屏预览及其他版本。底部保留通栏制作记录。造型模板的身份仅保留编号、名称、来源；造型信息仅保留模特编号与可选说明。同步规范、关联校验、读取和测试，输入素材仍逐项引用原版本，不复制资源。

## 验证结果

7份实际文档校验通过，固定资料12项测试及模特后端7项测试通过。三档桌面UI检查通过，验证左右2:3且顶部对齐、取消子标签、准确图片全屏、版本切换与刷新、其他版本倒序限高及返回列表。前端构建通过。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
