# W658：Chloe参考视频收录与展示

日期：2026-11-12
状态：已完成
关联版本：v0.8.383（已发布）

## 修改原因

Chloe 共用资产需要收录本地视频和通过实际视频网址取得的媒体，并在声音右侧提供统一浏览入口。

## 具体改动

新增参考视频业务技能、固定资料及版本引用。共用资产读取登记的播放版本，一条视频一张首帧卡片，详情左栏展示登记信息，右栏播放。

封面按播放版本生成并缓存。视频比例和分辨率包含显示方向。修复 Windows 并发登记读取锁定区域时的资源索引异常。

## 验证结果

- 技能格式、固定资料入口与实际项目 README 检查通过。24 项 Chloe 固定资料、初始化和图片用途回归通过。
- 24 项资产、参考视频和资源回归通过。隔离媒体核对裁剪与原件引用、首帧颜色、缓存复用、播放范围请求、旋转后的画幅及 Windows 并发登记。
- 公共组件复用检查覆盖入口 AssetMediaCard、ReleaseFilmPlayer、Result、PageCheckStatus 及既有左右栏。沿用真实公共组件和展示例。隔离浏览页在 1280×640、1366×768、1920×1080 核对标签位置、封面卡片、左右栏、实际播放、返回及空态，并在最低尺寸核对读取失败重试。TypeScript 检查通过。
- 旧的跨阶段证据夹具按参考视频的登记依据验证，新旧固定资料的 13 项复盘关联测试通过。暂存快照的公共组件检查、三档布局和生产构建通过。正式服务 v0.8.383 就绪，核对声音右侧的新入口及真实空列表。
