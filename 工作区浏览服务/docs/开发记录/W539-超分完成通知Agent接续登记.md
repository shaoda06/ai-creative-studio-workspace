# W539：超分完成通知Agent接续登记

日期：2026-11-07
状态：已完成
关联版本：v0.8.268（已发布）；v0.8.269（已发布）

## 修改原因

正常超分被后台标记无需通知，technical适配任务无法唤醒Agent落实正式采用。超分无需二次批准，但仍需要Agent接续，不能把技术完成视为业务登记完成。

后续真实超分已触发通知，但托管进程的PATH未包含Node目录，Codex CLI的env node入口退出127，形成delivery_unknown。此前测试给测试进程补齐PATH，没有覆盖托管环境缺少Node的情形。

## 具体改动

- 移除通知筛选与任务组恢复中按image-upscale静默的分支，正常超分和其他任务一样按组完成后通知来源Agent。
- 保留部分任务等待、失败恢复、读取回执、重复发送保护及重启恢复；历史已经静默结束的任务不批量补发。
- 共用监控规范统一超分接续责任，Agent复用技术核验并在原批准范围内补齐正式采用、来源记录及展示同步，完成后汇报用户。同步Nora图片、Chloe资产及任务提示词模板，删除原静默要求并更新章节引用。

- 通知子进程沿用任务中已登记的Node目录补齐自身PATH；不修改服务全局环境、原任务上下文或通知去重，已接收通知不重复发送。
