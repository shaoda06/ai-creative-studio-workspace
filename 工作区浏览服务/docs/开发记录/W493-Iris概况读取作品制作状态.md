# W493：Iris概况读取作品制作状态

日期：2026-11-07
状态：已完成
关联版本：v0.8.217（接口已发布，页面验收发现表格匹配问题）、v0.8.218（已发布）

## 修改原因

作品制作状态变化后，原先还要手动更新项目状态表的链接文字。漏改时，概况和作品详情会显示不同状态。

## 具体改动

概况的作品入口保留原有链接，显示文字读取该作品的「制作状态」。项目状态文档使用固定入口文字。

作品状态读取与制作页共用，概况沿用正文组件的链接和预览。只更新作品入口里的显示文字，原文阅读仍使用原有的版本提示。旧作品未登记制作状态时，入口显示「作品状态」。

## 验证结果

- 40 项 Iris 作品、制作台和项目空间接口测试通过。隔离用例只修改作品状态文件，项目接口即返回更新后的状态，项目文档的链接不变。
- 1280×640、1366×768、1920×1080 三档隔离浏览器用例均通过。概况自动刷新显示，缺省文字、原链接目标和正文其他链接保持正确。
- 公共组件复用人工核对覆盖 Document、Rich、Preview 和章节导航。业务页仅提供状态文字，继续使用原链接和弹窗。真实组件展示页加入本地状态切换，可验证正文更新与章节导航状态。
- v0.8.217 正式页的 Markdown 表格包含 table-scroll 外层，初次检查仅匹配直接表格。修正后隔离样例使用与实际 Markdown 一致的外层结构。

- 暂存快照的公共组件静态检查无待修正项，三档桌面布局及真实展示页的状态切换通过。
- 正式 v0.8.218 核对 C001 至 C004 共 13 条链接的状态文字与路径，实点五种现有状态均打开对应作品状态。项目文档的 13 个入口文字均已改为「作品状态」。

## 重复维护检查

- C001、C004 项目概况的当前状态也重复了单片阶段。整理后项目状态只写本轮覆盖范围，单片进度由作品状态维护。
- C004 F001 的若干旧轮次摘要仍写「待审」，而授权和采用记录已推进到 R005。历史轮次原稿及审阅依据留在对应记录。后续整理这类摘要时，应引用原轮次及采用记录。
- 制作状态、剪辑草稿交接和最终对外交付是不同事实。C001 的原中文交付与英文现行制作，以及 C002 的剪映包交接，分别按原记录显示。
