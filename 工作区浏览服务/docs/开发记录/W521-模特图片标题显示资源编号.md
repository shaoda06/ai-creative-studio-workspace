# W521：模特图片标题显示资源编号

日期：2026-11-07
状态：已完成
关联版本：v0.8.249，已发布

## 修改原因

隐藏图片卡内部重复标题后，需要在外层标题直接识别当前图片的准确编号。

## 具体改动

正面面部图、基础全身三视图标题后显示当前采用图片的完整资源编号@版本，使用现有muted文字样式。三视图切换原图或遮面版时同步对应引用；无当前采用图时不显示编号，不以其他版本补选。

## 验证结果

前端构建及三档桌面模特页面测试通过，核对面部准确引用、三视图原图／遮面版编号切换、左右对齐与预览。公共组件人工检查：只在业务标题添加资源文字，复用既有样式，不改公共组件、不重复维护资源字段；原图预览、版本记录及资料文件保持原样。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
