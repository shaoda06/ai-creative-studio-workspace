# W671：Songssx 派生整场主播放

日期：2026-11-12
状态：已完成
关联版本：v0.8.400，已在本机正式服务发布。

## 修改原因

完整的局部返修接回版和整场后处理版可沿用原 GEN 时间轴。旧制作页只把派生整片放在「本轮审阅产出」，切到当轮时主播放器仍显示原始生成。

## 具体改动

轮次可在已有的审阅产出中选定同时间轴的完整 MP4 作为当轮主播放。共用 Songssx 读取器解析本地完整文件或后台取回结果，保留原 GEN 时间区间和生成资料来源。下载与新意见按实际播放视频处理，试片和对照继续显示在审阅产出。Iris 和 Nora 的业务登记规则已同步。

## 验证结果

隔离后端回归 123 项通过，覆盖完整返修与后处理播放文件、待取回、原 GEN 时码、下载、意见归属、旧轮次及分段任务。

正式浏览器核对 F001 第 6、7 轮的媒体地址分别为 V002、V003。逐轮点击 P001 与 P002，浏览器在各自整场文件内跳至 0 秒及 15.083 秒，并继续播放。两轮视频接口均支持 206 分段读取。
