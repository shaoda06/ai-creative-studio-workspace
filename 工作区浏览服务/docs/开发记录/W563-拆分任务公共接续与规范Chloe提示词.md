# W563：拆分任务公共接续与规范Chloe提示词

日期：2026-11-08
状态：已完成
关联版本：不涉及页面发布；规则、离线校验及测试维护

## 修改原因

公共任务通知反向引用业务收尾，提示词记录允许正文而页面按文件读取。需要明确公共技术规则和各业务接续的归属，并统一提示词文件的写法。

## 具体改动

- 公共通知、结果收尾、持久重试、历史图片批次及业务同步报告规则归公共浏览技能；通知、恢复及交接模板不再反向引用业务技能。
- 视频待审登记、后处理采用、完集收尾及图片采用留在 Nora；Iris 与 Chloe 的阶段技能各自提供结果接续入口，按原授权与审阅范围推进。同步原章节调用与规则索引，保留历史规则快照。
- Chloe 视频生成记录只引用固定提示词文件；模型正文和中文参考各有固定章节。未提交的准备或取消记录不补造提示词；已提交或完成记录须具备文件。离线 check 核对文件、章节及未填写模板，其他执行类型不受影响。
- 补充现有页面读取测试，证明英文来自实际请求、中文来自对应文件，不复制媒体或技术记录。页面解析、布局及任务运行代码未改变。

## 验证结果

- 通知读取、异常交接、结果收尾、图片通知、图片收尾及三业务轮次/页面数据接入：139项回归运行通过，其中2项因初次环境缺少Node跳过；补齐现有Node路径后这2项单独通过。
- 提示词修改后的 Chloe 制作测试16项通过，覆盖未提交/取消、已提交缺文件、直接正文、失效链接、缺少/空/重复章节、未填模板及中英文读取来源。
- 9个受影响技能 quick_validate 通过；53条新增或调整的实际Markdown链接及章节锚点通过，代码示例中的待填路径不作为导航链接。
- 本地当前视频资料只读检查通过，未提交真实任务、未改业务记录、未创建或复制媒体。
- 首次回归遇到macOS临时目录 /var 与 /private/var 别名差异；使用规范化的 TMPDIR=/private/tmp 后通过，未改变生产路径代码。故障注入用例的预期日志不代表真实后台错误。
- 公共组件复用检查：差异只涉及技能规则、模板、离线 check 及数据读取测试，无前端组件、布局或页面行为覆盖；不涉及正式服务发布。
