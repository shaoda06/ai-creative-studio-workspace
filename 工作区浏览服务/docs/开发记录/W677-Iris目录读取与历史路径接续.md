# W677：Iris目录读取与历史路径接续

日期：2026-11-14
状态：已完成
关联版本：v0.8.402、v0.8.403（本地正式服务已发布）

## 修改原因

Iris 统一项目目录编号，作品最终成片直接放在作品根目录。资源、作品、交付和历史任务需要按迁移后的路径正常读取。

## 具体改动

资源工具与作品浏览适配编号目录。迁移脚本先留存受影响文稿及路径映射，再更新在用引用和资源索引。原任务证据保留原文，历史文件和整场播放按路径映射读取。

- 145 项相关回归测试通过，覆盖编号目录迁移、资源、作品展示、历史任务、装配和 Songssx。隔离浏览器验证覆盖 1280×640、1366×768 和 1920×1080。
- 正式服务 v0.8.403 就绪。真实项目逐个核对资源列表、文件读取、作品、成片、复盘和历史任务。迁移前后任务状态一致，原有文件入口可读。资源导入和父版本接续在各项目的隔离副本中验证。
- 公共组件复用检查：前端差异仅调整 Iris 复盘的目录映射，保留现有页签、成片播放器和下载按钮，未新增公共组件或样式覆盖。已人工核对调用，业务页隔离用例通过。暂存静态与布局验证见提交钩子结果。
