# W566：移除业务演示页面与入口

日期：2026-11-08
状态：已完成
关联版本：v0.8.289（已发布）

## 修改原因

正式业务页面仍显示临时演示入口。用户要求全局移除业务测试页面，并明确保留公共组件展示页。

## 具体改动

删除声音与账号概况演示组件、入口和前端路由，删除账号概况演示API及路由注册。全局核对前端路由、页面入口、后端接口与静态资源，未发现其他业务演示页面；公共组件展示、专用静态样本和自动化测试入口按用途保留，测试入口不发布到正式构建。

原账号概况虚构资料移入tests/fixtures，仅由自动化检查读取；回归改为在隔离API下检验正式业务页面，保留正常、空态、长内容和错误重试覆盖，并验证旧演示地址失效。同步声音业务规则、组件实现说明与浏览服务开发约定，不再发布业务演示页面；历史开发和版本记录保留当时事实。
