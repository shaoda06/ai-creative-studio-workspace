# W570：Chloe成片与发布资料页面

日期：2026-11-08
状态：已完成
关联版本：v0.8.293（已发布）

## 修改原因

成片与发布栏目只有占位，用户需要先取得基于实际成片准备的封面、文案、话题和挂品资料，再选择手动发布或Agent代发；手动发布所需资料应直接在页面预览、下载和复制。

## 具体改动

- Chloe进入发布环节先检查成片目录，结合实际成片及制作资料准备发布内容，页面核对后再询问发布执行方；公共发布技能沿调用方资料位置接续。
- 按需创建发布资料.md，以Q编号区分平台及不同资料组合。发布安排与结果仍归README，引用当次Q行；已被发布记录引用的资料保留，改版新增。更新固定资料模板、检查器、业务规则及工作区说明。
- 本视频新封面入本视频资源库，现有本视频或共用图片引用原件。只读适配扫描实际成片并解析准确封面、文本及挂品信息；媒体接口限制到本视频成片和明确引用的封面。
- 成片与发布页面提供视频列表、资料切换、成片播放下载、封面预览下载、标题正文话题及挂品复制、成片目录和发布历史。没有资料或成片时显示真实空态。
