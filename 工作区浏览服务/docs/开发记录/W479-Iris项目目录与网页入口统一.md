# W479：Iris 项目目录与网页入口统一

日期：2026-11-04
状态：已完成
关联版本：v0.8.191

## 修改原因

Iris 建档统一一级目录和阶段主文件。网页需要识别标准交接和复盘目录，并在封存资料归位后继续提供只读审阅。

## 具体改动

- 交付与复盘使用标准目录名，旧项目已有入口仍能读取。综合资料通过全部资料浏览。
- 商业生产读取器支持归档内的封存制作树。现有生产任务的执行记录和审阅身份沿用原接口。

## 验证结果

- 隔离浏览器检查覆盖交接和复盘预览入口、综合资料、制作批次及历史只读。工作区和生产接口回归使用临时项目。
- 公共组件复用检查：目录名称映射继续使用原文件树和预览组件，无新增公共组件或样式。三档桌面内容区使用现有隔离浏览器用例核对。
