# W470：修改意见逐句编辑台词

日期：2026-11-03
状态：已完成
关联版本：v0.8.183（首次发布后发现旧缓存问题）、v0.8.184（已发布并完成页面核对）、v0.8.185（一行高度微调已发布）

## 修改原因

审看片段时，修改台词需要切到分镜脚本复制原句，再返回修改意见填写。用户要求在“插入时间”上方自动列出当前分段的每条原台词，并逐句输入新台词，保存及导出后再交给制作会话处理。

## 具体改动

- Nora生成资料投影从所选候选明确关联的历史分镜读取独立“台词”字段，按镜号及接话顺序提供说话人和原句；同镜多人、再次接话及画外说明分别保留，不重写旧分镜或猜用当前稿。
- 修改意见页在工具行上方逐句显示原台词和新台词输入框，复用全局原生textarea样式；留空移除该句建议，普通“清空”仍只清空普通文字意见。输入沿既有自动保存、切换保存、状态、失败重试和冲突对照，不增加另一套定时器或提示。
- 同条意见保存dialogueEdits，继续按项目／集／场／P／阶段／R及审看轮次隔离。普通保存和整集、旧场次、共享生产意见导出同时比对台词建议的原值；旧页面只保存普通文字时保留已有台词建议，不自动迁移旧记录。
- 只有台词建议、没有普通意见的分段也进入导出；复制带镜号、说话人、原句、新句及普通意见。导出弹窗只读展示已保存台词建议，普通意见仍可整理。台词建议不是正式正文或生成授权。
- 新增dialogues字段后，浏览缓存格式从24更新至25；旧版跨发布复用的候选上下文自动重建。只更新浏览投影，项目原资料不改。
- 同步Nora视频修改意见规则及场次分镜模板的逐次接话写法，已有第五集格式可直接提取，无需改其创作正文或历史执行资料。同步组件实现说明及业务覆盖表，未新增公共组件。
