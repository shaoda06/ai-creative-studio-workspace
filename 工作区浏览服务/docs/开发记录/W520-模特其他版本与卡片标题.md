# W520：模特其他版本与卡片标题

日期：2026-11-07
状态：已完成
关联版本：v0.8.248，已发布

## 修改原因

用户确认下方只看其他版本，按倒序排列并限制展开高度；上方图片框内部标题与外层重复，需要隐藏。

## 具体改动

其他版本排除同用途当前采用图；按版本号数值倒序，同号按文档登记顺序倒序；无其他版本时不显示入口。列表默认折叠，使用compact单列卡片，最大高度1050px，约三张卡片，超出内部滚动。来源与执行记录在每项下折叠保留，不修改文档、资源或采用引用。

AssetMediaCard增加可选hideTitle，默认false，仅当前图片显式启用；其他页面保留标题。公共展示增加有图、无图实例，保留可访问名称和预览行为。

## 验证结果

前端构建、三档桌面模特页面测试通过，覆盖排除采用图、V005至V002倒序、无其他版本隐藏、超过上限内部滚动和图片预览。

公共组件复用人工检查：使用现有compact规格及公共预览；只为隐藏标题增加可选参数，不以业务CSS覆盖卡片。页面容器仅设置单列、滚动与高度。公共展示及共享检查已同步，提交静态与三档桌面检查通过，包含隐藏标题的有图／无图样例及预览。

统一启动器重启后/api/service返回v0.8.248、ready=true。正式M001页面核对通过：重复标题已隐藏，没有其他版本时不显示折叠入口；排序、滚动与多版本预览通过隔离样例验证，真实模特资料未写入测试媒体。
