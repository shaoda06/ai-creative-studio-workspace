# W573：Chloe横竖封面预览与下载

日期：2026-11-08
状态：已完成
关联版本：v0.8.294

## 修改原因

公共封面规则要求横竖成套，Chloe发布资料及页面却只有一个封面位。需要分别保存、预览和下载两版，并明确优先选用成片或已采用素材，按每条内容决定文字与排版。

## 具体改动

发布资料与实际发布记录分别保存横版、竖版准确图片引用；实际未使用的版式标明不适用。页面各用独立图片卡片与下载按钮，缺少某版时显示缺项并禁用该版下载。

制作优先选择实际成片或已采用素材，必要时再生成；文字与排版随每条内容确定，两版分别构图。默认交付规格继续引用公共封面规范，图片沿原资源存储规则管理。同步模板、投影、文档检查、隔离用例及现有项目的空发布表头，没有制作真实封面。

## 验证结果

后端发布、概况及工作区相关测试23项通过；Chloe文档与业务脚本测试26项通过。真实Chloe工作区13份文档检查无错误，三个受影响技能基础检查及实际文档链接检查通过。

页面在1280×640、1366×768、1920×1080通过双封面放大、原件下载字节与文件名、资料切换、缺少竖版、成片播放、文案复制、空态及错误重试验证，无横向越界、意外写入或浏览器错误。TypeScript与正式构建通过。

公共组件复用人工核对：本次仅更改ChloePublication的两版数据映射与业务网格；预览沿AssetMediaCard/Preview，下载沿DownloadButton，复制、选择与反馈沿已有公共组件。未复制公共交互或覆盖控件内部样式，无新增公共组件；组件实现说明同步，真实展示示例无需新增。暂存静态检查0项问题，暂存快照公共组件三档桌面浏览器检查通过。

正式服务已由统一启动器重启，/api/service返回v0.8.294、ready=true；正式页面视频列表及真实项目空态核对通过。当前项目没有成片与封面，双封面功能使用隔离资料验证，未向真实项目添加测试媒体。
