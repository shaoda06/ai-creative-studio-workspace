# W652：区分H3导演台并退役导演包

日期：2026-11-10
状态：待发布
关联版本：本地开发，未发布

## 修改原因

工作区开始为 AiMixer 导演台和 Songssx 导演台分别维护规范。AiMixer 的导演包导出已无业务需要，制作页保留原画布、视频和剪映交接。

## 具体改动

- 共用分镜定义制作对象、场次、分段。AiMixer 的整场多组、同场分批和返修选组归共用 H3 规范。Songssx 规范记录场次时间线、GEN 和实际场次输出，返修及网页接入另行确定。
- 移除 Studio 的 AiMixer 导演包导出接口、工作区命令及下载入口。历史实存 ZIP、清单和画布仍可通过原文件路径读取。Nora 按需场次留档只保存场次画布、API 和来源记录。
- Nora、Iris 和 Chloe 继续通过公共制作页下载原画布、视频 ZIP 和剪映草稿包。

## 验证结果

- 浏览服务后端 196 项、Nora 制作脚本 116 项通过。核对原画布、视频 ZIP、剪映包、历史文件原字节和导出地址退役。分镜层级说明未改项目路径、编号、索引字段或批准状态。
- 五个技能入口通过校验，89 处受影响的规则链接及锚点可达。TypeScript 与 Vite 隔离构建通过。
- 公共组件复用检查：暂存版组件与三档桌面浏览器检查通过。人工核对 FileLink、SceneDownloads、ComponentShowcase 及实际调用，已删除旧入口和演示，原文件、视频 ZIP 和剪映包继续复用 DownloadButton 与共用消息。Iris、Chloe 隔离工作台验证通过，使用模拟资料及本地下载响应。

### 2026-11-11 规则与兼容复查
