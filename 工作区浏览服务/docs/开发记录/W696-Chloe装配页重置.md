# W696：Chloe装配页重置

日期：2026-11-16
状态：已完成
关联版本：v0.8.427（已发布）

## 修改原因

用户希望在四个装配标签所在行的最右侧重置当前装配页。

## 具体改动

在四个装配子标签所在行的最右侧固定显示链接样式的「重置」。重置后当前页的已选资产、输入、预览和导出恢复初始状态，姿态分类和数量恢复为全部及 1。子标签和其他装配草稿各自保留。

## 验证结果

TypeScript 和三档桌面 Chloe 回归通过。隔离浏览器核对按钮同行靠右、四个子页可重置、姿态筛选和数量恢复默认，并确认重置视频装配后仍可回到保留的造型草稿。

8782 已更新到 v0.8.427。正式页核对入口同行最右，实测姿态装配重置后恢复零项、全部分类和数量 1，旧导出清空，仍停在姿态装配。

- 公共组件复用检查：暂存静态规则通过。人工核对共用 UnderlineTabs、LinkButton 及各子页的预览与导出组件，布局由装配页外层负责。重置只重新初始化当前标签的内容，入口继续使用公共链接样式。
