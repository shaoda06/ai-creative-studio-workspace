# W639：正面面部图按原图比例展示

日期：2026-11-09
状态：已完成
关联版本：v0.8.347（已发布）

## 修改原因

模特详情的正面面部图在固定高度的横向框中缩小显示。图片区域保留当前宽度，高度由实际图片比例决定。

## 具体改动

共用 AssetMediaCard 增加原图比例选项，Chloe 模特详情的正面面部图采用该规格。图片铺满左栏卡片可用宽度，高度按图片本身比例计算。空状态继续使用默认占位高度。

## 验证结果

前端类型检查通过。Chloe 隔离浏览器用例在 1280×640、1366×768、1920×1080 核对正面图按实际比例铺满可用宽度、基础全身图为方形、原图预览可开关。

正式前端构建并由统一启动器托管重启。8782 返回 v0.8.347 且已就绪。在 1724×910 的同一视口，正面图区域发布前后均宽 386 CSS 像素，高度由 260 变为约 514，和原图比例一致。右侧方图区域发布前后均为 626×626，正面图全屏预览可正常打开和退出。

- 公共组件复用检查：暂存静态检查零项需修正，公共组件三档桌面检查通过。展示页调用真实图片卡片覆盖原图比例，校验图片及框体宽高。人工核对采用同一预览入口，页面仅选择共用规格，样式由卡片维护。
