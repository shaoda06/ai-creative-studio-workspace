# W634：共用项目总索引与分类编号

日期：2026-11-08
状态：已完成
关联版本：v0.8.342（已发布）

## 修改原因

统一工作区项目总索引的规范、模板和登记实现，进行中与已归档分别排序编号，支持后续工作区按同一规范接入。

## 具体改动

- 共用浏览技能维护唯一规范、双表模板及登记／同步脚本。Nora 初始化、Chloe 具名项目初始化直接调用共用登记；Iris 建档规则提供同一命令。归档技能更新 README 后调用共用同步，保持项目状态唯一来源。
- 删除 Nora 原 project_index.py 和本地索引规则正文，迁移统一入口、业务规则、初始化模板及网页说明中的现行引用。历史原文留本地历史版本，不作为现行入口。
- 后台复用同一项目发现、排序及标记读取；Chloe 按具名项目索引排序。每个工作区提供只读索引接口与弹窗。前端共用 numberProjects，卡片与项目切换菜单分别对两类编号，归档原因筛选不再次编号。
- 现有三个工作区的索引及 README 入口已同步到双表格式；具体清单与迁移前原文留本地综合资料，未改项目状态、制作记录或 Codex 对话。

## 验证结果

- 后台与工作区相关测试 35 项、Nora 初始化 19 项、Chloe 项目初始化 4 项通过。验证旧表／旧列表迁移、额外说明保留、分类内顺序、归档／恢复追加目标表、重复登记幂等、失效条目清理、重复条目报错及多工作区索引接口隔离。最后的解析修改另跑索引与归档相关 18 项通过。
- 三工作区真实组件隔离浏览器验证在 1280×640、1366×768、1920×1080 通过：两个分类独立编号、原因筛选、各自索引弹窗、刷新、菜单及原链接、空态与错误恢复。工作区导航专项验证通过。
- 五个涉及的技能通过 quick_validate，新增本地链接有效；现行旧索引规则入口和旧登记调用已清理。前端 TypeScript 与构建通过。
- 公共组件复用检查：复用 TabNav、TabSelect、EntryCard、Dialog、Document、Result；仅调整业务数据、序号和索引地址，无新样式覆盖或重复组件。组件说明与框架展示覆盖表已同步；提交钩子的暂存自动检查及三档公共组件浏览器检查全部通过。

- 正式发布：托管启动器重启完成，/api/service 返回 v0.8.342、ready=true；三个工作区的实际索引接口及页面弹窗均已核对，进行中／已归档独立编号，归档原因正确。验证临时页已关闭，保留用户原有页面。
