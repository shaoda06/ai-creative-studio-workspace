# W585：Chloe任务详情与审阅入口接入

日期：2026-11-08
状态：已完成
关联版本：v0.8.300（已发布）

## 修改原因

具名项目迁移后，Chloe分段播放器的任务弹窗缺少任务空间，后台报告的审阅地址仍指向通用文件页。补齐接入，不改变公共页面布局和其他空间的既有入口。

## 具体改动

- ChloeProduction为现有公共工作台传入工作区级TaskApiContext，项目资料继续使用具名项目接口，任务详情复用原弹窗及错误重试。
- 公共报告链接转换支持已登记业务提供审阅地址；Chloe将具名视频任务送回视频制作页，共用资产任务送回该项目资产页。默认映射继续服务未提供该接入的工作区。
- 报告读取时映射链接，不改写任务、历史请求或成果记录；无媒体复制。同步业务说明和组件接入说明。

## 验证结果

- 68项隔离后端测试通过，覆盖空间隔离、报告主列表和精简交付列表链接、中文及特殊字符、共用资产、旧平铺数据和其他工作区默认入口；报告输入保持不变。macOS默认临时目录别名导致5项既有测试路径比较失败，改用物理路径TMPDIR=/private/tmp后全数通过，未改相关业务代码。
- 真实ChloeProduction组件配合隔离响应，在1280×640、1366×768、1920×1080下通过制作页导航、读取失败重试、任务详情成功及Esc关闭；没有业务API写入。
- 公共组件复用检查：人工核对仅增加Context提供者和链接映射，无新增DOM容器、CSS或弹窗实现。继续复用TaskDetailDialog、FloatingMessage和原布局；暂存静态检查0项需修正、0项待人工判断；暂存快照的公共组件三档桌面检查全部通过。TypeScript编译通过；正式构建及托管启动器重启完成，/api/service返回0.8.300且ready=true；真实制作页任务详情请求200，视频制作和共用资产审阅落点可用。
