# W518：模特图片左右对齐

日期：2026-11-07
状态：已完成
关联版本：v0.8.245，已发布

## 修改原因

模特图片左右两列用了不同结构，左侧参考版本另占白框、右侧采用折叠，当前采用与图片区域没有对齐。

## 具体改动

两列统一为栏目标题、当前采用与视图选择、采用图片、参考版本折叠四行，使用共享网格行对齐。保留左侧面部、右侧三视图的原宽度比例；两侧参考版本均在各自白框内默认收起。参考版本数据和当前采用引用不变。

## 验证结果

模特页面测试在1280×640、1366×768、1920×1080通过，核对标题、当前采用、图片卡、图片区域及参考版本折叠起始位置一致，版本预览与三视图切换保持可用。公共组件人工检查：继续调用AssetMediaCard、UnderlineTabs与原生details，只调整页面外层容器及网格行，不覆盖公共组件内部样式，不改数据或生成图片。
