# W625：轮次说明与画布用途标识

日期：2026-11-08
状态：已完成
关联版本：v0.8.336（已发布）

## 修改原因

Chloe资源下载的轮次标题没有显示现有说明，多个任务画布同名，无法判断对应分段和用途。

## 具体改动

轮次说明直接读取当前轮次note；画布按钮显示原记录中的分段、阶段、执行编号，下方显示工具与模式。同一次执行涉及多个分段时合并标识，仍只显示一份原画布。保留原文件名、地址和字节，不新增或回写业务记录。可选字段未提供时继续原有显示，Nora和Iris默认接入不变。公共展示归属与实现说明同步。

## 验证结果

- 56项后端测试通过：按选中轮次投影、混合阶段、同执行多分段仅一份画布、默认入口保留原文件名、源文件与记录未改写，以及原有临时包下载清理。
- Chloe三档桌面隔离检查通过：轮次说明随选择切换，画布标识、工具说明及原文件悬停提示正确；下载重试与既有页面功能通过。TypeScript与生产构建通过。
- 公共组件复用检查：继续使用DownloadButton/DownloadControl与原折叠入口，仅为SceneDownloads增加可选数据和内部说明排布，无业务页后代样式覆盖。展示归属与实现说明同步；暂存静态检查0项需修正、0项待人工判断，公共三档桌面检查通过，默认分阶段接入不变。
- 正式服务v0.8.336、ready=true；实页核对第4轮原说明及P001／E008、P002／E009和RIFE插帧＋RTX超分显示正确。截图保存在本次会话可视化目录。
