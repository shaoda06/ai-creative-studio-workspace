# W609：成片发布复用公共作品按钮

日期：2026-11-08
状态：已完成
关联版本：v0.8.323（已发布）

## 修改原因

成片发布列表使用EntryCard，与视频制作列表不同。用户要求直接复用同一个公共组件。

## 具体改动

成片发布作品列表改用ProductionEpisodeButton及公共双列网格，显示编号、名称、时长和状态；点击仍进入发布详情。Chloe两页复用同一制作资料地址配置及查询缓存，移除发布页独立列表样式，不修改公共按钮实现。

## 验证结果

制作与发布两套三档桌面隔离检查通过：公共按钮48px高度、双列网格、编号名称顺序、时长状态，以及键盘进入发布详情和原预览／下载／删除流程正常。公共组件人工核对：直接调用ProductionEpisodeButton，公共实现及外观未改；移除页面独立网格，新增Chloe共用地址Hook不生成或保存资源。前端构建、公共组件自动检查及三档桌面布局检查通过。服务重启后确认 v0.8.323 已生效；正式页面在 1280、1366、1920 三档宽度下，制作与发布按钮的尺寸、字体、内边距、边框及显示内容一致，点击进入发布详情，验证过程中无业务写入。
