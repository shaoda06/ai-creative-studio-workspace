## 修改原因

GitHub说明仍包含旧的环境要求、项目层级和本机状态；部分外部技能链接只在维护者机器上可读。统一公开说明，并单独核对能力组成、依赖登记与分发边界。本次仅文档维护及获授权的仓库简介更新，不修改制作细则、依赖安装或网页代码。

## 具体改动

- 浏览服务最低Python版本改为3.11＋，补齐Windows与macOS安装命令；首页引用服务环境真源，通知说明按平台区分。
- GitHub仓库简介更新为包含Nora、Iris、Chloe与公共运营的工作区介绍；未推送代码。
- 首页校验命令说明改为API结构与执行参数检查，去掉画布/API配对的错误表述。
- 服务说明区分业务适配和通用目录浏览，按公共登记说明工作流归属；首页补齐Chloe具名项目与单条视频两层README入口。
- 公共维护规范统一第三方依赖的发现、获取、版本依据、许可和分发方式；Nora保留业务使用条件，获取步骤改为引用公共规则。16处指向忽略技能文件的链接改为公开获取入口，实际调用按名称发现。
- 清除首次安装说明中的本机已构建状态、旧开发分支现场历史；原历史记录保留。
- 高层规则接入依赖专项审计；依赖变化、公共能力提炼及分发检查须同步登记并独立报告，不另建平行台账。

## 验证结果

### 依赖专项审计

- 范围：根说明、公共来源登记、业务调用入口、Git跟踪／忽略规则、当前可用技能、本机固定包元数据及登记的上游来源。平台临时工具不冻结为仓库能力清单。
- 14项被忽略的第三方技能全部有来源登记：10项提示词／方法／工程技能及4项剪辑工具。工作区已有11项独立安装，另外2项由平台全局技能提供，React规则已有平台插件入口；插件与独立包不推定版本一致。
- 3个ComfyUI适配技能保留随包真源、固定来源提交与MIT许可；Nora适配资源、打戏方法、节点包及视频读取方法来源继续在既有专项章节维护。平台工具、本机运行环境、远端服务和模型分别说明获取边界。
- 实际核对33个GitHub来源仓库、目录、固定提交及许可入口，均可访问；没有下载安装或升级依赖。
- 7项旧安装缺少可确认的来源提交：Qwen提示词、H3提示词、stop-that-shit、find-skills、React规则、humanizer-zh、山音。登记明确保留缺项；humanizer-zh另注明本地修订标识及适配来源，不能宣称下载上游即可还原本机改写。
- H3来源当前未查到许可声明；未将其标为MIT或纳入模板分发。Qwen来源按上游Apache-2.0登记，获取时需保留仓库许可证。
- 浏览服务requirements中的固定版本均与本机已安装元数据一致；这些包声明的Python下限最高为3.11（websockets）。本次没有执行空白机器安装，未将元数据检查描述为全新环境验收。
