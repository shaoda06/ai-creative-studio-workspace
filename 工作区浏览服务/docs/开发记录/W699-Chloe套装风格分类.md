# W699：Chloe 套装风格分类

日期：2026-11-17
状态：已完成
关联版本：v0.8.434 已发布到正式服务 8782

## 修改原因

套装需要由用户归类，以便在共用资产列表及造型装配中按风格找到要用的套装。

## 具体改动

- 风格清单随 Chloe 具名项目保存，默认提供「未分类」。新套装在模板写入默认值，缺少该字段的旧套装以相同默认值读取。用户更改风格时把新值保存回原服装说明。
- 套装列表新增风格入口、卡片下方的单选及多选筛选条。造型装配弹窗用同一份清单筛选可用套装。两处复用原有分页，先筛选再计算页数。
- 接口复用工作台同源管理检查。新增风格和分类修改各写一份文件，分类编辑保留原说明的其他字段和换行。
