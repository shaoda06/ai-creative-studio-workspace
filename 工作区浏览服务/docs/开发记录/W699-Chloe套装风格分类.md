# W699：Chloe 套装风格分类

日期：2026-11-17
状态：已完成
关联版本：v0.8.434 已发布到正式服务 8782

## 修改原因

套装需要由用户归类，以便在共用资产列表及造型装配中按风格找到要用的套装。

## 具体改动

- 风格清单随 Chloe 具名项目保存，默认提供「未分类」。新套装在模板写入默认值，缺少该字段的旧套装以相同默认值读取。用户更改风格时把新值保存回原服装说明。
- 套装列表新增风格入口、卡片下方的单选及多选筛选条。造型装配弹窗用同一份清单筛选可用套装。两处复用原有分页，先筛选再计算页数。
- 接口复用工作台同源管理检查。新增风格和分类修改各写一份文件，分类编辑保留原说明的其他字段和换行。

## 验证结果

- 后端 26 项测试通过，覆盖默认风格、旧格式、保存重读、分类筛选后分页、项目隔离、工作台同源限制和单件部位筛选。
- 固定资料校验 20 项通过。Chloe 扩展回归 114 项中 111 项通过，剩下三项在修改前的基线也复现，涉及 Windows 只读媒体删除和资源库测试的路径分隔符断言。
- TypeScript 类型检查和正式构建通过。隔离界面在 1280×640、1366×768、1920×1080 验证新增、归类、刷新后读取、复选筛选、造型装配候选资格和已有装配操作。
- 公共组件复用检查覆盖套装列表和造型装配选择弹窗。继续使用 Dialog、TabSelect、AssetMediaCard、AssetSelectionDialog、Pagination、Notifications 和 ChloeAssetTypes，业务样式只控制各区域排列。暂存快照静态检查无待修项，公共展示及布局检查三档通过。
- 本机服务报告 v0.8.434 且就绪。局域网地址的 Mini穿搭日记套装列表和造型装配套装弹窗均验证「未分类」筛选与第二页，正式资料共 16 套，验证期间未写入测试分类。
