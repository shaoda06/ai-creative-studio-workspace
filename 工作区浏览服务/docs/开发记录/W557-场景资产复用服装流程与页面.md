# W557：场景资产复用服装流程与页面

日期：2026-11-07
状态：已完成
关联版本：v0.8.285（已发布）

## 修改原因

场景资产沿用服装的资料、参考确认、生成审阅与超分采用流程，场景展示图为16:9单幅完整环境，网页统一左右详情。

## 具体改动

简化场景身份与说明字段，固定参考图和展示图用途，补齐两步确认、原始参考返修、2倍超分通知及自动采用规则。服装和场景共用只读资料解析及列表／详情模块，复用既有图片卡片、全屏预览、折叠记录与限高版本容器；不新增真实场景或生成图片。

## 验证结果

前端构建通过；服装／场景8项共用后端测试及模特8项回归通过，涵盖准确采用、模板错误、固定用途、重复编号和文件访问边界。正式资料11份校验无错误。隔离UI在1280×640、1366×768、1920×1080通过：服装／场景列表详情、多参考准确版本预览、点击／Esc退出、倒序限高版本、空对象／空参考及错误重试，未向正式资料写测试资产。

发布启动时修复了新旧路由工厂同名及并发编辑造成的导入别名冲突。统一启动器重启后/api/service返回v0.8.285且ready=true，正式场景接口为空列表，浏览页显示暂无场景资料，符合当前尚未建立场景对象的状态。

- 公共组件复用检查：服装和场景合并使用ChloeReferenceAssets业务模块，不新增样式或复制公共组件；暂存自动检查及公共组件三档布局检查通过。人工核对无公共组件内部样式覆盖；覆盖表同步实际业务模块归属，图片卡片、标签、全屏和错误反馈均沿用公共实现。
