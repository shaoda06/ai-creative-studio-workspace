# W491：修复项目正文的音视频与附件链接

日期：2026-11-07
状态：已完成
关联版本：v0.8.215（已发布，含原拟 v0.8.213 的改动）

## 修改原因

C004 正文链接出现两类读取错误。指向 Iris 资料区说明等项目外文件的链接越过项目预览范围。视频、音频和其他附件存在，但正文把它们当作文档查询，返回 404。

## 具体改动

正文和预览复用一份文件类型判断。音视频走已有播放器，其他附件复用查看和下载原文件入口。项目正文中的目录外本地引用只显示原有文字。

## 验证结果

- 核对 C004 的 50 份 Markdown。59 处错误预览链接对应的 48 个实际文件均可由文件接口读取。
- 暂存快照的项目浏览器用例在三档桌面验证正文视频、音频和原文件入口。项目外引用显示为文字，普通文档及章节导航可照常使用。
- 公共组件复用检查覆盖 Rich、Preview 与文件与正文展示。人工核对确认既有 Dialog、播放器和 FileActions 直接复用，展示调用本机静态样例，无页面样式覆盖。
- 正式 v0.8.216 从 C004 正文打开 R005 字幕样片和独立 WAV，两个播放器均读取到媒体数据。可编辑 ASS 显示原文件的查看与下载入口，作品 README 的 Iris 资料区引用按文字显示。
