# W692：Chloe装配卡片支持移除

日期：2026-11-16
状态：已完成
关联版本：v0.8.417、v0.8.421（均已发布）

## 修改原因

套装装配的单件和造型装配的配饰选入后，要再次打开选择弹窗才能撤掉其中一项。

## 具体改动

已选卡片底部通过公共资源卡片的插槽显示红色「移除」按钮。点击即更新选择、计数和导出信息，清空上次生成的交接词。移出的素材仍可再次选择。

## 验证结果

TypeScript 检查和 Chloe 导航隔离测试通过。在 1280×640、1366×768、1920×1080 核对按钮在预览下方、移除后的计数和列表、失效的旧导出、重新生成及素材可再次选择。

正式前端构建和托管重启完成。8782 返回 v0.8.417 且已就绪。通过局域网访问套装装配和造型装配，逐项核对红色按钮位于图片下方，点击后计数回到 0/5。

- 公共组件复用检查：暂存快照的静态检查和三档桌面浏览器检查通过。选中态复用 AssetMediaCard 的现有底部插槽和公共红色按钮样式。人工核对新增布局规则仅排列按钮容器，公共卡片预览和展示页继续使用现有实现。

## 移除按钮移到卡片正下方

套装装配的已选单件和造型装配的已选配饰共用同一布局。红色「移除」按钮作为卡片的相邻元素在卡片外部居中，本行的添加卡仍与资料卡主体对齐。

1280×640、1366×768、1920×1080 的隔离浏览器回归通过，覆盖卡片外居中、添加卡对齐、移除后更新计数、导出文字重置和重新选择。公共组件复用检查覆盖暂存静态规则和三档展示页。人工核对卡片继续调用 AssetMediaCard，红色按钮沿用公共样式，定位由装配网格负责。

8782 正式构建和托管重启后返回 v0.8.421 且已就绪。局域网正式页实测两处按钮均位于卡片外正下方并居中，点击后选中计数回到 0/5。
