# W477：后台取回复用相同媒体数据

日期：2026-11-04
状态：待发布
关联版本：未发布

## 修改原因

后台已为独立产出分配独立版本。取回字节相同的媒体时仍会保存多份数据。原任务重试应沿用已分配版本，独立产出的版本、路径和凭据各自保留。

## 具体改动

普通结果和分段视频在完成版本登记时复用共用媒体存储。首次完成在同一项目资源区内比较同扩展名文件的完整字节，字节相同才共享只读数据。沿用项目资源索引锁串行发布，并在共享存储后读取最终文件标记。独立产出各自保留版本路径、执行来源和取回凭据，重试仍使用原任务已分配的版本。

通过取回验证后，只读检查了历史重复组，按保留文件时间、权限和版本记录的条件列出合并候选。逐组清单保存在工作区私有审计资料。

## 验证结果

受影响的隔离回归 471 项通过，覆盖普通 PNG 取回重试、分段 MP4 重启续取、独立版本及凭据、并发完成和等长不同内容。另有 3 项路径缓存断言在扩展回归中失败，以本次修改前的源代码复跑得到同样结果。

- 公共组件复用检查：变更限于后台、资源工具、测试和存储规则，无前端源码、样式或依赖差异。按暂存范围检查，公共组件自动检查不触发。人工核对两个取回入口均复用同一资源完成逻辑，网页接口及公共组件调用未变化。
