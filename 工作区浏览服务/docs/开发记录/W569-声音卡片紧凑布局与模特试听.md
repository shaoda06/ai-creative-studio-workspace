# W569：声音卡片紧凑布局与模特试听

日期：2026-11-08
状态：已完成
关联版本：v0.8.291；v0.8.292（已发布）

## 修改原因

声音详情的关联模特链接错位，声音卡片留白过多；模特列表和信息页缺少已关联声音的试听入口。

## 具体改动

移除关联模特链接的段落边距。新增公共AudioReferenceCard，将版本标题、试听和靠右时长放在紧凑单行；声音当前采用、其他版本及模特声音信息共用该组件。

AssetMediaCard增加titleActions规格，入口卡通过标题链接覆盖区域维持卡片导航，试听按钮与链接为兄弟节点，不嵌套或误跳转。公共组件展示同步增加可试听、禁用和长标题示例，检查器登记新组件实现归属。

声音列表接口投影关联模特、声音说明、准确采用版本和时长；模特卡及人物特征下的声音信息直接使用该投影。无关联显示无或禁用试听，未采用不选候选替代。关联和采用仍只在声音说明维护，无需新增模特模板字段或复制素材。同步资产展示规范与组件覆盖说明。

## 验证结果

- 声音和模特后端12项检查通过，包含准确采用版本、实测时长及单向关联投影；首次执行因shell未包含FFprobe路径失败，补齐本机已有路径后通过。
- 声音与模特页面在1280×640、1366×768、1920×1080三档桌面通过：关联首行对齐、当前与其他版本卡片同高且小于70px、时长同排靠右、模特试听不跳转、无关联禁用及详情声音信息。
- 公共组件规则检查器7项测试通过。公共组件复用人工检查：新增声音卡片只维护自身布局，试听及提示直接复用公共组件；图片卡片标题操作由公共实现提供，业务CSS仅分配信息区间距，无页面覆盖公共样式。暂存差异检查通过。
- 公共组件自动检查通过：静态检查无问题，三档桌面布局与交互检查通过，覆盖新卡片长标题、禁用试听及卡片导航。
- 前端构建通过；正式服务已重启至v0.8.291且ready为true。实际声音详情、模特列表和模特声音信息已核对。
- 正式页核对发现固定资料规范的一行表格被空行隔开，修正格式后13份业务文档校验通过，资产接口恢复正常；未改动声音文件和采用记录。

## 声音详情间距与等高补充

原始参考章节与上方字段间隔24px，标题上下边距采用声音信息标题的10px／18px。声音详情两列改为随较高内容自动拉伸，保持当前和历史声音卡片自身紧凑；其他资产布局不变。三档桌面声音页面检查及构建通过；正式页核对收起与展开其他版本时左右面板等高，标题边距为10px／18px，章节间隔24px。服务v0.8.292且ready为true。

公共组件复用检查：本次仅调整声音详情容器拉伸和业务章节标题间距，未修改声音卡片、试听、链接等公共组件实现或外观，无需新增展示示例；提交钩子继续核对暂存源码与三档公共组件布局。
