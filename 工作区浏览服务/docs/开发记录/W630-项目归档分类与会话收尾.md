# W630：项目归档分类与会话收尾

日期：2026-11-08
状态：已完成
关联版本：v0.8.340（已发布）

## 修改原因

三个业务资料区需要按整个项目区分进行中与已归档，并按原因分类；项目归档时还需处理已核实归属的 Codex 对话。此次仅建立机制，不归档真实项目或对话。

## 具体改动

- 新增 studio-archive 共用技能与项目归档标记模板，接入总入口、三个业务入口、建档规则和本地工作区说明。Nora 按整个短剧项目，Iris 按整个订单，Chloe 按整个账号项目归档。
- 项目根 README 保存管理状态、原因、归档／恢复时间；原制作进度独立保留。索引可增加状态与原因显示列；登记脚本兼容两列及四列，不从索引反推归档。
- 浏览服务统一读取标记，工作区列表默认进行中，已归档按实际原因筛选；筛选保留完整列表序号，刷新保留分类。项目切换菜单用现有 badge 标注归档原因，原资料入口可访问。旧迁移只读标记保留原用途。
- Codex 对话流程按现有登记与实际内容核对归属，通过宿主归档工具操作，记录逐项结果；未决审批、运行中或归属未明的对话保留待处理。支持按需恢复，不直接编辑对话数据库，也不发送消息。

## 验证结果

- 后端隔离回归 34 项通过：覆盖三种项目结构、标记读取与恢复、原进度不变、未标记和代码示例不误判、单条视频不影响账号项目、错误与修正、旧迁移标记、四列索引及 Chloe 既有固定资料兼容。
- 归档界面夹具通过：三个空间、原因筛选、刷新保留、项目链接与菜单 badge、空态、错误重读；1280×640、1366×768、1920×1080 CSS 内容区无横向越界，并检查了对应截图。
- TypeScript 检查、新技能格式校验及新增本地引用检查通过。原 Chloe 项目切换与 Nora 项目切换回归在三档桌面均通过，无写请求或浏览器错误。
- 公共组件复用检查：列表使用现有 TabNav、TabSelect、EntryCard 和 Result；菜单沿用 ProjectSwitcher 与 TabSelect badge。人工核对未新增独立控件或覆盖公共外观，页面 CSS 仅设置筛选区排列、间距和外边距；展示页沿用真实组件及既有 badge 示例，覆盖说明已同步。暂存快照自动检查通过：静态检查无违规，公共组件三档桌面布局、菜单、输入、弹窗和消息等既有用例全部通过。
- 正式构建及托管启动器重启完成，`/api/service` 返回 v0.8.340、ready=true；三个登记空间的真实列表、分类空态和数量核对通过，无写请求或浏览器错误。未对真实项目、媒体、制作状态或 Codex 对话执行归档；对话流程本次仅规则核对，不宣称完成实际批量归档验证。

### 依赖专项审计

新增技能、模板和解析接入随公共仓库分发，无新第三方包、安装或升级。Python 与前端组件继续使用已登记运行环境；对话归档依赖宿主平台提供的 Codex 工具，按当前能力发现参数，公共平台登记已补充用途；宿主缺少工具时保留对话待办。技能不携带真实会话 ID、个人路径或凭据。原有锁文件与运行依赖保持不变。
