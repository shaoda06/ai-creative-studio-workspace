# W482：Iris 项目概况正文展示

日期：2026-11-04
状态：已完成
关联版本：v0.8.194、v0.8.195、v0.8.196、v0.8.197

## 修改原因

旧版项目概况显示状态摘要和文件入口，阅读文档需要打开弹窗。用户希望像 Nora 的项目定位页一样，进入栏目即可阅读正文。

## 具体改动

- 默认在页内展示项目根目录的 `README.md` 全文，显示名为「项目说明」。点「项目状态」切换到 `项目状态.md` 全文。
- 复用 Nora 项目正文使用的 Document，沿用章节导航和文档链接。只有一份正文可用时直接显示，两份都缺时显示空态。
- 正式页检查发现默认展开的章节导航占用了首屏。Iris 项目概况将目录默认收起，保留展开和跳转。
- v0.8.196 按页面反馈，使用文档组件已有选项去掉两份概况正文上方的「查看」和「下载」。
- v0.8.197 项目名称已在页首显示，「项目说明」跳过 README 开头重复的一级标题，保留章节、正文和原文件中的标题。

## 验证结果

- Iris 隔离页面测试通过 1280×640、1366×768、1920×1080。验证首屏正文、按需展开目录、状态切换和切回、读取失败后重试及空项目提示，并回归批次审阅。
- 公共组件复用检查：复用 Document、UnderlineTabs、Result 和原有文档接口。章节默认收起由共用组件参数控制，展示页使用同一参数演示，业务页不覆盖公共样式。暂存快照执行公共组件和三档布局检查。
- 正式服务返回 v0.8.195 和 `ready=true`。在 C001、C002、C003 打开默认项目说明及完整状态正文，均可页内切换。目视检查 C003 首屏可读，并实际展开目录跳转到「接续要求」。
- v0.8.197 继续复用共用文档组件和原有接口，只在项目说明读取时处理页内展示内容。提交时检查暂存快照的组件使用及三档桌面布局。
