# W678：修复Chloe制作资料编码读取

日期：2026-11-13
状态：已完成
关联版本：v0.8.402（已发布）

## 修改原因

制作详情读取共用引用时使用系统默认编码。Windows 以 GBK 读取含中文的 UTF-8 JSON 会使详情接口返回 409，作品列表因此无法读取时长。

## 具体改动

制作资料校验和声音资产接口显式按 UTF-8 读取共用引用、资源版本和剪映清单。制作资料回归测试以 GBK 模拟未指定编码的文件读取，并使用含中文的共用引用。

## 验证结果

制作资料 20 项测试、声音资产 4 项测试通过。在 Windows CP936 下关闭 Python UTF-8 模式，制作详情可读取含中文的 UTF-8 共用引用。当前服务通过等价 JSON 转义恢复受影响作品的读取，原接口返回 200。

- 公共组件复用检查：差异仅涉及 Python、测试、技能规则和开发记录，前端暂存检查无适用文件。人工核对确认复用现有作品详情和声音资产接口，现有组件和样式无变更。
