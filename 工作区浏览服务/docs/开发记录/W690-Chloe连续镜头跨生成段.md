# W690：Chloe连续镜头跨生成段

日期：2026-11-16
状态：已发布并验证
关联版本：v0.8.414、v0.8.415

## 修改原因

连续长镜头需要按模型容量分为相邻采样段。Chloe 原分段校验要求每个镜号只归一段，无法登记该类表演和分段范围。

## 具体改动

沿用分段计划三列。按镜头和分段的计划累计时长校验覆盖范围、顺序和时长，制作脚本和工作台共用同一解析结果。工作台仅在当前稿有镜头跨段时提供“当前分段计划”。轮次详情读取当时的分镜快照，Songssx 沿用整场任务、单一输出和执行时间轴定位。

## 验证结果

- Chloe 制作、回片、生产链、Songssx、Iris、场次轮次及下载共 129 项回归通过。覆盖跨段、混合镜头、缺漏和错序、旧快照及双段共用一个整场原片。Iris 有一条测试断言沿用了旧展示文案，确认原代码也出现同一失败后对齐当前文案，Iris 业务代码未改。
- 以 Mini穿搭日记当时的三个视频作为现有样本，旧分段资料与改动前的制作详情逐项一致。V004 写入新计划后，正式页实际切换 P007 和 P008，分别显示 SH017 的 0–10 秒、10–19 秒，关闭后回到第 6 轮。V003 仍按第 2 轮的历史分镜显示，整场原片准备完成。
- 公共组件复用检查覆盖工作台的计划入口、弹窗和分段切换。直接复用 `Dialog`、`TabNav`、`Rich` 和已有链接样式，无新增 CSS 与公共组件规格改动。暂存快照静态检查通过，1280、1366、1920 三档宽度的公共组件布局回归通过。
- 生产前端构建通过，8782 正式服务 v0.8.415 就绪。更新前后的在跑任务保持原远端任务 ID，排队任务留在原队列。
