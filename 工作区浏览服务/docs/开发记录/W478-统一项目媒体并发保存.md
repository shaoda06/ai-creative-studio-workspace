# W478：统一项目媒体并发保存

日期：2026-11-04
状态：已完成
关联版本：v0.8.190（已发布）

## 修改原因

两个上传同时保存，或上传与后台取回同时保存时，两个调用可能都查不到已保存的相同文件，各写入一份相同数据。

## 具体改动

网页上传、CLI 导入、受管 PNG 保存、普通结果和分段视频取回都调用同一版本完成入口。沿用项目资源索引锁，在同项目资源区完成完整字节比较、只读媒体写入和版本记录保存。网络取回仍在锁外，执行凭据和版本路径按各自任务保留。原任务同一输出及导入键重试继续沿用原版本。

## 验证结果

隔离回归 289 项通过，1 项 Windows 专用测试跳过。两个同时上传的 HTTP 请求只复制一次文件，仍可分别读取各自的版本记录。真实上传接口与模拟远端的后台取回交错执行，两条路径共享同一份数据，取回凭据指向原任务的具体版本。另用两个隔离 CLI 进程验证并发导入、同键重试和音频来源区间。

正式前端构建后经统一启动器重启 8782，确认 v0.8.190、ready=true。正式首页、前端版本脚本、Nora 和 Iris 共 8 个项目的资源接口均正常，836 条任务记录可查询。上线后在隔离项目复跑两个并发场景、原任务重试及等长不同字节检查，4 项通过。生产项目只做读取，上一轮合并的 11 对媒体原路径及创建、修改时间核对一致。
