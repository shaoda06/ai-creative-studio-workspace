# W703：Chloe成片上传与自动录入

- 日期：2026-11-17
- 状态：已完成
- 关联版本：v0.8.450（已发布）、v0.8.452（已发布）、v0.8.453（已发布）

## 修改原因

成片目录需要把较新的文件排在前面，并提供网页上传和脚本录入。

## 具体改动

在目录标题行右侧加入上传入口，按文件时间从新到旧显示，保留亚秒精度供排序。网页和脚本共用导入逻辑，校验媒体和同名后按原名录入当前作品。网页上传完成后刷新明细和作品列表。

## 验证结果

- 隔离接口和脚本测试通过，覆盖同源限制、错误媒体与文件名、同名保护、原件保留、倒序和新录入文件删除。
- 三档桌面的发布页浏览器测试通过，覆盖标题行位置、选文件、提交上传和表格更新。
- 公共组件复用检查覆盖成片目录标题、上传表单和完成反馈。暂存静态检查无待修项，三档公共组件浏览器检查通过。人工核对使用公共紧凑弹窗、公共消息和原生文件输入。业务样式只控制标题行和表单布局。
- 正式构建与托管重启后，8782 返回 v0.8.450 且就绪。正式页面核对实际三条成片的倒序、标题行右侧上传及弹窗打开和取消，测试过程没有业务写入。

## 成片上传的文件选择

成片上传弹窗使用公共 FilePicker。选择前显示「选择视频」，选中后显示完整文件名和「更换文件」。长文件名换行，上传中禁用更换。公共组件「按钮与切换」展示相同组件，演示更新本地文件名。

- 类型检查与三档桌面发布页测试通过，覆盖文件选择、提交期间禁用和录入结果刷新。
- 公共组件复用检查覆盖 FilePicker、上传弹窗与组件展示。暂存静态检查无待修项，三档真实展示验证了键盘和鼠标、长名称、更换及禁用。业务页复用原上传弹窗，样式统一由公共组件维护。
- 随 v0.8.452 部署。正式页核对空白与已选文件两种状态，并取消测试选择。未发出上传请求。

## 成片上传的按钮位置

上传弹窗底部的「上传」和「取消」同排靠右。复用紧凑 Dialog 和公共按钮，表单操作区负责对齐。

- 三档桌面隔离测试验证同排右对齐，正式页验证空白、已选文件与取消。
- 公共组件复用检查通过。暂存静态检查及三档组件布局检查无新增问题，页面样式限于按钮容器排列。
