# W485：Iris 资产准备页内查看

日期：2026-11-05
状态：已完成
关联版本：v0.8.201，已发布到正式浏览服务

## 修改原因

打开资产准备先看到清单文件入口，阅读正文还要打开弹窗。已采用素材的卡片占用较多空间，历史项目的资产清单需要从全部资料查找。

## 具体改动

- 有现行资产清单时默认显示已采用素材，卡片保留编号、名称、缩略图和资源版本，点击缩略图进入公共预览及下载。项目资源通过顶部导航访问。
- 切换到资产清单即可在页内查看现行正文、表格和章节导航，工作稿、旧版和执行资料默认折叠。仅有历史清单时，默认打开标有历史的清单视图。

## 验证结果

- 构建与 11 项隔离接口检查通过。三种桌面尺寸通过隔离页面检查，覆盖默认素材、预览下载入口、清单表格、章节导航及历史清单。
- 公共组件复用检查：业务页面共用 UnderlineTabs、Document、AssetMediaCard、FileLink 和预览。图片卡片的紧凑规格由公共组件和公共样式提供，展示页有真实本地示例。Iris 样式仅排列网格和归档说明，暂存快照检查卡片边界及预览操作。
- 正式服务返回 v0.8.201 和 `ready=true`。C003 显示 5 张采用图及 v08 清单，已核对大图预览和下载入口。C002 显示 8 张采用图及 v20 清单。C001 在页内显示归档资产清单。
