# W492：统一Iris项目概况与文档分工

日期：2026-11-07
状态：完成
关联版本：v0.8.215（已发布，含原拟 v0.8.214 的改动）、v0.8.216（已发布）

## 修改原因

具体业务背景保留在本地原始记录，本公共版本保留通用改动与验证。

## 具体改动

所有 Iris 项目的概况正文和导航共用三个默认省略的 README 章节，仍可叠加项目主动配置的例外。README 记录现行制作规格和需追溯的历史，项目状态记录跨作品决定及其依据，单片授权归作品状态。

## 验证结果

- 暂存快照用例在三档桌面验证。有项目配置和无项目配置时都应用统一的三节省略规则，有明确配置的额外章节也按配置处理。
- 人工核对公共组件复用。Iris 概况继续使用 Document、Result 和原有章节导航，规则只作用于传给公共组件的正文。

## 项目文档分工试行

项目 README 的三节本地导航合为「资料与接续」，现行规格在 README 集中维护，改名历史留本地。项目状态先写当前制作范围，再列作品、项目共用决定和实际待办，样片的制作授权引用 F001 作品状态。模板及建档规范同时按试行分工更新。

## 新模板的默认展示

原拟 v0.8.214 的旧模板省略规则已随 v0.8.215 发布。补充两项默认省略的 README 章节「资料与接续」及「历史与特殊事项」，新项目按模板建档后直接采用已确认的概况样式。

无项目配置的隔离用例覆盖新旧 README 章节与「当前状态」「作品入口」的顺序，在 1280×640、1366×768、1920×1080 三档桌面通过。人工核对本次修改只调整传给共用 Document 与章节导航的数据，沿用原预览、样式和交互。

涉及真实业务对象、状态和素材的验收明细保留在本地原始记录，不随公共仓库提供。
