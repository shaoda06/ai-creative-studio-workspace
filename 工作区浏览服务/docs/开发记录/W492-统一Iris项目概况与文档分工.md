# W492：统一Iris项目概况与文档分工

日期：2026-11-07
状态：待发布
关联版本：v0.8.214（待发布）

## 修改原因

C004 曾单独配置隐藏本地导航章节，C001 至 C003 仍在概况中显示这些内容。项目 README 与状态模板对制作规格的分工也有交叉。

## 具体改动

所有 Iris 项目的概况正文和导航共用三个默认省略的 README 章节，仍可叠加项目主动配置的例外。README 记录现行制作规格和需追溯的历史，项目状态记录跨作品决定及其依据，单片授权归作品状态。

## 验证结果

- 暂存快照用例在三档桌面验证。有项目配置和无项目配置时都应用统一的三节省略规则，有明确配置的额外章节也按配置处理。
- 人工核对公共组件复用。Iris 概况继续使用 Document、Result 和原有章节导航，规则只作用于传给公共组件的正文。
- 正式服务等待并行改动完成。现有四个项目先用已发布版本支持的同一份项目级展示设置，原文继续保留。
- 暂存快照通过公共组件静态检查和三档桌面回归。正式 v0.8.212 逐一打开 C001 至 C004，四页正文和导航均已省略三节。C001 至 C003 各有一条作品入口和实际交付章节，C004 有十条作品入口。统一默认逻辑尚待发布，四份现行设置在新版发布后可去除重复项。

## C004 文档分工试行

项目 README 的三节本地导航合为「资料与接续」，现行规格在 README 集中维护，改名历史留本地。项目状态先写当前制作范围，再列作品、项目共用决定和实际待办，样片的制作授权引用 F001 作品状态。模板及建档规范同时按试行分工更新。

C004 正式概况通过已有项目展示设置读取新资料。实页核对正文和导航同序显示六节，十个作品入口仍在，点击 F001 作品状态和 M001 参考图均能打开。两份原文的本地链接及章节锚点已核对。试行只使用现有概况和预览组件，未改动公共界面实现。
