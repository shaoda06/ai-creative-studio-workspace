# W670：Songssx整场下载与Iris轮次登记

日期：2026-11-12
状态：已完成
关联版本：v0.8.398（已发布）、v0.8.399（已发布）

## 修改原因

Songssx 制作播放器只在资源页提供整轮包，审阅当前场次时缺少可直接保存整场 MP4 的入口。Iris 制作轮次、技术批次与分镜用稿原先由人工填写，摘要误作分镜来源时未能在提交前发现。

## 具体改动

- 在共用 SegmentVideo 复用 DownloadControl，从已加载视频的原始文件地址下载当前场次及轮次的 MP4。三套业务经同一个工作台接入，保留整轮包和 AiMixer 原交互。
- Iris 新作品视频清单通过 iris_round 提供版本和执行依据。准备与提交从实际装配结果登记索引，校验作品边界、逐镜字段、镜号、段内时码和任务输出。原任务与历史轮次继续使用原记录。
- 现行要求见[共用下载规则](../../../.agents/skills/studio-workspace-browser/references/业务接入规范.md#songssx-整场视频下载)和[Iris 提交接口](../../../.agents/skills/iris-commercial-production/references/任务服务接入.md#iris-制作轮次自动登记)。

## 验证结果

- 139 项隔离后端测试通过，含 Iris 错误分镜拦截、仅准备、重复提交及旧任务接续。
- Nora、Iris、Chloe 的实际制作页组件在三档桌面隔离测试通过，覆盖当前文件、GEN／轮次切换及既有打包。Iris 完整制作页用例也通过。未取回场次的下载按钮禁用。
- 公共组件复用检查：仅调用现有 DownloadControl，保留原生下载与项目文件路由。无新增样式覆盖、重复下载逻辑或业务专用播放器。暂存快照静态检查无修正项、无人工待定项，真实展示组件通过三档浏览器检查。
- 正式 8782 服务版本和前端就绪检查通过。正式页下载的整场 MP4 与项目原文件逐字节一致，切换 GEN 后下载地址保持一致。现有 Iris 样片的装配记录及分镜通过只读校验。

## v0.8.399 下载入口修正

用户指定恢复视频控件里的浏览器原生下载。共用 SegmentVideo 恢复原生下载，移除播放器下方单独加的 DownloadControl 和调用参数。三个工作区复用同一实现。

- Nora、Iris、Chloe 隔离制作页三档检查通过，覆盖原生控件配置、独立按钮移除及 Songssx GEN 切换。
- 公共组件复用检查：展示页仍使用同一个 SegmentVideo。修正只使用 HTML 视频控件的原生下载，未新增下载逻辑或样式。
- 暂存静态检查无问题，公共组件三档桌面布局检查通过。正式 8782 的 Chrome 原生菜单下载成功，文件与原件逐字节一致。切换 GEN 后播放器继续使用同一文件。
