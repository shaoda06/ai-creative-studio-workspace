# W647：Chloe配饰列表三列瀑布流

日期：2026-11-09
状态：待发布
关联版本：未发布

## 修改原因

配饰展示图画幅各异，列表需要三列等宽、按原图比例显示并让各列独立向下排列。

## 具体改动

- 配饰列表将可见资产从左到右分入三列，各列以固定间距向下排列，封面铺满图片区域且按原图比例调整高度。筛选后按剩余资产重新分列。
- 在服装取材及造型获批两处接入配饰提取确认。补充逐件确定画幅、提取来源、遇到不确定项询问及展示候选获批后的远端RTX 2倍放大和采用规则。

## 验证结果

- TypeScript、资产技能格式、改动链接和真实项目固定资料检查通过。复查服装与造型的触发时机、既有决定、素材来源、配饰批准和造型遮面规则。
- 1280×640、1366×768、1920×1080隔离页面通过，验证三列等宽、横图和竖图比例、短列下一张直接接续、筛选后重新分列和详情入口。
- 公共组件复用检查：人工核对直接沿用AssetMediaCard原图比例规格，新增CSS只编排配饰列表的列和间距。暂存快照检查由提交钩子执行。
