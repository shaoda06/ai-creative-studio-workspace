## 修改原因

共用后处理以 RTX-RIFE 为起点，裁切时另读一份画布。将裁切节点归入同一份基准，任务按源视频和目标规格接入需要的处理步骤。

## 具体改动

RTX-RIFE 画布增加默认旁路的裁切节点。自动装配按需接入 RIFE、RTX、缩放和裁切。Nora 的旧 `profile: crop` 和 `profile: upscale` 参数从同一基准生成原有处理组合。更新共用视频处理技能、H3 基准表及 Nora 执行规范。

独立裁切画布和 API 从现行目录退役，原件归入视频处理技能的本地历史版本目录。
