# W687：复查工作台加载与缓存校验

日期：2026-11-15
状态：待发布
关联版本：v0.8.412（待发布）

## 修改原因

复查 [W685](W685-缩短工作台详情与媒体加载.md) 与 [W686](W686-共用资产及装配选材分页.md) 涉及的制作详情、任务侧栏、媒体、分页与维护说明。发现不同页和筛选共用缓存标记，兼容生产批次页仍会在播放器请求之外下载完整视频，连播使用默认预览产物时也可能预取错文件。

## 具体改动

- 浏览数据读取复用源资料构建结果，条件请求按实际请求路径和参数校验。同一页、筛选或候选资料可返回 304，带另一种响应的标记时读取本次请求的内容。
- 兼容批次页直接使用浏览器播放器的按需请求。分段连播在当前候选开始播放后，准备下一段默认的播放文件及其预览版本。
- 用现行媒体加载说明替换 README 的整场预下载说明，补齐制作页缩略图缓存的存储规范和分页说明入口。修正 Python 测试发现命令，避免浏览服务与技能中同名的测试模块冲突。

## 验证结果

- 187 项相关后端测试通过，覆盖 Chloe 共用资产、作品摘要与候选上下文、Iris 详情变更、Nora 文件范围请求、任务监控和节点重连。分页回归核实同页返回 304，其他页、筛选和编号查询返回相应资料。
- Iris 完整制作及兼容批次、Nora 整场与混合轮次、全局任务侧栏通过三档桌面验证。兼容批次启动播放器仅发媒体范围请求；连播在当前段开始播放后才预取下一段默认预览。技能校验、文档锚点和 TypeScript 通过。
- 全量测试运行 1552 项。28 项失败或错误可在优化前的代码上复现，涉及 Windows 路径、资料文件操作及旧断言；另一次共享目录拒绝访问错误单项重跑通过。保留修正后的测试入口，现有基线问题见本地验证结果。
- 公共组件复用检查：沿用同一播放器、素材和任务侧栏组件。播放器的缓存来源为可选，由连播传入，兼容批次和公共展示直接使用播放器原生请求；没有复制播放器或引入页面样式覆盖。暂存快照自动规则和三档公共展示布局由提交钩子核对。
