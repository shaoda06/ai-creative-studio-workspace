# W618：资源库音频标题

日期：2026-11-08
状态：已完成
关联版本：v0.8.330（已发布）

## 修改原因

资源库音频标题使用机器文件名，无法直接识别声音归属与参考用途。本次仅调整标题文字。

## 具体改动

Chloe资源库按原文件、资源编号及版本关联现有声音说明，标题显示“资产名称 · 参考用途”。同一声音的原始文件同时登记为声音参考时，标题优先标为原始参考。无关联时使用已有资源名称。原文件名、归属、时长、详情、下载和其他卡片内容不变，不写入项目资料或新增记录。

- 随已协调的v0.8.330构建发布，正式服务ready=true，前后端版本一致；实际页面两条音频标题符合来源，未出现页面异常。
