# W614：资源库完整卡片与视频首帧

日期：2026-11-08
状态：已完成
关联版本：v0.8.327（已发布）

## 修改原因

资源库预览框与下面的版本信息、操作分离，视频只有播放图标，难以识别内容。

## 具体改动

图片、视频、音频将预览及元信息、详情、下载包在同一张卡片内。图片复用AssetMediaCard可选children插槽，公共展示同步增加本地实例；视频直接预加载原文件首帧，保持暂停，点击进入原播放器。不新增封面文件或修改资源记录。

## 验证结果

- 三档桌面资源库UI检查通过：图片元信息／详情／下载在原卡片内，视频操作未超出边框；封面video已解码、currentTime为0、保持暂停且无控件，点击可打开播放器。原分类、分页、试听、来源、版本切换和下载仍通过。
- 公共组件复用人工检查：AssetMediaCard仅增加可选内容插槽，保留所有现有默认调用；真实展示同步增加信息与操作实例，公共三档检查补充边框容纳与详情点击。页面未覆盖公共卡片样式，视频仅设置其原生媒体元素的等比尺寸。暂存静态检查0项需修正、0项待人工判断，公共组件三档桌面检查通过。

- 构建及正式服务v0.8.327检查通过；实际资源库6个视频均已解码、停在时间0且暂停，1080／864／576宽度原文件封面可显示，点击可打开公共播放器，无页面异常。原资源没有新增文件。
