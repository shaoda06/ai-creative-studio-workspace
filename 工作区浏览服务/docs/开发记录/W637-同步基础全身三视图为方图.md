# W637：同步基础全身三视图为方图

日期：2026-11-09
状态：已完成
关联版本：v0.8.345（已发布）

## 修改原因

Chloe 基础全身三视图采用方图规格，模特详情页需要显示对应的标题和预览比例。造型定装三视图和服装展示图仍按各自的制作规格展示。

## 具体改动

基础全身三视图的制作比例、模特详情标题和图片预览框统一为 1:1。造型分支沿用 4:3 标题和原有图片组件用法。

## 验证结果

Chloe 模特详情的隔离 Playwright 测试在 1280×640、1366×768、1920×1080 通过，核对基础全身三视图标题、方形预览、原图与遮面版切换、定装三视图 4:3 标题及服装展示图 4:3 标题。测试使用具名项目夹具，兼容 Windows 路径与 UTF-8。

正式前端构建和托管重启成功，8782 服务返回 0.8.345 且已就绪。在 1366×768 下核对方图标题和 1:1 预览框，候选图预览可打开及关闭，浏览器无页面错误。
