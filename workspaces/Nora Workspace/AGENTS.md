# Nora资料区

本目录保存Nora连续短剧、角色资产项目及社媒运营资料。Codex日常打开总目录，所有业务与共用技能在总目录.agents/skills维护，本目录不另建技能库或服务。

- 连续短剧进入[一级业务](../../.agents/skills/nora-serial-drama/SKILL.md)，社媒运营进入[运营一级业务](../../.agents/skills/nora-social-operations/SKILL.md)，按当前阶段接续。
- projects下每个项目独立保存内容。处理具体项目先读其AGENTS、README和当前进度，再读当前任务资料；项目已确认约定优先，不把例外扩到其他项目。
- 共用规则及工具维护在总层，不在业务项目里复制执行实现。任务提交传实际project，查询及恢复传本资料根作为--workspace，不以总技能库位置判断业务归属。
- 新项目按所属一级/二级规则建档；真实项目、候选、采用、历史及任务记录不随工具维护改写。技术测试归总层综合资料中的隔离目录，不混入真实项目。
- 浏览服务由总层统一运行，本目录的工作区浏览服务/runtime只保存空间连接，不是独立后台。
